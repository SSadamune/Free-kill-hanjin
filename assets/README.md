## 来源与不回写边界

- 外部资料保持原始内容，JSON、CSV 与图片原稿按字节原样保存；不为标记来源向 JSON／CSV 插入注释或额外记录。公开图文的牌面、花色点数、牌堆差异和君主装备结算放在 `bilibili articles/cards/`，只收录正文和图面写明的内容，不把整理稿当成原文或项目裁定。
- 图片原稿只读保存，迁移与加工不改原字节；需要格式转换时另行记录来源与参数。
- 项目采用的规则、与外部资料的差异及用户裁定记入 `docs/rules/` 和 `rulebook/`，再据此维护实现与测试。
- 本目录不进入用户安装包；构建只包含 `init.lua`、`pkg/`、`image/`、`audio/`。
- 《三国杀规则集》副本的上游版本与来源信息尚待核实，不补写未经确认的版本、作者或授权结论。
