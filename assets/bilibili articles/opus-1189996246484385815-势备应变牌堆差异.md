## 跨牌写法

这些句子管多张牌，后面的逐张说明不再重复。

**无视次数。** 「【杀】不计入次数限制」和「【杀】无次数限制」合并，两项都执行。状态类效果除外，例如「咆哮」和【诸葛连弩】：脱掉连弩后不能再出一张【杀】。出牌阶段、非空闲时间点使用的【杀】默认无视次数。目标 +1／-1 的应变可以不触发；【南蛮入侵】的增减目标同样可以不触发。

**属性只是牌面信息。** 属性【杀】的牌名字数是 1，「火／雷／冰」不是牌名的一部分。只写「【杀】」的转化（【丈八蛇矛】、「武圣」等）指普通【杀】。泛转化列表（「视为使用任意一种基本牌」「视为使用任意一种单目标伤害牌」等）包含全部属性【杀】。国【无懈可击】同理：牌名字数是 4，「国」只是牌面信息；只写「【无懈可击】」的转化（「看破」等）指普通【无懈可击】，泛转化列表包含国【无懈可击】。

**应变是否成立，看「使用时」。** 因此【闪】的「孤军 → 获得目标牌」在因响应【万箭齐发】而被打出时，拿不到那张【万箭齐发】。雷【杀】的「孤军 → 无视次数」若也卡在使用前的次数预检，达到【杀】次数上限时就无法使用。原文建议让「无视次数」的应变绕过这次预检，以便和上面的合并原则一致。

**冰冻伤害。** 冰【杀】造成的伤害是冰冻伤害，可传导，与火焰、雷电并列。对一名角色造成非传导的冰冻伤害时，若其有牌，可以防止此伤害，然后依次弃置其两张牌，类似【寒冰剑】。

**「只能当」。** 鏖战状态的效果是：「【桃】只能当【杀】或【闪】使用或打出」，不改变【桃】的牌名。牵涉【桃】的非转化实体牌都受限制，「傲才」和【木牛流马】里的【桃】也一样。本系列的「X 视为 Y」改用手杀的结算和写法，避免多个「视为」叠出歧义。严格说法是：预使用／打出牌名 X 时，可选实体牌不包括实体牌 X；实体牌 X 可以当 Y 使用／打出。多个「只能当」叠加，其他转化效果不受影响。原文例子：红桃牌「只能当【过河拆桥】」与鏖战叠加后，红桃【桃】可以当【杀】、【闪】或【过河拆桥】；「急救」仍可把【桃】当【桃】；「龙胆」仍可把【桃】当【酒】。

**回合开始时的顺序。** 先给本轮第一个行动角色标轮数；再判断鏖战（场上没有两名势力相同的角色，且人数 ≥7 时存活 ≤4，或人数 ≤6 时存活 ≤3，则全体进入鏖战）；若是全场第一回合，执行「游戏开始时」；若是本轮第一个行动角色，执行「每轮开始时」；若叠置，改为平置（若同时是本轮最后一人，先结算「每轮结束时」），然后终止本回合，没有剩余时机和「回合结束时」，进入下一回合的「回合开始时」；若有暗置武将牌，可以明置任意张；然后才是「回合开始时」效果（「当先」等）。鏖战从新回合开始才判断，移出游戏不影响这次判定。

**「多结算 X 次」。** 采用 OL：只重复使用结算流程，不是新服那种「视为使用一张同名牌」。可理解为只重复全部「成为目标后」结束之后的结算。使用方法一旦确定就固定，例如濒死时用红色【酒】回复，两次都是回复，不是一次加伤一次回复。【酒】的加伤和回复要分成两种使用方法。结算两次的【五谷丰登】会亮出两次牌。

**额外目标。** 如无特别说明，只有符合原牌面目标条件的角色能当额外目标。【顺手牵羊】和【杀】仍有距离限制；【远交近攻】仍有势力限制；【以逸待劳】【勠力同心】【火烧连营】通常已经指定了一种用法下的全部目标，不能再加。【闪】、【无懈可击】、延时锦囊、装备牌不能指定额外目标。例外来自简雍时代的特殊结算：【桃】【酒】【洞烛先机】【无中生有】可以增加其他角色为目标。

**横置。** 「横置／重置副将」和「连环状态」一律写成「横置／重置」。

**移出游戏。** 【调虎离山】按手杀写成「移出游戏」。除结算胜负和判断天然野心家出现条件外，该角色视为不存在，包括距离与座次、角色数、大小势力、指定或成为牌的目标、技能延时效果、发动技能、体力变化、与场上角色比参数、助战、发起或响应「拉拢人心」、君主接替等。当前回合角色或濒死角色即将被移出时，防止之。被移出且主将暗置的专属野心家能发动「暴露野心」（因为涉及胜负），不能「拉拢人心」。持续时间和何时移回，原文说见后文，对应的是回合结束时的第 3、4 步。

**回合结束时的顺序。** 先结算「回合结束时」技能（若获得额外回合，此时确定即将执行，影响「本轮下一个行动角色」，但额外回合要等回合结束后才获得）；然后是【敕令】「此牌置入弃牌堆的回合结束时」；然后把「本回合移出游戏」或「移出直到某时机」的角色移回；然后把同类被移出的牌（如「破军」牌）移回；若是本轮最后一人，执行「每轮结束时」。

**明置武将牌后。** 国战标记的天然获取、糜夫人「闺秀」等，时机都是「明置武将牌后」。它不是明置操作一结束就插入，而是当前结算结束、进入下一个空闲点或回合流程时机之前，按当前回合逆时针，依次执行这段时间里明置过武将的角色。原文例子：全暗黄月英－诸葛亮用【敕令】，两人要等【敕令】结算后、下个空闲点前才拿珠联璧合；全暗黄月英－廖化则在同一窗口先因「当先」拿先驱，再拿阴阳鱼（技能先于游戏规则）。

**伤害牌。** 只包括角色能以该牌为渠道造成伤害的牌，不含【闪电】【三尖两刃刀】等。具体是：【杀】【决斗】【火攻】【万箭齐发】【南蛮入侵】【火烧连营】【水淹七军】【出其不意】。

**卜算。** 观看牌堆顶 X 张，任意张以任意顺序放回牌堆顶，其余任意顺序放牌堆底，类似「观星」。

**延时锦囊的共同写法。** 省略「将此牌置入目标角色判定区」等句子，视为这类锦囊的共同结算。仍然是后来先判，判定区不能有多张同名延时锦囊。

**木马牌怎样算「如手牌」。** 若需要使用或打出的是「其牌或手牌」且有特定数量，则符合实体牌标准（区域除外）的木马牌也进入可选范围。可以和手牌混着转化，也可以只用木马牌转化。需要「所有手牌」而不是特定数量时不能用，原文举荀攸「奇策」。不混拍手牌而使用或打出的木马牌始终不是手牌，不受陈到、杨修等封印手牌的限制。【木牛流马】不因交换而离开装备区后，木马牌置入弃牌堆。

**应变牌与无视条件。** 技能描述里带「应变条件 → 应变效果」的也是应变牌。同一张牌有多个应变条件时，「无视条件应变」只能声明其中一个。【铜雀】的时机在「使用牌时」，来不及把已经使用的雷【杀】「孤军 → 无视次数」后置补上。

## 逐张勘误

牌堆里只有一张的牌，原文不列花色点数，让读者看牌面。

### 基本牌

| 牌 | 原文差异 |

### 普通锦囊

| 牌 | 原文差异 |
| --- | --- |
| 【过河拆桥】 | 额外目标的区域内要有牌。汉势力加入时，♠4 可换【四海流钱】。 |
| 【顺手牵羊】 | 额外目标须距离 1 且区域内有牌。可超距的写法包括直接写「无距离限制」，以及「视为对 X 名其他角色使用」这种注明目标、从而无视原牌面条件的句子。给【顺手牵羊】加合纵来自海外服，原文沿用，理由是合纵更适合容易卡手的牌（并举【火烧连营】）。 |
| 【南蛮入侵】 | 增减目标的应变可以不触发。 |
| 【五谷丰登】 | 亮牌在结算开始时，即全部「成为目标后」结束之后。亮出张数等于目标调整后的最终目标数。结算两次就亮两次。 |
| 【决斗】 | 多目标按线上：对每个目标分别结算，不是多人轮流打【杀】直到有人不打。 |

| 国【无懈可击】 | 牌名与转化范围见「属性只是牌面信息」。 |
| 【知己知彼】 | 不用《群雄割据》看光一名角色全部暗将的效果。一般看主将，因此能看到野心家、尚未升变的君主。双势力武将可以故意把想被看到的一张放在主将位。 |
| 【远交近攻】 | 牌面写明：增加目标后自己不会多摸。无论几个目标都只摸三张。额外目标仍须与自己势力不同。双方势力都确定才能判断，暗将不能使用。 |
| 【以逸待劳】 | 自己与自己势力相同，暗将可以对自己使用。通常已经指定全部合法目标，不能再加。 |
| 【联军盛宴】 | 描述重写过。不同势力只在已确定势力的角色之间判断，暗将不能使用。通常不能增加目标。结算按当前回合逆时针：自己先选择 X 次，再依次结算其他目标的摸一张并重置。每选一次就执行一次，不是选完再一次性回复和摸牌。「摸一张」和「重置」不是并列，不能重置也可以摸一张。 |
| 【勠力同心】 | 通常已经指定本次所选大势力或小势力的全部目标，不能再加。 |
| 【调虎离山】 | 写成移出游戏，定义见「跨牌写法」。 |

| 【挟天子以令诸侯】 | 不能在额外回合使用，用来切断无限开，也压低同一人连续拿到多张时的爆发。许劭等改变行动顺序的效果改的是额定回合，额定回合里仍能使用。在自己回合、出牌阶段以外使用，无法让目标结束出牌阶段，没有效果。没有手牌可弃就不能获得额外回合。弃牌和获得额外回合的时机，按上面的回合结束时顺序。 |
| 【火烧连营】 | 角色数 ≤4 时仍判断阵法，三人局 1 对 2 可以烧到两个人。通常不能增加目标。 |
| 【水淹七军】 | 「执行两项」是先弃置，再造成 1 点雷电伤害。 |
| 【逐近弃远】 | 「执行两项」是先拆后顺，而且强制执行。对距离 1 且只有一张牌的目标使用时，若有人助战，效果会被强制改成拆牌。 |
| 【出其不意】 | 补上原文认为官方漏写的「有手牌」目标要求。无色牌无法判断花色不同，不能造成伤害。 |
