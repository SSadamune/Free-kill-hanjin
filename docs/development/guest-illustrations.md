# 客将默认插画

资源路径见[图片资源保存规范](assets.md)，扩展接线见[客将实现记录](implementation/guest-factions.md#客将插画)。

## 显示行为

| 场景 | 插画 | 势力标识 |
| --- | --- | --- |
| 武将一览 | 大厅的「客将势力」开关默认关闭，对所有分包生效。开启时，已登记客籍的武将优先使用客将图。缺图或未登记客籍时使用默认插画。 | 开启时按登记顺序显示全部客籍。关闭或无客籍时显示印刷势力。 |
| 局内武将牌 | 房间开启「客将替换规则」时，有客将图就使用客将图。关闭规则或缺图时使用默认插画。 | 房间开启替换、武将有客籍且所有印刷主势力均被禁用时，显示全部登记客籍。其余情况显示印刷势力。 |
| 主桌面头像 | 主副将各按当前公开的武将牌取图。暗置时使用暗将牌背。明置后按同一局内规则取图。 | 本人与其他角色的头像均只显示原生角色势力标。右键详情、技能弹窗和简化头像中的武将牌按上一行显示。 |

例如孙策登记群、汉。房间开启替换时，若吴仍可用，牌面使用客将图及吴字；禁吴、群且汉可用时，牌面展示群、汉，实际配将只按汉。朱儁只有客将插画，图鉴预览保持原牌面，房间开启替换时换图，牌面势力仍是汉。

## 接入与验收要求

核对图鉴与房间开关各自的两种状态、缺图回退、部分及全部主势力禁用、主副将分别明暗置，以及换将、重连和私看时仍按当前视角显示。实际接线和回归入口见[客将实现记录](implementation/guest-factions.md#客将插画)，已完成的验证和待复测范围见[开发状态](status.md#最近验证记录)。
