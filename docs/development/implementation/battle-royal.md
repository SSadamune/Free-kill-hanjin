# 鏖战状态：实现与验证

游戏语义见[对应规则](../../../rules/battle-royal.md)；当前实装与待办见[开发状态](../status.md)。本页保留接口、接线和验收依据，不替代规则裁定，历史覆盖说明不代表已完成全部人工验收。

## 当前实现

实现位于 `pkg/hanjin_mode/rules/battle_royal.lua` 与 `skills/battle_royal_rule.lua`，通过“只能当”公共来源 `battle_royal` 为存活角色提供桃当杀／闪的使用及打出用途。原实体桃的直接使用／打出限制不依赖所在牌区，也不以 `skillNames` 非空作为转化依据。

实际转换由 `skills/battle_royal.lua` 的“鏖战”效果提供，提示及生成牌的技能来源均归属于鏖战。“只能当”仅解释这条规则的语法，不另授予或发动名为“只能当”的技能。

进入时机沿用锁定国战现有流程：回合开始满足人数及势力条件、房间启用的首次洗牌条件，以及其他效果调用上游进入函数的路径。汉晋规则优先处理常规入口，遇到上游授予普通／新鏖战技能时撤销这些技能并清理本房间残留状态技，安装汉晋来源；重复进入不会重复叠加来源。本文不另行变更鏖战进入时机。

群狼环鼎默认关闭；开关两种设置下桃均只能按鏖战当杀／闪。开启时仍保留历史事件及奇珍等原有附加机制，关闭时不启用这些机制。状态横幅与房间设置帮助文本已同步。普通上游国战房间保留其原有普通／新鏖战行为，不修改全局上游函数或 `.dev/` 依赖。

## 木牛与傲才

木牛的 `$sa_carriage` 牌堆沿用合法视为手牌入口，受原实体桃禁用限制，同时可选择桃当杀／闪。

新增独立技能 `hanjin__aocai`（`skills/hanjin_aocai.lua`）调用公共 `askRestricted`，仅在牌堆顶两张牌中选择合法直接用途或转换用途。询问向使用者显示花色、点数与牌名，服务端复核所选底牌和目标；不将整个牌堆视为手牌，也不开放无关手牌。临时授权在消耗、取消或牌移动后失效。

此技能已通过测试房间的真实使用／打出请求验证，但尚未挂到正式武将；正式将池没有因该适配加入上游诸葛恪。其他正式技能及第三方特殊取牌入口须按各自设计接入，不能据此宣称全部正式技能已实装。

## 自动化验收

默认套件中的 `tests/battle_royal.lua`、`tests/only_as.lua`、`tests/upstream_battle_royal.lua` 与 `tests/mode_rules.lua` 覆盖：

- 进入条件、优先级、重复进入、上游进入函数调用及残留技能清理。
- 群狼开关两态下统一桃当杀／闪，并保留相应历史事件开关。
- 实体桃牌名不变；手牌、木牛及傲才顶牌的禁用与转换。
- 真实使用／打出、傲才直接用牌、同名转化、多个“只能当”并存及临时授权失效。
- 普通上游国战房间隔离，原有桃当酒的新鏖战行为保持不变。

急救、龙胆的回归使用测试专用对应物，正式技能仍按标准武将包的实现进度记录；傲才通用选项及目标选择已运行验证，专用 QML 展示未实现，尚未做人工视觉验收。
