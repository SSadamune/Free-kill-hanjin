# 基础牌表：实现与验证

游戏语义见[对应规则](../../rules/card-deck.md)；当前实装与待办见[开发状态](../status.md)。本页保留接口、接线和验收依据，不替代规则裁定，历史覆盖说明不代表已完成全部人工验收。

方天画戟沿用已选国战势备效果，由独立技能 `qiao__halberd_skill` 适配本地引擎：发动扩目标后，【杀】被【闪】抵消时，通过牌效果数据的无效化接口登记全部目标，避免上游调用不存在的 `UseCardData:setNullified` 而报错。扩目标势力筛选、出闪后跳过其余目标、无人出闪时依次伤害及未发动时的隔离行为纳入 `tests/card_reuse.lua` 回归。

正式牌包已登记 162 个基础牌位、12 张替换牌和 7 张特殊加入的势力锦囊。保留独立实体与牌位元数据，逐牌型的既有复用及空壳状态见 `pkg/qiao_cards/data/reuse.lua`。默认套件中的 `tests/card_deck.lua` 验证实体与牌堆构建。

2026-11-18 已确认[锦囊及装备统一采用汉晋版](../../rules/card-deck.md#6-卡牌版本与结算)。现有复用须逐牌按汉晋文本审阅。

### 君主装备

[14 张君主装备](../../rules/card-deck.md#君主装备的结算)均已接入正式牌包。六龙骖驾、临筱玉舆与飞云盖海共享双栏占用、正常用牌替换和直接置入的检查。飞龙夺凤、定澜夜明珠、太平要术以独立装备技能结算。赤霄剑和四海流钱按本次实际牌移动处理抵消限制与成对交换，锦绣征袍仅对装备者自身设置无效，虚妄之冕的摸牌和手牌修正随装备生效。

州郡领兵印的回合修正和汉晋合纵由 `pkg/qiao_mode/mode.lua` 接入。神授思召经同一合纵入口扩展装备区选牌范围。驺虞幡在实际使用或打出后建立延时效果，血海魔王樽沿原请求核对【酒】合法性，再分别执行协助者的打出和装备者的用牌。

- `python scripts/test.py --file tests/qiao_dual_mounts.lua --timeout 300` 通过 14 项，`python scripts/test.py --file tests/card_reuse.lua --timeout 420` 通过 41 项。两套均纳入最终全量。
- `python scripts/test.py --file tests/qiao_lord_equipment.lua --timeout 60` 通过 18 项。合纵用真实客户端对象完成按钮查询、点击、手牌与神授思召混选及目标可确认检查，服务端交牌与摸牌由独立用例覆盖。血海用求桃同款组合请求验证自救【酒】可以旁路该回合常规用酒次数，同时核对黑桃牌打出和询问停止。
- `python scripts/test.py --timeout 1800` 运行默认 `tests/all.lua`，1,076 项通过，0 项失败。`python scripts/build_release.py` 成功生成 `.dev/dist/qiao.zip`，共 1,084 个文件，核对了 14 项装备技能和模式接线。

尚待端到端验证的路径为合纵客户端从确认到服务器结算、四海流钱客户端选牌及血海魔王樽完整濒死链路。州郡领兵印准备阶段以默认额定摸牌数计算可分配扣减，引擎在摸牌事件才提供其他效果的动态修正。双栏坐骑的验证覆盖正常入场校验，直接用底层接口强制使用非法装备仍可能带入引擎原生栏位的旧装备替换移动。
