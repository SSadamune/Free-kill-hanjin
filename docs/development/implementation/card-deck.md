# 基础牌表：实现与验证

游戏语义见[对应规则](../../rules/card-deck.md)；当前实装与待办见[开发状态](../status.md)。本页保留接口、接线和验收依据，不替代规则裁定，历史覆盖说明不代表已完成全部人工验收。

方天画戟沿用已选国战势备效果，由独立技能 `qiao__halberd_skill` 适配本地引擎：发动扩目标后，【杀】被【闪】抵消时，通过牌效果数据的无效化接口登记全部目标，避免上游调用不存在的 `UseCardData:setNullified` 而报错。扩目标势力筛选、出闪后跳过其余目标、无人出闪时依次伤害及未发动时的隔离行为纳入 `tests/card_reuse.lua` 回归。

正式牌包已登记 162 个基础牌位、12 张替换牌和 7 张特殊加入的势力锦囊。保留独立实体与牌位元数据，逐牌型的既有复用及空壳状态见 `pkg/qiao_cards/data/reuse.lua`。默认套件中的 `tests/card_deck.lua` 验证实体与牌堆构建。

2026-11-18 已确认[锦囊及装备统一采用汉晋版](../../rules/card-deck.md#6-卡牌版本与结算)。现有复用仍需逐牌按汉晋文本审阅。三张君主装备中，六龙骖驾的距离修正仍为固定 ±1，定澜夜明珠仍有上游制衡联动与上游描述，飞龙夺凤的濒死触发及实际目标约束仍需定向验证。该次审阅仅更新规则文档。

[君主装备审阅](../../rules/card-deck.md#君主装备的结算)覆盖牌表中的 14 张。太平要术的同势力人数走汉晋公共规则，旧代码还额外读取旧版天兵牌堆。临筱玉舆已有进出装备区和当前回合者摸牌／回复的接线，双栏公用逻辑仍会禁止用普通坐骑替换双栏坐骑，须按汉晋 FAQ 调整。赤霄剑、四海流钱、州郡领兵印、锦绣征袍、飞云盖海、神授思召、驺虞幡、虚妄之冕、血海魔王樽仍是空壳。

优先从正式入口定向验证三个交互：普通坐骑替换临筱玉舆后仅由当前回合角色回复；神授思召按置入回合切换弃牌阶段跳过与装备区合纵；驺虞幡的回合外真实响应成功后，即使移走防具，下一次受伤后的失去体力仍结算。血海魔王樽须分别核对协助者的真实打出与装备者的真实用酒。
