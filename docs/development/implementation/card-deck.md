# 基础牌表：实现与验证

游戏语义见[对应规则](../../../rules/card-deck.md)；当前实装与待办见[开发状态](../status.md)。本页保留接口、接线和验收依据，不替代规则裁定，历史覆盖说明不代表已完成全部人工验收。

方天画戟沿用已选国战势备效果，由独立技能 `hanjin__halberd_skill` 适配本地引擎：发动扩目标后，【杀】被【闪】抵消时，通过牌效果数据的无效化接口登记全部目标，避免上游调用不存在的 `UseCardData:setNullified` 而报错。扩目标势力筛选、出闪后跳过其余目标、无人出闪时依次伤害及未发动时的隔离行为纳入 `tests/card_reuse.lua` 回归。

正式牌包已登记 162 个基础牌位、12 张替换牌和 7 张特殊加入的势力锦囊。保留独立实体与牌位元数据，已有牌沿用新月杀实装。存在多个版本时由用户指定，等待择版或尚未找到实现的牌暂留空壳。逐牌型状态见 `pkg/hanjin_cards/data/reuse.lua`。牌位、标记和应变条目的登记不代表卡牌专属效果已实现。默认套件中的 `tests/card_deck.lua` 验证实体与牌堆构建。
