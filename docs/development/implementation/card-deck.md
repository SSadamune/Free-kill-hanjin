# 基础牌表：实现与验证

游戏语义见[对应规则](../../rules/card-deck.md)；当前实装与待办见[开发状态](../status.md)。本页保留接口、接线和验收依据，不替代规则裁定，历史覆盖说明不代表已完成全部人工验收。

方天画戟沿用已选国战势备效果，由独立技能 `qiao__halberd_skill` 适配本地引擎：发动扩目标后，【杀】被【闪】抵消时，通过牌效果数据的无效化接口登记全部目标，避免上游调用不存在的 `UseCardData:setNullified` 而报错。扩目标势力筛选、出闪后跳过其余目标、无人出闪时依次伤害及未发动时的隔离行为纳入 `tests/card_reuse.lua` 回归。

正式牌包已登记 162 个基础牌位、12 张替换牌和 7 张特殊加入的势力锦囊。保留独立实体与牌位元数据，逐牌型的既有复用及空壳状态见 `pkg/qiao_cards/data/reuse.lua`。默认套件中的 `tests/card_deck.lua` 验证实体与牌堆构建。

2026-11-18 已确认[锦囊及装备统一采用汉晋版](../../rules/card-deck.md#6-卡牌版本与结算)。现有复用须逐牌按汉晋文本审阅。

### 君主装备

[14 张君主装备](../../rules/card-deck.md#君主装备的结算)均已接入正式牌包。六龙骖驾、临筱玉舆与飞云盖海共享双栏占用、正常用牌替换和直接置入的检查。飞龙夺凤、定澜夜明珠、太平要术以独立装备技能结算。赤霄剑和四海流钱按本次实际牌移动处理抵消限制与成对交换，锦绣征袍仅对装备者自身设置无效，虚妄之冕的摸牌和手牌修正随装备生效。

本方右下角与其他角色的装备栏共用坐骑距离显示。普通坐骑显示 `-1` 或 `+1`，双栏坐骑保留牌名。六龙骖驾显示当前的 `±X`，临筱玉舆显示 `±1`，飞云盖海按当前横置状态显示 `-2` 或 `+2`。显示的是该坐骑产生的距离修正，坐骑技能失效时显示 `0`。三个君主坐骑的距离状态技与客户端共用 `pkg/qiao_cards/mount_distance.lua`；房间按实体牌 ID 查询公开装备及角色状态，装备移动时刷新，也定时检查横置、势力与技能有效性。

坐骑定向套件 14/14，含客户端普通坐骑、双栏坐骑、横置切换与同势力坐骑变化的数值断言。离屏 Qt 用锁定版本的装备栏子组件及替身房间检查本方／其他角色面板、周期刷新和双栏文字布局。

[锦囊装备牌面文字提取](../../../assets/bilibili%20articles/cards/锦囊装备.json)中已登记的 40 种正式装备，其牌面和汉晋独立装备技能详情共用原文。攻击范围、牌类和双副类别由正式牌型提供。牌文与结算约定分开记录，例如木牛流马的五张上限与离开装备区的处理仍见对应规则。

木牛流马扣置手牌后，使用一次可取消的选人请求询问是否移动。选中能接收装备的角色后才可确认。原装备与木马牌在同次移动结算中转移，取消则继续留在原角色处。回归见 [君主装备套件](../../../tests/qiao_lord_equipment.lua)。

州郡领兵印的回合修正和汉晋合纵由 `pkg/qiao_mode/mode.lua` 接入。合纵检查手牌实体的合纵标记。装备区的神授思召以武器实体身份和置入回合状态独立判定，手牌没有合纵候选时它也能单独点亮按钮。`-turn` 标记由引擎在全部回合结束事件处理后清除，涵盖回合结束事件内才置入装备区的情况。麒麟弓的指定坐骑候选请求显式传送提示及技能 ID，供客户端和 AI 解析。驺虞幡在实际使用或打出后建立延时效果。血海魔王樽通过零材料视为技进入正常出牌和用牌询问，服务端带原请求参数复核【酒】是否合法，实际打出黑桃牌后才生成本次用酒结果。赤霄剑通过可取消的手牌选择请求处理交牌，以实际移动结果决定目标能否抵消【杀】。

### 势力锦囊

[势力锦囊规则](../../rules/card-deck.md#势力锦囊的结算审阅)通过模式级 `qiao__faction_trick_rule` 接入。正式用牌时以本次用牌数据保存使用者势力条件。移动结算只将势力锦囊实体从本次弃牌堆目的地分出并改至游戏外，保留原移动原因及同批其他牌。

七张势力锦囊的正式牌面、牌技能说明和诏书选项预览共用同一描述。以[《锦囊装备》](../../../assets/bilibili%20articles/cards/锦囊装备.json)逐张登记的牌面为基础，另起一行明示势力效果的使用者条件。洛水之誓的另行条件用于野心家对自己使用时立即结算，判定时对目标身份的检查仍写在基础效果中。势力条件、牌池及结算边界见规则页。

固国安邦以 `askToChooseCardsAndPlayers` 展开本次弃牌，已在真实客户端对象验证选牌和接收者，也通过正常出牌请求验证固定自用目标。党锢之祸通过公开将牌位置筛选与公共暗置事件处理，保护汉晋君主等特殊位置。文和乱武第二项用本次展示且仍在目标手中的牌构建明牌候选，确认后复核牌区，以弃置原因公开移出该牌。

号令天下、克复中原接入真实嵌套用牌。号令的参与者即使只有一项合法也收到选项询问，目标名随请求传入，符合魏势力条件时的专用选项写明免弃及取牌。既有回归覆盖号令排除并列最低体力、非魏参与者弃牌后实际出杀、魏参与者取得实际弃置的牌，以及克复的蜀角色用杀伤害 +1 与非蜀角色摸一张。

号令天下、克复中原和洛水之誓的手牌可用性与目标数量沿用两端共用的 `getPresentPlayers()`。三张牌通过引擎的 `Util.CardTargetFilter` 进入各自的目标规则。回归覆盖客户端刷新手牌及选目标，禁止夹具借用服务端的 `getAlivePlayers()`。

四海归平接入真实出牌阶段，按当前阶段实例查询实际入弃牌堆的实体，并在结束自由用牌后完成结算。覆盖不分牌仍继续询问晋角色实际用牌，以及后续请求接受合法转化。

洛水之誓接入延时锦囊与公开野心家出现后的诏书候选过滤。立即结算保留目标无效与无懈响应；非区间的重判在下个阶段准备点复核并置回原实体，再替换阶段。覆盖置入后才转野、自用立即判定、目标无效与无懈、改下一阶段并重判、命中但目标非野心家时直接结束，以及公开首次转野后的实际游戏外实体取得。回合内的明置与势力属性变化覆盖已核对，回合外公开转野及绑定阶段被跳过仍待专项验证。
