# 扩展加载与新核心布局

新月杀 v0.5.25 支持运行时根目录中的旧核心布局，以及 `packages/freekill-core` 布局。新布局下，`ModManager:loadPackages` 先切回运行时根目录加载扩展，再进入核心目录。引擎随后调用已登记的 `postLoad` 回调。此时首次执行 `require("packages.qiao...")` 会从核心目录查找，即使运行时根目录下的文件存在，也会报 `module ... not found`。扩展加载前，引擎已将全局 `package` 置空。

## 模块加载与注册

- 武将包在加载时解析技能来源标签、翼从来源与版本模块。实际登记仍在 `postLoad`，此时武将、技能骨架和牌原型已安装。冰清包的版本登记沿用相同时机。
- 魏君主工具模块在加载时提供技能来源查询。涉及核心 `ServerPlayer` 的接线留在 `postLoad`，此时可从核心目录加载该类，标准包的技能也已安装。
- 模式包提前加载模式工厂和客户端类。`postLoad` 先确认国战模式已注册，再安装势力查询及建国规则、创建两种汉晋模式并接入房间页面。
- 卡牌包在加载时取得 `packages.hegemony.util`，等包安装完成后再通过上游接口登记合纵牌。

工作目录由引擎管理。如果回调中途抛错，引擎会跳过后续回调。把目录切换和恢复分放在两个回调中，会让后续客户端或服务端入口从错误目录加载。新增回调时，应在扩展加载期间解析模块，把依赖已安装包的注册操作放在回调内。

## 验收

在没有旧核心脚本的运行时根目录下安装正式 qiao 包，启用 `packages/freekill-core` 并完成 `postLoad`。检查回调执行时仍在核心目录，确认技能来源标签、合纵牌、两种汉晋模式和房间规则均已接入。Windows 原生测试房间和实际客户端联网属于不同验收入口，结果分别记录在[开发状态](../status.md)。
