## 8. 自动化验收

执行 `python scripts/test.py`。默认套件包括上游流程回归、纯规则测试及独立汉晋场景。

- 默认六候选/上限 4 时禁二；自定义 3 候选/上限 3 时不禁；自定义 5 候选/上限 3 时禁二；候选少于上限时按候选数。
- 候选势力、上限、每势力开关的默认值与动态范围；旧房无新设置键时按默认六势力/4 兼容。
- 非法候选（空、未知、重复、非布尔开关）与非法上限（0、负数、非整数、超过候选数）被拒绝；初始化失败不静默降级。
- 未来第 7/8 势力可通过登记加入候选且不改变默认六势力；候选外武将不可选；将池缺失或仅客将出现的候选势力仍合法。
- 上一局胜利势力必禁、上局被禁势力必留；上局记录指向本局候选外时忽略；候选数不超过上限时上一局也不额外禁选。
- 双势力任一势力允许就保留；初始势力必须属于合法交集。
- 野心家默认四名、设为零、数量少于上限；从公共将池与已选武将合计检查上限。
- 经真实 `Request` 的取消/超时默认回复与非法回复均能得到合法双将。
- 连续两局中，上局胜利势力被禁、上局被禁势力保留；改模式清除历史，不同房间隔离。
- 君主装备成对替换、赤霄剑只增删、临筱玉舆与绝影互换、势力锦囊禁用。
- 汉晋场景中的每张实体卡与每名可选武将都来自独立汉晋包，原版内容被白名单排除。

测试数据位于 `tests/support/hanjin_content.lua`，仅在测试进程中登记独立无效果对象；不被 `init.lua` 引用、不进入发布同步内容，也不代表首批正式武将或卡牌设计。上游回归测试单独使用参考内容，不作为汉晋游戏内容。

本轮未人工验收界面、联网和断线重连；装备具体效果及双坐骑栏位交互属于后续正式卡牌实现验收。
