## 敛资

- **标识与依据** · 君孙权（EM(WU001)，变包），运行时 ID `qiao__skill_em_wu001_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_wu001_2.lua)和[逐将规则](../../../../rules/generals/em-wu001-sunquan.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L243)。

> 出牌阶段限一次，你可以弃置一张牌并亮出牌堆顶的X张牌（X为处于吴势力攻击范围内的角色数），获得其中你弃置类别的牌，若你本回合得到过的牌数达到角色数，你失去此技能并获得“制衡”。

- **实现与接口** · 君孙权出牌阶段弃置一张牌，按所有吴势力角色攻击范围的并集计算亮牌张数，获得与弃置牌同类别的牌。是否移除敛资并获得共享[制衡](../standard/wu001.md#wu001-1)，另按本回合累计取得牌数是否达到在场角色数判断。
- **验证依据** · [em_wu001_sunquan.lua](../../../../../tests/em_wu001_sunquan.lua#L255)。验证攻击范围数量与全场人数不同时的不足和达到门槛分支。

## 聚宝

- **标识与依据** · 君孙权（EM(WU001)，变包），运行时 ID `qiao__skill_em_wu001_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_wu001_3.lua)和[逐将规则](../../../../rules/generals/em-wu001-sunquan.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L244)。

> 锁定技，防止其他角色不因弃置而移动你装备着的宝物牌。结束阶段，若【定澜夜明珠】在场上或弃牌堆，你摸一张牌，获得装备着该牌的角色一张牌。

- **实现与接口** · 君孙权在移牌前识别发起者，对其他角色非弃置移动自己宝物的对应条目逐牌拦截。自己结束阶段若【定澜夜明珠】处于场上或弃牌堆，先摸一张，再在其有装备者时取得其一张牌。
- **验证依据** · [em_wu001_sunquan.lua](../../../../../tests/em_wu001_sunquan.lua#L309)。覆盖普通宝物、同批【破军】或【横征】、弃置放行，以及珍珠在手牌中不算。

## 缘江烽火图

- **标识与依据** · 君孙权（EM(WU001)）的派生技能或专属效果，运行时 ID `qiao__skill_em_wu001_flag`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_wu001_flag.lua)和[逐将规则](../../../../rules/generals/em-wu001-sunquan.md)。

完整牌面原文见[缘江烽火图-用户牌面.png](../../../../../assets/docs/缘江烽火图-用户牌面.png)。[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L253)只收录第一段。

> 吴势力角色出牌阶段限一次，其可以将一张装备牌置于此牌上，称为“烽火”。你的攻击范围+X（X为“烽火”数）。
> 吴势力角色的准备阶段，其可以根据“烽火”数于本回合获得以下一个技能：
> 1或以上～“英姿”；2或以上～“好施”；
> 3或以上～“攻心”；4或以上～“度势”；
> 5或以上～可多选择一个技能。
> 锁定技，当你受到牌的伤害后，你移去一张“烽火”，然后令你本回合下次受到的伤害-1。

旗标说明与完整牌面文字一致，授技档位合并显示为一行。吴势力角色的独立「烽火图」操作入口只显示置入装备的部分。

- **实现与接口** · 吴角色在自己的出牌阶段按独立次数置入一张装备牌，持旗者的攻击范围实时加上烽火数量。吴角色准备阶段按烽火层数取得[英姿](../standard/wu005.md#wu005-1)、[好施](../standard/wu014.md#wu014-1)、[攻心](#em-wu001-gongxin)或[度势](../standard/wu007.md#wu007-2)，五张及以上可再取得一个不同技能。授技到本回合结束或受益者死亡时只撤本次来源。旗有效且持有者受到牌的伤害后，选择并实际移去一张烽火才记下一次减伤。减伤由独立规则在下一次受到任意渠道的伤害时消耗，失旗不撤销已经建立的减伤，回合结束清理未消耗项。
- **验证依据** · [em_wu001_sunquan.lua](../../../../../tests/em_wu001_sunquan.lua#L209)。覆盖真实置牌和范围、逐档授技、实际移去指定烽火、失旗后减伤及到期。用例走客户端请求和服务端回包。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 攻心

- **标识与依据** · 君孙权（EM(WU001)）的派生技能或专属效果，运行时 ID `qiao__gongxin`。见[源码](../../../../../pkg/qiao_generals/skills/qiao_gongxin.lua)和[逐将规则](../../../../rules/generals/em-wu001-sunquan.md)。

牌面原文见[用户提供的攻心图片](../../../../../assets/docs/攻心-用户牌面.png)。

> 出牌阶段限一次，你可以观看一名其他角色的手牌，然后你可以展示其中一张♥牌，弃置之或将此牌置于牌堆顶。

- **实现与接口** · 出牌阶段用一次私密请求看目标的全部手牌，并可选一张有效红桃同时决定弃置或置顶。结束观看是合法选择，禁止弃置时仍可置顶。服务端重新检查手牌位置、花色和选择，公开的牌只有被选中的红桃。次数由普通出牌入口检查，同阶段重获攻心仍沿用已有历史。
- **验证依据** · [em_wu001_sunquan.lua](../../../../../tests/em_wu001_sunquan.lua#L344)。覆盖实际授予后通过普通出牌回包进入私密请求、置顶或弃置、取消、禁弃和过期输入。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
