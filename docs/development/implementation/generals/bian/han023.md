## 除奸

- **标识与依据** · 伍琼&种辑（HAN023，变包），运行时 ID `qiao__skill_han023_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han023_1.lua)、[变包模式规则](../../../../../pkg/qiao_mode/skills/bian_rules.lua)和[逐将规则](../../../../rules/generals/han023-wuqiong-zhongji.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 其他角色的出牌阶段开始时，若其体力值或手牌数最大，你可以令其此阶段对你使用【杀】无距离和次数限制，然后此阶段结束时，你对其造成1点伤害。

- **实现与接口** · 其他角色出牌阶段开始时（`fk.EventPhaseStart`），按在场角色（`room:getPresentPlayers()`）判断其体力值或手牌数是否为全场最大。发动后向该角色写入阶段级公开标记，由模式级规则 `qiao__bian_rules` 提供对其使用【杀】的 `targetmod`（`bypass_distances` 与 `bypass_times`）并在 `fk.PreCardUse` 中对目标全在列表内的【杀】标记 `extraUse = true`；同时记录阶段末延时伤害，在 `fk.EventPhaseEnd` 结算，不因伍琼&种辑中途暗置或失技而撤销。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L76)。验证远距离多次出【杀】不计入常规次数，以及中途暗置后阶段末仍造成 1 点伤害。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 心疾

- **标识与依据** · 伍琼&种辑（HAN023，变包），运行时 ID `qiao__skill_han023_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han023_2.lua)、[鏖战公共规则](../../../../../pkg/qiao_mode/rules/battle_royal.lua)和[逐将规则](../../../../rules/generals/han023-wuqiong-zhongji.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 锁定技，你处于鏖战状态。当你于濒死状态失救时，你减1点体力上限并回复体力至1点。

- **实现与接口** · 通过 `BattleRoyal.syncPersonal` 为明置伍琼&种辑本人挂载绑定 `skill = "qiao__skill_han023_2"` 的独立鏖战来源，同步钩子以 `hasShownSkill("qiao__skill_han023_2", true)` 区分“将牌仍明置但技能暂时无效”（保留来源由 `only_as` 暂挂）与“暗置或真正失去来源”，在明暗置、得失技能、武将交换、死亡、回合开始及技能临时无效化／恢复（`only_as.installServer`）时即时同步，不拉全局或其他角色进入鏖战；全局已进入鏖战时仍按全局约束生效。濒死求桃完毕仍 `hp < 1` 时，在 `fk.AskForPeachesDone`（先于默认死亡规则 `priority = 0`）强制执行减 1 点体力上限，若仍存活且 `hp < 1` 则回复体力至 1 点；原体力上限为 1 时减上限至 0 直接触发死亡流程。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L133)、`testHan023XinjiInvalidationRestoreAndGlobalBattleRoyal` 与 `testHan023XinjiInvalidAcquireSkillThenRestore`。核对个人鏖战、暗置退出、临时无效期间获得其他技能再恢复有效、全局鏖战覆盖、失救自救及体力上限为 1 直接死亡。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
