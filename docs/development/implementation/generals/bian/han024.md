## 竭缘

- **标识与依据** · 灵雎（HAN024，变包），运行时 ID `qiao__skill_han024_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han024_1.lua)和[逐将规则](../../../../rules/generals/han024-lingju.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你对其他角色造成伤害时，或受到其他角色造成的伤害时，若其体力值大于等于你，你可以弃置一张红色牌，然后令此伤害+1或-1。

- **实现与接口** · 分别监听 `fk.DamageCaused` 与 `fk.DamageInflicted`，检查对方为其他角色且 `other.hp >= player.hp`，同时灵雎手牌区或装备区存在可弃红色牌（含装备区红牌）。在同一个原生弹窗选择一张红牌并点「伤害+1」或「伤害-1」。取消或超时均保留红牌。确认后弃牌并调整伤害，减伤使伤害降至 0 及以下时调用 `data:preventDamage()`。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L191)。验证弃装备区红牌增伤，以及受伤时弃手牌红牌防伤。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 焚心

- **标识与依据** · 灵雎（HAN024，变包），运行时 ID `qiao__skill_han024_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han024_2.lua)、[变更公共规则](../../../../../pkg/qiao_mode/rules/general_change.lua)和[逐将规则](../../../../rules/generals/han024-lingju.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你杀死角色后，你可以变更副将，此次变更额外获得三张其副将牌面势力的备选武将牌。

- **实现与接口** · 在 `fk.Deathed` 时检查击杀者为灵雎且本局该来源尚未耗尽伪限定变更次数（`Change.canUseSkillChange`）。读取死者副将的牌面势力，通过 `Change.performSkillChangeDeputy` 在换将前先锁定来源键（防止副将灵雎换走自己后记错来源；发动前可拒绝，变更成功后计次），并传入 `extra_kingdoms` 与 `extra_num = 3`；常规候选沿用专属野心家随机副将池规则，显式传入的额外池仍严格按死者副将牌面势力筛选，两组合并在同一选将面板中，可分别取足时给六张不同的牌，常规池与额外池重叠时为稀缺的额外备选留出名额。展示后必须选择，空回复按已展示的第一张处理，允许无视势力限制选入异势力备选，不改变灵雎本局势力归属，换下的旧副将进入汉晋武将弃牌堆。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L191) 与 `testHan024FenxinWildExtraPoolAndSelfDeputySourceKey`。覆盖合并候选、专属野心家额外池限定、副将换走自己来源记账、展示后空回复仍完成变更、旧副将入弃牌堆及再次击杀不再触发。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
