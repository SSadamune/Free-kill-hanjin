## 忽辱

- **标识与依据** · 陈骞（JIN018，变包），运行时 ID `qiao__skill_jin018_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin018_1.lua)和[逐将规则](../../../../rules/generals/jin018-chenqian.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 每回合限一次，当你造成或受到伤害时，你可以同时展示来源和受伤角色各一张手牌，若：花色相同，你获得之；类别相同，此伤害-1。

- **实现与接口** · 监听 `fk.DamageCaused` 与 `fk.DamageInflicted`（自伤时仅在 `DamageCaused` 触发一次，避免同一事件重复询问，需至少 2 张手牌）。由陈骞全权挑选双方各一张手牌后，按各自实际牌主过锁视、写入记牌器、发战报与亮牌通知，并合并触发单次 `fk.CardShown`（`cardIds = { idA, idB }`），防止两张展示之间被插结；花色相同则获得对方展示的手牌，类别相同则令此次伤害减 1（降至 0 时防止伤害），两项独立判断可同时生效。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L397) 与 `testJin018HuruSimultaneousSingleCardShown`。覆盖红桃基本牌同花色且同类别双生效、双方各亮一张合并单次展示事件，以及陈骞自伤展示两张同类别手牌仅询问一次并防止伤害。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 武督

- **标识与依据** · 陈骞（JIN018，变包），运行时 ID `qiao__skill_jin018_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin018_2.lua)、[手牌可见性](../../../../../pkg/qiao_mode/rules/card_visibility.lua)、[变包模式规则](../../../../../pkg/qiao_mode/skills/bian_rules.lua)和[逐将规则](../../../../rules/generals/jin018-chenqian.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 出牌阶段限一次，你可以弃置一张牌并令一名有手牌的角色选择一项：1.其手牌对所有角色可见直到其回合结束；2.你对其造成1点伤害。

- **实现与接口** · 出牌阶段主动技，允许选择包括陈骞自己在内的有手牌角色；客户端与服务端同步校验弃置所选牌后目标仍保有手牌（弃唯一手牌时不能选自己，弃装备保留手牌时可选自己）。弃牌后目标二选一：选项 1 挂载公开标记 `@qiao_jin018_wudu` 接入 `Visibility.wudu` 公开手牌，并由 `qiao__bian_rules` 在目标真正触发 `fk.TurnEnd` 时清除（叠置跳过回合自动顺延）；选项 2 由陈骞对其造成 1 点伤害。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L397)。覆盖客户端选自己合法性校验、公开手牌可读性，以及他人回合结束不清除、目标真正回合结束才清除。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
