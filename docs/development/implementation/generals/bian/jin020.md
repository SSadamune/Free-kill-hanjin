## 应政

- **标识与依据** · 荀勖（JIN020，变包），运行时 ID `qiao__skill_jin020_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin020_1.lua)、[应变公共规则](../../../../../pkg/qiao_mode/rules/adaptation.lua)和[逐将规则](../../../../rules/generals/jin020-xunxu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 与你势力相同的角色回合内限一次，当其使用应变牌后，其可以令你获得此牌，然后若此牌触发应变，你可以令其变更副将（限一次）。

- **实现与接口** · 在 `fk.CardUseFinished` 检查使用者为当前回合的同势力角色、本回合未发动过、使用的牌满足 `A.isAdaptationCard` 且处理区/弃牌堆中仍有可获取实体牌。先由使用者决定是否令荀勖获得此牌；实际获得后，若 `A.getResult(data).triggered == true` 且本技能每局限一次变更未耗尽，由荀勖决定是否令其执行 `Change.performSkillChangeDeputy`。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L524)。验证先由同势力使用者决定给牌、再由荀勖决定令其变更副将的完整顺序与结算。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 拨律

- **标识与依据** · 荀勖（JIN020，变包），运行时 ID `qiao__skill_jin020_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin020_2.lua)、[应变公共规则](../../../../../pkg/qiao_mode/rules/adaptation.lua)和[逐将规则](../../../../rules/generals/jin020-xunxu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 出牌阶段限一次，你可以选择一名角色并重铸一张手牌，根据花色修改其使用下张应变牌的应变条件：黑桃~富甲；红桃~残躯；梅花~助战；方片~空巢。

- **实现与接口** · 出牌阶段选择一名在场角色并重铸一张手牌，依所重铸手牌花色为目标写入公开标记 `@qiao_bolu_condition`（重复施加直接覆盖旧条件，跨回合持续保留直至使用下一张应变牌）。`adaptation.lua` 中的 `effectiveEntries`、`ignoreTimesCandidate`、`lockIgnoreTimes` 与 `prepare` 在使用下张应变牌时将全部应变条目的条件统一覆写为该条件并消耗标记。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L524)。覆盖重复覆盖（黑桃改红桃）、跨回合保留，以及下一张双条目应变杀全部按「残躯」触发并消耗标记。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
