## 化形

- **标识与依据** · 左慈（QUN009，变包），运行时 ID `qiao__skill_qun009_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun009_1.lua)、[变包公共辅助](../../../../../pkg/qiao_generals/util/bian_common.lua)、[变包模式规则](../../../../../pkg/qiao_mode/skills/bian_rules.lua)和[逐将规则](../../../../rules/generals/qun009-zuoci.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你受到1点伤害后、其他角色脱离濒死时或出牌阶段限一次，你可以将一张（首次发动时改为三张）剩余武将牌扣置于武将牌上，称为“魂”，然后选择一项：1.移去一张“魂”；2.将副将武将牌额外变更为一张“魂”。

- **实现与接口** · 提供三个独立入口：出牌阶段限一次主动效果（按效果级 `usedEffectTimes` 计次，不与触发入口冲突）、`fk.Damaged`（按伤害点数逐次触发）与 `fk.AfterDying`（其他角色存活脱离濒死）。每次出牌请求前只同步将池是否有候选，服务端在明置与计次前复核。发动时从 `Change.skillAvailablePool` 不限势力随机取 1 张（整局首次发动取 3 张）存入房间私有账本 `qiao_zuoci_hun_v1`，经持有者本人的连接更新私密列表 `@&qiao_zuoci_hun`，公开标记 `@qiao_zuoci_hun` 仅同步数量；`PrivateMarks.register` 与【铁骑】复用同一个本人快照入口，统一包装汉晋房间 `room:tellRoomToObserver` 与 `room:serialize(viewer)`，重连快照仅为当前持有者本人补回 `@&qiao_zuoci_hun`，其他座位及借用首座视角生成的旁观者 `Observe` 包均仅见数量，后续增减「魂」也只更新旁观者的数量。选项 1 将所选「魂」移入汉晋武将弃牌堆，选项 2 校验副将非士兵非君主后调用 `Change.changeTo` 额外变更副将（无视势力且不改左慈势力，旧副将入武将弃牌堆）。武将交换通过 `Exchange.addCompletionListener` 随左慈武将牌迁移「魂」；武将变更通过 `Change.addCompletionListener` 覆盖暗置或明置左慈被换走时的清理，死亡掩埋或移除离场时剩余「魂」统一置入武将弃牌堆。登记客将势力为 `wei`、`shu`、`wu`，无珠联。
- **验证依据** · [变包专项](../../../../../tests/bian_wu_qun_jin.lua#L219)覆盖首次取魂、异势力额外变更、士兵副将限制、弃置及交换。另有[本人重连与旁观通知](../../../../../tests/bian_wu_qun_jin.lua#L823)和[空池按钮与过期请求](../../../../../tests/bian_wu_qun_jin.lua#L900)用例。
