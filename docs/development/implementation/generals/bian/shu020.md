## 蒺藜

- **标识与依据** · 沙摩柯（SHU020，变包），运行时 ID `qiao__skill_shu020_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu020_1.lua)和[逐将规则](../../../../rules/generals/shu020-shamoke.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你于一回合内使用或打出第X张牌时，你可以摸X张牌（X为你的攻击范围）。

- **实现与接口** · 监听 `fk.CardUsing` 与 `fk.CardResponding`，在每次使用或打出牌时实时统计当前回合内累计的使用与打出事件次数，并与当时的 `player:getAttackRange()` 比对；相等且大于 0 时允许摸取当时攻击范围张牌，支持安装或卸载武器后在同一回合内按动态攻击范围多次触发以及回合外打出触发。主线[角色状态面板](../../skill-ui.md)在技能明置时显示本回合累计使用和打出的牌数，暗置时撤下。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L425)。覆盖第 1 张使用武器按装前范围 1 摸 1、第 2 张出杀按装后范围 2 摸 2，以及回合外打出第 1 张牌摸 1。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
