## 散谣

- **标识与依据** · 马谡（SHU022，变包），运行时 ID `qiao__skill_shu022_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu022_1.lua)和[逐将规则](../../../../rules/generals/shu022-masu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 出牌阶段限一次，你可以弃置一张牌，对一名体力值或手牌数最大的角色造成1点伤害。

- **实现与接口** · 出牌阶段主动技，使用 `Fk:currentRoom():getPresentPlayers()` 在客户端与服务端一致计算在场角色的最大体力值与最大手牌数（排除已调离角色），允许选择满足任一最大值条件的角色。支付消耗弃置 1 张合法牌后对其造成 1 点伤害。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L481)。通过真实 `ClientPlayer` 核对体力最大、手牌最大及被调离角色的筛选结果，并验证弃牌造伤。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 制蛮

- **标识与依据** · 马谡（SHU022，变包），运行时 ID `qiao__skill_shu022_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu022_2.lua)、[变更公共规则](../../../../../pkg/qiao_mode/rules/general_change.lua)和[逐将规则](../../../../rules/generals/shu022-masu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你对其他角色造成伤害时，你可以防止此伤害，然后获得其区域里的一张牌，若其与你势力相同，其可以变更副将（限一次）。

- **实现与接口** · 在 `fk.DamageCaused` 对其他角色造成伤害时可防止伤害并选择获得其手牌区、装备区或判定区的一张牌（`flag = "hej"`）。若目标与马谡同势力且本技能每局限一次变更尚未耗尽，询问目标是否变更副将并调用 `Change.performSkillChangeDeputy`（按马谡来源记录次数）。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L481)。覆盖防止伤害、获得同势力目标判定区牌、成功变更副将及每局限一次记账。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
