## 奇策

- **标识与依据** · 荀攸（WEI020，变包），运行时 ID `qiao__skill_wei020_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei020_1.lua)和[逐将规则](../../../../rules/generals/wei020-xunyou.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 出牌阶段限一次，你可以将所有手牌当任意一种普通锦囊牌使用（不能为目标数大于转化所用牌数的牌或【挟天子以令诸侯】），然后你可以变更副将。

- **实现与接口** · 复用随君曹操【霸者求贤状】接入的共享技能实现，同步卡面完整牌名【挟天子以令诸侯】。普通荀攸武将牌自带该技能时，其每局限一次的变更副将账本按 `qiao_heg__wei020` 武将牌独立记账，与君曹操大旗临时授予来源互不冲突。另登记与 `HAN023`（伍琼&种辑）的客将珠联及汉势力客将（已与用户确认有且仅有汉势力客将）。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L279) 与 [em_wei001_caocao.lua](../../../../../tests/em_wei001_caocao.lua)。验证正式变包荀攸使用【奇策】并按自身武将牌记录变更副将。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 智愚

- **标识与依据** · 荀攸（WEI020，变包），运行时 ID `qiao__skill_wei020_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei020_2.lua)和[逐将规则](../../../../rules/generals/wei020-xunyou.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你受到伤害后，你可以摸一张牌，展示所有手牌，若颜色均相同，来源弃置一张手牌。

- **实现与接口** · 受到伤害后（`fk.Damaged`）摸 1 张牌，若仍有手牌则全部展示（`player:showCards`）。检查全部手牌是否同为红色或同为黑色（无色牌不满足）；若均相同且伤害来源存活有手牌，令来源弃置 1 张手牌。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L279)。覆盖摸牌后全红手牌令来源弃手牌，以及混色不弃牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
