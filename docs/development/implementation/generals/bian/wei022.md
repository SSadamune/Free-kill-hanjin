## 挽危

- **标识与依据** · 卞夫人（WEI022，变包），运行时 ID `qiao__skill_wei022_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei022_1.lua)和[逐将规则](../../../../rules/generals/wei022-bianfuren.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 每回合限一次，当确定与你势力相同的角色因其他势力角色的获得或弃置而移动的牌时，你可以将此次移动的牌改为你的一张牌。

- **实现与接口** · 在 `fk.BeforeCardsMove` 中分别按操作实际执行者筛选（`fk.ReasonPrey` 取获得者 `move.to or move.proposer`，兼容【巧变】以及同步改为 `fk.ReasonPrey` 的【烈刃】与【白马义从】；`fk.ReasonDiscard` 取 `move.proposer`），仅对其他势力角色发起、目标为同势力角色的整批手牌／装备移动生效，排除同势力队友间拿牌。卞夫人选择自己一张合法牌替换后，移至弃牌堆或来自装备区置 `moveVisible = true`，来自手牌区一律置 `moveVisible = false`（清除原 `specialVisible`／`visiblePlayers`），交由引擎按每位观察者的 `isBuddy` 与 `VisibilitySkill`（含旁观开关）各自判定。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L356)、`testWei022WanweiQiaobianTeammateAndPrivateVisibility`、`testWei022WanweiLierenAndBaimaPrey` 与 `testWei022WanweiPartialVisibilityAndObserverWudu`。覆盖多牌弃置、【巧变】与【烈刃】获得、队友拿牌不触发、【问道】替代暗手牌第四座位不可见、局部可见不扩散为全局以及【武督】明牌遵守旁观开关。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 约俭

- **标识与依据** · 卞夫人（WEI022，变包），运行时 ID `qiao__skill_wei022_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei022_2.lua)、[变包模式规则](../../../../../pkg/qiao_mode/skills/bian_rules.lua)和[逐将规则](../../../../rules/generals/wei022-bianfuren.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 轮次技，与你势力相同的角色准备阶段，你可令其本回合手牌上限为X（X为其体力上限），弃牌阶段结束时若其未弃置牌，其摸一张牌。

- **实现与接口** · 同势力角色准备阶段（`fk.EventPhaseStart`，每轮限一次 `Player.HistoryRound`），发动后为目标挂载回合标记 `qiao_wei022_yuejian-turn`。模式级规则 `qiao__bian_rules` 通过 `maxcards` 的 `fixed_func` 将手牌上限初值设为 `player.maxHp`（不阻止后续 `correct_func` 增减叠加），并在目标弃牌阶段结束时按弃置执行者（`move.proposer == player`）检查本阶段未执行过弃置则令其摸 1 张牌（被他人弃牌不计入）。
- **验证依据** · [bian_han_wei_shu.lua](../../../../../tests/bian_han_wei_shu.lua#L356) 与 `testWei022YuejianOpponentDiscardStillDraws`。覆盖手牌上限初值等于体力上限、叠加额外手牌上限标记、未弃牌摸 1 张，以及弃牌阶段仅被他人弃牌仍摸 1 张。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
