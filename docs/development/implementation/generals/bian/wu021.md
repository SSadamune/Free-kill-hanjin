## 旋略

- **标识与依据** · 凌统（WU021，变包），运行时 ID `qiao__skill_wu021_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu021_1.lua)和[逐将规则](../../../../rules/generals/wu021-lingtong.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 当你失去装备区里的牌后，你可以弃置一名其他角色的一张牌。

- **实现与接口** · 监听 `fk.AfterCardsMove`，单次移牌事件中只要凌统从装备区失去任意张牌即只触发一次，选择一名在场且手牌区或装备区有牌的其他角色，弃置其一张牌（`flag = "he"`）。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L33)。验证单次同时失去 2 张装备仅触发一次，以及配合【勇进】依次移出两件装备时逐次即时触发。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 勇进

- **标识与依据** · 凌统（WU021，变包），运行时 ID `qiao__skill_wu021_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu021_2.lua)、[变包公共辅助](../../../../../pkg/qiao_generals/util/bian_common.lua)和[逐将规则](../../../../rules/generals/wu021-lingtong.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 限定技，出牌阶段，你可以依次移动场上至多三张各不同的装备牌。

- **实现与接口** · 出牌阶段限定主动技，循环至多 3 次依次选择移出角色、装备牌与接收角色，每次移动后即刻结算（可即时联动【旋略】）。通过 `Bian.canMoveEquipTo(from, to, id, player)` 与 `Bian.boardEquipParticipants(room, movedIds, player)` 校验在场角色、空置装备栏、双副类别坐骑双空栏要求以及已明置【聚宝】对其他角色移动宝物牌的保护，并用 `movedIds` 集合阻止同一张装备牌被重复移动；第 2、3 次允许取消提前结束。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L33) 与 `testWu021YongjinSkipsRevealedJubaoTreasure`。覆盖已移动装备排除、双坐骑空栏校验、明置【聚宝】唯一宝物时双端禁用按钮，以及连续移动并即时联动【旋略】。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
