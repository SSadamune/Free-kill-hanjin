## 调度

- **标识与依据** · 吕范（WU022，变包），运行时 ID `qiao__skill_wu022_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu022_1.lua)、[变包公共辅助](../../../../../pkg/qiao_generals/util/bian_common.lua)和[逐将规则](../../../../rules/generals/wu022-lvfan.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 准备阶段，你可以获得或移动与你势力相同的角色装备区一张牌。每回合首次有牌置入每名与你势力相同的角色装备区后，其摸一张牌。

- **实现与接口** · 包含两个独立效果：准备阶段先提供「获得」「移动」「取消」。获得时再选同势力角色与装备，移动时复用场上移牌面板并限于同势力来源（遵循 `Bian.canMoveEquipTo` 空栏、双坐骑与【聚宝】规则）；`fk.AfterCardsMove` 监测有牌置入同势力角色装备区后，按目标角色回合级标记保证每名同势力角色每回合仅首次置入装备时摸 1 张牌。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L119) 与 `testWu022DiaoduSkipsProtectedTreasureKeepsOtherEquip`。验证准备阶段移动装备联动首次入装备摸牌、仅有明置【聚宝】宝物时不提供目标、混有普通装备时排除宝物并保留普通装备。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 典财

- **标识与依据** · 吕范（WU022，变包），运行时 ID `qiao__skill_wu022_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu022_2.lua)、[变更公共规则](../../../../../pkg/qiao_mode/rules/general_change.lua)和[逐将规则](../../../../rules/generals/wu022-lvfan.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json)。

> 其他角色的出牌阶段结束时，若你此阶段失去过的牌数达到X（X为你的体力值），你可以摸牌至体力上限，然后你可以变更副将。

- **实现与接口** · 其他角色出牌阶段结束时（`fk.EventPhaseEnd`），扫描本阶段 `GameEvent.MoveCards`，仅统计从吕范手牌区或装备区移至这两区以外的牌数（不计判定区移走及手牌与装备互移）。满足 `lost >= player.hp` 即允许发动——即使当前手牌数已大于等于体力上限（摸 0 张）仍可发动并继续询问每局限一次的副将变更（`Change.performSkillChangeDeputy`）。
- **验证依据** · [bian_wu_qun_jin.lua](../../../../../tests/bian_wu_qun_jin.lua#L119)。覆盖判定区失牌不计入、手牌移入装备区不计入，以及手牌已满摸 0 张仍可发动并完成变更副将。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
