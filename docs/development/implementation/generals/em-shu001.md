### EM(SHU001) 君刘备

<a id="em-shu001-1"></a>
#### 章武

- **标识与依据** · 君刘备（EM(SHU001)，阵包），运行时 ID `qiao__skill_em_shu001_1`。见[源码](../../../../pkg/qiao_generals/skills/skill_em_shu001_1.lua)和[逐将规则](../../../rules/generals/em-shu001-liubei.md)。

牌面原文见[石激桑资料](../../../../assets/docs/石激桑武将列表.json#L194)。

> 君主技，你拥有“六师率义旗”。

- **实现与接口** · 章武随君刘备的君主牌实际明暗置和技能存续更新，授予独立的[六师率义旗](#em-shu001-flag)，再按公开势力给其他蜀角色同步入口。
- **验证依据** · [em_shu001_liubei.lua](../../../../tests/em_shu001_liubei.lua#L124)。验证正式旗入口支付与授技，以及失效时到期清理并保留其他来源。[公共升变回归](../../../../tests/second_lord.lua)另验证章武进入真实技能来源。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../status.md#当前验收基线)。

<a id="em-shu001-2"></a>
#### 天钺

- **标识与依据** · 君刘备（EM(SHU001)，阵包），运行时 ID `qiao__skill_em_shu001_2`。见[源码](../../../../pkg/qiao_generals/skills/skill_em_shu001_2.lua)和[逐将规则](../../../rules/generals/em-shu001-liubei.md)。

牌面原文见[石激桑资料](../../../../assets/docs/石激桑武将列表.json#L195)。

> 锁定技，其他角色的【飞龙夺凤】置入场上或弃牌堆时，改为你获得之；你不因使用【飞龙夺凤】而失去此牌时，你展示之并置于牌堆底，摸两张牌。

- **实现与接口** · 君刘备在移动前把其他角色的【飞龙夺凤】进入场上或弃牌堆的记录改为自己获得。同批其他牌仍按原记录移动，拆出的条目沿用引擎 `MoveCardsData`。君刘备非因使用失去此牌时，移动后展示并将其置底，随后摸两张。
- **验证依据** · [em_shu001_liubei.lua](../../../../tests/em_shu001_liubei.lua#L73)。覆盖同批普通牌、与天授的两种顺序、离开后展示置底和私有牌堆边界。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../status.md#当前验收基线)。

<a id="em-shu001-3"></a>
#### 激诏

- **标识与依据** · 君刘备（EM(SHU001)，阵包），运行时 ID `qiao__skill_em_shu001_3`。见[源码](../../../../pkg/qiao_generals/skills/skill_em_shu001_3.lua)和[逐将规则](../../../rules/generals/em-shu001-liubei.md)。

牌面原文见[石激桑资料](../../../../assets/docs/石激桑武将列表.json#L196)。

> 限定技，当你处于濒死时，你可以回复体力至2点并失去“章武”，获得“仁德”，然后你可以摸等同体力上限的牌，将手牌弃置至体力上限。

- **实现与接口** · 君刘备进入濒死时（`fk.EnterDying`）可发动限定技，回复至 2 点，失去章武并获得共享的[仁德](conversion.md#shu001-1)。随后可选的后段先摸等同体力上限的张数，再把手牌弃至该上限。
- **验证依据** · [em_shu001_liubei.lua](../../../../tests/em_shu001_liubei.lua#L60)。专项核对旗相关正式技能已登记。
- **未完成与边界** · 濒死进出及可选摸弃的完整流程未找到直接断言。

<a id="em-shu001-flag"></a>
#### 六师率义旗

- **标识与依据** · 君刘备（EM(SHU001)）的派生技能或专属效果，运行时 ID `qiao__skill_em_shu001_flag`。见[源码](../../../../pkg/qiao_generals/skills/skill_em_shu001_flag.lua)和[逐将规则](../../../rules/generals/em-shu001-liubei.md)。

牌面原文见[石激桑资料](../../../../assets/docs/石激桑武将列表.json#L205)。

> 其他蜀势力角色的出牌阶段限一次，其可以交给你两张牌，然后于本回合获得以下一项场上没有的技能：
> “武圣”、“咆哮”、“龙胆”
> “铁骑”、“烈勇”、“狂骨”。

- **实现与接口** · 其他蜀势力角色在出牌阶段通过旗入口选择两张牌和未被公开来源占用的技能。实际交出两张牌后，授予所选技能直到本回合结束。到期撤本次授予的来源，即使此时旗或技能已经无效。
- **验证依据** · [em_shu001_liubei.lua](../../../../tests/em_shu001_liubei.lua#L124)。核对实际交牌、临时授技、失效后的清理及保留独立同名技能。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../status.md#当前验收基线)。
