## 2. 实现要点

- `TargetSpecified` 是每个目标分别生成的时机；谋溃在本次 `UseCardData` 上写入
  已发动标记，因此一张【杀】只发动一次，不会为每个目标重复询问。
- 发动者在本次【杀】的目标列表中选择**一个**目标，再通过 `askToChoices`
  选择一至两项：摸一张、弃置该目标一张牌。执行顺序固定为先摸后弃。
- 双选时在 use 上记录被选目标 id 与“双选”标记；抵消监听器只在
  `CardEffectCancelledOut` 的当前目标正是该目标时触发，其他目标抵消不触发。
  触发后由抵消者选择并弃置伏完一张手牌/装备牌。
- 反弃监听器是模块缓存的房间级对象，使用本次 use 已建立的标记，不依赖伏完
  当前是否仍有谋溃；失技/暗置后双选后续仍结算。
- 无「挂载」式额外技能，也没有为每个目标复制一套谋溃效果。
