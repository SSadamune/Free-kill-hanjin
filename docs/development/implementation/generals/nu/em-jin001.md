## 诸王敕封册与赐

- **标识与依据** · 君司马炎（EM(JIN001)）的派生技能或专属效果，运行时 ID `qiao__skill_em_jin001_banner`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_jin001_banner.lua)和[逐将规则](../../../../rules/generals/em-jin001-simayan.md)。受赠者使用独立的[消费入口](../../../../../pkg/qiao_generals/skills/skill_em_jin001_consume.lua) `qiao__skill_em_jin001_consume`。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L181)。完整四项见[乔剪国战表格.xlsx](../../../../../assets/docs/乔剪国战表格.xlsx)「兵情篇」I37、K37、M37及[弩包专栏](https://www.bilibili.com/opus/1181099586803990535)，现有逐将页保留[文字记录](../../../../rules/generals/em-jin001-simayan.md#太康与诸王敕封册)。

> 当一名角色的武将牌首次均明置后，或被晋势力角色杀死后，你可以将一张符合其副将牌面势力的剩余武将牌置为〖赐〗。
> （〖赐〗是一种国战标记：出牌阶段限一次，你可以消耗一枚〖赐〗，然后变更一张与此牌单独阴阳鱼数相同的武将牌（限一次），或根据此牌单独阴阳鱼数执行效果：≤3：本回合手牌上限+3。≥4：摸牌至四张。）
>
> 其他晋势力角色造成伤害后，你可以将你一个势力的所有〖赐〗交给其。
>
> 当你即将跳过一个阶段时，你可以移去你的一枚〖赐〗并防止之。

当前旗标把首句的「将一张」写成「随机将一张」，并将首句的「〖赐〗」显示为「“赐”」。随机抽取已有[2026-11-20 项目裁定与作者答疑](../../../../rules/generals/em-jin001-simayan.md#太康与诸王敕封册)。单独的「赐」消费入口沿用牌面括注中的消费文字。

头像下的「诸王敕封册」悬停提示列出取赐、交付和防止跳过阶段的效果，「赐」标记悬停说明出牌阶段的消耗效果。技能详情中「赐」的术语链接也复用标记说明。赐的查看、消耗、交付和移去面板使用简短提示，交付对象或阶段名过长时自动换行。

- **实现与接口** · 首次双亮和晋角色击杀共用取赐入口。以副将的本局可用势力与候选取交集，随机选出一张牌并记到持有者公开名单。查看、主动消耗、交付和移去共用 `CiPile.qml`。点牌可读技能，选中的牌显示绿色对勾。主动消耗以对应资源或变更位置按钮确认，出牌请求私下发送可用动作，服务端执行前再次复核。其他晋角色造成伤害后，持旗者确认询问即可查看自己的全部「赐」，选一个合法势力勾选该组，再交出。快要跳过自己的阶段时，也可在确认后选一枚「赐」移去。取消或变更失败保留「赐」。消费和死亡清理走武将弃牌堆。转交沿用原占用记录。
- **验证依据** · [em_jin001_simayan.lua](../../../../../tests/em_jin001_simayan.lua#L88)。覆盖客籍、转交、阶段恢复、取消、多人持有和转野后按原势力换将。真人联机仅覆盖受赠者的选牌与两种资源结算，范围见[开发状态](../../../status.md#当前验收基线)。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
