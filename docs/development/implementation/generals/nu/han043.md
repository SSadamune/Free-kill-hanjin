## 拔驾

> 锁定技，此武将牌明置后，你将场上一张装备牌置入装备区，称为“舆”；与你势力相同的其他角色视为装备着“舆”；若为君主装备，对应势力角色不能响应你的牌；当你失去“舆”后，你于此阶段结束时失去1点体力并暗置此武将牌。

按持有者和实体装备记录每张「舆」。暗置、失技仍保留状态，装备离开原装备区时清除；暗置失舆可以主动亮将。 [qiao__skill_han043_1](../../../../../pkg/qiao_bingqing/skills/skill_han043_1.lua)

同势力角色借「舆」获得的装备技由[兵情篇虚拟装备接口](../../../../../pkg/qiao_bingqing/virtual_equipment.lua)同步。撤回视为装备的来源时保留该角色的实体装备技能。
