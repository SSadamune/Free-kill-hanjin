## 替军

> 判定阶段开始前，你可以将场上一张延时锦囊牌移至你判定区，或将一张装备牌置入任意角色装备区。若如此做，此阶段改为出牌阶段。

重新核对候选与受保护宝物，按实体牌最终的拥有者及牌区决定是否改为出牌阶段。 [qiao__skill_jin067_1](../../../../../pkg/qiao_bingqing/skills/skill_jin067_1.lua)

<a id="jin067-2"></a>

## 誓众

> 每阶段限一次，你使用【杀】时可以多指定至多X个目标（X为你场上的牌数），若目标角色场上牌数各不相同，你摸等同目标数的牌。

按场上牌数给【杀】增加合法目标，随后比较各目标场上牌数并结算摸牌。 [qiao__skill_jin067_2](../../../../../pkg/qiao_bingqing/skills/skill_jin067_2.lua)
