# QUN139 管亥

[分包索引](../nu.md) · [逐将裁定](../../../../rules/generals/qun139-guanhai.md) · [石激桑卡面原文](../../../../../assets/docs/石激桑武将列表.json#L3477)

## 卸尾

> 每轮各限一次，你可以一张手牌置于武将牌上（称为“饵”），并视为使用【杀】/【闪】。

将一张实体手牌扣作「饵」，分别按轮记录转化【杀】和【闪】的使用次数。两项记录和「饵」随管亥武将牌转移。 [qiao__skill_qun139_1](../../../../../pkg/qiao_bingqing/skills/skill_qun139_1.lua)

<a id="qun139-2"></a>

## 诱阙

> 出牌阶段，你可以用点数最小的“饵”与一名角色拼点：没赢者展示手牌，弃置其中点数大于拼点牌的牌，视为对赢者使用雷【杀】，此牌造成伤害后，你摸一张牌。

用点数最小的「饵」拼点，平局双方分别弃牌；有赢者时才向其使用雷【杀】。 [qiao__skill_qun139_2](../../../../../pkg/qiao_bingqing/skills/skill_qun139_2.lua)
