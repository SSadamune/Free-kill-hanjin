## 殿军

> 回合结束时，你可以执行额外的出牌阶段。每回合限一次，当你需要使用【杀】时，你可以失去1点体力，将一张手牌当【杀】使用。

出【杀】与回合结束的额外出牌阶段分别登记。转化用【杀】时先支付体力，已使用记录随张翼武将牌交换。 [qiao__skill_shu054_1](../../../../../pkg/qiao_bingqing/skills/skill_shu054_1.lua)

<a id="shu054-2"></a>

## 抗锐

> 有角色于其回合内首次扣减体力后，你可以选择一项：1.其回复1点体力；2.其本回合下次造成伤害时，此伤害+1且其本回合手牌上限为0。

记录回合内首次扣减体力，可选择回复或给下次伤害加值，后者生效后修正本回合手牌上限。 [qiao__skill_shu054_2](../../../../../pkg/qiao_bingqing/skills/skill_shu054_2.lua)
