## 霸者求贤状

- **标识与依据** · 君曹操（EM(WEI001)）的派生技能或专属效果，运行时 ID `qiao__skill_em_wei001_banner`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_wei001_banner.lua)和[逐将规则](../../../../rules/generals/em-wei001-caocao.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L229)。

> 魏势力角色的准备阶段，其可以弃置一张牌并暗置一张武将牌，直到其下回合开始，其不能明置、移除、交换或变更此武将牌，且其根据此武将牌的单独阴阳鱼数获得以下一项场上没有的技能：
> ≥4：“突袭”、“骁果”、“常令”、 “巧变”、“断粮”；
> ≤3：“驱虎”、“奇策”、“完杀”、 “胆戾”、“遗计”。

旗标按两档分行显示，当前只省去原文中「巧变」与「胆戾」前的空格。

- **实现与接口** · 魏角色准备阶段先选可暗置的武将牌，再通过弃牌询问确认发动。实际暗置成功后，按该牌的单独阴阳鱼数分档，并重新检查场上公开技能。只有一项时直接授予，多项时再询问选择。高档复用[突袭](../standard/wei004.md#wei004-1)、[骁果](../standard/wei016.md#wei016-1)、[常令](#em-wei001-changling)、[巧变](../standard/wei009.md#wei009-1)和[断粮](../standard/wei010.md#wei010-1)，低档复用[驱虎](../standard/wei013.md#wei013-1)、[奇策](#em-wei001-qice)、[完杀](../standard/qun007.md#qun007-1)、[胆戾](#em-wei001-danli)和[遗计](../standard/wei006.md#wei006-2)。授技独立记账，与暗置牌的明置、移除、交换和变更限制同时到受益者自己的下次 `TurnStart` 为止。若该暗将也印有同名技能，合法的临时来源仍可发动，也不会因此把这张受限的牌明置。
- **验证依据** · [em_wei001_caocao.lua](../../../../../tests/em_wei001_caocao.lua#L105)。覆盖实际暗置与授技、两档候选、同名来源、额外回合在明置询问前到期、限制及合法候选复核。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 常令

- **标识与依据** · 君曹操（EM(WEI001)）的派生技能或专属效果，运行时 ID `qiao__skill_wei024_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei024_1.lua)和[逐将规则](../../../../rules/generals/em-wei001-caocao.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5263)的 WEI024 条目。

> 准备阶段，你可以将一张手牌交给一名其他势力角色，对其发起一次“军令”。若其执行，你摸一张牌；若其不执行，你于本回合摸牌阶段多摸三张牌。

- **实现与接口** · 持有者自己的准备阶段可以交一张手牌给一名其他势力角色，并以军令公共入口向其发令。对方执行时持有者摸一张，未执行时把三张额外摸牌登记到持有者本回合摸牌阶段。魏旗授予时按持有者实际势力取目标。
- **验证依据** · [em_wei001_caocao.lua](../../../../../tests/em_wei001_caocao.lua#L749)。覆盖军令执行与拒绝后摸牌，及客将或未确定势力的目标。

## 奇策

- **标识与依据** · 君曹操（EM(WEI001)）的派生技能或专属效果，运行时 ID `qiao__skill_wei020_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei020_1.lua)和[逐将规则](../../../../rules/generals/em-wei001-caocao.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5148)的 WEI020 条目。

> 出牌阶段限一次，你可以将所有手牌当任意一种普通锦囊牌使用（不能为目标数大于转化所用牌数的牌或【挟天子以令诸侯】），然后你可以变更副将。

- **实现与接口** · 普通出牌时把全部手牌转换为允许的汉晋普通锦囊，先按本牌自己声明的固定、手选或成组目标校验材料数，再走实际用牌。其他效果在用牌后追加的目标由额外目标机制处理。大旗授予者共享一次成功变更副将的机会，可在转化成功后走公共变更入口。房间禁用、牌面单独鱼数及建安锁定按公共流程复核，成功时旧副将进入武将弃牌堆。
- **验证依据** · [em_wei001_caocao.lua](../../../../../tests/em_wei001_caocao.lua#L783)。覆盖真实转换、客户端的目标候选、公开候选来源、整局共享变更和旧将去向。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 胆戾

- **标识与依据** · 君曹操（EM(WEI001)）的派生技能或专属效果，运行时 ID `qiao__skill_wei044_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei044_1.lua)和[逐将规则](../../../../rules/generals/em-wei001-caocao.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5443)的 WEI044 条目。

> 当你受到伤害后，你可以选择一项：1.摸牌至与来源相同（至多摸五张）；2.移除副将并回复1点体力，然后来源弃置手牌至与你相同。

- **实现与接口** · 受伤后根据当前状态列出摸牌和移将两项。摸牌需要活着的来源且最多补五张。若副将可移除，即使没有来源也可移除并回复 1 点，再在来源仍存活时要求其弃置手牌。
- **验证依据** · [em_wei001_caocao.lua](../../../../../tests/em_wei001_caocao.lua#L809)。覆盖两分支、受保护副将、无来源闪电和死亡来源。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
