## 鬻爵

- **标识与依据** · 刘宏（HAN003，权包），运行时 ID `qiao__skill_han003_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han003_1.lua)、[汉晋军令公共规则](../../../../../pkg/qiao_mode/rules/junling.lua)、[权包模式规则](../../../../../pkg/qiao_mode/skills/quan_rules.lua)和[逐将规则](../../../../rules/generals/han003-liuhong.md)。

> 每名角色的出牌阶段开始时，你可以弃置一张牌并对其发起“军令”：若其执行，其本回合下次造成伤害后摸两张牌；若其不执行，你暗置其一张武将牌且其本回合不能明置之（若其已有暗置的武将牌，则改为令其叠置）。

- **实现与接口** · 任意在场角色出牌阶段开始时，刘宏可弃置一张牌并通过汉晋军令公共入口对其发令（允许对自己发动）。对方执行时，在目标身上登记本回合延时标记 `qiao_han003_yujue_draw-turn`，由房间级 `qiao__quan_rules` 承接本回合下一次造成伤害后摸两张牌（刘宏离场或暗置后依然生效），并同步展示在角色状态面板。不执行时，若目标已有暗置武将牌则执行汉晋定向叠置（已叠置不反向平置），否则由刘宏选择其一张可暗置的普通武将牌暗置并添加本回合禁止明置标记。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)。覆盖执行分支跨暗置延时摸 2、不执行暗置禁明置与已有暗置时定向叠置。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
