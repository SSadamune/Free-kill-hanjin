## 守玺

- **标识与依据** · 曹节（HAN021，权包，客将势力：魏），运行时 ID `qiao__skill_han021_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han021_1.lua)和[逐将规则](../../../../rules/generals/han021-caojie.md)。

> 与你势力相同的角色装备区的一张牌被其他势力角色不因弃置而移动时，你可以弃置一张同花色的牌并防止之。

- **实现与接口** · 监听 `fk.BeforeCardsMove`，筛选来源为同势力角色装备区、操作方为其他势力角色且原因不为 `fk.ReasonDiscard` 的待移动项。若引擎在使用或打出材料进入处理区时省略操作方，从直接关联的用牌或打出事件核对实体牌和实际操作者。面对多张装备牌同批移动时逐张判定，每张分别询问曹节是否弃置一张同花色牌并通过 `room:cancelMove` 单独防止该张移动。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)、[quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖多张异花色装备同批移动逐张防止、弃置原因不触发，以及【甘露】交换装备、【决堰】由异势力角色将同势力角色的装备当冰【杀】使用。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 悬壶

- **标识与依据** · 曹节（HAN021，权包），运行时 ID `qiao__skill_han021_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han021_2.lua)、[权包模式规则](../../../../../pkg/qiao_mode/skills/quan_rules.lua)和[逐将规则](../../../../rules/generals/han021-caojie.md)。

> 每回合结束时，若本回合你的红色牌置入过弃牌堆，你可以令一名角色摸或弃置一张牌，然后若其手牌数等于体力值，其回复1点体力。

- **实现与接口** · 由 `qiao__quan_rules` 在 `fk.AfterCardsMove` 中追踪角色手牌区与装备区实体红牌直接或经处理区置入弃牌堆的记录（严格排除判定区红牌）。回合结束时，曹节选定目标并由曹节决定令其摸 1 牌或弃 1 牌；执行后若目标手牌数等于体力值且已受伤，令其回复 1 点体力。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)。覆盖判定区红牌不计入、手牌红牌计入、曹节选摸弃及手牌等于体力值后回复。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
