## 乘隙

- **标识与依据** · 卫瓘（JIN021，权包），运行时 ID `qiao__skill_jin021_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin021_1.lua)和[逐将规则](../../../../rules/generals/jin021-weiguan.md)。

> 准备阶段，你可以令一名角色视为使用【以逸待劳】，然后使用者对以此法弃置了非基本牌的目标角色各造成1点伤害。

- **实现与接口** · 准备阶段选择一名在场角色（允许卫瓘自己）视为使用虚拟 `qiao__await_exhausted`（按 `H.compareKingdomWith` 确定同势力目标，未确定势力时仅指定其自己）。结算完成后通过 `room.logic:getEventsByRule(GameEvent.MoveCards, ...)` 追溯本次 `CardEffect` 内由 `await_exhausted_skill` 实际弃置过至少一张非基本牌的目标（排除被【无懈可击】抵消者，包含使用者本人），按座次由使用者逐一造成 1 点普通伤害。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖使用者自身弃置非基本牌受自身伤害、仅弃基本牌目标免伤及伤害来源归属使用者。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 追诛

- **标识与依据** · 卫瓘（JIN021，权包），运行时 ID `qiao__skill_jin021_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin021_2.lua)、[汉晋军令公共规则](../../../../../pkg/qiao_mode/rules/junling.lua)和[逐将规则](../../../../rules/generals/jin021-weiguan.md)。

> 轮次技，当一名角色受到致命伤害时，你可以对其发起“军令”。若其执行，你可以防止此伤害；若其不执行，此伤害翻倍。

- **实现与接口** · 轮次技（`Player.HistoryRound`），监听 `fk.DamageInflicted`，在当前伤害值不小于目标当前体力值时触发（允许卫瓘自己受致命伤害时发动）。调用汉晋军令公共入口：目标若在军令中阵亡则防止原伤害；执行且存活时由卫瓘自选是否防止伤害；不执行则将当前伤害值翻倍。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖对自己致命伤害发动并选择防止、轮次重置后不执行令伤害翻倍。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
