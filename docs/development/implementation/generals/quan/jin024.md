## 伤败

- **标识与依据** · 贾南风（JIN024，权包），运行时 ID `qiao__skill_jin024_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin024_1.lua)、[权包共用辅助](../../../../../pkg/qiao_generals/util/quan_common.lua)和[逐将规则](../../../../rules/generals/jin024-jiananfeng.md)。

> 当你对其他角色造成伤害后，你可以令其弃置每个区域各一张牌。

- **实现与接口** · 监听 `fk.Damage`，在目标存活在场且至少有一个区域存在可弃牌时可发动，调用共用 `Quan.discardOnePerArea` 令目标依次从手牌区、装备区、判定区各弃置一张牌（空区跳过，允许弃置判定区延时锦囊）。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖三区同时有牌时逐区各弃置一张。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 废戮

- **标识与依据** · 贾南风（JIN024，权包），运行时 ID `qiao__skill_jin024_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin024_2.lua)、[单技能失去入口](../../../../../pkg/qiao_mode/rules/qun_duanchang.lua)和[逐将规则](../../../../rules/generals/jin024-jiananfeng.md)。

> 每名角色限一次，当一名角色进入濒死时，你可以令其选择一项：1.你移除其一个武将，其回复1点体力；2.你失去此技能，其死亡。

- **实现与接口** · 监听 `fk.EnterDying`（允许贾南风自己濒死时发动），按将牌来源在房间标签 `qiao_jin024_feilu_used_v1` 记录每名目标限一次。选项 1 仅在目标存在可移除的普通武将牌（排除君主、明置专属野心家与士兵／翼从）时可选，暗置将位仅展示 `mainGeneral` / `deputyGeneral` 不泄露暗将名，移除后目标回复 1 点体力；选项 2 通过 `Duanchang.loseCardSkill` 将失去【废戮】永久记在贾南风将牌上，并调用 `room:killPlayer { who = target }` 按无伤害来源直接结算死亡。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖暗置将不泄密移除回血、每名角色限一次、无可移除普通武将时强制选项 2、失技归属将牌及无来源直接死亡。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
