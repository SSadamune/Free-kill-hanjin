## 庸肆

- **标识与依据** · 袁术（QUN021，权包，客将势力：汉），运行时 ID `qiao__skill_qun021_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun021_1.lua)、[汉晋军令公共规则](../../../../../pkg/qiao_mode/rules/junling.lua)、[权包模式规则](../../../../../pkg/qiao_mode/skills/quan_rules.lua)和[逐将规则](../../../../rules/generals/qun021-yuanshu.md)。

> 出牌阶段限一次，你可以对本回合摸过牌的一名其他角色发起“军令”。若其不执行，你获得其所有手牌，然后交给其等量的牌。

- **实现与接口** · 由 `qiao__quan_rules` 在 `fk.AfterCardsMove` 中为本回合执行过 `fk.ReasonDraw` 的角色写入公开标记 `qiao_quan_drawn-turn`，供客户端与服务端统一筛选目标。不执行军令时，获得目标所有手牌并按实际获得的张数（非事前手牌数）要求袁术从手牌和装备区交回等量牌（不足则全交）。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖摸牌标记区分非摸牌移牌、真实客户端目标筛选及按实得张数交还手牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 伪帝

- **标识与依据** · 袁术（QUN021，权包），运行时 ID `qiao__skill_qun021_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun021_2.lua)和[逐将规则](../../../../rules/generals/qun021-yuanshu.md)。

> 锁定技，若场上没有【玉玺】，你视为装备着【玉玺】；当你成为【知己知彼】的目标后，你展示所有手牌。

- **实现与接口** · 锁定技。通过两端共用的 `Quan.virtualJadeSealActive` 实时判断场上公开装备区是否存在实体【玉玺】：不存在时经由 `bigkingdom`、`fk.DrawNCards` 与 `fk.EventPhaseStart` 提供【玉玺】大势力、摸牌 +1 及出牌阶段开始时视为使用【知己知彼】效力（不计装备数、不可被弃获或交换），实体【玉玺】入场后立即让位。另监听 `fk.TargetConfirmed`，成为【知己知彼】目标后展示全部手牌。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖无实体玉玺生效、实体玉玺入场让位及成为【知己知彼】目标后亮牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
