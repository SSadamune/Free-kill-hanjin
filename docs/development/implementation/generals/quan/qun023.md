## 从谏

- **标识与依据** · 张绣（QUN023，权包，客将势力：魏；统领 `{胡车儿(限一) | 顺手牵羊}`），运行时 ID `qiao__skill_qun023_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun023_1.lua)、[偏将胡车儿](retinue-hucheer.md)和[逐将规则](../../../../rules/generals/qun023-zhangxiu.md)。

> 锁定技，当其他角色于你回合内造成伤害时，或你于回合外造成伤害时，此伤害+1。

- **实现与接口** · 锁定技，监听 `fk.DamageCaused`（要求存在伤害来源 `data.from ~= nil`），按当前回合角色判定双向加伤，排除无来源伤害。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖回合内他人加伤、自己不加伤及回合外联动【附敌】伤害叠加。

## 附敌

- **标识与依据** · 张绣（QUN023，权包），运行时 ID `qiao__skill_qun023_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun023_2.lua)和[逐将规则](../../../../rules/generals/qun023-zhangxiu.md)。

> 当你受到伤害后，你可以交给来源一张手牌，然后对其势力中体力值最大且大于等于你的一名角色造成1点伤害。

- **实现与接口** · 监听 `fk.Damaged`，伤害来源须为在场其他角色且张绣有手牌。先执行交出 1 张手牌（不因后续无合法伤害目标而禁止交牌），再通过 `H.compareKingdomWith` 检索来源所属势力在场角色（未确定势力时自然包含来源本人）中体力值最大且不小于张绣当前体力者，选一人造成 1 点普通伤害。
- **机器人策略** · 沿用上述候选。比较实际伤害的收益、交出手牌的费用及对方获得此牌的收益。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖未确定势力来源、交牌后对来源造成伤害及回合外与【从谏】叠加为 2 点。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
