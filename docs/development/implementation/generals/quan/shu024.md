## 定军

- **标识与依据** · 法正（SHU024，权包，客将势力：群），运行时 ID `qiao__skill_shu024_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu024_1.lua)和[逐将规则](../../../../rules/generals/shu024-fazheng.md)。

> 摸牌阶段结束时，你可以交给一名其他角色两张手牌，其需视为对你选择的另一名角色使用任意一种【杀】，否则交给你至少两张手牌。

- **实现与接口** · 摸牌阶段结束时，法正选择两张手牌交给一名其他角色 A，再选择一名不为 A 的在场角色 B（允许选择法正本人）。由 A 选择视为对 B 使用一种合法汉晋【杀】（普／火／雷／冰，无视距离与通常次数），或交回至少两张手牌（`ReasonGive`，可自然触发【恩怨】）。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)。覆盖选择法正本人作为目标 B、虚拟火【杀】分支与拒绝出杀交回两张手牌联动【恩怨】分支。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 恩怨

- **标识与依据** · 法正（SHU024，权包），运行时 ID `qiao__skill_shu024_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu024_2.lua)和[逐将规则](../../../../rules/generals/shu024-fazheng.md)。

> 锁定技，其他角色交给你至少两张牌后，令其摸一张牌；当你受到其他角色的伤害后，令其需展示并交给你一张红桃牌，否则失去1点体力。

- **实现与接口** · 锁定技。第一段监听 `fk.AfterCardsMove`，按同一批移牌中 `fk.ReasonGive` 交给法正的张数汇总，满两张即令对应交牌者按座次依次摸一张牌（配合汉晋军令二 `proposer` 归属联动）。第二段监听 `fk.Damaged`，每次伤害事件触发一次（不按伤害点数重复），令伤害来源从手牌或装备区展示并交给一张红桃牌，否则失去 1 点体力。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)。覆盖军令二交牌触发、定军回交触发、单次 2 点伤害仅结算一次及有／无红桃牌两分支。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
