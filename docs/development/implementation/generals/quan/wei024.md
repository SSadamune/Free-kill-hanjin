## 常令

- **标识与依据** · 于禁（WEI024，权包，客将势力：汉、蜀、吴），运行时 ID `qiao__skill_wei024_1`，与[君曹操【霸者求贤状】](em-wei001.md#em-wei001-changling)共用同一实现。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei024_1.lua)、[汉晋军令公共规则](../../../../../pkg/qiao_mode/rules/junling.lua)和[逐将规则](../../../../rules/generals/wei024-yujin.md)。

> 准备阶段，你可以将一张手牌交给一名其他势力角色，对其发起一次“军令”。若其执行，你摸一张牌；若其不执行，你于本回合摸牌阶段多摸三张牌。

- **实现与接口** · 正式登记于禁卡面及汉、蜀、吴三项客将势力，直接复用已验证的 `qiao__skill_wei024_1`；其内部发起的 `H.askToCommand` 自动接入汉晋军令公共适配（军令一可选择执行者且排除移出游戏的角色、军令二交牌 `proposer` 归属、军令五定向叠置）。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)、[em_wei001_caocao.lua](../../../../../tests/em_wei001_caocao.lua#L749)。覆盖多客将登记、不执行多摸 3 张及与君曹操大旗回归兼容。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
