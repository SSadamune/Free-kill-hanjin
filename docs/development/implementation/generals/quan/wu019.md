## 决堰

- **标识与依据** · 陆抗（WU019，权包，主将 `mainHpAdjust = -1`），运行时 ID `qiao__skill_wu019_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu019_1.lua)、[权包模式规则](../../../../../pkg/qiao_mode/skills/quan_rules.lua)和[逐将规则](../../../../rules/generals/wu019-lukang.md)。

> 主将技（☯️-1），准备阶段，你可以选择区域内一张牌，令一名其他角色将此牌当冰【杀】对你使用，然后你令本回合摸牌阶段摸牌数、使用【杀】次数、攻击范围共计+3。

- **实现与接口** · 标记 `Skill.MainPlace`。准备阶段筛选陆抗手牌、装备或判定区中可由其他在场角色当 `qiao__ice__slash` 对陆抗使用（无视距离与次数）的牌，待该冰【杀】完整结算后，在【州郡领兵印】的三栏面板一次分配 3 点。各栏从零开始，可撤回已分配点数，合计为 3 时才能确认。关闭或超时默认 3 点加摸牌。增益分别记入本回合摸牌数、出【杀】次数、攻击范围三项标记，由 `qiao__quan_rules` 承接结算并同步展示在角色状态面板。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖判定区延时锦囊转化冰【杀】、结算后三项各 +1 分配及对应摸牌／出杀／攻击范围与状态面板核对。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 恪守

- **标识与依据** · 陆抗（WU019，权包），运行时 ID `qiao__skill_wu019_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu019_2.lua)、[应变规则](../../../../../pkg/qiao_mode/rules/adaptation.lua)和[逐将规则](../../../../rules/generals/wu019-lukang.md)。

> 你可以将两张牌当【闪】或【无懈可击】使用且具有<孤军→获得或消耗一枚阴阳鱼标记>。

- **实现与接口** · 转化技，仅限“使用”窗口（`enabled_at_response` 拒绝 `response == true` 的纯打出请求），通过 `Adaptation.setCardEntries` 挂载正式汉晋应变条目 `{ condition = "gujun", effect = "qiao_keshou_yinyangfish" }`；满足孤军且无阴阳鱼时直接获得 1 枚，已有阴阳鱼时可选获得 1 枚或消耗 1 枚直接兑现摸 1 牌／本回合手牌上限 +2。另在 `skill_source_labels.lua` 中对描述里的尖括号做富文本转义，保证客户端详情完整显示。
- **材料与用牌回复** · 发动条件合并 `getHandlyIds()` 和装备区牌并去重。选牌面板通过引擎的 `handly_pile` 展开“辎”。服务端处理求【闪】的回复时，使用选牌框回传的牌名重建转化牌。
- **验证依据** · [quan_han_wei_shu.lua](../../../../../tests/quan_han_wei_shu.lua)、[quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖富文本转义、纯打出禁用和孤军的阴阳鱼效果。原生用牌请求覆盖两张“辎”转【闪】抵消【杀】，以及一张手牌加一张“辎”转【无懈可击】抵消【决斗】。两例均核对材料进入弃牌堆、【木牛流马】留在装备区。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
