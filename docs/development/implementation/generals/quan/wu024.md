## 补益

- **标识与依据** · 吴国太（WU024，权包，客将势力：蜀），运行时 ID `qiao__skill_wu024_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu024_1.lua)、[汉晋军令公共规则](../../../../../pkg/qiao_mode/rules/junling.lua)和[逐将规则](../../../../rules/generals/wu024-wuguotai.md)。

> 每回合限一次，与你势力相同的角色脱离濒死时，你可以对来源发起一次“军令”。若其不执行，该濒死角色回复1点体力。

- **实现与接口** · 监听 `fk.AfterDying`，仅当同势力角色存活脱离濒死（`not target.dead and target.hp >= 1`）且存在在场伤害来源（含自伤来源）时可每回合发动一次。调用汉晋军令公共入口，对方不执行时令该角色回复 1 点体力。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖同势力脱离濒死（含自伤来源）、军令不执行回复 1 血。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 甘露

- **标识与依据** · 吴国太（WU024，权包），运行时 ID `qiao__skill_wu024_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu024_2.lua)和[逐将规则](../../../../rules/generals/wu024-wuguotai.md)。

> 出牌阶段限一次，你可以选择两名装备区牌数差小于等于X的角色（X为你已损失体力值），令这些角色交换装备区的所有牌。

- **实现与接口** · 出牌阶段主动技，使用 `Fk:currentRoom()` 校验两名在场角色装备数之差不超过已损体力值且不同时为空。与马隆【锋械】共用 [equipment_exchange.lua](../../../../../pkg/qiao_mode/rules/equipment_exchange.lua)，在移动前的触发与延后刷新结束后逐张核对并预留落栏位置。采用两段式处理区移牌（先统一 `ReasonExchange` 至处理区，再按对方当前可用空栏依次置入，兼容双副类别坐骑、废除栏位、曹节【守玺】与君孙权【聚宝】留场，未落栏者清理入弃牌堆）。
- **验证依据** · [quan_wu_qun_jin.lua](../../../../../tests/quan_wu_qun_jin.lua)。覆盖真实客户端目标筛选及与曹节【守玺】单张防止移动联动。[装备交换回归](../../../../../tests/jin023_malong.lua)另覆盖入栏前宝物栏被其他效果填充。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
