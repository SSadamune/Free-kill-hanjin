- **标识与依据** · 吉平（HAN019，势包），运行时 ID `qiao__skill_han019_1`。见[源码](../../../../pkg/qiao_generals/skills/skill_han019_1.lua)和[逐将规则](../../../rules/generals/han019-jiping.md)。
