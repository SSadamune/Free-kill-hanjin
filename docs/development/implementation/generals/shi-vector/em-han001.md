## 初平

- **标识与依据** · 君刘协（EM(HAN001)，矢包），运行时 ID `qiao__skill_em_han001_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_han001_1.lua)和[逐将规则](../../../../rules/generals/em-han001-liuxie.md)。

> 君主技，此武将牌明置后，你获得游戏外的“诏书”；你因“诏书”获得的势力锦囊由你选择。

- **实现与接口** · 这张君主牌实际明置后取得唯一[诏书](#em-han001-banner)。若标记已有持有者，明置刷新只同步状态。君刘协以此途径取得势力锦囊时，公共消费入口让其选择实际可得的牌。

## 转蓬

- **标识与依据** · 君刘协（EM(HAN001)，矢包），运行时 ID `qiao__skill_em_han001_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_han001_2.lua)和[逐将规则](../../../../rules/generals/em-han001-liuxie.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L147)。

> 当你成为伤害牌的唯一目标后，你可以交给使用者一张牌并令此牌对你无效；若你已使用过其势力锦囊，改为其需交给你一张牌，否则此牌对你无效。

- **实现与接口** · 君刘协成为伤害牌唯一目标时，按他是否已使用过来源势力的锦囊选正向或反向。正向确认自己的合法牌并执行交牌后使伤害牌对自己无效，牌被天授改移仍视为完成这一动作。反向由来源选择给牌，按本次移动记录核对君刘协实际收到的牌，未收到时才令伤害牌无效。
- **验证依据** · [em_han001_liuxie.lua](../../../../../tests/em_han001_liuxie.lua#L111)。用真实【杀】覆盖正反向，正向对【赤霄剑】及【玉玺】检查改入诏书、对方未收牌且伤害不结算。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 天授

- **标识与依据** · 君刘协（EM(HAN001)，矢包），运行时 ID `qiao__skill_em_han001_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_han001_3.lua)和[逐将规则](../../../../rules/generals/em-han001-liuxie.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L148)。

> 锁定技，其他角色的【玉玺】或【赤霄剑】置入场上或弃牌堆时，改为置入你装备区。当你从装备区失去这些牌时，改为置于“诏书”上并摸两张牌。

- **实现与接口** · 移牌前把其他角色的【玉玺】或【赤霄剑】即将进场或进弃牌堆的条目改为置入君刘协装备区，并保留该批其他牌的记录。君刘协从装备区失去这两种装备时则置于诏书，其后按符合条件的移牌结果摸两张。
- **验证依据** · [em_han001_liuxie.lua](../../../../../tests/em_han001_liuxie.lua#L201)。覆盖实际改移、装备离区后的摸牌、诏书普通移牌不误触发及私有牌堆不受影响。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 诏书

- **标识与依据** · 君刘协（EM(HAN001)）的派生技能或专属效果，运行时 ID `qiao__skill_em_han001_banner`。见[源码](../../../../../pkg/qiao_generals/skills/skill_em_han001_banner.lua)和[逐将规则](../../../../rules/generals/em-han001-liuxie.md)。持有者使用独立的[消费入口](../../../../../pkg/qiao_generals/skills/skill_em_han001_consume.lua) `qiao__skill_em_han001_consume`。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L157)与[诏书-牌面.jpg](../../../../../assets/bilibili%20articles/cards/指示物/诏书-牌面.jpg)。

> 与你势力相同的角色出牌阶段限一次，其可以将一张（若为小势力则改为至多两张）手牌置于此牌上。
> 出牌阶段限一次，若此牌上的牌包含四种花色，你可以移去此牌上的所有牌，然后随机获得一张势力锦囊。

当前把两段分给交牌和消费两个入口。消费说明写「若诏书上的牌包含四种花色，你可以移去所有牌，然后获得一张势力锦囊」，省去原文「随机」。初平有效时由君刘协选择，其余持有者仍随机获得，见[诏书结算](../../../../rules/generals/em-han001-liuxie.md#初平与诏书)。

- **实现与接口** · 房间将诏书持有者和上面的实体牌分别记账。同公开势力角色取得交牌入口，持有者另取得消费入口。用手牌支付的数量按当前大小势力计算，消费复核四种花色后移去全部实体牌。若获牌者是有效初平的持有者，由其选择可得的势力锦囊。持有者被移出时标记仍归其所有，入口依在场状态暂停。
- **验证依据** · [em_han001_liuxie.lua](../../../../../tests/em_han001_liuxie.lua)。覆盖实际交牌与消耗、敕令授予、暂停入口、实体是否仍可用及明置不会重建。客户端用五张含重复花色的牌核对面板计数和四个花色；移走唯一的方块后，面板同步减为三种花色。面板与弹窗见[诏书牌堆入口](../../skill-ui.md#诏书牌堆入口)。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
