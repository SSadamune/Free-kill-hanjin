## 锋引

> 锁定技，你相邻角色成为与你势力相同的角色使用普通【杀】的目标后，你令其不能响应。

成为目标后按当前座次找相邻角色，将该目标加入本次普通【杀】的不可响应名单。 [qiao__skill_han047_1](../../../../../pkg/qiao_bingqing/skills/skill_han047_1.lua)

<a id="han047-2"></a>

## 径出

> 当你于回合内使用牌后，你可以令一名角色本回合移出游戏，然后若场上仅剩你和一名其他角色，你摸两张牌且交给其一张牌，若你与其势力相同，其可以用一个武将交换此武将。

先完成移出，再数仍在场的角色；只剩两人时才结算摸牌、交牌和可选的武将交换。 [qiao__skill_han047_2](../../../../../pkg/qiao_bingqing/skills/skill_han047_2.lua)
