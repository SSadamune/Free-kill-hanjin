## 唆令

> 出牌阶段限一次，你可以将一张黑色手牌交给一名其他角色并指定另一名角色，令其选择一项：1.将两张黑色手牌当【杀】对后者使用；2.后者可以对其使用任意张【杀】。

服务端复核两张黑色手牌及用杀目标。连续出杀使用具体牌名候选，收牌人的暗手牌颜色不改变其他人看到的读条。 [qiao__skill_han051_1](../../../../../pkg/qiao_bingqing/skills/skill_han051_1.lua)

<a id="han051-2"></a>

## 趋奉

> 每回合限一次，你交给或得到其他角色牌后，若你手牌数大于其，你可以与其各摸一张牌。

从同批移动中核对交牌双方，以移动结束后的手牌数判断是否可以各摸一张。 [qiao__skill_han051_2](../../../../../pkg/qiao_bingqing/skills/skill_han051_2.lua)
