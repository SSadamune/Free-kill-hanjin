# JIN066 胡奋

[分包索引](../shi-vector.md) · [逐将裁定](../../../../rules/generals/jin066-hufen.md) · [石激桑卡面原文](../../../../../assets/docs/石激桑武将列表.json#L2335)

## 威惠

> 主将技，你的手牌上限+1；此武将牌被明置或交换后，你可以摸一张牌。

主将位提供手牌上限修正，并通过胡奋的公共明置、交换记录触发摸牌。 [qiao__skill_jin066_1](../../../../../pkg/qiao_bingqing/skills/skill_jin066_1.lua)

<a id="jin066-2"></a>

## 练战

> 副将技，你的攻击范围+1；此武将牌被明置或交换后，你可以视为使用一张目标+1的【杀】。

副将位提供攻击范围修正，明置或交换后用普通目标选择流程使用至多两个目标的虚拟【杀】。 [qiao__skill_jin066_2](../../../../../pkg/qiao_bingqing/skills/skill_jin066_2.lua)

<a id="jin066-3"></a>

## 转征

> 结束阶段，你可以交换主副将，或令一名与你势力相同的其他角色选择是否与你交换副将。

结束阶段枚举合法交换组合，和同势力角色交换副将前由对方确认。 [qiao__skill_jin066_3](../../../../../pkg/qiao_bingqing/skills/skill_jin066_3.lua)
