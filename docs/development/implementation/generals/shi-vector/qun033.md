# QUN033 蔡夫人

## 窃听

> 其他角色的结束阶段，若其本回合未对与其势力不同的角色使用过手牌，你可以摸一张牌，或将其装备区的一张牌移动给你。

记录手牌使用及目标势力，结束阶段筛出能移动的装备。仅有受公开【聚宝】保护的宝物时仍可摸牌。 [qiao__skill_qun033_1](../../../../../pkg/qiao_bingqing/skills/skill_qun033_1.lua)

<a id="qun033-2"></a>

## 献州

> 限定技，出牌阶段，你可以将装备区的所有牌交给一名其他角色，回复等量体力，其对攻击范围内至多等量名角色各造成1点伤害。

按交给另一角色的装备结算回复，再由收牌人从其攻击范围内选择伤害目标。 [qiao__skill_qun033_2](../../../../../pkg/qiao_bingqing/skills/skill_qun033_2.lua)
