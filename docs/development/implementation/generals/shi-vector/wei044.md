## 胆戾

> 当你受到伤害后，你可以选择一项：1.摸牌至与来源相同（至多摸五张）；2.移除副将并回复1点体力，然后来源弃置手牌至与你相同。

复用现有【胆戾】。无来源伤害后仍可移除副将并回复体力。 [qiao__skill_wei044_1](../../../../../pkg/qiao_generals/skills/skill_wei044_1.lua)

## 脱先

> 每回合限一次，与你势力相同的角色进入濒死时，你可以令另一名与你势力相同的角色选择是否用一个武将交换其一个武将。

由程昱选定的同势力角色决定是否交换，以及用哪两个武将位置交换。 [qiao__skill_wei044_2](../../../../../pkg/qiao_bingqing/skills/skill_wei044_2.lua)
