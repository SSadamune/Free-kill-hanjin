## 铁脊

> 你可以将两张牌当目标+1的火【杀】使用，然后选择一名与你势力相同的其他角色，若此火【杀】伤害数大于1，则你与其补充阴阳鱼标记，否则其选择是否用一个武将交换此武将。

两张实体牌转成火【杀】，在用牌结算结束后按该次用牌的伤害数处理阴阳鱼或交换。 [qiao__skill_wu027_1](../../../../../pkg/qiao_bingqing/skills/skill_wu027_1.lua)

<a id="wu027-2"></a>

## 醇义

> 与你势力相同的角色可以将国战标记当【酒】使用。

程普明置后，服务端只给符合公开势力关系且没有本体技能的角色同步转化入口。明暗置、势力变化或失去技能时重新计算入口。可用的角色选择并支付国战标记，使用虚拟【酒】。 [qiao__skill_wu027_2](../../../../../pkg/qiao_bingqing/skills/skill_wu027_2.lua)
