## 密重

> 锁定技，当你受到伤害时，若你的手牌数等于体力值，此伤害-1。

在即将受到伤害时比较手牌数与当前体力值，恰好相等才减伤。 [qiao__skill_wu032_1](../../../../../pkg/qiao_bingqing/skills/skill_wu032_1.lua)

## 秉壹

> 每阶段限一次，当你因弃置而失去牌后，你可以展示手牌，若颜色均相同，你令至多等同你手牌数的角色各摸一张牌。

弃置后展示剩余手牌，确认同色后按手牌数限制可选择的摸牌角色数。 [qiao__skill_wu032_2](../../../../../pkg/qiao_bingqing/skills/skill_wu032_2.lua)
