## 烈医

- **标识与依据** · 吉平（HAN019，势包），运行时 ID `qiao__skill_han019_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han019_1.lua)和[逐将规则](../../../../rules/generals/han019-jiping.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L856)。

> 当你对一名角色造成伤害后，你可以令其回复至多2点体力，然后防止你本回合你再造成伤害。

- **实现与接口** · 吉平对一名角色造成伤害后（`fk.Damage`），可以选择令其回复 1 或 2 点体力。在本回合建立后续的伤害防止记录，之后由房间规则防止吉平再造成伤害。
- **验证依据** · [han019_jiping.lua](../../../../../tests/han019_jiping.lua#L60)。核对两种回复量，以及发动后下一次伤害被防止。

## 蛊毒

- **标识与依据** · 吉平（HAN019，势包），运行时 ID `qiao__skill_han019_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han019_2.lua)和[逐将规则](../../../../rules/generals/han019-jiping.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L857)。

> 每回合限一次，其他角色回复体力时，你可以防止之。若如此做，当前回合结束时其失去1点体力，然后若其仍存活，你移除此武将牌。

- **实现与接口** · 其他角色即将回复体力时（`fk.PreHpRecover`），吉平可以防止这次回复并记录目标和实际提供蛊毒的武将牌。当前回合结束时先令目标失去 1 点体力。目标存活时，按牌身份移除吉平来源牌，即使它已通过交换离开原位置。
- **验证依据** · [han019_jiping.lua](../../../../../tests/han019_jiping.lua#L81)。核对防止回复、回合末扣体力和移除，并验证交换后找到原武将牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
