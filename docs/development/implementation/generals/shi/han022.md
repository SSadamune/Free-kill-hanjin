## 绥抚

- **标识与依据** · 刘虞（HAN022，势包），运行时 ID `qiao__skill_han022_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han022_1.lua)和[逐将规则](../../../../rules/generals/han022-liuyu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L895)。

> 每回合结束时，若存活角色之中有至少两名小势力角色于本回合受到过伤害，你可以令当前回合角色将所有手牌置于牌堆顶，你视为使用一张由你指定结算起点的【五谷丰登】。

- **实现与接口** · 回合结束时（`fk.TurnEnd`），刘虞检查本回合受过伤且仍存活的小势力角色是否至少两名。发动后先令当前回合角色把全部手牌置于牌堆顶，再从刘虞选定的起点结算虚拟【五谷丰登】。
- **验证依据** · [han022_liuyu.lua](../../../../../tests/han022_liuyu.lua#L83)。实际使用【五谷丰登】，验证从选中的起点按顺序取牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 安境

- **标识与依据** · 刘虞（HAN022，势包），运行时 ID `qiao__skill_han022_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han022_2.lua)和[逐将规则](../../../../rules/generals/han022-liuyu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L896)。

> 每回合限一次，与你势力相同的角色受到伤害后，你可以令与你势力相同的角色各摸一张牌。

- **实现与接口** · 同势力角色受伤后（`fk.Damaged`），刘虞可以令当前与其同势力的角色各摸一张牌。每回合至多执行一次，结算时按在场角色的当前势力取名单。
- **验证依据** · [han022_liuyu.lua](../../../../../tests/han022_liuyu.lua#L59)。核对同势力受伤后的摸牌及同一回合限次。
