- **标识与依据** · 王浑（JIN017）的派生技能或专属效果，运行时 ID `qiao__skill_jin017_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin017_3.lua)和[逐将规则](../../../../rules/generals/jin017-wanghun.md)。

遄征牌面括注见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1845)，其中的献捷原文如下。

> 你可以将一张非伤害牌当【铁索连环】<富甲→目标+1>使用

当前技能面板将应变括号显示为「〈〉」，并以句号结束。

- **验证依据** · [jin017_wanghun.lua](../../../../../tests/jin017_wanghun.lua#L31)。用例验证获得献捷。尚未单独验证真实用牌触发富甲。
- **未完成与边界** · 反馈 27 已复现。可用性、选牌和构造均读取错误的牌属性，待改用汉晋伤害牌判定并验证【杀】被拒绝、【闪电】和装备可用。
