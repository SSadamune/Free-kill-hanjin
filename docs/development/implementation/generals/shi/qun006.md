## 横征

- **标识与依据** · 董卓（QUN006，势包），运行时 ID `qiao__skill_qun006_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun006_1.lua)和[逐将规则](../../../../rules/generals/qun006-dongzhuo.md)。

> 准备阶段，若你的体力值为1或没有手牌，你可以获得每名其他角色区域里各一张牌。

- **实现与接口** · 准备阶段董卓体力为 1 或没有手牌时，可从每名其他在场角色的区域各获得一张牌。取得后继续正常阶段流程，摸牌阶段照常执行。

## 暴凌

- **标识与依据** · 董卓（QUN006，势包），运行时 ID `qiao__skill_qun006_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun006_2.lua)和[逐将规则](../../../../rules/generals/qun006-dongzhuo.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2648)。

> 主将技，锁定技，出牌阶段结束时，你移除副将，然后加3点体力上限并回复3点体力，获得“崩坏”。

- **实现与接口** · 主将董卓在自己出牌阶段结束时检查是否可移除副将武将牌。经公共移除成功后增加 3 点体力上限并回复 3 点，获得[崩坏](#qun006-benghuai)。
- **验证依据** · [qun006_dongzhuo.lua](../../../../../tests/qun006_dongzhuo.lua#L126)。检查真实副将只移除一次，并验证翼从副将不能代替武将牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 崩坏

- **标识与依据** · 董卓（QUN006）的派生技能或专属效果，运行时 ID `qiao__skill_qun006_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun006_3.lua)和[逐将规则](../../../../rules/generals/qun006-dongzhuo.md)。

- **实现与接口** · 暴凌移除副将后授予。自己结束阶段若体力值不为全场最小，强制选择失去体力、减体力上限中的一至两项。两项都选时增加一个摸牌阶段，仍处在同一回合。
- **验证依据** · [qun006_dongzhuo.lua](../../../../../tests/qun006_dongzhuo.lua#L154)。跑实际阶段入口，选择两项并观察额外摸牌。
- **未完成与边界** · 现有规则页记录结算，尚未找到可逐字验证的独立牌面原文。
