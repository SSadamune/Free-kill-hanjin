## 穿心

- **标识与依据** · 张任（QUN024，势包），运行时 ID `qiao__skill_qun024_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun024_1.lua)和[逐将规则](../../../../rules/generals/qun024-zhangren.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L3001)。

> 当你使用【杀】或【决斗】对目标角色造成伤害时，若你的翼从数小于2，你可以随机亮出未加入游戏的三种翼从并选择其中一张，其需将副将武将牌变更为此翼从，否则此伤害+1且你本局拥有此翼从。

- **实现与接口** · 张任的【杀】或【决斗】即将造成伤害时（`fk.DamageCaused`），按当前翼从实例数检查发动资格。公共候选过滤已实质取得过的兵种、偏将及房间禁用项；张任随机公开至多三种并选择一种，服务端复核仍可用。受伤者有真实副将武将牌时可选择变更，走公共位置保护、隐藏身份和来源迁移的检查。成功时旧副将进入武将弃牌堆。拒绝、没有合法副将或变更失败时，本次伤害加 1，张任另外获得一个该翼从实例。
- **验证依据** · [qun024_zhangren.lua](../../../../../tests/qun024_zhangren.lua#L34)。核对公开候选、正式副将入弃牌堆、暗将不先明置、士兵与受保护君主分别走否则分支。
- **未完成与边界** · [统领候选与实例](../../commander-retinue.md)、[武将来源同步](../../general-exchange.md#公共武将来源职责)各自维护底层接口。

## 龙飞

- **标识与依据** · 张任（QUN024，势包），运行时 ID `qiao__skill_qun024_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun024_2.lua)和[逐将规则](../../../../rules/generals/qun024-zhangren.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L3002)。

> 阵法技，你队列的其他角色也拥有你的翼从。

- **实现与接口** · 张任的队列发生变化时，同队列的其他角色取得他持有的实体或独立授予翼从的共享实例。每个共享来源独立编号，便于区分到期、迁移和使用历史，也避免把共享来的实例再向下递归授予。
- **验证依据** · [qun024_zhangren.lua](../../../../../tests/qun024_zhangren.lua#L120)。验证共享自己的实例并防止共享递归。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
