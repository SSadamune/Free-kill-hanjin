## 潜袭

- **标识与依据** · 马岱（SHU019，势包），运行时 ID `qiao__skill_shu019_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu019_2.lua)和[逐将规则](../../../../rules/generals/shu019-madai.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4094)。

> 准备阶段，你可以摸一张牌，弃置一张牌，令一名距离1的角色本回合不能使用或打出你弃置颜色的手牌。

- **实现与接口** · 马岱在准备阶段发动后先摸一张再弃一张。弃牌前保存该牌在当时过滤下的有效颜色，然后询问距离 1 的目标。目标选定后，本回合对这种颜色的手牌同时限制使用和打出，已建立的限制独立于马岱之后的技能状态。
- **验证依据** · [shu019_madai.lua](../../../../../tests/shu019_madai.lua#L93)。验证潜袭颜色、无候选仍执行摸弃、失技后限制仍在，以及过滤颜色快照。
- **机器人取舍** · 准备阶段比较未知摸牌、限制手牌响应带来的预计伤害增量和弃牌成本。实际摸牌后重选材料，再按结算保存的颜色和当前距离选择目标。[提前强命估值](../../robot-ai.md#提前强命与攻击目标)
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
