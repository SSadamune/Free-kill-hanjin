## 闺秀

- **标识与依据** · 糜夫人（SHU021，势包），运行时 ID `qiao__skill_shu021_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu021_1.lua)和[逐将规则](../../../../rules/generals/shu021-mifuren.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4131)。

> 锁定技，此武将牌明置后，或结束阶段若你未受伤，你摸两张牌。

- **实现与接口** · 糜夫人牌实际明置时摸两张牌。结束阶段比较当前体力值和体力上限，两者相等时也摸两张牌。明置触发核对来源牌的真实身份。
- **验证依据** · [shu021_mifuren.lua](../../../../../tests/shu021_mifuren.lua#L61)。覆盖牌明置和结束阶段两种摸牌入口。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 勇决

- **标识与依据** · 糜夫人（SHU021，势包），运行时 ID `qiao__skill_shu021_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu021_2.lua)和[逐将规则](../../../../rules/generals/shu021-mifuren.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4132)。

> 出牌阶段，你可以移除此武将牌，令一名角色获得一枚珠联璧合标记和技能“存嗣”（每轮各限一次，当你于回合内使用【杀】后/回合外使用【桃】后，你可以获得之。）。

- **实现与接口** · 糜夫人可以在出牌阶段选择受益角色，按实际武将牌身份移除自己。移除成功后授予角色级技能[存嗣](#shu021-cunsi)，基线实现同时增加双亮待发字段 `CompanionEffect`。
- **验证依据** · [shu021_mifuren.lua](../../../../../tests/shu021_mifuren.lua#L87)。基线用例移除此牌并断言双亮待发字段和存嗣。
- **未完成与边界** · 反馈 23 已复现。待通过国战标记公共发放入口授予可立即消耗的珠联璧合，并覆盖受益者已有一枚标记的情况。

## 存嗣

- **标识与依据** · 糜夫人（SHU021）的派生技能或专属效果，运行时 ID `qiao__skill_shu021_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu021_3.lua)和[逐将规则](../../../../rules/generals/shu021-mifuren.md)。

派生技能原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4132)。

> 每轮各限一次，当你于回合内使用【杀】后/回合外使用【桃】后，你可以获得之。

- **实现与接口** · 由勇决授予。回合内用【杀】和回合外用【桃】分别占用本轮额度，结算完成后只取得当前仍可获得的实体牌。
- **验证依据** · [shu021_mifuren.lua](../../../../../tests/shu021_mifuren.lua#L87)。覆盖真实用杀、用桃以及两个独立时机。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
