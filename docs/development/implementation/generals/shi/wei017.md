## 恂恂

- **标识与依据** · 李典（WEI017，势包），运行时 ID `qiao__skill_wei017_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei017_1.lua)和[逐将规则](../../../../rules/generals/wei017-lidian.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5105)。

> 你每回合首次摸牌前，你可以卜算2，若为回合内，改为卜算4（须将其中两张置于牌堆底）。

- **实现与接口** · 李典本回合首次进入摸牌前（`fk.BeforeDrawCard`）可卜算。回合外看两张，自己的回合看四张且恰好两张置底。首次摸牌查询使用本回合记录，获得技能之前已发生的摸牌也计入。
- **验证依据** · [wei017_lidian.lua](../../../../../tests/wei017_lidian.lua#L87)。覆盖回合内恰好两张置底、回合外两张不限置底数量及后获得技能的历史边界。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 忘隙

- **标识与依据** · 李典（WEI017，势包），运行时 ID `qiao__skill_wei017_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei017_2.lua)和[逐将规则](../../../../rules/generals/wei017-lidian.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5106)。

> 当你对其他角色造成伤害后，或受到其他角色的伤害后，你可以摸一张牌并令其摸一张牌。

- **实现与接口** · 造成伤害后（`fk.Damage`）与受到伤害后（`fk.Damaged`）共用双方均在场的检查。确认后分别处理 `fk.BeforeDrawCard`，再让双方在同一移动事件中摸牌。
- **验证依据** · [wei017_lidian.lua](../../../../../tests/wei017_lidian.lua#L243)。两个伤害方向分别验证每次只询问一次、双方同时摸牌，并覆盖致死伤害后跳过询问。
