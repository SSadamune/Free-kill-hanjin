## 横江

- **标识与依据** · 臧霸（WEI023，势包），运行时 ID `qiao__skill_wei023_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei023_1.lua)和[逐将规则](../../../../rules/generals/wei023-zangba.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5244)。

> 当你受到1点伤害后，你可以令当前回合角色本回合手牌上限-X（X为其装备区牌数，至少为1）。若如此做，其本回合弃牌阶段结束时，若其此阶段弃置过牌，则你摸一张牌，否则你摸牌至体力上限。

- **实现与接口** · 臧霸每受到 1 点伤害可为当前回合角色建立手牌上限修正，数值取其装备区牌数且至少为 1。弃牌阶段结束时按该角色本阶段是否弃过牌，令臧霸摸一张或补手牌至体力上限。已建立的后续在臧霸失去横江后继续执行。
- **验证依据** · [wei023_zangba.lua](../../../../../tests/wei023_zangba.lua#L20)。用多点伤害核对逐点发动、弃牌阶段后续及失技保留。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
