## 激昂

- **标识与依据** · 孙策（WU010，势包），运行时 ID `qiao__skill_wu010_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu010_1.lua)和[逐将规则](../../../../rules/generals/wu010-sunce.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6206)。

> 当你指定或成为【决斗】或红色【杀】的目标后，你可以摸一张牌（若为转化牌，则多摸一张牌且本回合此技能失效）。

- **实现与接口** · 孙策指定或成为【决斗】或红色【杀】的目标后，分别由 `fk.TargetSpecified` 和 `fk.TargetConfirmed` 提供摸牌。若该次牌是另行构造并带实体材料的转化牌，孙策多摸一张，本回合的激昂失效。
- **验证依据** · [wu010_sunce.lua](../../../../../tests/wu010_sunce.lua#L98)。比较普通牌、无材料虚拟牌与有实体材料的转化牌，并验证失效。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 鹰扬

- **标识与依据** · 孙策（WU010，势包），运行时 ID `qiao__skill_wu010_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu010_2.lua)和[逐将规则](../../../../rules/generals/wu010-sunce.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6207)。

> 你的拼点牌亮出后，你可以令点数+3或-3。

- **实现与接口** · 孙策亮出自己的拼点牌后（`fk.PindianCardsDisplayed`），可以选择将自己的点数增加或减少 3，结果通过引擎拼点点数接口写入。
- **验证依据** · [wu010_sunce.lua](../../../../../tests/wu010_sunce.lua#L162)。验证实用拼点结果中孙策自己的点数改变。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 魂殇

- **标识与依据** · 孙策（WU010，势包），运行时 ID `qiao__skill_wu010_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu010_3.lua)和[逐将规则](../../../../rules/generals/wu010-sunce.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6208)。

> 副将技（☯️-1），准备阶段，若你的体力值为1，本回合你获得“英魂”和“英姿”。

- **实现与接口** · 副将孙策在准备阶段且体力为 1 时，可获得本回合的[英魂](../standard/wu009.md#wu009-1)和[英姿](../standard/wu005.md#wu005-1)。授予以独立的回合末清理技能为来源，回合末按该来源撤销。
- **验证依据** · [wu010_sunce.lua](../../../../../tests/wu010_sunce.lua#L183)。通过实际移除副将验证两项仍保留，回合末只撤除魂殇授予，并保留原有英姿。另覆盖先移除主将周瑜，魂殇授予的英姿仍保留到回合末。
