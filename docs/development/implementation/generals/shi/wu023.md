## 奋命

- **标识与依据** · 陈武&董袭（WU023，势包），运行时 ID `qiao__skill_wu023_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu023_1.lua)和[逐将规则](../../../../rules/generals/wu023-chenwu-dongxi.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6517)。

> 出牌阶段各限一次，你可以：1.令至多X名角色横置（X为你已损失的体力值，至少为1），然后你横置；2.若你横置，弃置所有横置的角色各一张牌。

- **实现与接口** · 出牌阶段两个选项分别计次。第一项按已损失体力值选至多相应人数（至少可选一人），先横置目标，再横置自己。本人已横置才能发动第二项，由技能持有者从每名横置角色区域选择一张牌弃置。
- **验证依据** · [wu023_chenwu_dongxi.lua](../../../../../tests/wu023_chenwu_dongxi.lua#L120)。测试两选项独立限次及真实客户端可用性。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 断绁

- **标识与依据** · 陈武&董袭（WU023，势包），运行时 ID `qiao__skill_wu023_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu023_2.lua)和[逐将规则](../../../../rules/generals/wu023-chenwu-dongxi.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6518)。

> 锁定技，当你重置后，你摸一张牌，若此时是你回合内，你多摸一张牌。

- **实现与接口** · 先在连环状态变更前记录是否由横置转为重置，再在状态实际改变后摸牌。角色于自己回合重置时摸两张，其他回合摸一张。
- **验证依据** · [wu023_chenwu_dongxi.lua](../../../../../tests/wu023_chenwu_dongxi.lua#L196)。以真实重置验证回合内外的摸牌。
