# HAN002 刘辩

## 诗怨

- **标识与依据**：运行时 ID `qiao__skill_han002_1`；源码 [skill_han002_1.lua](../../../../../pkg/qiao_generals/skills/skill_han002_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN002。同将另见[毒逝](#han002-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L508)。

> 每回合各限一次，当你成为其他角色使用牌的目标后，若其体力值：大于你，你可以摸两张牌；小于等于你，你可以摸一张牌。

- **实现与接口** · 刘辩成为其他角色使用牌的目标后（`fk.TargetConfirmed`），按使用者体力是否大于刘辩分两档询问。确认发动后登记对应档位，分别摸两张或一张。拒绝发动不消耗次数，两档各用独立的回合标记。
- **验证依据** · [han_standard.lua](../../../../../tests/han_standard.lua#L103) 分别断言两个档位的摸牌数及同档在本回合再次成为目标时不再询问。
- **未完成与边界** · 客户端交互的人工验收范围见[汉包](../han-standard.md#han-standard-boundary)。

## 毒逝

- **标识与依据**：运行时 ID `qiao__skill_han002_2`；源码 [skill_han002_2.lua](../../../../../pkg/qiao_generals/skills/skill_han002_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN002；卡面原文以 `assets/docs/石激桑武将列表.json` 为准。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L509)。

> 锁定技，其他角色不能对你使用【桃】；你死亡时，来源获得此技能。

- **实现与接口** · 有效毒逝通过目标禁止效果阻止其他角色对持有者使用【桃】，持有者自用不受限制。死亡事件（`fk.Death`）仍检查死者的技能。若死亡有来源且来源不是死者，把技能授给来源角色，来源暗置也可获得。
- **验证依据** · [han_standard.lua](../../../../../tests/han_standard.lua#L140) 核对他人用【桃】与自用的区别，以及暗置的死亡来源获得毒逝。
- **未完成与边界**：没有逐项客户端交互与人工验收；未完成边界沿用[汉包](../han-standard.md#han-standard-boundary)。
