## 谋诛

- **标识与依据**：运行时 ID `qiao__skill_han005_1`；源码 [skill_han005_1.lua](../../../../../pkg/qiao_generals/skills/skill_han005_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN005；用牌目标入口见[效果指定的用牌目标条件](../../card-use-targets.md)。同将另见[构难](#han005-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L565)。

> 出牌阶段限一次，你可以令一名其他角色交给你一张手牌，然后若其手牌数小于你，其视为使用一张【杀】或【决斗】，若此牌目标与你势力相同，其弃置一张牌。

- **实现与接口**：
  - 出牌阶段限一次（效果 `max_phase_use_time = 1`，自定义 `can_use` 内同时检查阶段次数）。
  - 发动时只选一名其他存活角色，不选择牌，也不把“交牌能否执行”当作目标限制或何进消耗。交牌由被令角色选择一张手牌，再以 `moveCardTo(..., fk.ReasonGive, ...)` 交给何进；目标无手牌时交牌不执行，但继续“然后”的手牌比较与可执行效果。
  - 交牌后比较双方**当前手牌数**，仅当目标手牌数小于何进时，以 `selectVirtualCard` 按正常牌面条件选牌和目标。给返回的用牌数据附上本次何进来源，再执行一次 `room:useCard`。虚拟牌默认 `extraUse`。
  - `fk.CardUsing` 消费本次来源并检查当时的目标。若有与何进同势力的目标，使用者弃置一张牌，见[何进裁定](../../../../rules/generals/han005-hejin.md#谋诛)。
- **验证依据**：[han005_hejin.lua](../../../../../tests/han005_hejin.lua) 验证异势力目标无需弃牌，以及同势力场景在 `fk.TargetSpecifying` 已观察到牌位于弃牌堆，随后【杀】照常结算。
- **未完成与边界**：没有合法【杀】或【决斗】目标时选牌返回空。客户端选目标及弃牌界面待人工验收。

## 构难

- **标识与依据**：运行时 ID `qiao__skill_han005_2`；源码 [skill_han005_2.lua](../../../../../pkg/qiao_generals/skills/skill_han005_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN005；出牌阶段主动技谋诛见[谋诛](#han005-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L566)。

> 锁定技，你死亡后，来源本局因普通【杀】造成或受到伤害时，此伤害+1。

- **实现与接口**：
  - `fk.Death` 触发，按公共死亡数据取 `data.killer`；无来源不建立印记，来源已死也照常记录、后续不再复结算。暗将死亡先经公共 `GameOverJudge` 翻正再触发。
  - 来源角色显示公开印记 `@@qiao_skill_han005_2_source-noclear`。它不带技能名双下划线前缀，避免 Exchange 按来源技能迁移；`-noclear` 使其不随死亡清标记消失，移将、失技、暗置后已建立印记持续。
  - 伤害监听为房间级延迟技能（`DamageInflicted` + `global`），获得构难时安装，死亡建立印记时再次确保存在；不依赖死者当前 `hasSkill`，何进死后仍生效。
  - 只认正式普通杀牌名 `qiao__slash`，排除火／雷／冰杀，不以伤害属性代替牌名判断；印记角色作为来源（造成）或受伤者（受到）两个方向各 +1，每次伤害事件只加一次。
- **验证依据**：[han005_hejin.lua](../../../../../tests/han005_hejin.lua) 覆盖构难普通杀双向（暗将何进死亡后印记生效，来源造成／受到普通杀伤害各 +1）与属性杀排除（火杀仍为 1）；历史定向结果 3/3，见[共享验证证据](../verification-evidence.md#han005_hejin)。
- **未完成与边界**：来源为空或来源已死时只按公共死亡数据记录／跳过；若后续引入复活并需重新结算，应由公共流程决定。普通杀若新增别名需同步扩充而非改回按属性判断。客户端选目标／弃牌界面未人工验收。
