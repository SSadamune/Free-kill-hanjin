## 连计

- **标识与依据**：运行时 ID `qiao__skill_han006_1`；源码 [skill_han006_1.lua](../../../../../pkg/qiao_generals/skills/skill_han006_1.lua)。共用“本回合得到牌”查询 [han_history.lua](../../../../../pkg/qiao_generals/util/han_history.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN006；用牌目标策略见[效果指定的用牌目标条件](../../card-use-targets.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L582)。

> 出牌阶段每名角色限一次，你可以交给其他角色一张手牌，令其本回合下次受到的伤害+1。

- **实现与接口**：
  - 出牌阶段主动技；“每名角色限一次”的已选目标 ID 表记在**发动者**身上，采用 `qiao__skill_han006_1-given_targets-phase` 技能前缀，随王允武将牌由 Exchange 迁移，不会让两名持有者互相阻止。目标身上只保留已建立的下一次伤害 +1 延迟效果。
  - 只允许交出自己当前手牌；服务端在 `on_use` 重新核对牌仍属于发动者手牌，不依赖客户端选择。
  - 交给后给目标本回合 `next_damage` 计数；伤害在 `DamageInflicted` 按计数增加，在实际伤害后的 `fk.Damage` 才清零，被防止的伤害不消费。多个“下一次”同时存在时同一次实际伤害一并增加。
  - 加成监听器是模块缓存的房间级单一对象，第一次发动时安装并保留；王允之后失技、暗置或交换不影响已挂在目标身上的延迟效果，也不进入 Exchange 的武将标记迁移。
  - 连计/奋钺的主动技使用次数由引擎 `skillUsedHistory` 与正式模式已有的 `#qiao_exchange_history` 逐牌账本迁移；本组没有另建来源侧限次标记。
- **验证依据**：[han_standard_pindian.lua](../../../../../tests/han_standard_pindian.lua)（历史“待基础组执行”记录已被后续默认套件覆盖，见[共享验证证据](../verification-evidence.md#汉区)）覆盖交出手牌、下一次伤害 +1 且只消费一次、同一目标同阶段拒绝而另一目标仍可发动。
- **未完成与边界**：`han_history` 的 `clear` 仅作测试夹具查询下界，正式游戏不调用；未覆盖明置瞬间完整服务端复核、武将交换前后连续操作、死亡中断。客户端选牌／选目标未人工验收。

## 定著

- **标识与依据**：运行时 ID `qiao__skill_han006_2`；源码 [skill_han006_2.lua](../../../../../pkg/qiao_generals/skills/skill_han006_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN006；用牌目标策略见[效果指定的用牌目标条件](../../card-use-targets.md)。同将另见[连计](#han006-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L583)。

> 副将技（☯️-1），出牌阶段结束时，你可以选择一名本回合得到过牌的其他角色，其视为对由你指定的另一名角色使用一张【决斗】。

- **实现与接口**：
  - `Skill.DeputyPlace` 副将技；主将位不会获得该技能，界面与触发均不提供。
  - 记录的是本回合“得到过牌”的角色，不是当前手牌非空；得到后立即用掉／弃掉仍满足条件。共用[han_history.lua](../../../../../pkg/qiao_generals/util/han_history.lua) 查询本回合实际发生的 `GameEvent.MoveCards`，按进入手牌区的牌张累计，装备区与当前手牌数不参与；不安装记录器，因此暗置、晚获得技能或技能失效不会漏掉此前得牌。
  - 出牌阶段结束时先询问发动；发动询问、得到过牌角色与另一名目标角色都在 `on_cost` 中选定并保存，随后才进入 SkillEffect 的明置／技能效果结算，避免先明置再选目标。
  - 由得到过牌的角色视为对指定角色使用【决斗】。目标条件使用汉晋公共显式目标策略，先校验再执行一次真实用牌，不重复结算。
- **验证依据**：[han_standard_pindian.lua](../../../../../tests/han_standard_pindian.lua) 覆盖得到过牌后随即失去仍可作候选、仅有手牌但本回合未得牌不作候选、主将位不可用而副将位可用、真实【决斗】使用。历史记录见[共享验证证据](../verification-evidence.md#汉区)。
- **未完成与边界**：`han_history` 的 `clear` 仅作测试夹具查询下界，正式游戏不调用；未覆盖明置瞬间完整服务端复核与武将交换前后连续操作。客户端选牌／选目标未人工验收。
