## 敏思

- **标识与依据**：运行时 ID `qiao__skill_han007_1`；源码 [skill_han007_1.lua](../../../../../pkg/qiao_generals/skills/skill_han007_1.lua)；共用工具 [minsi.lua](../../../../../pkg/qiao_generals/util/minsi.lua)。规则见[王荣规范](../../../../rules/generals/han007-wangrong.md)。同将另见[追德](#han007-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L599)。

> 出牌阶段限一次，你可以弃置任意张点数之和为13的牌，摸两倍的牌并展示之，其中的红桃牌本回合不计入手牌上限。

- **实现与接口**：
  - 本体主动技、追德额外发动用的辅助主动技，以及手牌上限豁免的 `maxcards` 状态技；两处共用选牌、13 点子集判断、弃牌、双倍摸牌、展示和红桃标记。技能不把敏思永久授予受赠者。
  - 选牌上限按 `player:getCardIds("he")` 计算，`include_equip = true`；服务端在真正移动前复核牌仍归自己、未被禁止弃置且点数和为 13，非法回复不动牌。
  - 「本回合不计入手牌上限」按卡牌标记实现，标记键含受益者 id，只豁免此次摸到的红桃；牌转给其他角色后不替原角色继续豁免。`-turn` 由房间在回合结束清理。`maxcards` 状态技是房间级的，受赠者额外发动后即使王荣死亡，标记仍按受赠者 id 生效。
  - 额外敏思走独立辅助主动技名 `#qiao__skill_han007_1_aux`，不经过本体 `max_phase_use_time` 的阶段历史；受赠者已用普通敏思仍可额外发动，且不占用、不增加主技能次数。
  - 红桃判定使用 `Room:filterCard(id, player)` 的有效花色；点数和仍取实体牌原始点数。
- **验证依据**：[han007_wangrong.lua](../../../../../tests/han007_wangrong.lua) 覆盖敏思手牌和（A+Q 弃置、摸 4 展示、同阶段第二次不可用）、敏思装备牌（可参与凑 13）、手牌上限豁免（真实弃牌阶段：体力 1、手中 5 张含 2 张红桃，只弃 2 张）；追德额外敏思用例见[追德条目](#han007-2)。历史定向记录见[共享验证证据](../verification-evidence.md#han007_wangrong)。
- **未完成与边界**：手牌上限的引擎显示值不逐个扣除“不计入”的牌，实际弃牌阶段按 `MaxCardsSkill:excludeFrom` 计算；界面数字与有效上限差异属引擎显示范围，未修改公共机制。

## 追德

- **标识与依据**：运行时 ID `qiao__skill_han007_2`；源码 [skill_han007_2.lua](../../../../../pkg/qiao_generals/skills/skill_han007_2.lua)。共用工具 [minsi.lua](../../../../../pkg/qiao_generals/util/minsi.lua)。规则见[王荣规范](../../../../rules/generals/han007-wangrong.md)；同将另见[敏思](#han007-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L600)。

> 你死亡时，你可以展示任意张红桃牌并交给一名其他角色，令其摸等量的牌，然后其可以发动一次“敏思”。

- **实现与接口**：
  - `fk.Death` 触发，位于 `GameOverJudge` 之后、`BuryVictim` 清理死亡角色牌之前（`ltk/server/events/death.lua`）；国战公共流程在 `GameOverJudge` 翻开暗置武将，因此暗将来源追德仍能触发，给牌不跳过公共牌移动。
  - 选牌与接收者由辅助主动技只完成选择，`on_use` 再执行展示、给牌、摸牌和额外敏思。红桃牌展示并交给、等量摸牌。
  - 红桃判定使用 `Room:filterCard(id, player)` 的有效花色，已核对 `Fk:getCardById` 过滤缓存行为；不再直接依赖实体牌原始 `suit`，点数和仍取实体牌原始点数。
- **验证依据**：[han007_wangrong.lua](../../../../../tests/han007_wangrong.lua) 覆盖追德基础（红桃展示交付、等量摸牌、无 13 组合不额外发动、剩余牌随死亡清理）与追德额外敏思（暗置主将死亡后仍触发，受赠者已有普通敏思阶段记录时额外敏思仍发动且主技能次数保持 1）。历史定向记录见[共享验证证据](../verification-evidence.md#han007_wangrong)。
- **未完成与边界**：手牌上限的引擎显示值不逐个扣除“不计入”的牌，实际弃牌阶段按 `MaxCardsSkill:excludeFrom` 计算；界面数字与有效上限差异属引擎显示范围，未修改公共机制。客户端死亡与给牌交互未人工验收。
