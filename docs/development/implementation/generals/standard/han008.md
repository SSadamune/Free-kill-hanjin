## 惴恐

- **标识与依据**：运行时 ID `qiao__skill_han008_1`；源码 [skill_han008_1.lua](../../../../../pkg/qiao_generals/skills/skill_han008_1.lua)。规则见[伏皇后规范](../../../../rules/generals/han008-fuhuanghou.md)。同将另见[求援](#han008-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L618)。

> 其他角色的准备阶段，若你已受伤，你可以与其拼点。若你赢，防止其本回合造成伤害；若你没赢，其可以视为对你使用一张【杀】。

- **实现与接口**：
  - `EventPhaseStart` 全局监听其他角色的准备阶段；伏皇后已受伤且可与该角色拼点时，通过正规 `can_trigger/on_cost/on_use` 发动。`createTriggerSkill` 会用 `can_trigger` 覆盖基类 target 门槛，因此不需要 refresh／`room:useSkill` 代理；正常明置来源并记录技能发动。
  - 伏皇后赢：给该角色加本回合公开的「惴恐」标记。房间级 `DamageCaused` 监听器按标记防止该角色造成的伤害，监听器不依赖伏皇后之后是否仍有技能。
  - 没赢（含平局）：该角色可选择视为对伏皇后使用【杀】；使用显式目标策略，目标为伏皇后，不叠加普通距离条件，仍复核禁止使用／禁止指定。
- **验证依据**：[han008_fuhuanghou.lua](../../../../../tests/han008_fuhuanghou.lua) 覆盖惴恐赢后防止目标本回合伤害、平局按没赢允许目标视为使用无距离【杀】。历史记录见[共享验证证据](../verification-evidence.md#han008_fuhuanghou)。
- **未完成与边界**：未执行真实客户端选目标与拼点交互；未覆盖多个伏皇后同时惴恐、目标中途死亡／失技等排列；依赖公共目标／用牌复核。旧记录保留的计划定向入口为 `python scripts/test.py --file tests/han008_fuhuanghou.lua --timeout 120`（当时标为待基础组执行，未产生该文件单独输出，后由默认套件覆盖）。

## 求援

- **标识与依据**：运行时 ID `qiao__skill_han008_2`；源码 [skill_han008_2.lua](../../../../../pkg/qiao_generals/skills/skill_han008_2.lua)。规则见[伏皇后规范](../../../../rules/generals/han008-fuhuanghou.md)、[牌的使用相关事件](../../../../../rulebook/events/use-card.md)与[指定额外目标](../../../../rules/extra-targets.md)。同将另见[惴恐](#han008-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L619)。

> 当你成为其他角色使用【杀】的目标时，你可以令另一名其他角色也成为目标且优先结算，此【杀】被抵消后对其余目标无效。

- **实现与接口**：
  - `TargetConfirming` 触发，只在伏皇后成为其他角色【杀】的目标时提供一次；同一名伏皇后对同一次 use 不会重复求援。
  - 候选使用公共 `ExtraTargets` 显式条件 `other_roles = true`：不按普通攻击距离阻挡，但仍排除已禁止、已在本次目标列表中的角色。
  - 通过 AimData 的目标加入接口增加目标，新增目标仍会生成 `TargetSpecified`／`TargetConfirmed` 等正常目标事件。
  - 新增目标 id 记录在本次 `UseCardData` 上；效果顺序只在 `BeforeCardUseEffect` 调整为新增目标优先，不在目标阶段排序、不提前事件。该字段避免 `extra_data` 在目标事件结束时被 AimData 旧值覆盖。
  - 任意目标抵消后，复用方天画戟的 use 级 `nullifiedTargets` 登记，使其余目标无效；监听器按 use 上已建立的记录执行，不依赖伏皇后当前是否仍有求援。
- **验证依据**：[han008_fuhuanghou.lua](../../../../../tests/han008_fuhuanghou.lua) 覆盖求援新增目标保留目标事件、效果顺序优先，且被【闪】抵消后原目标不再受此【杀】影响。历史记录见[共享验证证据](../verification-evidence.md#han008_fuhuanghou)。
- **未完成与边界**：未执行真实客户端选目标、拼点及新增目标响应交互；未覆盖多个伏皇后同时求援、目标中途死亡／失技、无合法新增目标等排列；未验证手工强制取消或伪造目标数据，依赖公共目标／用牌复核。
