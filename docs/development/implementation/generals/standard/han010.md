## 承诏

- **标识与依据**：运行时 ID `qiao__skill_han010_1`；源码 [skill_han010_1.lua](../../../../../pkg/qiao_generals/skills/skill_han010_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN010；用牌目标策略见[效果指定的用牌目标条件](../../card-use-targets.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L661)。

> 每回合结束时，若你于本回合得到过至少两张牌，你可以与一名角色拼点：若你赢，你视为对其使用一张无视防具的【杀】。

- **实现与接口**：
  - `fk.TurnEnd` 全局监听，任意角色的回合结束都可发动；条件是董承本人本回合得到过至少两张牌，且当前存在可拼点角色（共用 [han_history.lua](../../../../../pkg/qiao_generals/util/han_history.lua) 的本回合得牌查询）。
  - `on_cost` 直接选择拼点对象以确认发动，只有一个对象时直接询问是否发动。随后进入 SkillEffect 的明置与效果结算；平局或没赢均不产生【杀】。
  - 赢时视为对拼点对象使用【杀】，使用显式目标策略。该次用牌在 `TargetSpecified` 复用青釭剑的公共无视防具机制（`addQinggangTag`），只在该次结算内令目标防具无效，不改变其他【杀】。
- **验证依据**：[han_standard_pindian.lua](../../../../../tests/han_standard_pindian.lua) 覆盖本回合两张得牌的统计、拼点赢生成【杀】、该次用牌的防具无效标记、没赢不生成【杀】。历史记录见[共享验证证据](../verification-evidence.md#汉区)。
- **未完成与边界**：未覆盖明置瞬间完整服务端复核、武将交换前后连续操作、死亡中断；防具部分只验证公共标记已生效，八卦阵／仁王盾等完整响应链未覆盖。客户端拼点界面未人工验收。旧记录保留的计划定向入口为 `python scripts/test.py --file tests/han_standard_pindian.lua --timeout 120`（覆盖 HAN006／HAN010／HAN013；当时标为待基础组执行，未产生该文件单独输出，后由默认套件覆盖）。
