## 铸典

- **标识与依据**：运行时 ID `qiao__skill_han012_1`；源码 [skill_han012_1.lua](../../../../../pkg/qiao_generals/skills/skill_han012_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN012。同将另见[博通](#han012-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L697)。

> 当你成为其他角色使用黑色牌的目标后，你可以重铸一张牌，然后若你摸到的牌为黑色，你可以展示之并摸一张牌。

- **实现与接口**：
  - 时机为“成为目标后”，使用 `fk.TargetConfirmed`；条件排除自己使用，并要求使用牌为黑色。
  - 重铸是“置入弃牌堆，然后摸一张牌”，不是弃置。选牌直接放在 `on_cost`：取消即不发动，避免先明置再询问可取消消耗；不调用 `prohibitDiscard` 过滤，也不把重铸写成弃牌消耗。`Room:recastCard` 返回实际摸到的牌。
  - 黑色分支对 `Room:filterCard(id, player)` 的有效颜色判断；展示前复核该牌仍由自己持有，展示通过 `Room:showCards`，再摸一张。重铸前再次核对牌仍属于自己；重铸后死亡则不继续展示／补摸。
- **验证依据**：[han012_caiyong.lua](../../../../../tests/han012_caiyong.lua) 覆盖铸典黑色分支（装备牌在禁止弃置下仍可重铸、摸到黑色后展示并补摸、红牌不入展示）与非黑分支（摸到红牌不展示、不补摸，重铸牌进弃牌堆）。历史记录见[共享验证证据](../verification-evidence.md#han012_caiyong)。
- **未完成与边界**：重铸牌若因其他效果多摸，只按第一张判断黑色分支；标准重铸规则为摸一张，此边界未另作扩展。客户端选牌与展示未人工验收。

## 博通

- **标识与依据**：运行时 ID `qiao__skill_han012_2`；源码 [skill_han012_2.lua](../../../../../pkg/qiao_generals/skills/skill_han012_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN012。同将另见[铸典](#han012-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L698)。

> 你可以将四种花色或三种类别各一张牌当任意一种基本牌使用，然后你可以将这些牌交给其他角色。

- **实现与接口**：
  - `viewas` 转化任意基本牌；`fk.CardUseFinished` 时可将仍在处理区的全部子牌交给一名其他角色。
  - 选牌范围为手牌区或装备区（`include_equip = true`）；合法组合仅两种：4 张且四种花色各一张，或 3 张且基本牌／锦囊牌／装备牌各一张。
  - `card_filter` 以“补选后仍可能形成上述任一组合”防止选牌死路；`feasible` 做最终校验。多子牌颜色／点数由引擎 `Card:addSubcards` 按普通多子牌规则确定，不手算。
  - 牌名交互用 `UI.CardNameBox`，候选由公开的 `Player:getViewAsCardNames` 过滤；转化结果只允许「使用」，`enabled_at_response = false`。
  - 使用结算结束时 `fk.CardUseFinished` 先于处理区子牌置入弃牌堆触发；该效果标记 `is_delay_effect = true`，属于本次转化使用的后续效果，不作为新技能发动，也不因中途失去博通而消失。“这些牌”是本次以博通转化使用的实体子牌。交牌询问只提供接收者，多名候选时选择一名，只有一名候选时直接询问是否交给其。确认后复核接收者，并一次移动本次使用仍在处理区的所有子牌；拒绝时由引擎照常清理。
- **验证依据**：[han012_caiyong.lua](../../../../../tests/han012_caiyong.lua) 覆盖博通四花色（4 张四花色当【杀】使用，结算后 4 张子牌全部交给 p2，额外手牌留在原位，选择窗口无可选牌）与博通三类别（基本／锦囊／装备各一张成功使用，拒绝交出时三张正常进弃牌堆）。历史记录见[共享验证证据](../verification-evidence.md#han012_caiyong)。
- **未完成与边界**：基本牌名表目前列汉晋已登记的基本牌（含属性【杀】），卡表新增基本牌时应同步扩充。
