## 劲弩

- **标识与依据**：运行时 ID `qiao__skill_han016_1`；源码 [skill_han016_1.lua](../../../../../pkg/qiao_generals/skills/skill_han016_1.lua)。规则见[刘宠规范](../../../../rules/generals/han016a-liuchong.md)与[标准武将表](../../../../rules/standard-generals.md)。牌面编号保留 `A`，运行时仍为 `qiao_heg__han016`；同将另见[威屯](#han016a-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L780)。

> 出牌阶段结束时，若你此阶段使用过的牌均为【杀】，或使用的最后两张牌均不为【杀】，你可以视为使用一张无距离限制的【杀】。

- **实现与接口**：
  - 出牌阶段结束时触发执行一次；零用牌不满足任何分支。
  - 直接查询本阶段真实发生的 `GameEvent.UseCard` 事件，按事件 id 排序，因此技能在非空闲时点使用的牌也进入完整牌序；不依赖引擎聚合用牌次数。纯“打出”的 `GameEvent.RespondCard` 不是“使用”，不进入本条件。
  - 两个分支：至少使用过一张牌且全部为【杀】；或至少使用过两张牌且最后两张均不为【杀】。
  - 满足时在 `on_cost` 选定目标，再使用显式目标策略的 `bypass_distance` 虚拟【杀】：保留通常目标规则但不计算距离，真实使用一次，避免重复结算；实际使用也带 `bypass_times`，修复本阶段已出过【杀】时目标组合校验误挡技能视为使用的【杀】。
- **验证依据**：[han016_liuchong.lua](../../../../../tests/han016_liuchong.lua) 覆盖劲弩零用牌不触发、全部为【杀】触发一次无距离【杀】、最后两张均非【杀】触发、不逐项拆分排列。历史记录见[共享验证证据](../verification-evidence.md#han016_liuchong)。
- **未完成与边界**：未执行真实客户端出牌与目标选择交互；未覆盖阶段内响应／非空闲窗口的复杂牌序边界、技能造成目标死亡后的目标复核、禁止使用／禁止指定的具体来源；未验证武将交换与跨回合清理。资源编号迁移不在本轮范围。

## 威屯

- **标识与依据**：运行时 ID `qiao__skill_han016_2`；源码 [skill_han016_2.lua](../../../../../pkg/qiao_generals/skills/skill_han016_2.lua)。规则见[刘宠规范](../../../../rules/generals/han016a-liuchong.md)与[标准武将表](../../../../rules/standard-generals.md)。牌面编号保留 `A`，运行时仍为 `qiao_heg__han016`；同将另见[劲弩](#han016a-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L781)。

> 限定技，弃牌阶段开始前，若你的手牌最多，你可以跳过此阶段，然后视为对任意名角色使用【桃园结义】和【五谷丰登】。

- **实现与接口**：
  - 限定技。`EventPhaseChanging` 的弃牌阶段开始前检查手牌数是否全场最多，并列最多也满足。
  - `on_cost` 先筛选候选并让发动者选定一组共同目标；`on_use` 设置 `data.skipped = true` 跳过弃牌阶段，然后依次对同一组目标使用【桃园结义】和【五谷丰登】。
  - 两张牌使用汉晋显式目标策略：允许自己、允许满血等通常牌面会排除的目标；独立的禁止使用／禁止指定仍由公共目标策略和真实用牌入口复核。目标组不因第一张牌结算后重新选择。
- **验证依据**：[han016_liuchong.lua](../../../../../tests/han016_liuchong.lua) 覆盖并列手牌最多、跳过弃牌阶段、同一组目标依次使用【桃园结义】和【五谷丰登】并检查目标包含自己。历史记录见[共享验证证据](../verification-evidence.md#han016_liuchong)。
- **未完成与边界**：未执行真实客户端出牌、阶段跳过及两张群体牌的目标选择交互；未覆盖技能造成目标死亡后第二张牌的目标复核、禁止使用／禁止指定具体来源；未验证武将交换、跨回合清理。资源编号迁移不在本轮范围。旧记录保留的计划定向入口为 `python scripts/test.py --file tests/han016_liuchong.lua --timeout 120`（当时标为待基础组执行，未产生该文件单独输出，后由默认套件覆盖）。
