## 集兵

- **标识与依据** · 运行时 ID `qiao__skill_han018_1`。源码见 [skill_han018_1.lua](../../../../../pkg/qiao_generals/skills/skill_han018_1.lua)，逐次结算见[集兵裁定](../../../../rules/generals/han018-jianshuo.md#集兵)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L840)。

> 摸牌阶段，你可以多摸X张牌（X为与你势力相同的角色数）。若如此做，回合结束时，若你本回合造成伤害数小于X，你失去1点体力。

- **实现与接口** · 每次发动分别保存当时同势力在场人数 X。回合末按发动顺序比较本回合已造成伤害，每低于一个 X 就单独失去 1 点体力。
- **验证依据** · [han_standard.lua](../../../../../tests/han_standard.lua) 覆盖拒绝发动、单次发动，以及同回合先记录 4、再记录 3 时，分别造成 0、3、4 点伤害的结果。
- **未完成与边界** · 客户端日志与动画待点验。
