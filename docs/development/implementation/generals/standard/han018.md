## 集兵

- **标识与依据**：运行时 ID `qiao__skill_han018_1`；源码 [skill_han018_1.lua](../../../../../pkg/qiao_generals/skills/skill_han018_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)汉区 HAN018。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L840)。

> 摸牌阶段，你可以多摸X张牌（X为与你势力相同的角色数）。若如此做，回合结束时，若你本回合造成伤害数小于X，你失去1点体力。

- **实现与接口** · 每次发动时，按当时同势力的在场角色数（含自己）多摸 X 张，并把 X 写入发动者的回合标记。同一回合在多个摸牌阶段发动时，后一次会覆盖前一次的 X。独立的回合末效果按引擎的实际伤害历史累计发动者本回合造成的伤害，最多以最后一次记录的 X 判定一次。伤害不足时失去 1 点体力，达到 X 时由回合标记清理收尾。
- **验证依据**：[han_standard.lua](../../../../../tests/han_standard.lua) 覆盖不足 X 时扣体力与触发本地化、达到 X 时无触发，以及选择不发动。
- **未完成与边界** · **待确认**。同一回合多次发动后，回合末是否应按每次发动各自保存的 X 分别结算。实际客户端日志与动画待点验。
