## 垂统

- **标识与依据**：运行时 ID `qiao__skill_jin001_1`；源码 [skill_jin001_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin001_1.lua)。规则见[司马炎规范](../../../../rules/generals/jin001-simayan.md)与[装备移动通则](../../../../rules/equipment-movement.md)。同将另见[兴图](#jin001-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1482)。

> 当其他角色进入濒死时，你可以将其装备区的一张牌移动给你。

- **实现与接口**：
  - `fk.EnterDying` 提供一次发动机会，`target` 为进入濒死的其他角色；`target == player` 直接排除，不按敌友或势力筛选。未改为监听求桃，同一濒死流程不会按求桃次数反复触发。
  - 候选牌只取该角色装备区中 `target:canMoveCardInBoardTo(player, id)` 为真的牌；该锁定接口检查目标栏存在、未废除且为空，并排除目标为自己；已有同类装备、废除栏或无牌时 `can_trigger` 不成立。
  - 发动者从复核后的候选牌中选择一张（`Room:askToChooseCard`，候选以 `$Equip` 列表给出）；选择后再次复核来源归属、双方存活与 `canMoveCardInBoardTo`，再调用 `Room:moveCardIntoEquip(player, card, skill, false, target)`。`convert = false` 保证不替换目标已有装备；移动进入对应空栏而非手牌，并按正常移牌触发失去／得到装备结算。
  - 发动在 `askToSkillInvoke` 处可取消；取消、候选为空或复核失败时不移动。
- **验证依据**：[jin001_simayan.lua](../../../../../tests/jin001_simayan.lua) 覆盖其他角色进入濒死时移入空置对应栏且非手牌；同类栏已占用、废除栏、无牌、取消、自己濒死均不移动；`hp = 0` 的完整濒死流程只提供一次发动；主将、副将、暗置预亮来源均验证，见[共享验证证据](../verification-evidence.md#jin001_simayan)。
- **未完成与边界**：未应用开发适配的本体人工交互验收尚未执行；规范化描述待办见[规范化描述待办](#jin001-todo)。

## 兴图

- **标识与依据**：运行时 ID `qiao__skill_jin001_2`；源码 [skill_jin001_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin001_2.lua)。规则见[司马炎规范](../../../../rules/generals/jin001-simayan.md)。辅助主动技 `#qiao__skill_jin001_2_active`；同将另见[垂统](#jin001-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1483)。

> 每回合结束时，若本回合有应变牌被使用过，你可以选择一项：1.将一张装备牌当【桃】对一名角色使用；2.摸一张牌。

- **实现与接口**：
  - 本回合应变牌使用事实：不要求当前拥有兴图的全局 `fk.PreTurnStart` 效果在每个回合开始时把房间标记 `qiao_jin001_2_adaptation_used` 置为 false，下一回合不继承上一回合事实；全局 `fk.AfterCardUseDeclared` 以 `A.isAdaptationCard(data.card, data)` 判断使用级应变牌，只检查本次实际使用的牌／使用数据，不把实体材料牌的应变条目或 `Adaptation.Triggered` 成功事件当作使用事实。任意角色使用均记录，条件是否满足、是否成功触发不影响事实。记录效果在技能尚未获得、暗置或后来获得时仍存在。纯“打出”走 `RespondCard`，不计入。
  - `fk.TurnEnd` 对每名角色（包括自己）的回合结束检查房间标记；技能有效且本回合序号匹配时只发起一次 `askToChoice`，直接给出“将一张装备牌当【桃】对一名角色使用”“摸一张牌”和取消。分支选择在 `on_cost` 完成并写入 `event:setCostData(self, { choice = ... })` 传给 `on_use`；取消返回 false，不进入 SkillEffect，因此不摸牌、不用牌、不消耗，也不明置来源或计为发动。第一项不合法时只提供摸牌与取消。
  - 第一项：辅助主动技只允许选择自己手牌区或装备区中的装备牌（`card_num = 1`、`include_equip = true`、`card_filter` 检查归属与 `Card.TypeEquip`），目标限已受伤角色（含自己与其他角色）。服务端再次复核材料归属／类型、目标存活及 `player:isProhibited`，然后调用公共 `C.useVirtualCard`，以 `C.explicit({})` 替换普通【桃】的牌面目标条件，并把 `skillName` 记为兴图；实际进入一次完整用牌流程，由【桃】自身效果回复体力，不直接 `recover`。
  - 第二项：直接 `drawCards(1, skill.name)`，不要求拥有装备牌。任一项都可取消；选择第一项后在选牌／选目标处取消，不摸牌、不使用、不移动。
- **验证依据**：[jin001_simayan.lua](../../../../../tests/jin001_simayan.lua) 覆盖无应变用牌／普通牌／纯打出不触发；其他角色在本回合使用应变牌、条件未成功触发也计数；用牌发生在获得技能之前仍计入；下一回合清空；任意角色回合结束可发动；摸牌项与拒绝；第一项用手牌或装备区装备作材料、对受伤角色完整使用一次【桃】、材料离区且 `skillName` 为兴图，候选筛选和用牌校验均排除满体力角色；无合法装备时只提供摸牌项；主将、副将、暗置来源；真实 `ClientPlayer` 装备牌／非装备牌与目标可选性，见[共享验证证据](../verification-evidence.md#jin001_simayan)。
- **未完成与边界**：用户曾报告“应变牌后的下一回合，敌方普通杀→八卦阵视为闪，兴图误触发”，自动化未复现；真实连续回合回归及虚拟闪无应变条目检查通过，2026-11-13 用户复测确认无异常、反馈关闭，不据此追认具体根因，也未保留无复现依据的回合序号补丁。全局记录以使用牌事件为准，未覆盖“无任何目标但被使用”的边缘牌型。规范化描述待办见[规范化描述待办](#jin001-todo)。
