## 泰然

- **标识与依据**：运行时 ID `qiao__skill_jin002_1`；源码 [skill_jin002_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin002_1.lua)。规则见[司马师规范](../../../../rules/generals/jin002-simashi.md)。同将另见[夷灭](#jin002-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1507)。

> 出牌阶段开始时，你可以失去任意点体力，且可以弃置至多等同已损失体力值的牌。若如此做，结束阶段，你回复以此法失去的体力，摸等同以此法弃牌数的牌。

当前显示「回合结束时」，与[药枫桑大合集337.csv](../../../../../assets/docs/药枫桑大合集337.csv#L190)的时机一致。项目暂按「回合结束时」结算，最终时机待定。[司马师裁定](../../../../rules/generals/jin002-simashi.md#泰然)

- **实现与接口**：`fk.EventPhaseStart`（出牌阶段）询问是否失去任意点体力，并可弃置至多当前已损失体力值的牌；两项都可放弃。实际失去量与弃牌数分别交给 [jin_resources.lua](../../../../../pkg/qiao_generals/util/jin_resources.lua) 记录，由模式规则 [jin_resources_rule](../../../../../pkg/qiao_mode/skills/jin_resources_rule.lua) 在 `fk.TurnEnd` 逐条结算：先回复该次实际失去的体力，再摸该次实际弃牌数。
- **验证依据**：[jin_resources.lua](../../../../../tests/jin_resources.lua) 覆盖数字控件提交数值后继续弃牌和回末结算、两条记录分别结算、救回后按实际失去量记录；历史验证见[共享验证证据](../verification-evidence.md#jin-resources)。
- **未完成与边界**：后续时机尚未定案，当前暂按 `fk.TurnEnd` 逐条结算，**不是最终裁定**；回合结束前死亡、弃牌触发插入效果、客户端交互未验。

## 夷灭

- **标识与依据**：运行时 ID `qiao__skill_jin002_2`；源码 [skill_jin002_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin002_2.lua)。规则见[司马师规范](../../../../rules/generals/jin002-simashi.md)。同将另见[泰然](#jin002-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1508)。

> 限定技，当你对体力值大于等于你的角色造成伤害时，你可以令此伤害翻倍。

- **实现与接口**：限定技，`fk.DamageCaused`（造成伤害时、确定伤害值时）；`data.from == player`、当前伤害值 > 0，且目标体力值不小于司马师当前体力值。发动后 `data:changeDamage(data.damage)` 令本次伤害翻倍；取消不消耗 `HistoryGame` 限定机会，发动后才计入。
- **验证依据**：[jin_resources.lua](../../../../../tests/jin_resources.lua) 覆盖仅对体力不小于自己的目标翻倍、同一局只发动一次、目标体力更低时不触发；定向 15/15（3.686s），见[共享验证证据](../verification-evidence.md#jin-resources)。
- **未完成与边界**：伤害被防止、连锁传导、伤害值已被其他效果修改、暗置来源未单独验；客户端发动提示未人工验收。
