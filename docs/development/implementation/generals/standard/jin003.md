## 昭然

- **标识与依据**：运行时 ID `qiao__skill_jin003_1`；源码 [skill_jin003_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin003_1.lua)。规则见[司马昭规范](../../../../rules/generals/jin003-simazhao.md)。同将另见[挟征](#jin003-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1548)。

> 出牌阶段开始时，你可以令此阶段你的手牌对所有角色可见，且你首次失去每种花色最后的手牌后，你摸一张牌或弃置其他角色一张牌。

- **实现与接口**：出牌阶段开始加 `-phase` 可见标记；`visibility` 的 `card_visible` 只认当前在所有者手牌区的牌，因此本阶段之后获得的手牌也可见。`fk.AfterCardsMove` 以移动前牌面快照统计每种花色首次失去最后一张手牌，按 `newlyLostSuits` 固定并记录到 `lost_suits`；每个新花色由司马昭选择摸一张或弃其他角色一张。房间级可见性来源 [jin_information_rule](../../../../../pkg/qiao_mode/skills/jin_information_rule.lua) 已随 mode 接线，保证失去昭然后本阶段已经公开的手牌仍可见。阶段标记由 `-phase` 后缀清理，同花色事实不因重新获得而重开。
- 手牌转手时，【昭然】与房间级规则共用[移牌可见性](../../skill-ui.md#交牌和获得牌的可见性)。其他座位在本次移动中仍能看清牌面，进入新主人的手牌区后按新位置判断。
- **验证依据**：[jin_information.lua](../../../../../tests/jin_information.lua) 覆盖首次失去花色，以及失去【昭然】后【顺手牵羊】获得公开手牌。[shu_retinues.lua](../../../../../tests/shu_retinues.lua) 从第三个座位核对【白马义从】取得普通或公开手牌时的动画、战报及到手后的查看权限。
- **未完成与边界**：客户端可见性、同事件多花色、摸回同花色与暗置来源未人工验收。

## 挟征

- **标识与依据**：运行时 ID `qiao__skill_jin003_2`；源码 [skill_jin003_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin003_2.lua)。规则见[司马昭规范](../../../../rules/generals/jin003-simazhao.md)。同将另见[昭然](#jin003-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1527)。

> 限定技，出牌阶段，你可以令一名角色需将一张基本牌当【杀】对你指定的角色使用，否则你获得其所有手牌，交给其等同其体力值的牌。

- **实现与接口**：限定技，`active` 选两名不同角色：第一名被要求将一张基本牌当【杀】对第二名实际使用，第二名由效果显式指定；走 `card_use_targets` 的 `C.useVirtualCard`＋`C.explicit({ other_roles = true })`，移除默认攻击距离并把实际目标固定为第二名角色。被要求者在可取消的 `askToCards` 请求中选一张基本手牌或拒绝；拒绝、无基本手牌或无法合法用出时，司马昭一次获得其所有手牌，再交给其等于其当前体力值张自己的牌。用出后即使被闪也不进入惩罚。
- 罚则交牌时收牌人已确定。`askToCards` 仅要求选足手牌或装备，不再要求选自己。回归从客户端选择牌、确认和服务端实际移交验证。
- **验证依据**：[jin_reactive.lua](../../../../../tests/jin_reactive.lua) 覆盖基本牌当杀与拒绝惩罚，并含远距离反制/原来源/非原来源分支；6/6（1.379s）通过，见[共享验证证据](../verification-evidence.md#jin-reactive)。
- **未完成与边界**：目标死亡、无牌可给、转化基本牌、客户端两次选人未人工验收。
