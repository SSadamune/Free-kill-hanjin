## 通法

- **标识与依据**：运行时 ID `qiao__skill_jin004_1`；源码 [skill_jin004_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin004_1.lua)。规则见[贾充规范](../../../../rules/generals/jin004-jiachong.md)与[应变规范](../../../../rules/adaptation.md)。同将另见[悖弑](#jin004-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1571)。

> 与你势力相同的角色使用应变牌时，其可以交给你（若为你则弃置）一张牌并无视条件应变。

- **实现与接口**：全局监听 `fk.AfterCardUseDeclared`，由实际使用应变牌的角色发动。贾充自己使用时可在原生发动流程中明置，并以 `askToDiscard` 弃置一张自己的手牌或装备。其他同势力使用者以可取消的 `askToCards`＋`obtainCard` 向已生效的贾充技能来源交牌。付款即确认发动，`A.grantIgnore` 给本次用牌增加一个无视条件令牌，交由共享 [jin_adaptation_rule](../../../../../pkg/qiao_mode/skills/jin_adaptation_rule.lua) 结算。`PAID` 记录于 `data.extra_data`，同一使用只收一次。
- **验证依据**：[jin_adaptation.lua](../../../../../tests/jin_adaptation.lua) 覆盖支付者的发动记录、贾充自行支付并明置、其他角色不能明置贾充、支付后一个条目触发与延迟 ignore 令牌。公共机制历史结果见[共享验证证据](../verification-evidence.md#jin-adaptation)。
- **未完成与边界**：多个应变条目同时满足、无法支付与同一使用多次询问未单独验；客户端交互未人工验收。

## 悖弑

- **标识与依据**：运行时 ID `qiao__skill_jin004_2`；源码 [skill_jin004_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin004_2.lua)。规则见[贾充规范](../../../../rules/generals/jin004-jiachong.md)。同将另见[通法](#jin004-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1572)。

> 当你成为其他角色使用【杀】或锦囊牌的唯一目标时，你可以弃置一张同类别牌并取消之，获得之且可以使用一张牌（无距离限制），若你未因此对其造成伤害，你失去1点体力。

- **实现与接口**：`fk.TargetConfirming` 时若成为其他角色使用的【杀】或锦囊牌（含延时）唯一实际目标，弃一张同类别自己的牌，取消该目标并从原牌可得实体材料中取得材料。取消早于乌铁锁链的指定目标后。随后用 `card_use_targets` 允许使用一张无距离限制的牌。后续用牌在本次 `use.extra_data` 写 token `{ actor, source, damaged }`；房间级 `fk.Damage` 读取该 token，要求 `data.card == use.card`、伤害对象是原使用者 `source`，才记对原来源的伤害。未使用、取消或未造成伤害时失去 1 点体力。
- **验证依据**：[jin_reactive.lua](../../../../../tests/jin_reactive.lua) 覆盖取消唯一目标后乌铁锁链不横置、无伤害失去体力及原来源/非原来源分支。历史验证见[共享验证证据](../verification-evidence.md#jin-reactive)。
- **未完成与边界**：多目标、延时锦囊、转化牌材料、后续用牌被抵消与客户端选牌未人工验收。
