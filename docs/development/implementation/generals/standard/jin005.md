## 柔克

- **标识与依据**：运行时 ID `qiao__skill_jin005_1`；源码 [skill_jin005_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin005_1.lua)。规则见[羊祜规范](../../../../rules/generals/jin005-yanghu.md)与[易读描述的时机与然后](../../../../rules/general-principles.md)。同将另见[顺流](#jin005-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1592)。

> 与你势力相同的角色每回合使用首张【杀】可以改为冰【杀】，然后若此牌未造成伤害，你可以令至多两名角色横置或重置。你的手牌上限+X（X为横置角色数）。

- **实现与接口**：
  - `fk.PreCardUse` 按用牌者触发。用牌者接受询问后发动，并记录已生效的同势力柔克来源。柔克关闭预亮。首张杀事实读取本回合 `GameEvent.UseCard` 历史，暗置或尚未取得技能时的用牌历史仍保留。`UseCardData:changeCard` 保留本次使用与实体材料。首张杀原为冰杀也执行改牌，拒绝则不记录本次改牌。
  - `data.qiao_jin005_1_changed` 记录羊祜的角色 ID。房间级监听器 `#qiao__skill_jin005_1_follow` 在 `fk.CardUseFinished` 通过 `state_toggle.ask` 让羊祜一次选至多两名角色或取消。监听器的发动通知也译为「柔克」。`state_toggle.chain` 对每名所选角色读取当时状态并切换。用牌结束前失去柔克仍处理已经建立的后续。
  - `maxcards.correct_func` 先按 `player:hasSkill("qiao__skill_jin005_1")` 过滤，仅持有者获得“当前横置角色数”的手牌上限修正；`hasSkill` 为客户端公开判定。
- **验证依据**：[jin_chain.lua](../../../../../tests/jin_chain.lua) 覆盖用牌者发动、普通和冰属性首张杀改为冰杀、拒绝改冰杀、未伤害后按状态横置/重置、手牌上限及改牌后失技保留后续。历史结果见[共享验证证据](../verification-evidence.md#jin-chain)。
- **未完成与边界**：多羊祜来源仅由来源 id 设计覆盖，未做双来源夹具；冰杀真实伤害重置由同一套件单独验证；客户端改牌显示与暗置历史未人工验收。

## 顺流

- **标识与依据**：运行时 ID `qiao__skill_jin005_2`；源码 [skill_jin005_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin005_2.lua)。规则见[羊祜规范](../../../../rules/generals/jin005-yanghu.md)。副将技；同将另见[柔克](#jin005-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1593)。

> 副将技（☯️-1），当你造成属性伤害后，你可以依次弃置受伤角色和所有横置的角色各一张牌。

- **实现与接口**：`Skill.DeputyPlace`；副将体力贡献 -1 由 `data/standard.lua` 的 `deputyHpAdjust` 提供，不另发标记。`fk.Damage`（造成伤害后）且 `data.from == player`、伤害为火/雷/冰属性。先固定“伤害后、第一次弃牌前”的横置名单，再先由羊祜为受伤者选一张手牌/装备弃置，后按名单为每名横置角色各弃一张；不做全局去重，受伤者若仍横置会再次纳入。弃牌走 `askToChooseCard`＋`throwCard`，由羊祜选牌。
- **验证依据**：[jin_chain.lua](../../../../../tests/jin_chain.lua) 覆盖受伤者与当时横置者各弃一张、受伤者不重复按伤害前快照纳入；定向 6/6，见[共享验证证据](../verification-evidence.md#jin-chain)。
- **未完成与边界**：受伤者仍横置时二次弃牌、冰属性连锁、无牌/禁弃、目标死亡与客户端选牌未单独验。
