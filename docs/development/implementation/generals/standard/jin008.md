# JIN008 夏侯徽

[返回分包索引](../jin-standard.md)

## 宜室

- **标识与依据**：运行时 ID `qiao__skill_jin008_1`；源码 [skill_jin008_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin008_1.lua)。规则见[夏侯徽规范](../../../../rules/generals/jin008-xiahouhui.md)。同将另见[识度](#jin008-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1659)。

> 每回合限一次，与你势力相同的角色弃置任意角色的牌后，你可以将其中一张交给其，然后你获得其余一张牌。

- **实现与接口**：全局监听 `fk.AfterCardsMove`，每回合一次；按弃置操作者 `proposer`（不是牌的原拥有者 `from`）和同势力筛选，收集本批仍在弃牌堆的牌。选一张交给操作者，再从剩余牌中选一张获得；只取一张，不收取全部剩余。已被其他同时机效果移走的牌不再从新区域强取；第一步合法执行后不因第二步无法执行而倒推取消。
- **验证依据**：[jin_resources.lua](../../../../../tests/jin_resources.lua) 覆盖交给一张再获得一张、按操作者势力而非原拥有者；定向 15/15（3.686s），见[共享验证证据](../verification-evidence.md#jin-resources)。
- **未完成与边界**：多批弃牌、同一操作者多次弃置、目标死亡与客户端选牌未人工验收。

<a id="jin008-2"></a>

## 识度

- **标识与依据**：运行时 ID `qiao__skill_jin008_2`；源码 [skill_jin008_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin008_2.lua)。规则见[夏侯徽规范](../../../../rules/generals/jin008-xiahouhui.md)。同将另见[宜室](#jin008-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1660)。

> 出牌阶段限一次，你可以与一名角色拼点。若你赢，你获得其所有手牌，然后你将半数手牌（向下取整）交给其。

- **实现与接口**：出牌阶段限一次，`active` 选一名合法其他角色真实拼点；只有 `pindian.results[to].winner == player` 才获得其所有手牌，再按此时自己全部手牌数向下取半交还。收牌人已由拼点确定，`askToCards` 只选手牌，给牌无需经过禁弃过滤。回归从确认按钮生成回包。客户端可用性使用 `canPindian`。
- **验证依据**：[jin_resources.lua](../../../../../tests/jin_resources.lua) 覆盖赢得拼点后获得再交还半数、平局不获得；定向 15/15（3.686s），见[共享验证证据](../verification-evidence.md#jin-resources)。
- **未完成与边界**：拼点牌被移走、手牌不足半数、目标死亡与客户端拼点交互未人工验收。
