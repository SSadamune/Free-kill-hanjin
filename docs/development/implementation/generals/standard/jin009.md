## 权变

- **标识与依据**：运行时 ID `qiao__skill_jin009_1`；源码 [skill_jin009_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin009_1.lua)。规则见[司马懿规范](../../../../rules/generals/jin009-simayi.md)；共享工具 [jin_deck.lua](../../../../../pkg/qiao_generals/util/jin_deck.lua)。同将另见[骤霆](#jin009-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1684)。

> 当你于出牌阶段内第一次使用每种花色的手牌时，你可以令你此阶段不能再使用此花色的手牌，然后卜算3并摸一张牌。

- **实现与接口**：`fk.AfterCardUseDeclared` 按本阶段 `GameEvent.UseCard` 历史判断每种花色的首张真实手牌使用；响应中的实际使用也计入，纯打出不计。发动后把该花色写入 `jin_deck.lua` 的中性 `-phase` 标记，同时在角色插画用「权变」列出本阶段被禁止使用的手牌花色；模式规则 [jin_deck_rule](../../../../../pkg/qiao_mode/skills/jin_deck_rule.lua) 在真实用牌入口禁止使用该花色手牌，但不禁止打出、不限制非手牌来源，失技后已建立限制保留。
- **验证依据**：[jin_deck.lua](../../../../../tests/jin_deck.lua) 覆盖首张红桃后禁手牌不禁响应；3/3（0.787s），见[共享验证证据](../verification-evidence.md#jin-deck)。
- **未完成与边界**：暗置/晚明置、同花色重复获得、客户端禁选显示未人工验收。

## 骤霆

- **标识与依据**：运行时 ID `qiao__skill_jin009_2`；源码 [skill_jin009_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin009_2.lua)。规则见[司马懿规范](../../../../rules/generals/jin009-simayi.md)。同将另见[权变](#jin009-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1685)。

> 限定技，出牌阶段，你可以连续亮出且使用牌堆顶牌，直到无法使用或亮出牌数达到角色数。

- **实现与接口**：限定技，出牌阶段发动；每次只从牌堆顶亮出一张并移入处理区，用正式 `askToUseRealCard` 实际使用（默认已执行，`extraUse` 不占空闲杀次数），完整结算后再取下一张；无法使用或亮出数达到当前存活角色数即止，不能任意取消。`expand_pile` 只授权本次亮出的处理区牌，不先拿入手牌，因此不会触发权变。
- **验证依据**：[jin_deck.lua](../../../../../tests/jin_deck.lua) 覆盖处理区顶牌真实使用、无法使用即止、不能以手牌替代；3/3（0.787s），处理区唯一牌修正已通过，见[共享验证证据](../verification-evidence.md#jin-deck)。
- **未完成与边界**：亮出即死亡、使用被抵消、牌堆不足与客户端连续用牌未人工验收。
