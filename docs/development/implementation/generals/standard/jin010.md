## 伤逝

- **标识与依据**：运行时 ID `qiao__skill_jin010_1`；源码 [skill_jin010_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin010_1.lua)。规则见[张春华规范](../../../../rules/generals/jin010-zhangchunhua.md)。同将另见[扼绝](#jin010-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1708)。

> 一名角色的结束阶段，你可以选择一项：1.若其手牌数大于你，将任意张手牌当冰【杀】对其使用；2.摸牌至你已损失的体力值。

- **实现与接口**：结束阶段在同一可取消询问中展示冰【杀】和补牌两个选项，仅允许选择当前合法项。冰【杀】至少选择一张实际手牌。开放该选项前检查有无合法材料组合，选择后复核具体合成牌的限制，再以 `C.useVirtualCard` 和显式目标策略固定当前结束阶段角色。`extraUse` 不占空闲出杀次数。两项均不可执行时不发请求。
- **验证依据**：[jin_sources.lua](../../../../../tests/jin_sources.lua) 覆盖双合法项时选择补牌、零手牌、单合法项、取消选牌、一张材料实际出冰【杀】、潜袭禁用材料及两张合成后无花色的合法分支。见[共享验证证据](../verification-evidence.md#jin-sources)。
- **未完成与边界**：真人客户端选项及对局中动态状态变化待复测。

## 扼绝

- **标识与依据**：运行时 ID `qiao__skill_jin010_2`；源码 [skill_jin010_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin010_2.lua)。规则见[张春华规范](../../../../rules/generals/jin010-zhangchunhua.md)。同将另见[伤逝](#jin010-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1709)。

> 当你造成伤害时，若你没有手牌，你可以失去一个其他技能，然后令此伤害+1。

- **实现与接口**：`fk.DamageCaused`，张春华无手牌时可失去自己实际拥有的一个其他武将技能，令本次伤害 +1。[候选来源](../../../../../pkg/qiao_generals/util/jin_sources.lua)按武将牌、角色获授来源和翼从实例分别列出。翼从技能以翼从名显示，选中后撤销这一份技能来源。大旗、统领、标记、装备和规则技能不入候选。已建立的效果按原时限结算，伤害增加写入本次 `DamageData`。
- **验证依据**：[jin_sources.lua](../../../../../tests/jin_sources.lua) 覆盖按来源失技、伤害加一，以及同名翼从逐份失技、同步后不恢复。原有武将牌交换定向验收见[共享验证证据](../verification-evidence.md#jin-sources)。
- **未完成与边界**：无合法失技候选、失去后伤害被防止、客户端选项未人工验收。
