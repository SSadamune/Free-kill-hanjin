## 慈威

- **标识与依据**：运行时 ID `qiao__skill_jin012_1`；源码 [skill_jin012_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin012_1.lua)。规则见[羊徽瑜规范](../../../../rules/generals/jin012-yanghuiyu.md)。同将另见[弘训](#jin012-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1748)。

> 其他角色于其回合内使用第二张牌时，你可以弃置一张牌，若其使用牌为基本牌或普通锦囊牌，则令此牌对任意个目标无效，否则其横置。

- **实现与接口**：全局监听 `fk.AfterCardUseDeclared`，只在该事件使用者就是当前回合角色、且其为其他角色时检查。第二张牌按本回合 `GameEvent.UseCard` 事件计数，包含响应中的实际使用和装备使用；纯“打出”只生成 `RespondCard`，不计入。发动消耗为弃置自己一张手牌或装备牌（`askToDiscard(skip)`＋`throwCard`）。若此牌为基本牌或普通锦囊，允许选择任意个当前目标（含零个），写入 `UseCardData.nullifiedTargets`，由引擎按目标跳过响应与效果，不 `removeTarget`、不取消整张牌；装备牌或延时锦囊则对使用者调用 `setChainState(true)`，不翻面、不重置。锁定上游 `hegemony/pkg/jin_zqdl/skills/ciwei.lua` 的慈威是旧版“取消整张牌所有目标”，效果不同且未复用；本实装采用引擎目标级 `nullifiedTargets` 字段。
- **验证依据**：[jin_basic.lua](../../../../../tests/jin_basic.lua) 以真实 `Turn`／`useCard`／`responseCard` 验证：第一张装备后纯打出【闪】不计，第二张【杀】的目标无效且不受伤；普通锦囊【决斗】目标无效；第二张装备与延时锦囊均横置使用者且延时牌正常进入判定区；每例弃置一张牌。本批 `jin_basic` 套件合计 19/19。
- **未完成与边界**：未应用开发适配的本体人工交互验收尚未执行；在“使用时”之后由其他技能追加的目标不进入本次无效名单，客户端多目标选择未人工验收。

## 弘训

- **标识与依据**：运行时 ID `qiao__skill_jin012_2`；源码 [skill_jin012_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin012_2.lua)。规则见[羊徽瑜规范](../../../../rules/generals/jin012-yanghuiyu.md)。同将另见[慈威](#jin012-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1749)。

> 锁定技，与你势力相同的角色的结束阶段，若其：已受伤，你令其摸一张牌；已横置，你令其重置并摸一张牌。

- **实现与接口**：锁定技，`fk.EventPhaseStart`（`Player.Finish`）的全局触发；`B.sameKingdom` 复用 [jin_basic.lua](../../../../../pkg/qiao_generals/util/jin_basic.lua) 与 hegemony 公共势力比较，合法情况下包含自己。已受伤先摸一张；已横置先用 `setChainState(false)` 定向重置，再摸一张；两项分别检查，可各执行一次。没有发动询问，也不依赖服务端私有字段。短时按同名查找未发现同效果上游实现；重置复用引擎 `setChainState`，摸牌复用 `drawCards`。
- **验证依据**：[jin_basic.lua](../../../../../tests/jin_basic.lua) 覆盖自己同时受伤且横置时摸两张并重置、同势力仅受伤／仅横置分别摸一张、不同势力不摸牌且不重置。本批 `jin_basic` 套件合计 19/19。
- **未完成与边界**：未应用开发适配的本体人工交互验收尚未执行；暗置来源、多来源同势力与死亡中断未单独覆盖。
