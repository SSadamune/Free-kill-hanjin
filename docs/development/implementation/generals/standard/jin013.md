## 乘流

- **标识与依据**：运行时 ID `qiao__skill_jin013_1`；源码 [skill_jin013_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin013_1.lua)。规则见[王濬规范](../../../../rules/generals/jin013-wangjun.md)与[应变规范](../../../../rules/adaptation.md)。同将另见[克清](#jin013-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1769)。

> 你的伤害牌具有<富甲→改为雷电伤害>，且结算后你可以横置任意名受到此牌伤害的角色。

- **实现与接口**：`fk.PreCardUse` 对王濬使用的伤害牌加入〈富甲→改为雷电伤害〉条目；条目写在本次 `use` 上，由共享应变规则 [jin_adaptation_rule](../../../../../pkg/qiao_mode/skills/jin_adaptation_rule.lua) 读取，不覆盖其他条目，也不把牌永久改成雷伤。`fk.CardUseFinished` 按本次 `damageDealt` 的关联角色提供横置，不要求富甲已触发，也不使用回合总伤害或当前手牌实体。已明置时自动赋条目；暗置时走真实 `TriggerSkill` 选择明置后发动。
- **验证依据**：[jin_adaptation.lua](../../../../../tests/jin_adaptation.lua) 覆盖本次雷伤、无富甲也可横置实际受伤者；应变定向 5/5；公共应变 25/25、`ignore_times` 14/14 属公共机制历史结果，不挪作本技能覆盖，见[共享验证证据](../verification-evidence.md#jin-adaptation)。
- **未完成与边界**：暗置来源、伤害牌被抵消、多个伤害目标、条目被其他效果覆盖与客户端条目显示未人工验收。

## 克清

- **标识与依据**：运行时 ID `qiao__skill_jin013_2`；源码 [skill_jin013_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin013_2.lua)。规则见[王濬规范](../../../../rules/generals/jin013-wangjun.md)。同将另见[乘流](#jin013-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1770)。

> 出牌阶段限一次，你可以选择一名已横置的其他角色，直到你再次发动该技能或死亡：当其使用或打出牌时，若其横置，其弃置一张牌。

- **实现与接口**：出牌阶段限一次，`active` 选一名已横置其他角色。目标身上以表标记记录来源 id；首次发动时按需安装房间级延迟监听器 `#qiao__skill_jin013_2_effect`，分别监听 `fk.CardUsing` 与 `fk.CardResponding`：目标横置且来源仍存活时，由目标自己 `askToDiscard`（已执行弃牌）一张手牌/装备，不双计、不每回合限一次。失去克清不撤销监听器；再次发动替换旧目标；来源死亡由 `fk.Death` 清理，监听器亦在下次触发时惰性清理已死来源。
- **验证依据**：[jin_chain.lua](../../../../../tests/jin_chain.lua) 覆盖发动、首次弃牌、失技后继续触发、来源不再存活后不触发；定向 6/6，见[共享验证证据](../verification-evidence.md#jin-chain)。真实 `killPlayer` 因测试夹具先游戏结束，死亡用例改用真实 `dead` 状态后继续真实用牌，`fk.Death` 清理链路待独立夹具。
- **未完成与边界**：真实死亡事件、跨重连监听器、多个来源/目标、客户端弃牌交互未人工验收。
