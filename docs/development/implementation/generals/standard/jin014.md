## 膂力

- **标识与依据**：运行时 ID `qiao__skill_jin014_1`；源码 [skill_jin014_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin014_1.lua)。规则见[文鸯规范](../../../../rules/generals/jin014-wenyang.md)。同将另见[夺气](#jin014-2)，关联翼从见[文虎](retinue-wenhu.md#wenhu)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1794)。

> 每回合限一次，当你造成伤害后，你可以选择一项：1.摸牌至体力值；2.弃置所有手牌，然后回复体力至X点（X为以此法弃置的牌数）。

- **实现与接口**：`fk.Damage`（造成伤害后，使用者为事件目标；不是 `DamageFinished`）且 `data.from == player`、`data.damage > 0`，按 `HistoryTurn` 每回合限一次，不按伤害点数重复。选项一仅在当前手牌数小于体力值时出现，使用 [jin_basic.lua](../../../../../pkg/qiao_generals/util/jin_basic.lua) 的 `drawHandToHp`，按当前体力值与手牌数差额摸牌；手牌已不少于体力值时不展示无效的补至项。选项二仅在 `canDiscardAllHand` 为真（手牌非空且全部可弃）时出现；先实际弃置全部手牌，再按实际张数 `recoverHpTo`，受体力上限限制，当前体力高于目标值时不降低。两项均不可执行时不发动、不占次数；空手不能以部分弃置充作全弃。短时按同名查找未发现同效果上游实现；复用引擎 `Damage`、`drawCards`、`throwCard` 与 `recover`。
- **验证依据**：[jin_basic.lua](../../../../../tests/jin_basic.lua) 覆盖补至当前体力值、弃两张后回复至2、体力高于弃牌数时不被降低、空手只显示摸牌项、手牌不少于体力值时隐藏补至项、`fk.Damage` 早于 `fk.Damaged` 的结算顺序、同一回合第二次伤害不再发动。本批定向 19/19。
- **未完成与边界**：未应用开发适配的本体人工交互验收尚未执行；伤害被防止、濒死死亡、禁弃来源并存等边界未单独覆盖。

## 夺气

- **标识与依据**：运行时 ID `qiao__skill_jin014_2`；源码 [skill_jin014_2.lua](../../../../../pkg/qiao_generals/skills/skill_jin014_2.lua)。规则见[文鸯规范](../../../../rules/generals/jin014-wenyang.md)。同将另见[膂力](#jin014-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1795)。

> 限定技，每回合结束时，若当前回合角色没有手牌，你可以获得一个额外的回合。

- **实现与接口**：限定技，全局监听 `fk.TurnEnd`，不是结束阶段；每个回合结束时按当时手牌重新检查当前回合角色是否空手，不使用此前快照。`HistoryGame` 限制整局一次。满足时询问文鸯，并以 `gainAnExtraTurn(true, skill.name)` 把额外回合加入房间正式延迟队列，由回合流程在现回合结束后执行，不手工递归调用阶段结算。当前回合角色可以是文鸯自己。短时按同名查找未发现同效果上游实现；复用引擎 `ServerPlayer:gainAnExtraTurn` 与房间 `extra_turn_list` 调度，与放权共享同一正式入口。
- **验证依据**：[jin_basic.lua](../../../../../tests/jin_basic.lua) 覆盖回合结束时空手排队额外回合并记录 `who`／`reason`；结束阶段不触发、有手牌不触发；同一局第二次回合结束不再排队。本批 `jin_basic` 套件合计 19/19。
- **未完成与边界**：未应用开发适配的本体人工交互验收尚未执行；只验证队列与限制，未在自动测试中完整跑完额外回合的全部阶段与客户端表现。
