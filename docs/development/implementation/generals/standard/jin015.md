## 前驱

- **标识与依据**：运行时 ID `qiao__skill_jin015_1`；源码 [skill_jin015_1.lua](../../../../../pkg/qiao_generals/skills/skill_jin015_1.lua)。规则见[石苞规范](../../../../rules/generals/jin015-shibao.md)与[应变规范](../../../../rules/adaptation.md)。同将无其他已实装技能。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1811)。

> 与你势力相同的角色准备阶段，你可以使用一张无距离限制的【杀】<助战→弃置目标角色装备区里的一张牌>，然后若此【杀】造成伤害，当前回合角色获得此【杀】并摸一张牌。

- **实现与接口**：全局监听同势力角色（含自己）准备阶段，石苞可用 `card_use_targets` 的 `askToUseCard` 选择一张【杀】的真实使用数据（允许合法转化，不凭空生成杀）；`C.bypassDistance` 只取消距离限制，`extra_data.bypass_times/extraUse` 不占通常出杀次数，随后 `C.useCard` 真实执行。本次使用附加〈助战→弃置目标角色装备区里的一张牌〉条目。模式在 `fk.CardUseFinished` 读取这一次【杀】的前驱登记。即使石苞中途失去技能，若此杀造成过伤害，存活的当前回合角色仍获得处理区内的材料，实际取得后摸一张。
- **验证依据**：[jin_adaptation.lua](../../../../../tests/jin_adaptation.lua) 覆盖无距离真实用杀、助战弃目标装备、造成伤害后当前回合角色获得此杀并摸牌，包含用杀过程中失去前驱；应变定向 5/5；公共应变 25/25、`ignore_times` 14/14 属公共机制历史结果，不挪作本技能覆盖，见[共享验证证据](../verification-evidence.md#jin-adaptation)。
- **未完成与边界**：未应用开发适配的本体交互未验；转化杀无实体材料、被闪与多来源同势力仍待逐项验证。
