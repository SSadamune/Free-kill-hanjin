## 济世

- **标识与依据**：运行时 ID `qiao__skill_qun001_1`；源码 [skill_qun001_1.lua](../../../../../pkg/qiao_generals/skills/skill_qun001_1.lua)。规则见[华佗规范](../../../../rules/generals/qun001-huatuo.md)。同将另见[除疠](#qun001-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2540)。

> 你可以将红色牌当【桃】对濒死角色使用 [，此濒死结算后，若此武将为客将，与你势力不同的角色依次选择是否用一个武将交换此武将]。

- **实现与接口**：可用自己的红色手牌或装备牌当【桃】对濒死角色使用，没有回合外限制；客户端请求与服务端 `before_use` 都复核目标确实处于濒死及材料归属。救援记录在本次桃的 `CardUsing` 时建立，先于回复清除濒死状态，绑定模式级 [qun_dying_rule](../../../../../pkg/qiao_mode/skills/qun_dying_rule.lua) 分配的本次濒死序号；濒死结算结束后，仅当提供技能的华佗将牌为客将，才按逆时针逐人询问是否用一张明置武将牌交换，首次成功即止，跨势力许可与交换本身复用公共交换模块。
  `Fk:getDescription` 按公开的房间设置展开济世的方括号内容。图鉴无房间设置时展示默认开启的版本。
- **验证依据**：已执行 [qun_dying.lua](../../../../../tests/qun_dying.lua) 的 `testJishiSavesWithRedEquipmentThenExchangesHuatuoOnce`、`testJishiStillExchangesWhenDyingPlayerDies`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：「客将替换规则」控制济世的交换段。关闭房间设置、连续交换和中途死亡组合仍待客户端人工验收。见[华佗规范](../../../../rules/generals/qun001-huatuo.md)。

## 除疠

- **标识与依据**：运行时 ID `qiao__skill_qun001_2`；源码 [skill_qun001_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun001_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN001。同将另见[济世](#qun001-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2541)。

> 出牌阶段限一次，你可以选择至多三名不与彼此势力相同的其他角色，弃置你和这些角色各一张牌，以此法失去黑桃牌的角色各摸一张牌。

- **实现与接口**：出牌阶段限一次，同时选定华佗自己将弃置的一张手牌或装备，以及至多三名**彼此势力不相同**的其他角色。之后按结算顺序选择其他目标的牌并执行各次弃置。全部弃置完成后按实际失去的牌结算，失去黑桃者各摸一张，后弃的黑桃不漏记。
- **验证依据**：已执行 [qun_basic.lua](../../../../../tests/qun_basic.lua) 的 `testChuliTwoCandidatesSpadeDraws`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
  按钮计算经 `Fk:currentRoom()` 读取公开存活角色，不读取 `ClientPlayer` 不具备的 `room` 字段。`testChuliClientAvailabilityWithoutPlayerRoom` 使用配套客户端角色／房间走 `ReqPlayCard.setup` 与 `skillButtonValidity`，覆盖合法候选、本人无牌、全场无候选及阶段次数耗尽；已通过自动化回归。
- **未完成与边界**：候选势力并列、目标无牌、华佗自己无牌等边界未穷举；客户端选人／弃牌未人工验收。
