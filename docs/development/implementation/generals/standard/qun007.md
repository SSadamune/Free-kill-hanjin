## 完杀

- **标识与依据**：运行时 ID `qiao__skill_qun007_1`；源码 [skill_qun007_1.lua](../../../../../pkg/qiao_generals/skills/skill_qun007_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN007。同将另见[乱武](#qun007-2)及[帷幕](#qun007-3)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2665)。

> 锁定技，其他角色于你回合内进入濒死时，除其外的其他角色于结算中不能对其使用【桃】。

- **实现与接口**：`fk.EnterDying` 仅在贾诩自己的回合、其他角色进入濒死时给本次濒死设置标记；实际用桃禁止与清理放在模式级 [qun_dying_rule](../../../../../pkg/qiao_mode/skills/qun_dying_rule.lua)，除濒死者外均受限，贾诩本人也无豁免，不把限制写成永久状态。
- **验证依据**：已执行 [qun_dying.lua](../../../../../tests/qun_dying.lua) 的 `testWanshaBlocksEveryoneButDyingPlayer`、`testWanshaAllowsDyingPlayerOwnPeach`、`testWanshaInactiveOutsideJiaxuTurn`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：贾诩在濒死结算中死亡／失技、多个完杀来源并存未穷举；客户端求桃提示未人工验收。

## 乱武

- **标识与依据**：运行时 ID `qiao__skill_qun007_2`；源码 [skill_qun007_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun007_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN007。同将另见[完杀](#qun007-1)，帷幕见[帷幕](#qun007-3)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2666)。

> 限定技，出牌阶段，你可以令所有其他角色各选择一项：1.使用一张【杀】（须指定其距离最近的另一名角色为目标）；2.失去1点体力。

- **实现与接口**：限定技，出牌阶段从当前回合角色起逆时针逐人处理其他角色；先按全体其他角色算最近距离，再用 `card_use_targets` 的显式策略要求所选【杀】目标至少包含一名最近且合法角色，最后按通常【杀】流程真实使用一张【杀】，不能改选较远目标，也不是“视为使用”。
- **验证依据**：已执行 [qun_cards.lua](../../../../../tests/qun_cards.lua) 的 `testLuanwuRealSlashIncludesNearest`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：无合法【杀】目标、最近目标死亡／失技、多目标上限等排列未逐项覆盖；客户端选目标未人工验收。

## 帷幕

- **标识与依据**：运行时 ID `qiao__skill_qun007_3`；源码 [skill_qun007_3.lua](../../../../../pkg/qiao_generals/skills/skill_qun007_3.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN007。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2667)。

> 锁定技，你成为黑色锦囊牌的目标时，取消之。

- **实现与接口**：锁定技，`fk.TargetConfirming` 时若目标为贾诩、牌为黑色锦囊，则 `data:cancelTarget(player)` 取消该目标；不改成禁止选取，也不额外用 `BeforeCardsMove` 拦截黑色延时锦囊移入判定区。
- **验证依据**：已执行 [qun_judgement.lua](../../../../../tests/qun_judgement.lua) 的 `testWeimuCancelsOnlyBlackTrickTarget`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：多目标黑色锦囊、其他角色同时改目标等组合未专项覆盖；客户端提示未人工验收。
