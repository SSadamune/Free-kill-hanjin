## 雷击

- **标识与依据**：运行时 ID `qiao__skill_qun010_1`；源码 [skill_qun010_1.lua](../../../../../pkg/qiao_generals/skills/skill_qun010_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN010。同将另见[鬼道](#qun010-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2726)。

> 当你使用或打出【闪】时，你可令一名其他角色判定，若为：黑桃，你对其造成2点雷电伤害；梅花，你回复1点体力，对其造成1点雷电伤害。

- **实现与接口**：分别接使用【闪】的 `fk.CardUsing` 与纯打出的 `fk.CardResponding`，不以一个入口覆盖两者；令一名其他角色走正式判定，黑桃造成 2 点雷电伤害，梅花先由张角回复 1 点、再造成 1 点雷电伤害。判定使用最终生效结果，改判后按新花色结算。
- **验证依据**：已执行 [qun_basic.lua](../../../../../tests/qun_basic.lua) 的 `testLeijiOneAskPerJinkAndSpadeDamage`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：梅花分支、改判后重结算、无其他角色可选的边界未直接覆盖；客户端判定展示未人工验收。

## 鬼道

- **标识与依据**：运行时 ID `qiao__skill_qun010_2`；源码 [skill_qun010_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun010_2.lua)。规则见[张角规范](../../../../rules/generals/qun010-zhangjiao.md)。同将另见[雷击](#qun010-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2727)。

> 当一张判定牌生效前，你可以打出一张黑色牌替换之。

- **实现与接口**：`fk.AskForRetrial` 时从手牌或装备区选一张黑色、未被禁止打出的牌，先走真实 `responseCard` 完成打出（跳过默认弃置），再 `changeJudge{exchange=true}` 替换判定牌并把原判定牌交给张角；`response=true` 只指定移动原因，不产生完整打出事件，不能省去 `responseCard`。
- **验证依据**：用一个可取消的 `askToCards` 请求列出黑色手牌和装备。`include_equip` 允许客户端点选装备，确认后按当前牌区和打出限制复核。[qun_retrial.lua](../../../../../tests/qun_retrial.lua) 覆盖取消时原判继续、点选黑色装备后改判并获得原判定牌，以及红牌不进入请求。
- **未完成与边界**：其他改判者竞争、打出牌被中途移动、装备区最后一牌等边界未穷举；客户端改判提示未人工验收。
