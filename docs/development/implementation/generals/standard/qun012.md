## 悲歌

- **标识与依据**：运行时 ID `qiao__skill_qun012_1`；源码 [skill_qun012_1.lua](../../../../../pkg/qiao_generals/skills/skill_qun012_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN012。同将另见[断肠](#qun012-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2767)。

> 当一名角色受到【杀】造成的伤害后，你可以弃置一张牌，然后令其判定，若为：
> 红桃，其回复1点体力；方片，其摸两张牌；
> 梅花，来源弃置两张牌；黑桃，来源叠置。

运行时用 `<br>` 表示原文换行，措辞与原文一致。

- **实现与接口**：角色受到【杀】造成的伤害后，蔡文姬弃一张牌，令受伤角色走正式判定（鬼道可改判）；红桃其回复 1 点，方片其摸两张，梅花伤害来源弃两张，黑桃伤害来源定向叠置。叠置仅平置→叠置，已叠置不翻回；来源缺失或已死亡时该分支不执行。
- **验证依据**：已执行 [qun_judgement.lua](../../../../../tests/qun_judgement.lua) 的 `testBeigeHeartRecoversDamagedPlayer`、`testBeigeSpadeStacksSourceWithoutFlippingBack`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：方片／梅花分支、无来源伤害、来源中途死亡未逐项覆盖；客户端判定与弃牌未人工验收。

## 断肠

- **标识与依据**：运行时 ID `qiao__skill_qun012_2`；源码 [skill_qun012_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun012_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN012 与[技能效果分类](../../../../../rulebook/topics/skill-effect-classification.md)。同将另见[悲歌](#qun012-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2768)。

> 锁定技，你死亡时，你令来源失去一张武将牌的技能。

角色状态以「断肠 + 武将牌名」显示失去技能的对象。未明置的牌名用私密标记发给本人，其他视角只看见「暗置武将牌」。交换后标记跟随失技的武将牌，明置后显示实际牌名。

- **实现与接口**：锁定技，`fk.Death` 时由蔡文姬选择来源的一张武将牌，按该牌移除技能并作永久失技记录；来源选择、按牌失技与记录在模式级 [qun_duanchang](../../../../../pkg/qiao_mode/rules/qun_duanchang.lua)，[qun_duanchang_rule](../../../../../pkg/qiao_mode/skills/qun_duanchang_rule.lua) 在后续明置时幂等兜底，交换通过 `general_exchange` 来源过滤器避免重新授技。已建立的延时效果不因失技撤销。
- **验证依据**：已执行 [qun_duanchang.lua](../../../../../tests/qun_duanchang.lua) 的 `testChooseOneCardKeepsTheOther`、`testHiddenCardStaysLostAfterReveal`、`testExchangeDoesNotRestoreLostSkills`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：失技记录覆盖整张将牌的印刷技能；预亮不作为本牌的独立来源，另一将同名来源须仍有效。`GeneralShown` 复核已失来源及仍存来源，相关暗将与共享马术回归已通过定向验证；同名来源恢复只在该角色持有被断肠将牌时启用，不处理普通明置的授技。客户端选择与明置提示未人工验收。
