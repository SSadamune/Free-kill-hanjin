## 雄异

- **标识与依据**：运行时 ID `qiao__skill_qun013_2`；源码 [skill_qun013_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun013_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN013。同将马术复用[共享马术锚点](shu006.md#shu006-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2793)。

> 限定技，出牌阶段，你可以令所有与你势力相同的角色各摸三张牌，然后若与你势力相同的角色数最小，你回复1点体力。

- **实现与接口**：限定技，出牌阶段先令所有与自己势力相同的角色（含自己）各摸三张；再按锁定上游 `hegemony.util` 的 `compareKingdomWith`／`getKingdomPlayersNum` 统计，若同势力人数全场最少（含并列）才回复 1 点，不自行聚合势力字符串。
- **验证依据**：已执行 [qun_basic.lua](../../../../../tests/qun_basic.lua) 的 `testXiongyiSameKingdomDrawsAndTieMinimumRecovers`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：野心家、并列最少、摸牌中死亡等边界未穷举；客户端提示未人工验收。
