## 死谏

- **标识与依据**：运行时 ID `qiao__skill_qun016_1`；源码 [skill_qun016_1.lua](../../../../../pkg/qiao_generals/skills/skill_qun016_1.lua)。规则见[田丰来源基线](../../../../rules/generals/qun016-tianfeng.md)。同将另见[随势](#qun016-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2825)。

> 当你失去最后的手牌后，或当你的体力值变化为1后，你可以弃置一名其他角色的一张牌。

- **实现与接口**：两个独立时机。失去最后的手牌：本次移动批次确实有手牌离开，且移动结束后为空手，不在已是空手的其他批次重复触发。体力值变化为 1：比较变化前后，仅从非 1 变为 1 时触发，维持在 1 或变为 0 不触发，也不要求是失去体力。效果为弃一名其他角色一张手牌或装备，不含判定区，不附带回复。
- **验证依据**：已执行 [qun_basic.lua](../../../../../tests/qun_basic.lua) 的 `testSijianLastHandcardDiscardsOtherCard`、`testSijianNotTriggeredWhileStillHoldingHandcards`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：同批次多次失牌、体力一次变化跨过 1、目标无牌等边界未穷举；客户端选择未人工验收。

## 随势

- **标识与依据**：运行时 ID `qiao__skill_qun016_2`；源码 [skill_qun016_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun016_2.lua)。规则见[田丰来源基线](../../../../rules/generals/qun016-tianfeng.md)。同将另见[死谏](#qun016-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2826)。

> 锁定技，其他角色进入濒死时，若来源与你势力相同，你摸一张牌；与你势力相同的其他角色死亡时，你失去1点体力或弃置所有手牌。

- **实现与接口**：锁定技，两个独立分支。其他角色进入濒死时，检查造成此次濒死的来源（不是濒死角色）与田丰势力相同才摸一张；无来源的体力流失不摸。与自己势力相同的其他角色死亡时，由田丰选择失去 1 点体力或弃置所有手牌，即使当前无手牌也提供两选项，不强制失去体力。
- **验证依据**：已执行 [qun_basic.lua](../../../../../tests/qun_basic.lua) 的 `testSuishiEnterDyingDrawsForSameKingdomKiller`、`testSuishiDeathChoiceDiscardsAllHandcards`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：来源为暗将／野心家、死亡时无手牌可选、同回合多次濒死未穷举；客户端选择未人工验收。
