## 祸水

- **标识与依据**：运行时 ID `qiao__skill_qun018_1`；源码 [skill_qun018_1.lua](../../../../../pkg/qiao_generals/skills/skill_qun018_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN018。同将另见[倾城](#qun018-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2860)。

> 你的回合内，其他角色不能明置其武将牌；出牌阶段，你可以弃置一张黑色牌并暗置一名武将牌均明置的其他角色一张武将牌，然后其交给你一张牌。

- **实现与接口**：主动段未写限一次，每阶段可反复发动；弃一张自己的黑色牌，选一名双将均明置的其他角色暗置其一张武将牌，再令其交给自己一张牌。暗置复用公共 `doHideGeneral` 的主副将选择与来源迁移。被动“回合内其他角色不能明置”不在技能本体重复实现，由 [qun_control_rule](../../../../../pkg/qiao_mode/skills/qun_control_rule.lua) 与 [util/qun_control](../../../../../pkg/qiao_generals/util/qun_control.lua) 按持有者＋技能来源维护，失技／暗置只撤销本条来源。
- **验证依据**：已执行 [qun_control.lua](../../../../../tests/qun_control.lua) 的 `testHuoshuiRevealProhibitionFollowsItsOwnSource`、`testHuoshuiActiveHidesGeneralAndTakesCardTwice`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：死亡翻面不按明置拦截、其他禁明置来源并存、双将明暗组合未穷举；客户端交互未人工验收。

## 倾城

- **标识与依据**：运行时 ID `qiao__skill_qun018_2`；源码 [skill_qun018_2.lua](../../../../../pkg/qiao_generals/skills/skill_qun018_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)群区 QUN018。同将另见[祸水](#qun018-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2861)。

> 出牌阶段限一次，你可以选择一名手牌数小于等于你的其他男性角色，你与其交换手牌。

- **实现与接口**：出牌阶段限一次，选一名手牌数小于等于自己的其他男性角色，双方交换全部手牌；交换的是一方或双方为空也可执行。保留来源：用一次移牌事件交换两边手牌，不逐张获得／交给。次数按本阶段记录。
- **验证依据**：已执行 [qun_judgement.lua](../../../../../tests/qun_judgement.lua) 的 `testQingchengSwapsAllHandcardsOncePerPhase`。历史批次见[验证记录](../verification-evidence.md#qun-standard)。
- **未完成与边界**：交换中手牌被其他效果移动、双方空手、手牌数变化等边界未穷举；客户端交换展示未人工验收。
