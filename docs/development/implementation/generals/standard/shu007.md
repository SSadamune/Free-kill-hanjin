## 藏机

- **标识与依据**：`qiao__skill_shu007_2`；[源码](../../../../../pkg/qiao_generals/skills/skill_shu007_2.lua)；[标准武将表](../../../../rules/standard-generals.md) SHU007。

- **实现与接口**：BeforeCardsMove 筛选本人装备区因弃置离开的非坐骑牌，每回合可取消其中一张的移动，保留其余移动。
