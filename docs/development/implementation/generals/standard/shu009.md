## 狂骨

- **标识与依据**：`qiao__skill_shu009_1`；[源码](../../../../../pkg/qiao_generals/skills/skill_shu009_1.lua)；[标准武将表](../../../../rules/standard-generals.md) SHU009。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L3846)。

> 当你对距离1以内的角色造成伤害后，你可以选择摸一张牌或回复1点体力，若选择项与本回合上次不同，你本回合使用【杀】的次数+1。

- **实现与接口**：`BeforeHpChanged` 在扣减体力前记录到最终伤害目标的距离。仅 `fk.Damage`（实际造成伤害后）进入摸牌或回复的选择。相邻两次选择不同则增加本回合公共杀次数额度，失技后仍保留。
- **验证依据**：[shu_effects.lua](../../../../../tests/shu_effects.lua)；[本批共享证据](../verification-evidence.md#shu-standard)。
- **未完成与边界**：真实客户端、联网与重连未人工验收。击杀后收益由真实伤害、死亡、摸牌回归确认。
