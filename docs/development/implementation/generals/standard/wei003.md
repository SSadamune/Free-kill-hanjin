## 刚烈

- **标识与依据**：运行时 ID `qiao__skill_wei003_1`；源码 [skill_wei003_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei003_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI003；同将另见[持重](#wei003-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4847)。

> 当你受到伤害后，你可以判定，若为：红色，你对来源造成1点伤害；黑色，你弃置来源的一张牌。

- **实现与接口**：`fk.Damaged` 触发；判定红色对来源造成 1 点普通伤害，黑色弃置来源一张牌；来源离场后不再执行对应分支。
- **验证依据**：[wei_damage.lua](../../../../../tests/wei_damage.lua) 覆盖红／黑两分支。
- **未完成与边界**：客户端判定与选牌交互未人工验收。

## 持重

- **标识与依据**：运行时 ID `qiao__skill_wei003_2`，源码 [skill_wei003_2.lua](../../../../../pkg/qiao_generals/skills/skill_wei003_2.lua)。规则见[夏侯惇](../../../../rules/generals/wei003-xiahoudun.md#持重)与[阶段](../../../../../rulebook/terms/game-flow-terms/phase.md)。同将另见[刚烈](#wei003-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4848)。

> 每回合限一次，当你于摸牌阶段外得到牌后，你可以将多于体力值的手牌交给其他角色。

- **实现与接口**：
  - `fk.AfterCardsMove` 检查是否有牌移入该角色手牌区；装备区不计为“得到”。
  - “摸牌阶段外”依 `rulebook/terms/game-flow-terms/phase.md` 的“某角色于阶段内”默认指其自身阶段，直接检查 `player.phase == Player.Draw`；其他角色的摸牌阶段内自己得到牌仍可发动。
  - `Room:askToCards` 可取消，最小及最大张数均为当前手牌数减体力值。确认后使用 `Room:askToYiji` 分配全部选中牌。
  - 每回合一次以 `usedEffectTimes(..., Player.HistoryTurn)` 判定；分配目标为其他存活角色，不含自己。
- **验证依据**：[wei_support.lua](../../../../../tests/wei_support.lua) 的 `testChizhongCanCancelAndDistributesExactExcess` 检查取消保留本回合次数，以及 4 体力、6 手牌时交出 2 张并保留 4 张。
- **未完成与边界**：客户端分配界面未人工验收；引擎显示值与有效上限差异不在本技能范围。
