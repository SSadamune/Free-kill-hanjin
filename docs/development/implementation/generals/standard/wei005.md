## 裸衣

- **标识与依据**：运行时 ID `qiao__skill_wei005_1`；源码 [skill_wei005_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei005_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI005。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4895)。

> 摸牌阶段结束时，你可以弃置一张牌，然后本回合你使用【杀】或【决斗】造成的伤害+1。

- **实现与接口** · 摸牌阶段的 `fk.EventPhaseEnd` 支付弃牌，`fk.DamageCaused` 延时效果按回合标记给【杀】／【决斗】伤害 +1。结算独立于当前技能，回合标记留在角色上，回合结束由 `-turn` 清理。头像读取同期发动次数，每次发动显示一枚无参数的〖裸衣〗标签。旧记录只有加伤标记时默认显示一枚。
- **验证依据** · [wei_damage.lua](../../../../../tests/wei_damage.lua) 覆盖失去技能后本回合加伤仍生效，以及重复发动生成两枚无参数标签。
