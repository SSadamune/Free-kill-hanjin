## 裸衣

- **标识与依据**：运行时 ID `qiao__skill_wei005_1`；源码 [skill_wei005_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei005_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI005。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L4895)。

> 摸牌阶段结束时，你可以弃置一张牌，然后本回合你使用【杀】或【决斗】造成的伤害+1。

- **实现与接口**：`fk.EventPhaseEnd`（摸牌阶段）弃一张牌；`fk.DamageCaused` 延时效果按回合标记给【杀】／【决斗】伤害 +1。效果独立于技能存在：延时效果通过回合标记与 `fk.DamageCaused` 结算，不检查 `hasSkill`；标记 `qiao_wei005_luoyi-turn` 不以技能名前缀开头，避免武将交换把它当成来源技能标记迁走，回合结束由 `-turn` 清理。裸衣的回合标记只服务端判定，不使用 `@@` 展示标记。
- **验证依据**：[wei_damage.lua](../../../../../tests/wei_damage.lua) 覆盖失去技能后本回合加伤仍生效。
- **未完成与边界**：客户端提示与人工交互未验收。
