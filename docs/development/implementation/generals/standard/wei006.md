## 轻辎

- **标识与依据**：运行时 ID `qiao__skill_wei006_1`；源码 [skill_wei006_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei006_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI006。同将另见[遗计](#wei006-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L4914)。

> 准备阶段，你可以弃置一名与你势力相同的其他角色装备区的一张牌，令其获得“神速”直到其回合结束。

- **实现与接口**：
  - 准备阶段弃置同势力其他角色装备区一张牌，令其获得“神速”直到其回合结束。
  - 临时技能授予使用 `Room:handleAddLoseSkills(player, skill, source, ...)`，来源记为轻辎；到期用同一来源 `"-" .. skillName` 移除。授予状态使用不带 `-turn` 的独立标记，不随郭嘉回合末自动清除，只在目标自己的 TurnEnd 回收。
  - 目标原有暗将神速或后获其他来源的同名技能不会被移除；同势力候选复用 hegemony 公共的 `HegUtil.compareExpectedKingdomWith`（拥有者暗置时按本人可见的 `__heg_kingdom`／`__heg_wild` 预测，他人暗置时公开势力为 `unknown`，不进入候选）。
- **验证依据**：[wei_phases.lua](../../../../../tests/wei_phases.lua) 覆盖轻辎弃置目标装备后授予神速、施加者回合结束仍保留、目标回合结束回收、目标原有／另一来源神速不被移除。
- **未完成与边界**：客户端授予技能提示与选牌未人工验收。

## 遗计

- **标识与依据**：运行时 ID `qiao__skill_wei006_2`；源码 [skill_wei006_2.lua](../../../../../pkg/qiao_generals/skills/skill_wei006_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI006；同将另见[轻辎](#wei006-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L4915)。

> 当你受到伤害后，你可以观看牌堆顶两张牌，将其中一至两张牌交给一名角色，然后将其余的牌交给一名角色。

- **实现与接口**：`fk.Damaged` 每次伤害事件一次；看牌堆顶两张，先选 1~2 张给一名角色，剩余再给一名角色，不做上游式任意循环分配。使用 `getNCards(2)` 读取牌堆顶两张（只读取、不移入处理区），选择对话框以 `expand_pile` 展示，再按两次分配从牌堆移动到目标手牌；未新增仅客户端可见的私有展示层。
- **验证依据**：[wei_damage.lua](../../../../../tests/wei_damage.lua) 覆盖一次 2 点伤害只发动一次且分两次给牌。
- **未完成与边界**：客户端分配界面未人工验收；未展开与死亡时失去装备等触发之间的完整时序回归。
