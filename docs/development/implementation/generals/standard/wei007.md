## 倾国

- **标识与依据**：运行时 ID `qiao__skill_wei007_1`；源码 [skill_wei007_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei007_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI007。同将另见[洛神](#wei007-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4935)。

> 你可以将一张黑色手牌当【闪】使用或打出。

- **实现与接口**：黑色手牌当【闪】使用或打出，响应表达式用引擎牌名 `jink`，生成的正式牌为 `qiao__jink`。使用与打出共用转换入口。
- **验证依据**：[wei_phases.lua](../../../../../tests/wei_phases.lua) 走实际客户端【闪】请求，核对按钮、黑色手牌、红色手牌和装备区牌的可选性，再验证确认回包生成正式【闪】。
- **未完成与边界**：客户端转化提示未人工验收。

## 洛神

- **标识与依据**：运行时 ID `qiao__skill_wei007_2`；源码 [skill_wei007_2.lua](../../../../../pkg/qiao_generals/skills/skill_wei007_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI007。同将另见[倾国](#wei007-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L4936)。

> 准备阶段，你可以判定，若为黑色，你可以重复此流程。然后你获得所有黑色的判定牌。

- **实现与接口**：
  - 准备阶段判定；黑色可重复，全部判定结束后统一获得黑色判定牌。
  - 使用 `Room:judge`：其返回值不是 `JudgeData`，判定结果写回传入的 spec 表（`TriggerData:_data` 包装），因此调用后读取原表；循环结束后只收集仍在处理区／弃牌堆的黑色判定牌，一次 `obtainCard` 统一移动。
  - 记录本次流程最终生效的黑色判定牌（含改判后的判定牌），全部判定结束后统一获得，修正了上游逐次 `FinishJudge` 入手的写法，并修正对 `room:judge` 返回值的假设。
- **验证依据**：[wei_phases.lua](../../../../../tests/wei_phases.lua) 覆盖洛神连续两次黑色后红桃终止、`AfterCardsMove` 探针确认黑色判定牌只产生一次得到移动、共两张。
- **未完成与边界**：客户端判定展示与获得提示未人工验收。
