## 断粮

- **标识与依据**：运行时 ID `qiao__skill_wei010_1`；源码 [skill_wei010_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei010_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI010。同将另见[长驱](#wei010-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L4987)。

> 你可以将一张黑色非锦囊牌当【兵粮寸断】使用。其他角色跳过摸牌阶段后，你可以令一名角色摸一张牌。

- **实现与接口**：转换按黑色与 `basic,equip` 同时筛选。引擎牌表达式的区域和完整牌名字段用 `.` 表示不限，留空会被解析成空匹配集合。底牌区域按视为技权限处理，其他角色跳过摸牌阶段后仍可令一名角色摸一张牌。
- **验证依据**：[wei_phases.lua](../../../../../tests/wei_phases.lua) 覆盖他人跳过摸牌阶段后的摸牌，以及临时授技后的按钮、黑色基本牌及装备材料、红牌及黑色锦囊拒绝、合法选人与确认。本轮专项 17/17。
- **未完成与边界**：装备区素材的真实客户端选取尚未人工验收，不将“仅手牌”增写为规则限制。

## 长驱

- **标识与依据**：运行时 ID `qiao__skill_wei010_2`；源码 [skill_wei010_2.lua](../../../../../pkg/qiao_generals/skills/skill_wei010_2.lua)。事实层 [wei_history.lua](../../../../../pkg/qiao_mode/rules/wei_history.lua) 与 [wei_damage_history.lua](../../../../../pkg/qiao_mode/skills/wei_damage_history.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI010。同将另见[断粮](#wei010-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L4988)。

> 锁定技，你对本回合未受到过你伤害的角色使用牌无距离限制。

- **实现与接口**：
  - `targetmod.bypass_distances` 只对公开标记中“本回合未被该来源伤害过”的目标返回真，不修改距离本身；事实由模式记录器负责，技能本身不再记录。
  - 不使用私有 `room:getTag`。记录器把“目标 id 集合”写入同步玩家标记 `qiao_wei_damage_targets`（`room:setPlayerMark`），客户端与服务端 `targetmod` 读同一公开数据，不在客户端回调里读取 server history；每回合开始清空，仅在真实伤害（`data.damage > 0`）后刷新。
  - `mode.lua` 在 `logic:start` 前安装记录器，因此与长驱武将是否已选、明置或之后换将无关。
- **验证依据**：[wei_active.lua](../../../../../tests/wei_active.lua) 覆盖不授予长驱时模式记录器仍写入同步标记、距离不变、`TurnStart` 清空，以及 `ClientPlayer:getTableMark` 读取。
- **未完成与边界**：真实客户端 targetmod 的 UI 距离提示未人工验证。记录器按 `mode.lua` 的 `logic:start` 安装；若其他模式复用该 logic 但不应记录，需要按模式再限定。
