## 强袭

- **标识与依据**：运行时 ID `qiao__skill_wei012_1`；源码 [skill_wei012_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei012_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI012。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5032)。

> 出牌阶段每名角色限一次，你可以选择一名攻击范围内的角色，弃置一张武器牌或失去1点体力，然后对其造成1点伤害。

- **实现与接口**：出牌阶段每目标一次（`-targets-phase` 表标记）。第一步只按当前攻击范围选目标，明确不选牌；之后弃武器或失去 1 点体力，再造成 1 点伤害。默认 `askToDiscard` 直接支付武器消耗。`can_use` 要求体力至少 1，或拥有可弃武器牌。
- **验证依据**：[wei_active.lua](../../../../../tests/wei_active.lua) 专项 7/7，覆盖失去体力分支、经原生请求从两张手牌武器中选一张并只弃置一次、造成 1 点伤害和记录目标。
- **未完成与边界**：客户端选目标与弃武器交互未人工验收。
