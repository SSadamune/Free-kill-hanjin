## 驱虎

- **标识与依据**：运行时 ID `qiao__skill_wei013_1`；源码 [skill_wei013_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei013_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI013。同将另见[节命](#wei013-2)；伤害与没赢视为【杀】见[伤害与用杀分支](#wei013-1-outcomes)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5049)。

> 出牌阶段限一次，你可以与一名体力值大于你的角色拼点，若你赢，其对其攻击范围内由你选择的另一名角色造成1点伤害；若你没赢，其视为对你使用一张【杀】。

- **实现与接口**：按拼点结果分流——赢则转入伤害分支，没赢（含平局／空结果，`winner ~= player`）则转入使用【杀】分支；两个分支的实际来源、目标与用牌细节见[伤害与用杀分支](#wei013-1-outcomes)。
- **验证依据**：[wei_active.lua](../../../../../tests/wei_active.lua) 覆盖驱虎赢（伤害来源为对手；该用例仍以测试桩固定拼点结果，属输入夹具）与驱虎平局（双方各出一张同点数牌经官方回复队列完成拼点，随后对手视为对发动者使用【杀】，验证恰好一次真实使用、来源为拼点对手、目标为发动者、发动者受伤而对手不受伤）。
- **未完成与边界**：若后续改动技能内嵌使用流程，需重跑并重新核对请求消费顺序；客户端拼点与目标选择未人工验收。

<a id="wei013-1-outcomes"></a>

### 伤害与用杀分支

- **实现与接口**：拼点赢→对手为来源、对其攻击范围内由你选择的角色造成 1 点伤害；没赢（含平局／空结果）→对手视为对你使用【杀】（`extra = true` 不计次数、显式目标策略）。赢的伤害来源与没赢的用牌都按真实使用数据结算，不重复用牌。
- **验证依据**：[wei_active.lua](../../../../../tests/wei_active.lua) 覆盖驱虎赢（伤害来源为对手；该用例以测试桩固定拼点结果，属输入夹具）与驱虎平局（双方各出一张同点数牌经官方回复队列完成拼点，随后对手视为对发动者使用【杀】，验证恰好一次真实使用、来源为拼点对手、目标为发动者、发动者受伤而对手不受伤），见[共享验证证据](../verification-evidence.md#wei_active)。
- **未完成与边界**：若后续改动技能内嵌使用流程，需重跑并重新核对请求消费顺序；客户端拼点与目标选择未人工验收。

## 节命

- **标识与依据**：运行时 ID `qiao__skill_wei013_2`；源码 [skill_wei013_2.lua](../../../../../pkg/qiao_generals/skills/skill_wei013_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI013；同将另见[驱虎](#wei013-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5050)。

> 当你受到1点伤害后，你可以令一名角色摸牌至其体力上限（至多摸至五张）。

- **实现与接口**：`fk.Damaged` + `trigger_times = data.damage`；每个伤害点分别询问目标并摸至 `min(体力上限,5)` 张手牌。保留引擎逐次调度：未拆分伤害事件，也未在 `on_use` 内循环。
- **验证依据**：[wei_damage.lua](../../../../../tests/wei_damage.lua) 覆盖 2 点伤害逐点发动两次并按点节命。
- **未完成与边界**：客户端逐点选择未人工验收。
