## 行殇

- **标识与依据**：运行时 ID `qiao__skill_wei014_1`；源码 [skill_wei014_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei014_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)魏区 WEI014 与[曹丕结算约定](../../../../rules/generals/wei014-caopi.md)。同将另见[放逐](#wei014-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5068)。

> 其他角色死亡时，你可以获得其所有牌，若其没有牌，则改为回复1点体力。

- **实现与接口**：`fk.Death`（弃置其牌之前）触发；获得死亡角色的手牌与装备牌（“某人的牌”不含判定区，取牌范围由 `getCardIds()` 改为 `getCardIds("he")`）；其没有牌时回复 1 点体力。只有判定区牌的死亡角色视为没有牌。
- **验证依据**：[wei_damage.lua](../../../../../tests/wei_damage.lua) 覆盖取得死亡角色手牌与装备牌及无牌回复；判定区用例 `testXingshangTakesCardsOrRecovers` 断言只有判定区牌时改为回复、判定区牌不移动。
- **未完成与边界**：用例直接触发 `fk.Death`（真实死亡事件类与真实请求／回复），未经过完整 `killPlayer` 死亡结算链；完整死亡、奖惩与客户端界面仍待验收。未新增判定区延迟锦囊交互测试。

## 放逐

- **标识与依据**：运行时 ID `qiao__skill_wei014_2`；源码 [skill_wei014_2.lua](../../../../../pkg/qiao_generals/skills/skill_wei014_2.lua)。规则见[曹丕结算约定](../../../../rules/generals/wei014-caopi.md)与[叠置与平置](../../../../../rulebook/terms/general-op-terms/stack.md)。同将另见[行殇](#wei014-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5069)。

> 当你受到伤害后，你可以令一名其他角色叠置并摸两张牌，然后其可以弃置四张牌并平置，若牌名字数之和大于7，其失去1点体力。

- **实现与接口**：
  - `fk.Damaged` 每次伤害事件一次；目标须为其他存活角色，先叠置再摸 2；手牌＋装备合计 ≥4 时可足额弃 4 并平置，弃置牌名字数之和 >7 则失去 1 点体力。
  - 国战“叠置／平置”对应引擎 `faceup`：平置 `faceup = true`，叠置 `faceup = false`。叠置仅在 `faceup` 为真时调用原生 `player:turnOver()`；已叠置不重复翻转，但后续摸牌与弃牌分支仍分别执行。
  - 摸牌后不足四张不进入弃牌分支：不平置，也不检查牌名字数、不失去体力。足够四张时由目标决定是否弃置；`min_num = max_num = 4` 保证足额，范围含手牌与装备。弃置后仅在仍为叠置时调用原生 `turnOver` 平置，再按实际弃置的四张牌逐张累计中文牌名字数（`utf8.len`），大于 7 则失去 1 点体力。
  - 使用原生翻面入口，保留 `BeforeTurnOver`／`TurnedOver` 事件、翻面跳回合流程与客户端 `faceup` 朝向显示；未修改引擎本体。
- **验证依据**：[wei_support.lua](../../../../../tests/wei_support.lua) 的 `testFangzhuStackDrawDiscardAndHpLoss`：平置→叠置并摸 2；足额弃 4 后平置且牌名字数和 >7 失去体力；已有叠置目标不反转且仍摸 2；不足 4 张时不提供弃牌分支、保持叠置。
- **未完成与边界**：客户端翻面朝向与弃牌交互未人工验收。
