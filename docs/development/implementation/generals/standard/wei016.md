## 骁果

- **标识与依据**：运行时 ID `qiao__skill_wei016_1`；源码 [skill_wei016_1.lua](../../../../../pkg/qiao_generals/skills/skill_wei016_1.lua)。规则见[乐进规范](../../../../rules/generals/wei016-yuejin.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5087)。

> 其他角色的准备阶段，你可以弃置任意张基本牌，然后其弃置装备区等量的牌（不足全弃，无牌不弃），若你以此法弃置的基本牌多于装备牌，则你对其造成1点伤害，否则你摸一张牌。

- **实现与接口** · 其他角色进入准备阶段时（`fk.EventPhaseStart`），乐进可以从手牌中选至少一张可弃置的基本牌。取消即不发动。请求只记录选中的牌，进入结算后才实际弃置。按本次移动结果计算弃置张数，没有基本牌进入弃牌堆时结束。随后由进入准备阶段的角色弃置等量可弃置的装备牌，不足时全弃，没有时跳过。若乐进本次实际弃置的基本牌更多，则对该角色造成 1 点伤害，否则乐进摸一张牌。
- **验证依据** · [魏包伤害回归](../../../../../tests/wei_damage.lua)覆盖实际弃牌后的伤害或摸牌。[君曹操专项](../../../../../tests/em_wei001_caocao.lua#L1578)覆盖目标亲自执行弃装备以及装备被改移时按实际进入弃牌堆的张数计数。
- **未完成与边界** · 此处记录目标分支的实际支付和张数计算。结合[逐将裁定](../../../../rules/generals/wei016-yuejin.md)理解当前口径。
