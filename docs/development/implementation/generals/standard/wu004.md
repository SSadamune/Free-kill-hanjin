## 苦肉

- **标识与依据**：运行时 ID `qiao__skill_wu004_1`；源码 [skill_wu004_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu004_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU004；同将另见[诈降](#wu004-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6084)。

> 出牌阶段限一次，你可以失去1点体力，然后你可以交给一名其他角色一张牌。

- **实现与接口**：出牌阶段主动发动时直接确认。失去体力并完整结算 `HpLost` 后，才从当前牌区选要交出的牌和接收者。黄盖可交出刚由诈降摸到的牌。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 22 项定向历史 22/22 通过，包含真实伤害／失去体力；见[共享验证证据](../verification-evidence.md#wu_damage)。
- **未完成与边界**：客户端确认与联网／重连未人工验收。

## 诈降

- **标识与依据**：运行时 ID `qiao__skill_wu004_2`；源码 [skill_wu004_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu004_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU004。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6085)。

> 锁定技，当你失去体力后，你摸三张牌，本回合你使用【杀】的次数+1且使用红色【杀】无距离限制。

- **实现与接口**：监听 `HpLost` 摸牌并累计本回合出杀次数；次数修正使用锁定杀接口查询的 `HistoryPhase`；红杀距离与累计次数在失去技能后继续生效（中性回合标记＋模式级距离技能）。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖两次诈降累计及真实用杀次数、失技后持续。
- **未完成与边界**：客户端红杀距离提示未人工验收。
