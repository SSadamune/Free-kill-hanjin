## 英姿

- **标识与依据**：运行时 ID `qiao__skill_wu005_1`；源码 [skill_wu005_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu005_1.lua)。规则见[周瑜规范](../../../../rules/generals/wu005-zhouyu.md)。同将另见[反间](#wu005-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6106)。

> 锁定技，摸牌阶段，你多摸一张牌；你的手牌上限为X（X为你的体力上限）。

- **实现与接口** · 周瑜摸牌阶段修改摸牌数时（`fk.DrawNCards`）额外摸一张。有效英姿还通过 `maxcards.fixed_func` 将基础手牌上限设为体力上限。英姿不限制主副将位置，反间的位置条件单独处理。
- **验证依据** · [英姿回归](../../../../../tests/wu_support.lua#L151)直接触发实际摸牌数事件，核对由 2 增至 3，并在当前体力低于体力上限时从正式手牌上限查询验证结果。
- **未完成与边界** · 普通孙策的[魂殇](../shi/wu010.md#wu010-3)与君孙权的[缘江烽火图](../bian/em-wu001.md#em-wu001-flag)共享这个运行时 ID，各自管理授予到期。

## 反间

- **标识与依据**：运行时 ID `qiao__skill_wu005_2`；源码 [skill_wu005_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu005_2.lua)。规则见[周瑜规范](../../../../rules/generals/wu005-zhouyu.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6107)。

> 主将技（☯️-1），出牌阶段限一次，你可以展示一张手牌并交给一名其他角色，其需展示手牌且弃置你展示花色的所有牌（至少两张），否则失去1点体力。

- **实现与接口**：交牌前快照展示花色；响应只展示手牌，弃同花色手牌与装备，检查至少两张及禁弃；弃置执行者是目标；响应有选择权。主将体力贡献 −1 按半格公共表示处理。
- **验证依据**：[wu_support.lua](../../../../../tests/wu_support.lua) 覆盖反间接受与拒绝、手装弃置及拒绝。
- **未完成与边界**：反间红颜组合及实际 `ProhibitSkill` 禁弃组合未单独验证；客户端点击未人工验收。
