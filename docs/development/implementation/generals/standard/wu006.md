## 国色

- **标识与依据**：运行时 ID `qiao__skill_wu006_1`；源码 [skill_wu006_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu006_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU006。同将另见[流离](#wu006-2)；弃置分支的费用与限次见[弃置分支](#wu006-1-discard)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6127)。

> 出牌阶段各限一次，你可以：1.将一张方片牌当【乐不思蜀】使用；2.弃置一张方片牌和场上一张延时锦囊牌。然后摸一张牌。

- **实现与接口**：主动技用 `UI.ComboBox` 提供当前可执行的分支，选择分支后仍可选牌、选人及确认。使用分支把所选方片装入虚拟【乐不思蜀】，用相同材料查询牌的使用及目标合法性；弃置分支沿用批量移动，见[弃置分支](#wu006-1-discard)。共用的虚拟牌目标复核与客户端同样接受引擎判定的真值。
- **验证依据**：[wu_phases.lua](../../../../../tests/wu_phases.lua) 覆盖客户端进入国色、两分支选牌选人、确认回包以及独立限次。
- **未完成与边界**：客户端两分支选择未人工验收。

<a id="wu006-1-discard"></a>

### 弃置分支

- **实现与接口**：两分支独立限次，在交互、牌／目标筛选及执行前分别复核；弃置分支的两项费用都确认可执行后才批量移动，避免只支付一部分。
- **验证依据**：[wu_phases.lua](../../../../../tests/wu_phases.lua) 覆盖国色两分支及不可重用，见[共享验证证据](../verification-evidence.md#wu_phases)。
- **未完成与边界**：客户端两分支选择未人工验收；复杂禁弃／费用不足组合未穷举。

## 流离

- **标识与依据**：运行时 ID `qiao__skill_wu006_2`；源码 [skill_wu006_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu006_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU006。同将另见[国色](#wu006-1)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6128)。

> 当你成为其他角色使用【杀】的目标时，你可以弃置一张牌并将此【杀】转移给攻击范围内的另一名其他角色。

- **实现与接口**：先完成合法弃牌与目标选择再支付费用；取消目标不弃牌。以 `inMyAttackRange` 的 `excludeIds` 预测弃武器／坐骑后的范围，排除已有目标，通过 AimData 取消当前目标并加入新目标。
- **验证依据**：[wu_phases.lua](../../../../../tests/wu_phases.lua) 覆盖流离真实转移与取消不付费。
- **未完成与边界**：复杂改目标与范围组合未穷举；客户端选牌与目标转移未人工验收。
