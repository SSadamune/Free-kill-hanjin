## 谦逊

- **标识与依据**：运行时 ID `qiao__skill_wu007_1`；源码 [skill_wu007_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu007_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU007。同将另见[度势](#wu007-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6146)。

> 锁定技，你每回合首次成为锦囊牌的目标时，若此牌有未指定的合法目标，取消之。

- **实现与接口**：包括自己使用的锦囊。首次成为锦囊目标时，存在未指定的合法目标才进入技能发动并取消自身；没有此类目标时由刷新监听记录首次，不发出技能提示或战报。
- **验证依据**：[wu_phases.lua](../../../../../tests/wu_phases.lua) 覆盖谦逊。
- **未完成与边界**：无目标锦囊等边缘牌型未逐项验证；客户端取消提示未人工验收。

## 度势

- **标识与依据**：运行时 ID `qiao__skill_wu007_2`；源码 [skill_wu007_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu007_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU007。同将另见[谦逊](#wu007-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6147)。

> 你可以将本回合未置入过弃牌堆的花色的一张牌当【以逸待劳】使用，然后若均已置入过，你可以令一名小势力角色选择是否将X张红色牌当【火烧连营】使用（X为目标数）。

- **实现与接口** · 完成【以逸待劳】且四种花色均已进过弃牌堆后，取【火烧连营】的目标数 X。若被指定者的手牌数加装备区红牌数至少为 X，就询问其是否使用。确认时须从其当前手牌和装备区选出 X 张不同的红牌作为转化的子牌。
- **验证依据** · [wu_phases.lua](../../../../../tests/wu_phases.lua) 覆盖客户端的首段花色筛选、全黑与全红手牌收到同一可取消询问、公开牌数不足时跳过，以及用手牌和红色装备实际转化【火烧连营】。
- **未完成与边界**：客户端筛选与后续用牌交互未人工验收。
