## 结姻

- **标识与依据**：运行时 ID `qiao__skill_wu008_1`；源码 [skill_wu008_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu008_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU008 与[装备置入](../../../../rules/equipment-movement.md)。同将另见[枭姬](#wu008-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6164)。

> 出牌阶段限一次，你可以选择一名其他男性角色，弃置一张手牌或将一张装备牌置于其装备区，然后你与其之中体力值较大的角色摸一张牌，较小的角色回复1点体力。

- **实现与接口**：用主动技的同一请求选分支、一张自己的牌和目标。选牌与目标相互校验，装备置入要求空置对应栏，体力相等时没有较大／较小收益；客户端安全房间访问支持无 `room` 字段的真实 `ClientPlayer`。
- **验证依据**：[wu_support.lua](../../../../../tests/wu_support.lua) 覆盖结姻置入及代表性真实 `ClientPlayer` 用例（无 `room` 字段下的可用性与候选）。
- **未完成与边界**：客户端置入动画与人工交互未验收。

## 枭姬

- **标识与依据**：运行时 ID `qiao__skill_wu008_2`；源码 [skill_wu008_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu008_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU008。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6165)。

> 当你失去装备区里的牌后，你可以摸一张牌，若此时在你的回合外，改为摸两张牌。

- **实现与接口**：失去装备逐张触发，回合内／外分别摸一张／两张。
- **验证依据**：[wu_support.lua](../../../../../tests/wu_support.lua) 覆盖枭姬回合内外。
- **未完成与边界**：客户端失去装备提示未人工验收。
