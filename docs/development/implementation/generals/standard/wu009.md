## 英魂

- **标识与依据**：运行时 ID `qiao__skill_wu009_1`；源码 [skill_wu009_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu009_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU009。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6185)。

> 准备阶段，你可以选择一名其他角色并选择一项：1.令其摸X张牌，然后弃置一张牌；2.令其摸一张牌，然后弃置X张牌（X为你已损失的体力值）。

- **实现与接口** · 准备阶段打开一个可取消的请求。选择一名其他角色后，点击按当前已损失体力值填写的摸弃选项，即确认发动。结算先令目标摸牌，若其仍存活，再令其从手牌或装备区弃置对应张数。
- **验证依据** · [wu_support.lua](../../../../../tests/wu_support.lua) 使用包含目标及分支的原生回包，验证摸弃顺序。
