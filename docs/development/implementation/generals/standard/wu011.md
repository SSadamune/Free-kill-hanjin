## 天香

- **标识与依据**：运行时 ID `qiao__skill_wu011_1`；源码 [skill_wu011_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu011_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU011；同将另见[红颜](#wu011-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6230)。

> 每回合每项限一次，当你受到伤害时，你可以弃置一张红桃牌并防止此伤害，然后选择一名其他角色和以下一项：1.来源对其造成1点伤害，其摸等同已损失体力值的牌（至多摸五张）；2.其失去1点体力，然后获得你弃置的牌。

- **实现与接口**：只展示可弃置红桃候选，含红颜视为红桃的牌，并在支付前复核；先防止原伤害，再执行新伤害／失去体力两分支，不写成旧版转移伤害。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖天香／红颜组合。
- **未完成与边界**：天香无来源、多次濒死完整求桃链等复杂边界未独立验收；客户端点击、联网／重连未人工验证。

## 红颜

- **标识与依据**：运行时 ID `qiao__skill_wu011_2`；源码 [skill_wu011_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu011_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU011。同将另见[天香](#wu011-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6231)。

> 锁定技，你的黑桃牌和黑桃判定牌视为红桃牌。

- **实现与接口**：手牌区、装备区及当次判定牌按有效花色处理，判定区里的牌维持原花色，见[自己的牌](../../../../../rulebook/terms/description-terms/limit_card.md)。锁视入口与锁定国战包 `pkg/standard/skills/hongyan.lua` 一致，使用 `Fk:cloneCard` 保留注册包，并复制汉晋实体牌的 `extra_data`，保留应变、牌位等信息。汉晋牌面只规定花色变化。
- 明置获得或暗置失去【红颜】时，引擎会重算手牌。技能通过 `Room:filterCard` 同时重算仍在装备区的印刷黑桃牌，并通知客户端。装备离区后按新区域和持有者计算花色。
- **验证依据**：[吴区伤害专项](../../../../../tests/wu_damage.lua) 在服务端和原生测试客户端核对明暗置前后的装备花色。先装备再亮将可用黑桃八卦阵支付【天香】；暗置时黑桃青釭剑无法支付法正【恩怨】，重新亮将后可交给法正。两张牌离开小乔后均恢复黑桃。既有用例另覆盖黑桃 9 雷【杀】的牌包音效、实体应变信息、雷伤害及弃牌。
- **未完成与边界**：交换武将后的客户端刷新、少见的禁弃组合及真人联机、重连仍待独立验收。
