## 天义

- **标识与依据**：运行时 ID `qiao__skill_wu012_1`；源码 [skill_wu012_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu012_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU012。同将另见[酣战](#wu012-2)；持续用杀修正见[持续用杀修正](#wu012-1-slash)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6255)。

> 出牌阶段限一次，你可以与一名角色拼点。若你赢，本回合你使用【杀】无距离限制、可多指定一个目标且可多使用一张【杀】；若你没赢，本回合你不能使用【杀】。

- **实现与接口**：拼点赢即获得本回合的用杀增益，没赢包括平局则本回合禁用【杀】；赢后无距离、多目标、额外出杀与失技后持续等具体修正见[持续用杀修正](#wu012-1-slash)。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖真实拼点与平局、真实 `ClientPlayer` 可用性。持续修正与失技后的用例见[持续用杀修正](#wu012-1-slash)。
- **未完成与边界**：客户端拼点与用杀次数提示未人工验收。

<a id="wu012-1-slash"></a>

### 持续用杀修正

- **实现与接口**：赢后本回合无距离、多目标与额外出杀由静态模式技能读取公开中性标记；没赢包括平局，本回合禁用【杀】。已确定的增益／禁用不因失去天义提前结束，次数增益按锁定杀接口的 `HistoryPhase` 查询。天义可用性使用客户端安全房间访问。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖真实拼点、平局、失技持续与真实 `ClientPlayer`，见[共享验证证据](../verification-evidence.md#wu_damage)。
- **未完成与边界**：客户端拼点与用杀次数提示未人工验收；复杂多目标／改目标组合未穷举。

## 酣战

- **标识与依据**：运行时 ID `qiao__skill_wu012_2`；源码 [skill_wu012_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu012_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU012。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6256)。

> 你拼点后，你可以获得拼点牌之中点数最大的【杀】。

- **实现与接口**：在拼点结束、牌仍在处理区时，取得本次拼点中最大点数的【杀】；并列最大者一并取得，不额外加入只选一张的限制。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖酣战取得及并列用例。
- **未完成与边界**：多人联网、重连或实际客户端拼点交互未验收。
