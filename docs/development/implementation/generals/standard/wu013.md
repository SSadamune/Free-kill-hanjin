## 不屈

- **标识与依据**：运行时 ID `qiao__skill_wu013_1`；源码 [skill_wu013_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu013_1.lua)。规则见[周泰规范](../../../../rules/generals/wu013-zhoutai.md)。同将另见[奋激](#wu013-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6272)。

> 锁定技，当你进入濒死时，你摸X张牌（X为你本回合濒死的次数），将一张牌置于武将牌上，称为“创”，然后移去至每种花色各一张，若你未移去牌，无须移去则改为回复体力至1点。

当前显示删去「若你未移去牌，」。这是 2026-11-14 确认的文字调整，保留「无须移去则改为回复体力至1点」。见[周泰裁定](../../../../rules/generals/wu013-zhoutai.md)及[正式描述登记](../../../../../pkg/qiao_generals/data/standard.lua)。

- **实现与接口**：真实进入濒死时摸 X 张，从手牌／装备置一张「创」到角色的公开特殊牌堆。同花色重复由玩家选择保留牌并移去其余，无须移去才回复至一。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖真实濒死不屈、装备置创、选择保留。
- **未完成与边界**：「创」目前在暗置时保留，尚未接入交换迁移和实例终止清理。待接入[牌类标记生命周期](../../general-exchange.md#牌类标记生命周期)，由公共接口绑定生成它的不屈实例。多次濒死完整求桃链未穷举，客户端「创」显示与人工交互未验收。

## 奋激

- **标识与依据**：运行时 ID `qiao__skill_wu013_2`；源码 [skill_wu013_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu013_2.lua)。规则见[周泰规范](../../../../rules/generals/wu013-zhoutai.md)。同将另见[不屈](#wu013-1)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6273)。

> 每回合结束时，你可以令一名本回合失去过所有手牌的角色摸两张牌，然后你失去1点体力。

- **实现与接口** · 有角色因实际牌移动失去最后一张手牌后，模式在整批移牌完成、分发 `fk.AfterCardsMove` 前给该角色记本回合标记，即使周泰此时仍暗置或尚未获得奋激也会记录。到回合结束，周泰可指定一名仍在场且有标记的角色令其摸两张，然后周泰失去 1 点体力。开局就没有手牌不计入，目标回合中后来获得手牌也不会抹掉已经记录的历史。
- **验证依据** · [奋激回归](../../../../../tests/wu_damage.lua#L648)覆盖先清空手牌、重新获得手牌后周泰才取得奋激的情形。实际弃置目标最后一张手牌，进入回合结束请求后核对目标摸两张、周泰失去 1 点体力。 已覆盖【制衡】同时弃掉最后手牌和【临筱玉舆】、玉舆立即补牌的情形。
- **未完成与边界** · 本例通过正式回合结束回调及预设选择回包验证，客户端目标选择未人工验收。
