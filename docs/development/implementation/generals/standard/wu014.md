## 好施

- **标识与依据**：运行时 ID `qiao__skill_wu014_1`；源码 [skill_wu014_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu014_1.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU014。同将另见[缔盟](#wu014-2)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6293)。

> 摸牌阶段，你可以多摸两张牌，然后若你的手牌数大于5，你将半数（向下取整）手牌交给一名手牌最少的其他角色。

- **实现与接口** · 在 `fk.DrawNCards` 多摸两张，并将后续给牌记录在本次摸牌事件数据上。[房间规则](../../../../../pkg/qiao_mode/skills/wu_turn_effects.lua#L65) 在 `fk.AfterDrawNCards` 清除这项记录，再检查发动者的手牌是否超过五张。满足时，从手牌最少的其他在场角色中必选一名，交出发动者此时手牌的一半（向下取整）。服务端复核选中的牌和张数。失去好施后仍结算已建立的给牌效果。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖好施承诺后失技、好施与缔盟来源到期。
- **未完成与边界**：客户端给牌交互未人工验收。

## 缔盟

- **标识与依据**：运行时 ID `qiao__skill_wu014_2`；源码 [skill_wu014_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu014_2.lua)。规则见[标准武将表](../../../../rules/standard-generals.md)吴区 WU014。到期辅助 [wu_dimeng_expiry.lua](../../../../../pkg/qiao_mode/skills/wu_dimeng_expiry.lua)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6294)。

> 出牌阶段限一次，你可以选择两名其他角色并弃置等同其手牌数差的牌，令其交换手牌，你可以对其中手牌未增加的角色纵横“好施”。

- **实现与接口**：使用可弃牌支付手牌数差。手牌数相等时客户端允许提交空弃牌，服务端直接交换。交换后用一次可取消的选人请求，向选中的角色授予纵横好施至其下个回合结束。到期辅助按来源撤回纵横技能。
- **验证依据**：[wu_damage.lua](../../../../../tests/wu_damage.lua) 覆盖零张弃牌的客户端回包、实体手牌两段移动的逐席可见性、一次选两人和多来源到期。
- **未完成与边界** · 原反馈没有录像。换牌沿用[公共移牌可见性](../../skill-ui.md#卜算交牌和获得牌的可见性)，真人三席动画复测进度见[联测待复测范围](../../../status.md#联测待复测范围)。
