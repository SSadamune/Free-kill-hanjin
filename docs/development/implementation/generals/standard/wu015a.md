## 直谏

- **标识与依据**：运行时 ID `qiao__skill_wu015a_1`；源码 [skill_wu015a_1.lua](../../../../../pkg/qiao_generals/skills/skill_wu015a_1.lua)。规则见[张昭规范](../../../../rules/generals/wu015a-zhangzhao.md)与[装备置入](../../../../rules/equipment-movement.md)。同将另见[固政](#wu015a-2)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6316)。

> 出牌阶段，你可以将手牌区/装备区的一张装备牌置于一名其他角色的装备区，然后你/其摸一张牌。

- **实现与接口**：手牌区→你摸牌、装备区→其摸牌的顺序对应；装备置入要求空置对应栏；仅展示合法候选。
- **验证依据**：[wu_support.lua](../../../../../tests/wu_support.lua) 覆盖直谏两来源（手牌／装备区决定摸牌者）与空栏。
- **未完成与边界**：客户端置入面板未人工验收。

## 固政

- **标识与依据**：运行时 ID `qiao__skill_wu015a_2`；源码 [skill_wu015a_2.lua](../../../../../pkg/qiao_generals/skills/skill_wu015a_2.lua)。规则见[张昭规范](../../../../rules/generals/wu015a-zhangzhao.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6317)。

> 每回合限一次，当其他角色的至少两张牌因弃置而置入弃牌堆后，你可以将其中一张牌交给其，然后你获得其余至多三张牌。

- **实现与接口**：同事件多个弃牌者由玩家择一，只取该角色本事件仍在弃牌堆的牌，返一后批量取得至多三张。取得面板初始选中全部候选，超过三张时需取消多余选择，允许取零张。服务端复核张数、候选和牌区。
- **验证依据**：[wu_support.lua](../../../../../tests/wu_support.lua) 保留多弃牌者选择并增补返牌后的候选断言。离屏 Qt 用锁定版本的选牌框及选牌模型验证四张全选、取消至三张和提交零张。
- **未完成与边界**：客户端弃牌者选择未人工验收。
