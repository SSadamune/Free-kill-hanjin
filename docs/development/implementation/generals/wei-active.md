# WEI010–WEI013 主动/距离技能：实现与验证

本页记录[标准武将表](../../../../rules/standard-generals.md)魏区 WEI010 长驱、WEI011 伪溃、WEI012 强袭、WEI013 驱虎的程序接线与验收范围，不是正式规则条文。

## 本轮实质修正

1. **伪溃私看**：`room:showCards(hand, player)` 是全体展示，已改为真实私看 `room:viewCards(player, { cards = hand, skill_name = ..., prompt = ... })`。测试记录 `viewCards` 的收件角色与牌集，防止以 mock 通过保留泄露。
2. **长驱事实层**：不再使用私有 `room:getTag`。新增 `rules/wei_history.lua`（公开标记 `hanjin_wei_damage_targets`、记录/清空/查询）与 `skills/wei_damage_history.lua`（模式级全局 `fk.Damage` 记录器）。`mode.lua` 在 `logic:start` 前安装记录器，因此与长驱武将是否已选、明置或之后换将无关。记录器只把“目标 id 集合”写入同步玩家标记（`room:setPlayerMark`），客户端与服务端 `targetmod` 读同一公开数据，不在客户端回调里读取 server history；每回合开始清空，仅在真实伤害（`data.damage > 0`）后刷新。
3. **费用可用性**：强袭、伪溃的 `can_use` 增加 `player.hp >= 1` 条件（失去 1 点体力不得超过当前体力）；强袭在无武器牌且体力不足时客户端禁用。
4. **驱虎没赢**：拼点 `winner ~= player`（含平局/空结果）走真实视为【杀】分支；新增平局测试验证对手为使用者、发动者为目标并承受伤害（伤害来源为对手）。
5. **鹰视**：新增 `skill_wei002_2.lua`，见 [鹰视实现与验证](wei-retrial.md)。

## 接线要点

1. **长驱**：`targetmod.bypass_distances` 只对公开标记中“本回合未被该来源伤害过”的目标返回真，不修改距离本身；事实由模式记录器负责，技能本身不再记录。
2. **伪溃**：出牌阶段限一次；失去 1 点体力→私看目标手牌；有【闪】则按公共 `explicit` 目标策略视为【杀】，距离固定只对“发动者 → 目标”单向生效（`-turn` 标记）；否则弃置其一张手牌。
3. **强袭**：出牌阶段每目标一次（`-targets-phase` 表标记）；目标先按当前攻击范围确定，再弃武器或失去 1 点体力，然后造成 1 点伤害。
4. **驱虎**：拼点赢→对手为来源、对其攻击范围内由你选择的角色造成 1 点伤害；没赢（含平局）→对手视为对你使用【杀】（`extra=true` 不计次数、显式目标策略）。

## 测试（`tests/wei_active.lua`，已由整合方加入 all.lua）

夹具已改为明确白板双将：`support.initHanjinRoom()` 后统一替换为 `hanjin_test__wei_1/2`，写入 `__heg_general/__heg_deputy`、势力与 `__heg_*` 标记，并用 `getGeneralMaxHp()` 重算 `maxHp/hp`；显式设置当前角色与出牌阶段。这样避免随机真实双将的技能在嵌套【杀】时插入额外询问。

1. 长驱：不授予长驱时，模式记录器仍写入同步标记；距离不变；`TurnStart` 清空。
2. 强袭：无武器时失去体力并对攻击范围内目标造成 1 点伤害，写入每目标标记。
3. 伪溃（无【闪】）：私看请求收件人为发动者、牌集为目标手牌；无【闪】时弃置一张。输入回复走 `FkTest.setNextReplies`。
4. 驱虎（赢）：赢的伤害来源为对手；该用例仍以测试桩固定拼点结果，属输入夹具。
5. 伪溃（有【闪】）：恢复真实【杀】分支。私看通过包裹原 `room:viewCards` 记录参数（仍调用真实实现），检查发动者收到目标手牌；目标不打出【闪】，真实 `CardUseFinished` 记录显示恰好一次来源为发动者、目标为该角色的【杀】，并验证失去体力、目标受伤与距离标记。
6. 驱虎（平局）：恢复真实拼点与真实【杀】。双方各出一张同点数牌经官方回复队列完成拼点；随后对手视为对发动者使用【杀】，验证恰好一次真实使用、来源为拼点对手、目标为发动者，发动者受伤而对手不受伤。
