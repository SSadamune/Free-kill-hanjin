## 摧破

- **标识与依据** · 朱儁（HAN014，阵包），运行时 ID `qiao__skill_han014_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han014_1.lua)和[逐将规则](../../../../rules/generals/han014-zhujun.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L736)。

> 锁定技，当你每回合使用第X张牌指定目标后（X为此牌的牌名字数），若你为此牌目标，则你摸一张牌，否则此牌伤害+1。

- **实现与接口** · 声明用牌目标后（`fk.TargetSpecified`），朱儁比较本回合的用牌序号与牌名的字数。相等时，若自己是这张牌的目标则摸一张牌，否则让这张牌增加 1 点伤害。
- **验证依据** · [han014_zhujun.lua](../../../../../tests/han014_zhujun.lua#L73)。通过实际用牌核对本回合第一张一字牌对目标增伤。

## 虎翼

- **标识与依据** · 朱儁（HAN014，阵包），运行时 ID `qiao__skill_han014_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han014_2.lua)和[逐将规则](../../../../rules/generals/han014-zhujun.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L737)。

> 阵法技，每回合限一次，与你处于同一围攻关系的围攻角色对被围攻角色使用【杀】后，另一名围攻角色可以对被围攻角色使用一张【杀】。

- **实现与接口** · 同一围攻关系的另一名围攻角色对被围攻角色使用【杀】并结算完毕后（`fk.CardUseFinished`），本回合未发动虎翼的朱儁可以发动。结算时以当前围攻关系复核目标，再发出可取消的用牌请求，只接受对该角色实际使用的一张【杀】。
- **验证依据** · [han014_zhujun.lua](../../../../../tests/han014_zhujun.lua#L87)。从围攻角色的真实用杀进入，核对另一名围攻者追加用杀。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
