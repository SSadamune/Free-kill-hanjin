## 用良

- **标识与依据** · 卢植（HAN015，阵包），运行时 ID `qiao__skill_han015_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han015_1.lua)和[逐将规则](../../../../rules/generals/han015-luzhi.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L759)。

> 出牌阶段限一次，你可以弃置一张牌并视为仅对一名其他角色使用【敕令】（无视目标条件限制）。

- **实现与接口** · 出牌阶段，卢植弃置一张牌，视为只对选中的另一名角色使用【敕令】。虚拟用牌入口使用显式目标策略，绕过【敕令】通常的目标条件。
- **验证依据** · [han015_luzhi.lua](../../../../../tests/han015_luzhi.lua#L104)。验证已确定势力的角色可成为目标，并通过真实客户端对象核对按钮和候选。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 备寇

- **标识与依据** · 卢植（HAN015，阵包），运行时 ID `qiao__skill_han015_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han015_2.lua)和[逐将规则](../../../../rules/generals/han015-luzhi.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L760)。

> 主将技（☯️-1），每名角色限一次，当一名角色的武将牌明置后，若其已没有暗置的武将牌，你可以令其摸两张牌或弃置两张牌。

- **实现与接口** · 一张武将牌明置后（`fk.GeneralRevealed`），若该角色已经没有暗置武将牌且此前未受此技能影响，主将位置的卢植可以令其摸两张牌或弃置两张牌。按受影响角色分别记一次。
- **验证依据** · [han015_luzhi.lua](../../../../../tests/han015_luzhi.lua#L125)。实际明置后验证询问与同一角色只结算一次。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 修体

- **标识与依据** · 卢植（HAN015，阵包），运行时 ID `qiao__skill_han015_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_han015_3.lua)和[逐将规则](../../../../rules/generals/han015-luzhi.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L761)。

> 副将技，结束阶段，你可以令至多X名角色摸牌至体力上限（X为本回合明置的武将牌数）。

- **实现与接口** · 副将位置的卢植于结束阶段（`fk.EventPhaseStart`）可以指定至多本回合实际明置武将牌数的角色，按各自体力上限补手牌。历史按实际牌身份去重，同一张牌暗置后再次明置不重计。
- **验证依据** · [han015_luzhi.lua](../../../../../tests/han015_luzhi.lua#L152)。通过实际明置历史验证去重及各目标的补牌上限。
- **未完成与边界** · 回合内重复明置按当前暂行口径去重。
