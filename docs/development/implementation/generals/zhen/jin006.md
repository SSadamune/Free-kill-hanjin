## 三陈

- **标识与依据** · 杜预（JIN006，阵包），运行时 ID `qiao__skill_jin006_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin006_1.lua)和[逐将规则](../../../../rules/generals/jin006-duyu.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1611)。

> 出牌阶段限一次，你可以令一名角色摸三张牌，然后其弃置三张牌，若弃置牌类别各不同，其摸一张牌或复原此技能（本回合不能再选择相同角色）。

- **实现与接口** · 杜预在出牌阶段可令一名角色摸三张再弃三张。弃牌类别各不同时，由受益者选择摸一张或让杜预复原三陈。复原刷新阶段内可发动状态，本回合用过的目标仍记在名单中。
- **验证依据** · [jin006_duyu.lua](../../../../../tests/jin006_duyu.lua#L56)。验证摸弃和复原的主流程，以及阶段复原后不重复同一目标。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 破竹

- **标识与依据** · 杜预（JIN006，阵包），运行时 ID `qiao__skill_jin006_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin006_2.lua)和[逐将规则](../../../../rules/generals/jin006-duyu.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1612)。

> 主将技（☯️-1），出牌阶段限X次（X为此阶段“三陈”被复原的次数），你可以将一张手牌当【出其不意】使用。

- **实现与接口** · 主将杜预按本出牌阶段三陈的复原次数取得使用额度。每次只能把一张手牌通过公共虚拟用牌入口当正式【出其不意】使用，提交时按阶段额度复核。
- **验证依据** · [jin006_duyu.lua](../../../../../tests/jin006_duyu.lua)。杜预专项覆盖三陈复原的阶段记账，尚未找到从复原后实际转化【出其不意】的直接断言。
- **未完成与边界** · 独立用牌路径仍待专项验证。

## 武库

- **标识与依据** · 杜预（JIN006，阵包），运行时 ID `qiao__skill_jin006_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin006_3.lua)和[逐将规则](../../../../rules/generals/jin006-duyu.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L1613)。

> 副将技，你可以将一张宝物牌当你本回合使用的上一张基本牌或普通锦囊牌使用。

- **实现与接口** · 副将杜预以一张宝物为转化材料。查询本回合放在公开历史中的上一张已使用基本牌或普通锦囊，在普通出牌和使用型响应中生成相同牌名的虚拟牌。
- **验证依据** · [jin006_duyu.lua](../../../../../tests/jin006_duyu.lua#L103)。覆盖真实声明经公开历史同步后的牌名选择，及两类响应入口的区别。
- **未完成与边界** · 上一张牌的读取采用当前规则页的暂行口径。
