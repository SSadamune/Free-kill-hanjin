## 锋械

- **标识与依据** · 马隆（JIN023，阵包），运行时 ID `qiao__skill_jin023_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin023_1.lua)和[逐将规则](../../../../rules/generals/jin023-malong.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1980)。

> 出牌阶段限一次，你可以交换两名角色场上各一张装备牌，若其中一名角色为你，你视为对其中另一名角色或其队列使用一张【杀】。

- **实现与接口** · 马隆于出牌阶段选择两名角色的场上装备各一张，先经处理区把两张牌交到对方手中。自己为其中一方时，进一步选择只对另一方，或对另一方所在的队列，使用一张虚拟【杀】。
- **验证依据** · [jin023_malong.lua](../../../../../tests/jin023_malong.lua#L41)。断言基线的入手去向和随后对单人结算用杀。
- **未完成与边界** · 反馈 20、21 已定位。待按[交换条文](../../../../../rulebook/terms/card-op-terms/swap.md#交换装备区中的各一张牌)校验候选栏位、交换至装备区，并将发动者从队列用杀的目标中排除。

## 锥形

- **标识与依据** · 马隆（JIN023，阵包），运行时 ID `qiao__skill_jin023_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_jin023_2.lua)和[逐将规则](../../../../rules/generals/jin023-malong.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L1981)。

> 阵法技，若你为围攻角色，被你围攻的角色对你使用【杀】伤害-1；若你为被围攻角色，你对围攻你的角色使用【杀】伤害+1。

- **实现与接口** · 伤害确定前（`fk.DamageCaused`），按当前围攻关系检查马隆和对方的位置。被围攻者用【杀】伤害马隆且马隆为围攻者时减 1，马隆处于被围攻位置且伤害围攻者时加 1。
- **验证依据** · [jin023_malong.lua](../../../../../tests/jin023_malong.lua#L77)。在实际围攻关系中分别验证自己处于两侧时的伤害修正。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
