## 千幻

- **标识与依据** · 于吉（QUN011，阵包），运行时 ID `qiao__skill_qun011_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun011_1.lua)和[逐将规则](../../../../rules/generals/qun011-yuji.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2747)。

> 与你势力相同的角色受到伤害后，你可以将一张牌置于武将牌上（数量至多为体力上限）；与你势力相同的角色成为非装备牌的唯一目标时，你可以移去一张“千幻”牌，取消之。

- **实现与接口** · 同势力角色受伤后，于吉可将自己的一张牌置为「千幻」。每份【千幻】独立检查体力上限和可消耗的牌。同势力角色成为非装备牌唯一目标时，可移去本实例的一张牌并取消目标。
- **验证依据** · [于吉专项](../../../../../tests/qun011_yuji.lua) 从实际伤害生成千幻牌，核对同花色并存、真实用杀取消目标、暗置和临时失效期间保留，以及同名牌面技能与角色授技在交换、永久失技和授予撤回时各自的归属。
- **来源与去向** · [公共接口](../../general-exchange.md#牌类标记生命周期)逐张登记来源。有两份【千幻】时，角色获授的实例留在角色处，武将牌的实例随牌交换。实例终止时仅弃置仍绑定的牌。
