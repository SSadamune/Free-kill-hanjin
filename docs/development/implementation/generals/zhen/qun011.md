## 千幻

- **标识与依据** · 于吉（QUN011，阵包），运行时 ID `qiao__skill_qun011_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun011_1.lua)和[逐将规则](../../../../rules/generals/qun011-yuji.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L2747)。

> 与你势力相同的角色受到伤害后，你可以将一张牌置于武将牌上（数量至多为体力上限）；与你势力相同的角色成为非装备牌的唯一目标时，你可以移去一张“千幻”牌，取消之。

- **实现与接口** · 同势力角色受伤后，于吉可将自己的一张牌置入「千幻」公开特殊牌堆，置入前检查牌堆张数少于其体力上限。同势力角色成为非装备牌唯一目标时，他可移去其中一张并取消目标。当前 `derived_piles` 供交换流程识别牌堆，同时会在普通失技时清堆。技能另有失技回调和暗置监听，暗置会清空千幻牌。
- **验证依据** · [qun011_yuji.lua](../../../../../tests/qun011_yuji.lua#L20)覆盖同花色牌可并存、直接撤技后清堆以及真实单目标【杀】被取消。
- **未完成与边界** · 待接入[牌类标记生命周期](../../general-exchange.md#牌类标记生命周期)，用实例绑定接管现有迁移识别和清堆。接入后，暗置及临时失效均保留千幻牌，交换时随原实例移动，实例终止时统一清理。
