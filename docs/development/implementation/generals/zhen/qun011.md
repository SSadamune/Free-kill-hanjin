## 千幻

- **标识与依据** · 于吉（QUN011，阵包），运行时 ID `qiao__skill_qun011_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun011_1.lua)和[逐将规则](../../../../rules/generals/qun011-yuji.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L2747)。

> 与你势力相同的角色受到伤害后，你可以将一张牌置于武将牌上（数量至多为体力上限）；与你势力相同的角色成为非装备牌的唯一目标时，你可以移去一张“千幻”牌，取消之。

- **实现与接口** · 同势力角色受伤后，于吉可把一张牌置入“千幻”角色牌堆，上限为允许的体力上限。同势力角色成为非装备牌唯一目标时，他可移去其中一张并取消目标。引擎 `derived_piles` 清理失技牌堆，暗置监听补齐来源牌暗置的路径。
- **验证依据** · [qun011_yuji.lua](../../../../../tests/qun011_yuji.lua#L20)。验证同花色牌可并存、失技清堆以及真实单目标【杀】被取消。
- **未完成与边界** · 角色牌堆的归属边界记录现行实现，桌游中牌随武将的语义见规则页。
