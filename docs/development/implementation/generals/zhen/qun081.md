## 剽戮

- **标识与依据** · 徐荣（QUN081，阵包），运行时 ID `qiao__skill_qun081_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun081_1.lua)和[逐将规则](../../../../rules/generals/qun081-xurong.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L3414)。

> 当你使用伤害牌指定目标后，你可以选择一个目标并弃置你或其一张坐骑或宝物牌，然后令此牌对其伤害+1。

- **实现与接口** · 徐荣使用伤害牌指定目标后，通过[公共联动选择](../../skill-ui.md#发动时需要玩家决定的输入)选其中一个目标，并选择自己或该目标的一张合法坐骑或宝物支付。以本次用牌数据记录，只增加对所选目标的伤害。
- **验证依据** · [qun081_xurong.lua](../../../../../tests/qun081_xurong.lua#L89)。对两名受伤角色检查真实客户端的双向筛选，确认弃置徐荣的坐骑且仅所选目标增伤。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 杀绝

- **标识与依据** · 徐荣（QUN081，阵包），运行时 ID `qiao__skill_qun081_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_qun081_2.lua)和[逐将规则](../../../../rules/generals/qun081-xurong.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L3415)。

> 有角色进入濒死状态时，若其体力小于0，你可以获得造成此伤害的牌。

- **实现与接口** · 有角色进入濒死时（`fk.EnterDying`），若其体力小于 0 且伤害事件中的牌可获得，徐荣可以取得造成此次伤害的实体材料。
- **验证依据** · [qun081_xurong.lua](../../../../../tests/qun081_xurong.lua#L134)。从实际使用伤害牌进入濒死，验证取得本次伤害牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
