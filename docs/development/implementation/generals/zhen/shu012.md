## 挑衅

- **标识与依据** · 姜维（SHU012，阵包），运行时 ID `qiao__skill_shu012_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu012_1.lua)和[逐将规则](../../../../rules/generals/shu012-jiangwei.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L3917)。

> 出牌阶段限一次，你可以令至多两名攻击范围内有你的角色依次执行以下效果：其可以对你使用一张【杀】，若你未因此受到伤害，你弃置其一张牌。

- **实现与接口** · 姜维于出牌阶段可指定至多两名攻击范围覆盖自己的角色，分别询问是否对自己使用【杀】。逐名跟踪是否实际造成伤害，未受该角色本次【杀】伤害时，姜维弃置该角色一张牌。
- **验证依据** · [shu012_jiangwei.lua](../../../../../tests/shu012_jiangwei.lua#L93)。分别覆盖真实用杀与取消后弃该角色牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 天覆

- **标识与依据** · 姜维（SHU012，阵包），运行时 ID `qiao__skill_shu012_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu012_2.lua)和[逐将规则](../../../../rules/generals/shu012-jiangwei.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L3918)。

> 主将技，阵法技，你队列的角色的回合内，所有角色的攻击范围+2。

- **实现与接口** · 天覆由主将阵法来源生效。房间距离状态查询当前行动者是否处于姜维的队列，其回合内统一为所有角色增加 2 点攻击范围。公开状态变化后按实际队列重算。
- **验证依据** · [shu012_jiangwei.lua](../../../../../tests/shu012_jiangwei.lua#L69)。在实际队列和非队列上下文读取攻击范围。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 承志

- **标识与依据** · 姜维（SHU012，阵包），运行时 ID `qiao__skill_shu012_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_shu012_3.lua)和[逐将规则](../../../../rules/generals/shu012-jiangwei.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L3919)。

> 副将技（☯️-1），若你的主将拥有“观星”，则该技能卜算牌数+2，否则你拥有“观星”。

- **实现与接口** · 承志属于副将。若当前明置主将提供有效的观星，该来源的卜算张数增加 2。否则，承志为持有者建立独立的观星来源。明暗置、变更主将或技能得失后重新同步，撤销承志派生来源时保留主将印刷或后天附着的同名技能。
- **验证依据** · [shu012_jiangwei.lua](../../../../../tests/shu012_jiangwei.lua#L82)。覆盖实际变更主将、恢复独立主将来源及真实观星卜算七张。
- **未完成与边界** · 相关主将与副将状态详见[公共技能来源](../../general-exchange.md#公共武将来源职责)。
