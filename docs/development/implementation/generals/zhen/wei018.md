## 护援

- **标识与依据** · 曹洪（WEI018，阵包），运行时 ID `qiao__skill_wei018_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei018_1.lua)和[逐将规则](../../../../rules/generals/wei018-caohong.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5126)。

> 你的回合内，当牌置入一名角色的装备区后，你可以弃置其距离1的另一名角色区域里的一张牌。结束阶段，你可以将一张装备牌置于一名角色的装备区。

- **实现与接口** · 曹洪于结束阶段可以把一张装备牌置入角色的装备区。在自己的回合有装备牌进入任意角色装备区后（`fk.AfterCardsMove`），曹洪可从被置入者距离 1 的另一名角色区域选择并弃一张牌，候选可含判定区。
- **验证依据** · [wei018_caohong.lua](../../../../../tests/wei018_caohong.lua#L90)。以真实装备移动触发，核对按被置入者距离弃区域牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 鹤翼

- **标识与依据** · 曹洪（WEI018，阵包），运行时 ID `qiao__skill_wei018_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei018_2.lua)和[逐将规则](../../../../rules/generals/wei018-caohong.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L5127)。

> 阵法技，你队列的角色拥有“飞影”。

- **实现与接口** · 明暗置、技能来源或在场者变动时重新计算曹洪的队列，为仍在队列里的角色同步独立飞影来源。预注册的来源槽位与角色对应，客户端从公开层数读取距离修正。来源撤回后保留其他鹤翼与独立飞影。
- **验证依据** · [wei018_caohong.lua](../../../../../tests/wei018_caohong.lua#L133)。核对队列授技、解除时保留别的来源，以及派生来源预注册、客户端可加载和无队列的边界。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 飞影

- **标识与依据** · 曹洪（WEI018）的派生技能或专属效果，运行时 ID `qiao__feiying`。见[源码](../../../../../pkg/qiao_generals/skills/feiying.lua)和[逐将规则](../../../../rules/generals/wei018-caohong.md)。

此处引用[项目登记的飞影文字](../../../../../pkg/qiao_generals/skills/feiying.lua)。外部资料在鹤翼条目中仅列技能名。

> 锁定技，其他角色计算与你的距离+1。

- **实现与接口** · 鹤翼按队列同步飞影来源。飞影的距离回调只读取目标的公开层数，总修正包含当前有效的各队列来源与独立来源。
- **验证依据** · [wei018_caohong.lua](../../../../../tests/wei018_caohong.lua#L133)。覆盖有无队列、来源并存和客户端已有的预注册来源。
