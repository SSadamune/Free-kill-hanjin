## 精策

- **标识与依据** · 郭淮（WEI032，阵包），运行时 ID `qiao__skill_wei032_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei032_1.lua)和[逐将规则](../../../../rules/generals/wei032-guohuai.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5302)。

> 每回合结束时，若你本回合使用或打出过的牌数：大于体力值，你可以摸一张牌；等于体力值，你可以摸两张牌。

- **实现与接口** · 回合结束时（`fk.TurnEnd`），无论是谁的回合，郭淮都读取自己本回合实际使用和打出的牌数，并与当前体力比较。超过体力时可摸一张，等于时可摸两张，少于时跳过询问。发动提示显示按当前牌数和体力算出的张数。回合中获得精策时仍读取已经发生的用牌和响应。
- **验证依据** · [wei032_guohuai.lua](../../../../../tests/wei032_guohuai.lua#L156)。在他人回合比较牌数与体力，逐项核对不足时跳过询问、相等时询问并摸两张、超过时询问并摸一张。同套件也覆盖使用和打出的计数、获得技能前的记录及暗将预亮。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 疲攻

- **标识与依据** · 郭淮（WEI032，阵包），运行时 ID `qiao__skill_wei032_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei032_2.lua)和[逐将规则](../../../../rules/generals/wei032-guohuai.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5303)。

> 主将技（☯️-1），当你使用或打出基本牌时，你可以指定一名角色，其交给其势力角色各一张手牌。

- **实现与接口** · 郭淮作为主将，使用或打出基本牌时分别通过 `fk.AfterCardUseDeclared` 和 `fk.CardResponding` 提供发动。选中的角色向自己势力中的角色分别交一张手牌，逐次复核可以接收的对象和剩余手牌。
- **交牌可见性** · 每张手牌分别暗交。指定角色的人可以看到谁交给谁一张牌。看见牌面需要是本次交牌人、收牌人或另有查看权限。
- **验证依据** · [郭淮专项](../../../../../tests/wei032_guohuai.lua)从主将郭淮使用实体【桃】发动，以预设选人和选牌回复将两张手牌给不同队友。检查两张牌的最终归属，以及郭淮、交牌人、两位收牌人、通牌队友和其他座位各自看到的牌。
- **未完成与边界** · 多客户端联网实局仍待复测。

## 屏御

- **标识与依据** · 郭淮（WEI032，阵包），运行时 ID `qiao__skill_wei032_3`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wei032_3.lua)和[逐将规则](../../../../rules/generals/wei032-guohuai.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L5304)。

> 副将技，与你势力相同的其他角色需要使用【闪】时，其可以令你选择是否打出之（视为由其使用）。

- **实现与接口** · 副将位置的郭淮可在同势力其他角色的【闪】请求中代为打出。保留原请求及多闪上下文，郭淮以 `skipDrop` 打出闪，把在处理区的实体材料交给请求者构造待执行的用牌或响应数据。
- **验证依据** · [wei032_guohuai.lua](../../../../../tests/wei032_guohuai.lua#L98)。检查使用和打出两个入口，并在真实【杀】结算中由郭淮提供【闪】。
- **未完成与边界** · 多闪与客户端交互沿用[分批证据中的未验收说明](../verification-evidence.md#阵包与势包分批验证)。
