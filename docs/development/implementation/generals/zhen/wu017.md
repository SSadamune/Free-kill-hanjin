## 尚义

- **标识与依据** · 蒋钦（WU017，阵包），运行时 ID `qiao__skill_wu017_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu017_1.lua)和[逐将规则](../../../../rules/generals/wu017-jiangqin.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6379)。

> 出牌阶段限一次/当你响应其他角色的牌后，你可以令一名其他角色/其观看你的手牌，然后你观看其所有暗置武将牌和手牌，且你可以弃置其中每种黑色花色的手牌至多各一张。

- **实现与接口** · 出牌阶段的主动入口从公开在场角色中取候选。响应后的入口区分使用型响应与打出型响应，取原牌的使用者。两者结算时都先让对方看蒋钦手牌，再让蒋钦以私密面板查看对方暗将和手牌，黑桃、梅花各可弃至多一张。
- **验证依据** · [wu017_jiangqin.lua](../../../../../tests/wu017_jiangqin.lua#L79)。覆盖真实客户端的出牌按钮及候选、主动弃两种黑色花色和响应入口。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 鸟翔

- **标识与依据** · 蒋钦（WU017，阵包），运行时 ID `qiao__skill_wu017_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu017_2.lua)和[逐将规则](../../../../rules/generals/wu017-jiangqin.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6380)。

> 阵法技，若你是围攻角色，被你围攻的角色需多一张【闪】才能抵消围攻角色的【杀】。

- **实现与接口** · 蒋钦是围攻者时，同一围攻关系中的角色对被围攻者用【杀】，会在逐目标指定阶段（`fk.TargetSpecified`）将该目标所需的【闪】数量加 1。
- **验证依据** · [wu017_jiangqin.lua](../../../../../tests/wu017_jiangqin.lua#L181)。以已需要多张【闪】的【杀】验证再增一张。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
