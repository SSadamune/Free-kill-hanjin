## 疑城

- **标识与依据** · 徐盛（WU020，阵包），运行时 ID `qiao__skill_wu020_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu020_1.lua)和[逐将规则](../../../../rules/generals/wu020-xusheng.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6444)。

> 与你势力相同的角色成为【杀】的目标后，你可以令其摸一张牌，其选择一项：1.使用一张装备牌；2.于此回合结束时弃置一张牌。

- **实现与接口** · 同势力角色成为【杀】的目标后，徐盛可以令其摸一张牌，再由其选择使用一张装备牌或在回合末弃一张牌。延迟弃牌由回合末处理，记录建立后按受益者执行。
- **验证依据** · [wu020_xusheng.lua](../../../../../tests/wu020_xusheng.lua#L56)。通过实际被指定为【杀】目标验证摸牌，并在回合结束检查延迟弃置。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 破军

- **标识与依据** · 徐盛（WU020，阵包），运行时 ID `qiao__skill_wu020_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu020_2.lua)和[逐将规则](../../../../rules/generals/wu020-xusheng.md)。

牌面原文见[石激桑资料](../../../../../assets/docs/石激桑武将列表.json#L6445)。

> 当你使用【杀】指定一个目标后，你可以扣置其至多X张牌（X为其势力角色数），这些牌本回合移出游戏。

- **实现与接口** · 徐盛使用【杀】指定一个目标后，可按目标实际势力人数选至多相应数量的牌进行扣置。只为这次实际移到 `Card.Void` 的牌登记回合末返还。若角色当回合还被移出游戏，等其移回后再尝试返还。
- **验证依据** · [wu020_xusheng.lua](../../../../../tests/wu020_xusheng.lua#L95)。核对实际扣置与回合末返还。[君孙权专项](../../../../../tests/em_wu001_sunquan.lua)另覆盖宝物被聚宝保护时只登记成功扣置的牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
