## 疑城

- **标识与依据** · 徐盛（WU020，阵包），运行时 ID `qiao__skill_wu020_1`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu020_1.lua)和[逐将规则](../../../../rules/generals/wu020-xusheng.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6444)。

> 与你势力相同的角色成为【杀】的目标后，你可以令其摸一张牌，其选择一项：1.使用一张装备牌；2.于此回合结束时弃置一张牌。

- **实现与接口** · 同势力角色成为【杀】的目标后，徐盛可以令其摸一张牌，再由其选择使用一张装备牌或在回合末弃一张牌。受益者可以使用手里的装备，也可以使用【木牛流马】下能如手牌般使用的装备。两项都展示给受益者，无可用装备时装备项置灰，由其确认回合末弃牌。
- **验证依据** · [wu020_xusheng.lua](../../../../../tests/wu020_xusheng.lua#L57)。覆盖无装备时确认回合末弃牌、立即使用刚摸到的装备，以及摸到基本牌后使用木牛下唯一的【青釭剑】。两条用装备的路径都核对了剑进入装备区，且本次没有登记回合末弃牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。

## 破军

- **标识与依据** · 徐盛（WU020，阵包），运行时 ID `qiao__skill_wu020_2`。见[源码](../../../../../pkg/qiao_generals/skills/skill_wu020_2.lua)和[逐将规则](../../../../rules/generals/wu020-xusheng.md)。

牌面原文见[石激桑武将列表.json](../../../../../assets/docs/石激桑武将列表.json#L6445)。

> 当你使用【杀】指定一个目标后，你可以扣置其至多X张牌（X为其势力角色数），这些牌本回合移出游戏。

- **实现与接口** · 徐盛使用【杀】指定一个目标后，在询问前核对目标公开势力的人数与手牌、装备张数。未确定势力或没有可扣置区域牌时跳过询问；实际扣置时重新计算上限。只为这次实际移到 `Card.Void` 的牌登记回合末返还。若角色当回合还被移出游戏，等其移回后再尝试返还。
- **状态显示** · 被扣置者显示〖破军〗状态及仍在游戏外的牌数。各席位可见牌数，实体牌列表只发给被扣置者本人，重连同样按座位发送。该角色点开标签后使用原生牌堆查看面板。
- **验证依据** · [徐盛专项](../../../../../tests/wu020_xusheng.lua)覆盖有手牌的暗将不触发询问、已定势力目标的手牌被扣置，以及回合末的两个去向。目标存活时暗返手牌，目标死亡时公开置入弃牌堆。两种情况均检查各座位看到的牌。[君孙权专项](../../../../../tests/em_wu001_sunquan.lua)另覆盖宝物被聚宝保护时只登记成功扣置的牌。
- **未完成与边界** · 本条只记录上述覆盖。共通的人工验收范围见[开发状态](../../../status.md#当前验收基线)。
