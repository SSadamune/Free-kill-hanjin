# 机器人玩家决策

三个汉晋模式在扩展自己的房间初始化中，为各席位创建扩展内的 `HanjinRobot` 实例。它继承上游 `SmartAI`，只在机器人或托管接管时由服务端调用。策略接线全部随扩展发布，候选、费用和效果复用引擎已有的请求及结算接口。

房间入口在 [`mode.lua`](../../../pkg/qiao_mode/mode.lua)，请求分发在 [`ai/init.lua`](../../../pkg/qiao_mode/ai/init.lua)。牌与费用、主动技、触发技、应变、转化、改判和移牌分别由同目录模块负责。选目标并确认后，只向原生接口返回牌、技能与目标。触发期间可读取本次真实结算，例如改判看到当前判定牌，慈威看到当前用牌目标。待处理的触发数据只在服务端当前请求内可见。

## 出牌

| 操作 | 条件 |
| --- | --- |
| 洞烛先机、固国安邦、桃 | 能合法使用时优先补充资源；桃用于已受伤的自己。 |
| 装备 | 优先填空槽。双栏坐骑要求两个坐骑栏都有空位。 |
| 杀（普通、火、雷、冰）、决斗、出其不意、水淹七军 | 攻击可确认的敌人，优先低体力目标。属性伤害按本次预计传导的敌我人数、濒死风险及受伤技能收益取舍。 |
| 过河拆桥、顺手牵羊、逐近弃远 | 按可移除的具体牌估算，可以拆取敌方牌、清除己方判定区里的不利牌，并在敌方可改判时处理闪电。能获得牌时，敌方手牌及装备额外加 2 分。 |
| 借刀杀人 | 持武器者及被要求出杀的目标均须是合法的确定敌人。若一名持武器者没有这样的次目标，则尝试下一个。 |
| 乐不思蜀、兵粮寸断 | 对合法的确定敌人使用，优先手牌多的目标。 |
| 万箭齐发、南蛮入侵、火烧连营 | 按原生目标与结算顺序累计预计伤害，敌方受影响人数须超过己方与未知势力人数之和，己方与未知势力均不能因此濒死，计入各方受伤技能后仍须净赚。已知免疫不计，火烧连营计入传导及重复直击。 |
| 克复中原 | 尽量选择自己和已确认队友。 |
| 远交近攻 | 从牌面允许的已确定异势力目标中优先选合作倾向更高者。倾向相同时优先体力较高者。自身摸三张，目标摸一张。 |
| 酒、火攻 | 有杀可以攻击确定敌人时先用酒。火攻要求自己至少有三种花色的低价值合法弃牌，再选能安全造成火焰伤害的敌人。结算时按实际展示花色重新挑选费用。 |
| 桃园结义 | 至少一名己方角色会回血，且所有会回血的目标均为己方。 |
| 铁索连环 | 用于解除自己或已确认队友的连环。 |

敌友判断读取其他角色公开势力。自己尚未确定势力时，可以依据自己的选将信息识别公开异势力敌人。同势力角色在这种情况下仍未成为确定队友。需要按牌面确认双方势力相同或不同的操作一律通过原生合法性检查。只有国号公开的野心家才能按国号合计，未公开国号的明置野心家各算一方。死亡、移出和势力未知的对手不列为进攻候选。

出牌阶段统一比较实体牌、主动技和转化技，常规按摸牌、己方准备、支援、破坏敌方状态、伤害、延时锦囊的顺序逐档尝试。摸牌包括克复中原、远交近攻、制衡、苦肉与诈降、敏思、雄异和庐江上甲。临时结盟紧接摸牌。己方准备包括自疗和填空栏装备。支援包括桃园结义、解连环、结姻和直谏。奇袭、克清和祸水在破坏档，强袭、乱武和乱击在伤害档，断粮在延时档。有可攻击的目标时，酒在伤害牌前用。重铸和极低价敌方合纵在常规操作之后。每档先尝试实体牌，再试主动技和转化技。常规选目标同分时按座位顺序。

有可生效的摧破时，读取本回合全部真实用牌事件。每次先寻找牌名字数等于下一次用牌序号、且可对己方实际摸牌或对敌方加伤的合法操作，再恢复常规牌序。实体牌及转化牌都参与；有害的用牌仍须通过原安全检查，并将预计加伤计入。

### 【杀】的防具判断

- 普通【杀】跳过会被生效的【藤甲】免疫的目标。无视该防具时可以选中，属性【杀】照常评估伤害与连环。
- 普通及属性【杀】按预计命中收益排序。对生效的【八卦阵】按一半计分，对回合外仍可提供【闪】的【驺虞幡】按四分之一计分。能限制响应或额外要求【闪】时按全额计分。有生效的改判技能时也对【八卦阵】按全额计分。生效的【青釭剑】跳过【藤甲】免疫检查和两种防具的折扣。实际响应和防具结算仍走原生流程。
- 〖制衡〗归入摸牌顺序，〖奇袭〗归入【过河拆桥】转化，〖咆哮〗的实际用【杀】次数由原生次数修正计算。强行命中按当前目标检查条件，例如〖烈勇〗比较双方体力及手牌数。[技能分类](../../../pkg/qiao_mode/ai/skill_effects.lua) · [防具评分](../../../pkg/qiao_mode/ai/slash_defense.lua)

### 提前强命与攻击目标

- 【杀】的目标分按预计伤害净收益和命中机会排序。手牌为空时不估算手牌【闪】，装备产生的【闪】仍另计。〖潜袭〗已限制的颜色按实际手牌材料规则从响应估算中去掉。已有〖空城〗状态时，【杀】和【决斗】对该目标的预计收益为零。各目标的受伤技能收益从预计伤害中扣除。[选目标](../../../pkg/qiao_mode/ai/cards.lua) · [手牌响应估算](../../../pkg/qiao_mode/ai/slash_defense.lua)
- 〖潜袭〗在准备阶段比较 `未知摸牌的 3 分 + 提前强命的增量收益` 和合法弃牌的留牌成本。增量收益是 `本次伤害净收益 × 受限制后减少的响应机会`，按有望对距离 1 的确定敌人打出的一刀取最高值。只使用对方公开手牌张数、生效的手牌转化技能和防具。牌堆中的实体【闪】只有红色，〖倾国〗、〖龙胆〗及鏖战【桃】改变对应材料颜色的估计。已有封锁、不能出【杀】或无法安全造成伤害时，额外强命收益为零。[潜袭决策](../../../pkg/qiao_mode/ai/qianxi.lua)
- 发动后根据实际摸到的牌重选弃牌，优先保留能兑现的【杀】。选人使用结算保存的弃牌颜色与弃牌后的原生合法目标。单靠低价牌换未知摸牌也可发动。[马岱实装](generals/shi/shu019.md#shu019-2)

## 随机性格

进房开局为每个席位随机分配激进型、保守型、辅助型或刷牌型，每局保持一致。真人转入托管时沿用该席位在这局分到的性格。性格使用独立随机序列，牌堆、选将和其他房间规则沿用原生随机流程。

| 性格 | 牌序偏好 | 评分差异 |
| --- | --- | --- |
| 激进型 | 体力大于 1 时，先摸牌和破坏敌方状态。然后优先攻击，再整理自己的装备或支援。 | 每点伤害加 1 分，每点回复减 0.5 分。有效体力至多 2 的确定敌人获得额外 1 分攻击优先级。 |
| 保守型 | 体力至多 2 时，优先处理回复、装备和解连环，再继续摸牌。 | 每点伤害减 0.5 分，每点回复加 1 分。【闪】和【无懈可击】加 1 分，防具和防御坐骑加 0.5 分。主动承伤的评分门槛加 1.5 分。 |
| 辅助型 | 场上有确定队友时，摸牌后先考虑桃园结义、解连环、结姻和直谏，再整理自身。没有确定队友时用常规牌序。 | 每点回复加 1 分。有确定队友时，桃园结义、铁索连环和克复中原的留牌加 0.75 分。对其他确定队友的选人和助战评分加 0.5 分。 |
| 刷牌型 | 可先重铸手中至多 3 分的牌，再进破坏和伤害阶段。己方有人需要解连环时保留相应的铁索连环。 | 洞烛先机、固国安邦、克复中原和远交近攻的留牌加 0.75 分。制衡与敏思的单牌预算分别升为 3 和 3.5 分。 |

摧破优先找本次可兑现的收益，其余操作仍检查原生合法性、敌友和濒死风险。

## 伤害、回复与留牌估值

- 每点实际结算的伤害、失去体力或回复以 6 分为基准，再应用性格补正。按经过防伤修正的伤害点数计分。护甲影响是否进入濒死，超过剩余体力的伤害仍会增加救援所需的回复量。使目标进入濒死另加 4 分。回复以实际缺失体力为限，军令禁止回复或〖无当飞军〗会防止的回复本次计 0 分。〖狂骨〗可以回复时按一点回复记分，可以摸牌时按一张牌记 3 分。[共同估值](../../../pkg/qiao_mode/ai/health_value.lua) · [伤害估算](../../../pkg/qiao_mode/ai/damage.lua)
- 机器人处于全场或个人鏖战时，每点伤害和回复在性格补正后再加 4 分。【桃】分别按照一张【杀】和一张【闪】估值，保留两者较高分。试算比较当前手中已有的同类牌和实际用【杀】次数。出牌和响应走汉晋鏖战原生转化入口。[留牌估值](../../../pkg/qiao_mode/ai/costs.lua) · [鏖战规则](../../rules/battle-royal.md)
- 留牌估值衡量将来使用机会。常态中性格未补正的【桃】为 6 分，【桃园结义】的基础留牌为半点回复的分数。伤害牌按各牌原有的可用性折算伤害收益。唯一【杀】按三分之二点未兑现的伤害记 4 分，重复【杀】按额外可用次数记 2 或 3.5 分。唯一【闪】按当前状态未补正的伤害基准记 6 或 10 分，重复【闪】折半。[留牌估值](../../../pkg/qiao_mode/ai/costs.lua)

## 武将技、装备技与翼从

| 操作 | 条件 |
| --- | --- |
| 诗怨、安境、夺气、闭月、生息、奸雄的初次摸牌、洛神及继续判定、行殇、精策、枭姬、激昂、魂殇、酣战、空城、杀绝、双雄取牌、存嗣取牌、铸典展示黑牌 | 技能自身满足条件并发出确认时接受。 |
| 狼顾、刚烈、横江、破军、飞龙夺凤、麒麟弓、白马义从、西凉精骑的弃牌效果 | 受影响的角色须是确定敌人。 |
| 蛊毒 | 只阻止体力为 0 或更低的确定敌人回复。目标仍可能在后续求桃中获救，届时失去武将牌的代价仍可能发生。 |
| 忘隙、腹心死士的摸牌后交牌 | 受益者须是自己或确定队友。腹心死士的额外杀在合法目标中选确定敌人。 |
| 八卦阵、锦绣征袍、护心镜 | 八卦阵在使用闪和打出闪的两条请求中均接受判定；锦绣征袍有合法触发就接受；护心镜按原效果只询问致命伤害或一次至少两点的伤害，机器人此时交镜防伤。 |
| 涅槃、神智 | 涅槃用于自己可用的桃和酒数量不足以脱离濒死时。神智只在受伤、体力为 1、且仅有一张低价值手牌时换取回复。 |
| 冰冻伤害 | 对体力至少 3、装备至少两张的确定敌人，将本次单点冰冻伤害换成弃牌。 |
| 前驱、西凉精骑及其他额外杀询问 | 只在请求允许的目标中攻击确定敌人；前驱先检查有合法实体杀及目标。 |
| 铸典、太公阴符 | 只重铸低价值牌。太公阴符在出牌阶段优先解除己方连环。 |
| 水淹七军、克复中原的受益选项 | 水淹七军先比较实际传导及己方濒死风险。无传导时可用受伤技能补偿失去体力。在体力大于 2 时，装备净损失达到本次伤害代价加半点基础伤害分，也可选择承伤。估计不会受到伤害时可保留装备。克复中原选择确定能得到的摸牌。 |

【无懈可击】基础留牌为 7 分，已装备的牌、【洞烛先机】和【固国安邦】为 6 分，能填空槽的装备为 4 分，一般牌为 3 分，占用现有装备槽的手牌装备及少用牌为 1 分。【酒】按一点伤害与一点回复较高分的六分之五估算，常态基准为 5 分。逐张选择会重新核对重复【杀】和【闪】的数量。手中装备在〖枭姬〗可生效时加 1.5 分，〖固政〗可生效加 1 分。〖集智〗为能触发其效果的实体锦囊加 1.5 分。拥有可生效的拼点相关技能时，点数 9 至 K 各额外加 0.25 至 1.25 分。只在引擎列出的合法候选中支付。必弃时选够下限，可选费用按具体效果比较。

- 应变预估使用自己手中的实体牌后能否满足条件。空巢须是最后一张手牌，富甲比较移走此牌后的手牌数。提前锁定次数的效果用宣告前手牌数。残躯、孤军用原规则。加伤与转雷的留牌加分按三分之一点伤害估算，摸牌、双项与自动拆装备记 2 分，其余已知效果记 1 分，单牌合计最多加 3 分。助战按实际询问另算。同牌序及同基础优先级的实体牌，先使用高值牌。回应时先用低值牌。
- 真正的弃牌费用可比较枭姬的预期摸牌与失去装备的机会成本。未知摸牌每张计 3 分，自己回合计一张、他人回合计两张。只有预期收益严格大于装备和较便宜可用替代牌的差值才用装备。同批可选费用最多计并选择一件装备。强制弃置牌不足时仍按原生下限处理。制衡用装备时若无可用手牌，以一张补牌的 3 分为比较基准。转化、赠与和重铸不计这笔弃牌收益。
- 〖贯石斧〗只对确定敌人支付。被【闪】抵消后，用牌加伤、【藤甲】、护甲、属性传导、〖狂骨〗和【驺虞幡】等都进入伤害净收益。估计可能使己方或势力未明者濒死时取消。两张合法弃牌的总费用可支付到本次净收益。[发动判断](../../../pkg/qiao_mode/ai/trigger_policies.lua) · [伤害估算](../../../pkg/qiao_mode/ai/damage.lua)
- 三尖两刃刀只对确定敌人的合法次目标使用。一张费用至多 3 分，通常要求目标只有 1 点体力。目标有 2 点体力时，还要求自己的手牌已超过上限。
- 火攻按实际花色挑合法费用，目标只有 1 点体力时至多 3 分，其余目标至多 2 分。
- 铸典和太公阴符的重铸费用至多 2 分。奸雄先免费摸牌，只有可取得的伤害牌估值高于费用时才选择交换。

## 杀的留牌与追加次数

- 重复杀通常为 2 分。对至少一个合法的确定敌人仍能实际用出两次时，升为 3.5 分。按原生目标和次数接口读取咆哮、诸葛连弩、总戎等绕过次数效果，以及天义、诈降、庐江上甲、州郡领兵印等已生效的有限加成。出牌阶段扣除已用次数。杀的应变仍按具体实体牌条件加分。
- 天义在伤害档前评估。至少两张手中实体杀能打到确定敌人，且赢拼点带来的次数或距离确实可用。自己须有一张 12 点以上、至多 5 分的非杀手牌，仅向手牌一至两张的确定敌人发起。真拼点选最高点且较便宜的合法材料。赢后在原生许可内多选一个通过伤害安全判断的敌人。
- 州郡领兵印的准备阶段只从服务端提供的合法分配中选择。按已知的后续出牌和摸牌阶段、当前能攻击确定敌人的实体杀数量、当前合法用杀次数、实际可触发不计次数的应变和预计超过手牌上限的牌数评估。多一次可兑现的【杀】按四分之三点伤害估算，多摸一张计 3 分，每少溢出一张计 1 分。把有限首刀降至零额外扣 1.5 分。无正收益时取消分配。

### 杀与伤害效果的策略覆盖

这轮按正式牌、武将技能、翼从、应变和模式规则的执行入口审查。估值使用己方已知的牌、原生合法候选、公开装备和标记，以及当前结算已经写入的数据。其他角色的响应由手牌数量和生效中的技能估算。获得多次出杀机会后，仍逐次检查当时的合法目标和费用。

| 效果 | 机器人如何取舍 |
| --- | --- |
| 使用【杀】及以牌追击 | 普通与属性【杀】、〖短兵〗、〖虓猛〗、〖誓众〗、〖迅击〗、〖司镇〗、〖督锐〗、〖虎豹骑〗及〖宿卫中军〗共用目标估值。〖督锐〗只在唯一仍在场的受伤角色确实是目标时计入加伤。〖方天画戟〗比较扩大目标可能取消剩余伤害的损失与新增目标的净收益。 |
| 直接伤害 | 〖强袭〗按弃武器或失去体力的实际代价选择。〖驱虎〗比较拼点胜率、可命中的第三方与失败时的反伤。〖雷击〗分别估算黑桃、梅花及回复，包含连环与〖红颜〗。〖三尖两刃刀〗和〖附敌〗只用能换回足够净伤害的材料。〖曲阿小将〗检查重合目标的总收益及己方濒死风险。〖散谣〗、〖挥鞭〗、〖清剿〗等沿用阵营判断并使用统一伤害单位。 |
| 强命与增加响应次数 | 〖潜袭〗、〖烈勇〗、〖越险〗、〖奋钺〗及〖贯石斧〗按发生时机估算可兑现的伤害。〖奋钺〗比较低点立即使用无响应火【杀】与高点留给下一张牌的收益。〖无双〗、〖短兵〗、〖鸟翔〗以额外【闪】处理手牌响应，防具折扣沿用强命类例外。〖铁骑〗、〖猛撼〗、〖赤霄剑〗及已写入的禁止响应效果进入同一目标检查。 |
| 视为或转化伤害牌 | 〖武圣〗、〖龙胆〗、〖武库〗、〖铁脊〗、〖卸尾〗、〖殿军〗、〖火计〗、〖乱击〗、〖离间〗、〖双雄〗、〖奇策〗、〖五行鹤翎扇〗及鏖战【桃】使用同一套牌与目标估值。〖丈八蛇矛〗从合法材料中支付两张牌，主动用【杀】时比较预期伤害，响应时按当前请求的成本取舍。 |
| 加伤 | 【酒】和〖裸衣〗比较后续攻击的增量。〖摧破〗、〖连计〗、〖构难〗、〖抗锐〗、〖督锐〗及〖剽戮〗按可用状态或本次用牌记录计入伤害。〖剽戮〗分别计入弃敌方装备的收益或弃自己装备的成本。〖陷阵营〗、〖黄巾雷使〗比较加伤前后，后者还计入红判给己方来源牌的收益。 |
| 额外次数和阶段 | 〖咆哮〗、〖天义〗、〖诈降〗、〖前驱〗、【诸葛连弩】及【州郡领兵印】按引擎实际限次、距离和目标入口处理。〖神速〗比较额外【杀】与跳过阶段、弃装备或失去体力的代价。〖庐江上甲〗、〖弓骑〗等保留各自的费用和距离判断。 |

〖乘隙〗、〖滔乱〗、〖谋诛〗、〖挟征〗等包含未知摸牌、隐藏选择或连续结算，仍沿用原生入口和保守的取消策略。目标数目、禁止响应、附加伤害、使用次数及元素传导均以正式规则结算。

## 主动操作与应变

| 操作 | 条件 |
| --- | --- |
| 制衡、庐江上甲 | 制衡重选留牌分数至多 2 的合法手牌，最多选至体力上限。符合上述枭姬取舍时另可用一件有效费用至多 3 分的装备。庐江上甲在手牌少于装备时补牌，也可为能兑现的额外一次杀支付低价非杀手牌。 |
| 突袭 | 在有手牌的确定敌人中按 `10 ÷ 手牌数` 加势力与真人倾向排序，最多替代本次可摸牌数。取暗牌由引擎随机。 |
| 卜算 | 自己回合且判定区为空时，可把值较高的牌留在牌堆顶，按请求的上下限划分。 |
| 重铸 | 常规出牌和已支持的主动技均无合适动作时，重铸手中实际有重铸入口的牌。 |
| 合纵 | 只向手牌区可用的已确定异势力角色交一张合法标记手牌。临时合作时，收益为 `2.5 + 2.5 × 合作倾向`，手牌须至多 3 分且费用低于收益。优先处理摸牌档，再优先合纵。没有合适的临时盟友时，等常规用牌、主动技、转化和重铸都无可用动作，才考虑用至多 1 分的手牌向敌方合纵。两类候选都按净收益和合作倾向排序，牌面仍要求交牌后能摸牌。 |
| 拆牌选牌 | 比较可拆取的公开关键牌与暗手牌的预期收益。获得敌方手牌或装备额外加分。选择暗手牌时让引擎随机选。 |
| 应变增减目标 | 只额外选合法且效果明确有利的目标。减目标用于避免伤害或拆牌等波及己方或未明势力，或免去给敌人克复中原。借刀杀人的新增武器持有者和副目标均须是确定敌人。 |
| 助战 | 按本次应变条目的增量效果、目标、连环后果和实际弃牌估算净收益。真正队友和高收益的临时盟友可获助战，具体费用与边界见下节。 |

### 助战评分

| 应变效果 | 估算增量收益 |
| --- | --- |
| 水淹七军执行两项 | 目标须有装备，追加雷电伤害须安全。普通结算下目标可选代价较小的一项，因此取装备损失与伤害分中较大的一项。 |
| 逐近弃远、勤边执行两项 | 目标手牌与装备至少两张且判定区为空。基本 2.5 分，目标有装备时为 3 分。 |
| 前驱额外弃装备 | 只估算额外弃掉一件装备。目标无装备时跳过。 |
| 烈戎等伤害加一 | 比较加伤前后的伤害净收益。额外一点若使目标进入濒死，记入濒死加分。超过目标可失去的体力和护甲时，仍核对对其他连环目标的增量。 |
| 杀、出其不意、火攻增加目标 | 只算新增目标。其伤害走上面的评分。出其不意、火攻及对有手牌的角色使用杀时减 0.75 分，火攻使用者无手牌时放弃。本扩展的可定制移除或控制效果一般计 2.5 分。对真人及托管使用者按合法候选中最不利的选项计算。对机器人按其现有选人策略预计新增目标。 |

装备收益为 `1.5 + 件数`，水淹七军最多计三件，前驱只计一件。有防具加 0.5 分，目标有枭姬减 1 分。每个收益目标再按进攻倾向给最多 1.2 分的局势加成。多个实际目标的有效收益相加。任一需要评估的目标关系不明、已经无效或会造成不安全的连环传播时放弃。未知应变条目、借刀的额外双目标暂不资助。

协助者只弃一张原生合法的同类别手牌。净收益须超过留牌分和 0.5 分的资源预留，体力至多 1 或手牌至多两张时预留升为 1.5 分。临时盟友须对双方确认为敌的目标产生收益，达到当前每点基础伤害的 1.25 倍，且额外预留 1.5 分。弃牌上限对真实队友为 4 分，低储备为 2 分，对临时盟友分别为 3 分和 1 分。对真正的人类队友照常加入 0.15 分辅助权重。所有协助者仍参加同一次原生竞速请求，服务端继续核对合法弃牌和最终胜者。

## 关键牌与拆取目标

- 大势力角色的挟天子以令诸侯基础留牌 8.5 分，其他角色 3 分。乐不思蜀通常为 6 分，大势力为 7 分。火烧连营在下家是确定敌人时由 4.5 分起，每个同队列的其他确定敌人加 1 分，附加分最多 2.5。下家关系不明或是己方时基础 1.5 分。
- 敌人的防具、防御坐骑、武器和其他装备分别计 7、5.5、4.5 和 3.5 分。目标有可生效的枭姬时减 1.5 分。暗手牌按 `3 + 1.5 ÷ 当前手牌数` 估算。过河拆桥、顺手牵羊、逐近弃远的选人及实际拆取公用评分，顺手和距离为 1 的逐近给敌方手牌和装备额外加 2 分。保留能限制敌方的延时锦囊。
- 清除己方乐不思蜀计 8 分，兵粮寸断计 7 分。若有可生效的敌方鹰视、鬼道并具备可能的改判资源，对已确认关系角色判定区里的闪电计 7.5 分。减目标策略保留这种对己方有益的拆取。
- 奇袭先尝试省牌。材料超过 2 分时，目标收益须至少 5 分，并严格大于材料价值加 0.5 分。材料上限为 7 分。

### 同类技能横向接入

- 国色拆判定分支在破坏档。选合法方片后，只为有正收益的判定区目标发动，最高付 7 分，实际在栏中挑最高值的有害延时牌。作为乐不思蜀使用的分支排在延时档，只向确定敌人用，材料至多 3 分。两个分支各按原规则摸一张。
- 除疠在破坏档最多付 2.5 分一张合法牌，选至多三个满足原规则且预计拆牌收益至少 3 分的确定敌人。公开黑桃装备按能让其摸牌扣 3 分；暗手牌未知黑桃扣 0.5 分。定澜夜明珠在摸牌档共用制衡的换牌与枭姬估值，装备本身的禁止弃置及实际摸牌数由装备规则处理。
- 护援的装备进场拆牌用原生距离候选，比较敌方高值牌和清除己方判定牌。结束阶段优先尝试将手中装备放到自己或确定队友的原生可用栏位。
- 谋溃从本次杀的确定敌人中优先挑可拆高值牌者。单一目标有至少 5 分的拆牌收益时只弃牌，否则只摸牌。保留会引发反拆的双选机会。抵消谋溃后的实际拆牌也使用公开牌优先级。
- 猛撼只对安全的敌方杀目标、且目标有可弃装备时发动，明确弃装备以免让目标得到杀。狼顾、刚烈、死谏也用同一套公开装备与暗手牌估值选择。
- 顺流只在初次受伤者为确定敌人、仍有可拆牌，而且不会连带拆掉有牌的己方或未知势力角色时确认。每次拆牌使用原生给定区域。
- 庐江上甲的补牌仍在摸牌档。弃牌分支在伤害前核对可打到确定敌人的实体杀是否多于可用次数。最多支付两张非杀手牌，每张至多 2 分，总计至多 3 分。实际支付优先保留全部杀。

## 军令的发起与响应

机器人用同一套估值评估六项命令，以每个技能执行或拒绝后造成的增量修正决策。发起时从原请求的两个候选中选令，按执行者的公开体力、牌数、朝向和当前阶段估计代价。给己方选令时偏向低代价，给敌方选令时偏向压制。军令一从原生候选中选实际伤害目标，优先确定敌人，避免使己方或关系未明角色濒死。补益和追诛在服务端请求期间分别提供实际回复对象和待结算伤害。

| 技能 | 发起与后果 |
| --- | --- |
| 常令 | 可进入摸牌阶段时只向确定敌人交低值手牌。执行令发起者立即摸一张。拒绝使其摸牌阶段多摸三张。每张按 3 分、结合发起者敌友权重比较。 |
| 鬻爵 | 对平置的确定敌人支付低值费用。拒绝会导致暗置锁将，若已有暗置武将牌则评估定向叠置。执行后的摸牌只在预计能造成伤害时计收益。 |
| 补益 | 确定队友脱离濒死且仍受伤时，可向确定敌方伤害来源发令。答复者按获救角色的实际敌友、体力和回复限制估计拒绝的收益。 |
| 庸肆 | 对本回合摸过牌、仍有手牌的确定敌人发令。答复者按自己手牌价值估计被换走手牌的差价。实际换牌时优先交低值牌。 |
| 追诛 | 对即将受到致命伤害的己方角色发令，执行后为己方防止伤害。答复者比较执行所需费用、发起者可能防止的伤害，以及拒绝后增加的伤害。 |

| 军令 | 执行代价 |
| --- | --- |
| 一 | 评估对实际指定角色的一点普通伤害。保护自己和队友免于濒死，纳入受伤技能收益。 |
| 二 | 预计先摸一张，再按两张最便宜的牌比较自己付出的价值和发起者得到的资源。实际交牌时重选最便宜的合法牌。 |
| 三 | 体力至多 1 时拒绝。按失去一点体力计价，体力为 2 时另计 2.5 分风险。〖诈降〗可生效且体力至少 3 时扣除摸三张牌的 9 分收益。 |
| 四 | 已受同令限制时计零。估算余下回合失去应手牌与非锁定技的代价，低体力且手里有防御牌时提高拒绝权重。自己的回合受此限制计 9 分。 |
| 五 | 平置转叠置通常计 8 分。已叠置仍保持叠置，只评估当前回合禁止回复的增量代价。体力为 1 时保留救援机会，追诛可能防止当前致命伤害时另作比较。 |
| 六 | 分别预计留下手牌和装备区最有价值的一张，其余可弃牌的净值乘 0.65。枭姬按实际离开装备件数回补。执行后走原生选择逐区保留高值牌。 |

## 有条件发动的翼从

| 操作 | 条件 |
| --- | --- |
| 锦帆军 | 在原请求列出的可弃颜色和牌区内，选最低保留价值且至多 3 分的一张，换两张摸牌。 |
| 曲阿小将 | 与结算共用同一组重合目标。必须有存活重合目标，并且全部可确认为敌人。 |
| 黄巾雷使 | 伤害来源须是己方，受伤者须是确定敌人，并且加一点才会达到其体力与护甲总数。已属传导的伤害不加伤。对属性伤害按加伤后的数值复核各方人数和濒死风险。仅付至多 2 分的手牌。 |
| 青州精锐 | 从引擎提供的手牌数最小候选中选确定敌人，优先低体力。作为受影响者，只要有合法弃牌，体力不超过 2 或有至多 4 分的手牌就选择弃牌。仅有高价手牌且体力较高时选择承受伤害。 |
| 牛金 | 每次自由用牌询问沿用普通用牌的收益和目标条件。类别、次数与被动牌过滤由原入口处理。额外窗口保留酒，避免用掉唯一基本牌额度后无法接杀。 |

| 操作 | 条件 |
| --- | --- |
| 集智 | 有合法触发即接受。默认发动询问使用技能骨架 ID 识别。 |
| 观星、恂恂 | 自己回合且本方判定区为空时发动。结束阶段的卜算保留项目原先的牌序处理，避免把高值牌排给下家。 |
| 激诏 | 自己的实体桃、酒不足以脱离濒死时救命。随后接受摸牌，再用通用低价必弃策略选择弃掉的牌。涅槃使用同样的自救判断。 |
| 守成 | 给确定队友或自己触发。原结算摸两弃一，弃牌走通用策略。 |
| 武圣追加水淹七军 | 只追加给确定敌人，检查该雷电伤害的连环传播。 |
| 铁骑 | 仅对确定敌人发动，从合法可选的武将牌中优先选择公开非锁定技较多的一张，平局优先主将。作为防守方，只在支付后还留有可用实体闪时弃同花色的牌。总费用至多 3 分，1 点体力时至多 6 分。 |
| 夷灭 | 仅对确定敌人的非传导伤害使用限定机会。翻倍前未达到目标体力和护甲之和，翻倍后达到时才接受。属性伤害按翻倍后的数值复核传导收益和濒死风险。 |
| 权变、好施 | 权变只在当前使用牌的实体材料以外没有同花色手牌时接受。好施只在本次额外摸两张后预计不超过五张手牌时发动，避免触发交出半手牌。 |

| 淑慎、狂骨 | 淑慎优先低体力队友，其已受伤且体力至多 2 时帮其回复，其余选择双方摸牌。狂骨有回复选项就回复，满血摸牌。 |
| 突阵、雷击、死谏 | 只选择确定敌人。突阵、雷击优先低体力，雷击检查连环。死谏按装备及手牌数量选择有牌的敌人。 |
| 慈威 | 只在确定敌人的基本牌或普通锦囊对己方已有实际破坏目标时支付至多 2 分的牌。选择所有仍合法、尚未被无效的己方目标。其他可横置使用者的分支保留费用。 |
| 备寇、烈医、膂力 | 备寇让己方摸两张、让能弃牌的确定敌人弃牌，其余取消。烈医只给濒死队友或在自己的结束阶段给队友回复，优先最大回复。膂力一般补手牌，自己 1 点体力且手里有两至三张时，比较一点回复、弃尽手牌和补牌的净收益。 |

## 回合外因防守明置

机器人在其他角色回合内成为不利牌的目标时，可以在对应触发时机临时预亮暗将技能。服务端检查本次目标是否已取消或无效、使用者是否为已确认队友，以及所属位置是否允许明置。原生技能请求接受后才翻开所属武将牌。临时预亮在本次时机结束后清理。[预亮策略](../../../pkg/qiao_mode/ai/reactive_reveal.lua)

| 技能 | 判断 |
| --- | --- |
| 〖谦逊〗 | 这是本回合首次成为锦囊目标，且存在未指定的合法目标时，接受不利锦囊的发动请求，例如【乐不思蜀】或【兵粮寸断】。有益锦囊也计入首次。 |
| 〖享乐〗、〖祸首〗、〖巨象〗 | 在自己成为【杀】或【南蛮入侵】目标后的防御时机，接受原生发动确认。〖祸首〗的伤害来源时机独立处理。 |
| 〖流离〗、〖舍宴〗 | 由原选牌、选人策略决定是否真的发动。〖流离〗评估费用和转移目标。〖舍宴〗只在可从多目标不利普通锦囊中减去自己时自动预亮。 |

原生回归经过真实用牌、技能请求和结算，覆盖暗陆逊取消首张【乐不思蜀】、保留有益锦囊、禁止明置、暗刘禅用〖享乐〗令【杀】无效，以及〖流离〗无弃牌费用时清理临时预亮。其他回合外时机仍按各技能原有入口处理，例如〖集智〗在暗置时尚无回合外使用锦囊的自动预亮策略，〖空城〗在失去最后手牌时也尚无自动预亮判断。[机器人回归](../../../tests/robot_ai.lua)

## 主动技费用与技能联动

- 乱击只取两张原生合法材料，合计至多 4 分。按万箭齐发规则估算后，敌方受影响人数还须至少多两名。
- 乱武预先计入无手牌、装备或其他可用手牌来源者必失去的体力；对可能出杀者，保守计算其对射程内己方或未知势力角色的最坏伤害，并计可能的连环。失去体力本身不计受伤技能。禁止己方及未知角色濒死，且须有敌方预计濒死或预计人数优势至少两名才花限定技。

| 操作 | 条件 |
| --- | --- |
| 苦肉与诈降 | 自己至少 3 点体力，且实际拥有、能生效的诈降，才主动失去 1 点体力，换取诈降的摸三张与用杀加成。苦肉的可选给牌默认放弃。 |
| 强袭 | 通常只对 1 点体力且无护甲的确定敌人发动。优先支付手里的备用低价武器，缺少备用武器时仅在自己至少 3 点体力时用体力支付。诈降可生效且自己至少 3 点体力时改用体力支付，也允许对其他确定敌人发动。 |
| 敏思 | 正常发动及追德给出的额外发动均从引擎允许的牌中找点数正好为 13 的组合。每张须至多 3 分，组合按每张 `4 − 留牌分数` 的合计排序。逐张选牌时再检查实际合法性和最后一张杀、闪的保留价值。 |
| 雄异 | 至少有两名其他确定队友时使用。仅有一名确定队友时，自己只有 1 点体力才消耗这次机会。 |
| 克清、祸水 | 克清只标记横置的确定敌人，综合手牌数和进攻倾向。维持仍在生效的标记，直到有进攻倾向更高且手牌与局势综合分更高的目标。祸水只为有牌的确定敌人支付至多 2 分的合法黑牌。 |
| 结姻、直谏与枭姬 | 结姻选择体力不等且较低者受伤的确定队友，优先从手牌置入装备，其次支付至多 2 分的弃牌费用，比较枭姬对装备成本的补偿。直谏给确定队友装备空栏。通常从手牌供装，仅在枭姬可生效且同武器栏仍有另一件武器时允许移动已装备武器。 |
| 英魂 | 已损失至少 2 点体力才发动。优先让手牌少的队友多摸后弃一张。没有合适队友时，选择拥有至少 X−1 张手牌及装备的确定敌人，令其摸一张并弃 X 张。 |
| 骁果、悲歌 | 骁果对确定敌人仅付一张至多 2 分的合法基本牌。悲歌只在受伤者为己方、伤害来源为正面朝上的确定敌人时付一张至多 2 分的牌。 |

## 转化、改判与改变目标

| 操作 | 条件 |
| --- | --- |
| 武圣、龙胆、奇袭、断粮 | 奇袭变过河拆桥在破坏档，武圣或龙胆变杀在伤害档，断粮变兵粮寸断在延时档。断粮材料至多 2 分，变【杀】的材料按半点预计伤害核定。奇袭按目标牌收益动态核定材料上限。额外用杀询问也先尝试实体杀。目标沿用实体牌的合法性、敌友及伤害安全判断。 |

| 西园军 | 只在确定队友的出牌阶段，且其攻击范围内有合法的确定敌人时发动。优先选低体力，拆其手牌时请求引擎随机选一张。 |

## 势力倾向与人类目标优先级

- 每次机器人请求按当前在场角色重算。单人战力为 `4 + 0.5 ×（有效体力 + 手牌数 + 装备数）`。有效体力是非负体力加护甲，三项分别封顶为 6、5、4。己方只合计自己和确定队友，敌方按公开势力合计。身份未明者、死亡者和已移出者不计入，手牌只统计数量。
- 确定队友的倾向为 `+1`，未知关系为 `0`，确定敌人的基准为 `−0.4`。场上至少有两个敌对势力，且最大敌方战力领先己方和次大敌方超过 2 分时，才引入制衡压力。压力是 `（领先分 − 2）÷ 8`，上限为 1。按敌方战力在最小与最大之间的比例 `r`，给敌人基准倾向加上 `压力 ×（0.8 − 1.4 × r）`。强势方更值得攻击，弱势方最高为 `+0.4`，可成为暂时合作对象。势力此消彼长时重新计算。
- 进攻目标在原局部评分上加 `−8 ×（当前倾向 − 敌人基准倾向）`。人类敌人再加 0.1 分，原有辅助类合法候选中的人类队友加 0.15 分。玩家托管后仍算人类席位。外交评分和人类微调都用于排序。只有一个合法目标时，原有发动条件继续起作用。
- 通用排序覆盖伤害、拆取、控制牌、额外用杀、转化、借刀两步选人、应变增减目标及场上移牌。其他可交互目标包括突阵、雷击、求援、死谏、西园军、流离、突袭、腹心死士、青州精锐、三尖两刃刀、强袭、克清、祸水、英魂的敌方分支，以及藏机在同批阻止不同弃牌者时的取舍。辅助评分通过共用选人入口，也用于真正己方的补牌、回复、解连环、移牌和保护选择。
- 临时合作影响远交近攻、合纵、交互目标排序和具体助战。是否救桃、是否保护己方、是否提供同势力效果、连环伤害的敌我分类，继续使用真实敌友及各自的合法性条件。远交近攻和合纵仍按牌面检查势力。暂时合作者仍可成为进攻候选。

## 连环伤害取舍

- 按本次属性、初始目标和仍在场的横置角色估算。初始目标与传导目标都计入，已是传导的伤害不会再扩散。估算计入护甲、酒、裸衣、本次用牌的额外伤害、藤甲加火伤，以及可见的属性免伤。起点实际伤害提高时，将提高后的数值用于预测传导。
- 已知敌人严格多于己方和关系不明者的合计，且自己、队友与关系不明者都不会因这次伤害进入濒死时，再比较总分。群攻沿用相同门槛。各目标适用共同的伤害、濒死和回复分数。已知敌人的代价为正，己方与未知势力代价为负。己方受伤技能抵消部分代价，敌方或未知势力技能收益扣分。总分严格大于零才执行。预估也计已建立的连计加伤、构难的普通杀加伤和缘江烽火图的待生效减伤。
- 主动攻击仍将确定敌人作为直接目标。应变和助战按实际属性与加伤重新估算。为临时盟友助战时，将双方的实际队友都计入保护范围。
- 实际杀请求闪、南蛮入侵请求杀、万箭齐发请求闪及水淹七军的装备选择都使用同一份估算。伤害引发有利传导且自己安全时保留牌或装备。对原锦囊效果查询无懈可击时，也可以基于当前目标是自己且值得承伤而保留牌。后续的反无懈请求沿用原策略。
- 鹰视和鬼道将闪电命中与未命中的结果比较。队友会承受非致命雷伤且整条连环有利时，可保留命中判定。将危及队友时争取改成不命中。

## 受伤技能与主动承伤

| 技能 | 计分条件 |
| --- | --- |
| 奸雄 | 能实际发动且手牌区可用时计 3 分，对应稳定摸一张。后续换牌单独结算。 |
| 节命 | 每点伤害分配给一个尚有缺口的同方角色，按补牌缺口从大到小，每张计 2 分。实际选人共用缺口计算。 |
| 安境 | 本回合尚未发动，按牌面确认的同势力角色中每个能摸牌者计 2 分。 |
| 狼顾 | 伤害来源是确定敌人，且还有牌可取时计 4 分。 |
| 刚烈 | 来源是确定敌人时按有无可弃牌计 3 或 1.5 分。 |
| 忘隙 | 来源是其他确定队友，双方都能摸牌时计 4 分。 |
| 放逐 | 有能翻回的确定队友，或有牌少的平置确定敌人可供叠置时计 3 分。 |

使用可生效的技能、公开角色状态、实际伤害来源和手牌数量。南蛮入侵按祸首记录的来源判断。每名角色的预计收益最多 10 分，预计濒死时不依赖获救后发动，纯失去体力时无受伤技能收益。护心镜、天香等需要后续支付并实际防止伤害的效果保持保守，未确定的防止与救桃不会解除安全限制。

无传导时，主动承伤只接受至多损失 1 点体力且安全的真实伤害。代价按共用伤害估值计算，预计剩 2 或 1 点体力再加 2 或 4 分。实际可用的实体【桃】每张减 1 分，至多减 2 分。剩 1 点体力时至少需要一张可用【桃】。至少一项可预期的受伤技能收益，加上防御费用的四分之三（最多 6 分），须达到代价。使用或打出牌按实际实体或转化材料计，水淹七军按弃掉全部装备的净损失计，并扣减枭姬按实际失去件数的摸牌估值。若没有可合法应对的牌，仍由原生规则继续结算。连环会伤害己方且总收益不合格时，个人技能收益不能绕过安全门槛。

## 审查范围

基础覆盖审计通过锁定运行时核对了 118 张武将牌、17 张翼从及扩展通用和卡牌／装备，共 292 个去重入口。变包、权包另按正式登记核对 24 张普通武将牌、两张君主武将牌及三种翼从／偏将。以已有规则和真实请求为依据，先确定收益和代价的发生时机，再判断双方关系、合法候选、资源保留以及其他已生效技能对这次选择的影响。

锁定效果和法定结算由原生规则处理。未定制的技能确认和主动请求可进入 SmartAI 的已有策略，其余按引擎默认结果继续。铁索连环和雷杀另有引擎模拟效果，麒麟弓的通用模拟按弃置坐骑的收益判断。汉晋直接用牌和麒麟弓确认采用上表的策略。曲阿小将的原生确认直接复用重合目标条件。涉及跨回合投机、移除或改变武将牌、隐藏信息和多段费用的策略保守保留，例如勇决、遄征的移将，奋钺的拼点，文虎的整区弃牌，以及闪电的分配。统领能力与翼从分别结算。缺少足够证据时，已接管的可选请求取消，强制请求仍按引擎的合法候选及默认规则继续。策略的取舍阈值是局面判断标准，测试验证具体分支及结算。

可选策略以约 75% 的判断把握为纳入门槛。即时补牌、保护己方或拆取敌方关键牌以本次合法候选衡量。主动与转化在现有牌序中复用同类牌的安全检查。多阶段效果优先接入能单独核对收益和代价的分支。回归统计记录实际执行的用例。

| 千幻、悖弑 | 千幻只储存至多 2 分的牌，只为己方取消有害牌。悖弑比较未能反击时失去 1 点体力的风险，自己体力至少 2、原敌方伤害超过护甲与 1 点体力且费用至多 2 分时才防伤，随后优先向原使用者反击。 |
| 横征、放逐 | 横征须能从每名有牌的角色取得有益目标牌，优先拿走敌方防具或清除己方延时锦囊。放逐优先给已经叠置的队友补牌，其次叠置至多一张手牌或装备的平置确定敌人。 |

| 伤逝 | 优先补牌。无法补牌时，只对确定敌人用一张至多 2 分且经复核可合法转化的牌使用冰杀。 |

## 单次决策超时

汉晋机器人与托管每次计算回包有独立的 10 秒预算。预算从进入机器人策略起算，与房间设置和等待真人回复的时间无关。扩展对当前 Lua 决策按指令间隔检查时间。超时会中断策略、清理尚未完成的选择、恢复先前请求上下文并记录警告。出牌阶段按取消处理，可选技能跳过本次询问，必选询问继续采用原生默认结果。

检查依赖 Lua 虚拟机能执行指令钩子。阻塞中的原生调用只能在返回后丢弃逾期回包。若运行时已安装 Lua 无法恢复的原生钩子，扩展保留该钩子并同样丢弃逾期回包。

## 矢包与弩包的策略覆盖

两包共用汉晋机器人的出牌顺序、费用估值和敌友判断。专用策略读取当前技能的结算数据和原生请求给出的合法候选。机器人只根据自己的手牌、其他角色的公开手牌数量、场上的牌和公开武将牌做决定。

### 矢包

- **支援与压制。** 〖趋奉〗、〖法恩〗和〖秉壹〗把摸牌收益留给己方。〖秉正〗优先让己方摸牌或让敌方弃牌，并估算手牌数等于体力值时自己的额外摸牌。〖品第〗用低价值牌支付费用，按本回合已消耗的牌类别数估算摸牌或弃牌收益。〖窃听〗先比较摸一张牌和取得敌方可移动装备的收益。〖袭阵〗在能兑现攻击、或能牵制多名敌人时支付费用。被询问的机器人会根据自己的防御需求决定是否接受禁牌。
- **选目标与转化。** 〖唆令〗优先让能攻击敌人的队友接牌，也可以迫使两名敌人消耗资源。〖献州〗在自己需要回复、队友能攻击敌人时才交装备。〖舍宴〗会从有害锦囊的目标中保护己方，或给有利效果和攻击增加合适的目标。〖铁脊〗优先用两张低价值牌攻击两个安全的敌人，也可用于可能令单个敌人濒死或对〖藤甲〗造成额外伤害的情形。〖醇义〗和〖孤忿〗在能兑现攻击或自救时转化出【酒】。〖度断〗在当回合难以利用相关牌名时才考虑换取摸牌。
- **武将牌及君主效果。** 〖径出〗优先找能留下确定队友并触发摸牌的局面。〖转征〗考虑胡奋主副将效果的收益。〖芟敌〗和〖脱先〗只在公开武将牌交换能产生明确收益时接受。强制交换照常从规则允许的组合中选。君刘协用低价值牌发动〖转蓬〗防止敌方伤害，诏书优先收缺失花色，四花色齐时按原规则取得可用势力锦囊。

### 弩包

- **资源与阶段。** 〖拔驾〗优先取得敌方有价值的合法装备。〖替军〗优先移走己方不利的延时锦囊，或把装备放到有收益的己方栏位，再换取一次出牌阶段。〖州忧〗优先把牌交给确定队友，〖厉治〗交出低价值牌。〖积弩〗可保存并实际使用或打出扣置牌，〖天述〗只让己方摸牌。〖殿军〗有可兑现动作时进入额外阶段，转换【杀】时才考虑体力费用和致命收益。〖抗锐〗通常给受伤队友回复。君司马炎会比较〖採幸〗的坐骑收益和出牌机会，持有〖赐〗时可以领取摸牌或保留手牌的收益。涉及从未知备选变更武将牌时，机器人保留该标记。
- **攻击与响应。** 〖迅击〗、〖司镇〗、〖督锐〗从原生候选中选定敌人，〖督锐〗优先兑现加伤。〖誓众〗优先选场上牌数各异的敌人来保留摸牌。〖擐甲〗优先暂时移走敌方防具。〖越险〗优先切断敌方响应，同时考虑对方摸牌的补偿。〖卸尾〗按真实的【杀】、【闪】请求选择低价材料，〖诱阙〗检查己方输掉拼点的弃牌损失以及雷【杀】的传导风险。〖弓骑〗比较扩大距离和拆牌的收益，〖驰援〗优先给能实际获得多张牌的己方角色，〖闪击〗比较支付费用和拆取后的收益。
- **翼从。** 〖宿卫中军〗和〖虎豹骑〗只对合法且值得攻击的确定敌人追击。〖陷阵营〗比较现有伤害与加伤后的结果，优先为新增的濒死机会支付费用。〖解烦卫〗优先救援体力低的队友，或在回复之余复原原生规则允许的技能。共享的〖无当飞军〗只对确定敌人发动，〖青州精锐〗沿用现有策略。〖丹阳青巾〗和无需询问的效果继续由规则自动结算。
