# 当前开发状态

本页集中记录程序实装、验证及待办，不定义游戏规则，也不代表《汉晋规则集》已编纂完成。项目裁定见 [`docs/rules/`](../rules/README.md)，正式规则集编纂见 [`rulebook/`](../../rulebook/README.md)。规则是否已确认、代码是否已实现、自动化及人工验证做到哪里应分别判断。
