## 主创速审：待裁定问题汇总

下列问题集中在版本基准（JSON vs CSV）和关键结算边界；确认后即可与权包一并转入分批实装。

### 一、版本基准总确认（JSON vs CSV 差异）

按项目既有惯例，**拟统一以 [石激桑武将列表.json](../../assets/docs/石激桑武将列表.json) 为正式卡面与版本基准**。以下 7 将存在 JSON 与药枫 CSV 实质差异，请主创确认是否全部采用 JSON 版（或指明例外）：

1. **左慈（QUN009）**：两份资料完全不同——JSON 为单技能【化形】（扣置剩余武将牌「魂」+ 移魂或将副将武将牌额外变更为魂）；CSV 为双技能【汲魂】+【役鬼】。
2. **卞夫人（WEI022）**：两份资料完全不同——JSON 为团队护牌【挽危】+ 轮次技【约俭】（手牌上限=体力上限 + 未弃牌摸 1）；CSV 为自保【挽危】+ 锁定技【约俭】。
3. **伍琼&种辑（HAN023）**：【除奸】延时伤害时机，JSON 为“此阶段结束时”（出牌阶段结束），CSV 为“当前回合结束时”。
4. **灵雎（HAN024）**：【竭缘】弃牌范围，JSON 为“红色牌”（含装备区），CSV 为“红色手牌”。
5. **马谡（SHU022）**：【散谣】目标 JSON 为“体力值或手牌数最大”（CSV 仅体力值最大）；【制蛮】取牌 JSON 为“区域里的一张牌”（CSV 仅“场上”）。
6. **李傕（QUN022A）**：【凶算】目标 JSON 限“与你势力相同”（CSV 不限势力）；【挠袭】次数 JSON 为“每回合限一次”（CSV 为“出牌阶段限一次”）。
7. **荀勖（JIN020）**：【应政】触发频率 JSON 为“回合内限一次”（CSV 为“出牌阶段限一次”）。

### 二、关键结算边界确认

1. **左慈【化形】（若采用 JSON 版）**：
   - 「魂」是否仅左慈本人可见、从剩余武将牌堆**不限势力**随机抽取？
   - 选项 2 将副将武将牌额外变更为一张「魂」后，旧副将牌是放回公共武将牌堆/移出本局，还是扣置回「魂」区？变更为异势力「魂」时左慈势力不变、主副将技按副将位生效，请确认。
   - “首次发动时改为三张”按左慈武将牌整局首次计，交换不重置，请确认。
2. **卞夫人【挽危】与【约俭】（若采用 JSON 版）**：
   - 【挽危】面对其他势力一次获得/弃置多张牌时，是否允许用卞夫人 1 张牌整体顶替全部移动的牌？目标为卞夫人自己时能否发动？
   - 【约俭】“手牌上限为 X（体力上限）”是把基础手牌上限设为体力上限（允许消耗阴阳鱼继续 +2），还是绝对锁定为 X？
3. **李傕【凶算】、【挠袭】与【飞熊军】**：
   - 【凶算】对自己发动时，回合结束时是否允许复原【凶算】自身？限定技选择权归李傕？
   - 【挠袭】若场上不存在不与原目标重叠的合法目标，是否禁止发动以防白扣体力上限？
   - 【飞熊军】依次视为使用【顺手牵羊】和【杀】是否均**无视距离**？目标区域无牌时是否跳过【顺手牵羊】直接视为用【杀】？
4. **荀勖【拨律】与【应政】**：
   - 【拨律】修改目标下张应变牌的条件时，若该牌有**多项**应变条件，是全部统一修改还是选改一项？未消耗前再次对其发动【拨律】是否覆盖旧条件？且该标记跨回合保留直到使用下张应变牌？
   - 【应政】与马谡【制蛮】的“变更副将（限一次）”按 FAQ 通则均为**该技能来源全局限一次**，还是每名同势力角色各自限一次？
5. **陈骞【忽辱】与【武督】**：
   - 【忽辱】“同时展示来源和受伤角色各一张手牌”是否由双方各自同步挑选 1 张手牌后同时亮出？自伤时不可发动？
   - 【武督】选项 1 明牌“直到其回合结束”，若目标下回合因叠置跳过，效果是顺延至下个实际结束的回合还是随叠置结束解除？能否指定陈骞自己？
6. **灵雎【焚心】、吕范【调度】/【典财】、伍琼&种辑【心疾】、沙摩柯【蒺藜】、荀攸客将珠联**：
   - 【焚心】是否遵循“每技能限一次变更”还是每次击杀皆可变更？死者副将为多势力或客将时，额外 3 张备选如何检索？
   - 【调度】后半段同势力首次入装备摸牌在吕范明置时是否自动触发？【典财】手牌已达体力上限（0 摸）时能否空发以换取变更副将？
   - 【心疾】体力上限为 1 失救时减上限至 0 直接死亡；减上限后回至 1 血走正式回复事件，请确认。
   - 【蒺藜】使用武器牌本身时按“使用牌时”的当前攻击范围判断（尚未装入该武器），请确认。
   - 荀攸 JSON 的 `zhulian_ke` 登记了 `HAN023`（伍琼&种辑），是否确认其客将势力含汉并构成客将珠联？
