# 不臣篇武将图纸

本篇共 79 张武将牌，按紫乔《汉晋大合集全图鉴》第 14 至 16 期的刊登顺序索引。64 张普通武将、7 张专属野心家、7 张对应效忠版、1 张君主，共 142 项武将牌面技能。每页保留来源原文，另列结算依据和可复现的验收场景。2026-11-28 已确认的五项裁定汇总于文末。

卡面原文取自[石激桑武将列表](../../assets/docs/石激桑武将列表.json)，专栏用于核对版别、卡图、附属技能卡及作者补注。客籍取卡图底栏括号所列势力；本局是否启用按[客将](guest-factions.md)判断。下表的势力栏为原有势力，逐将页另列客籍。

**客籍采用项目既定口径。** 专栏另举孟达为例，称禁魏后可作蜀、群。项目规定只要原有主势力仍有一项可用，就按剩余主势力入池。因此禁魏而蜀仍可用时，孟达只能按蜀入池；魏、蜀均不可用才检查客群。[项目客将规则](guest-factions.md) · [紫乔上篇](https://www.bilibili.com/opus/1182953049838059545)

## 已确认裁定

1. [祖郎（QUN&WU254）](generals/qun-wu254-zulang.md)　〖恃力〗采用卡图“若你没赢”。祖郎拼点平局也暗置，不摸牌。

2. [文钦（WEI&WU080）](generals/wei-wu080-wenqin.md)　〖犷骜〗须以本技能实际追加过目标，才检查偶数手牌、摸牌及令【杀】无效。

3. [刘伶（JIN&QUN080）](generals/jin-qun080-liuling.md)　〖忽忽〗回合末将仍然移出的牌返还刘伶手牌，原装备也返手。

4. [君董卓（EM(QUN006)）](generals/em-qun006-dongzhuo.md)　普通董卓配吕布，从 4 上限升变为君董卓时上限变为 5，按升变通则回复 1 点体力；此组合不发双 2.5 的阴阳鱼。

5. [刘焉（AM(QUN&HAN068)）](generals/am-qun-han068-liuyan.md)　〖图射〗在本次用牌的第一次“指定目标后”检查一次。第三张牌指定三人，发动共摸 3 张。
