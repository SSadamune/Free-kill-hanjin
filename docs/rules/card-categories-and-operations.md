# 卡牌分类、泛转化、合纵、变更与武将牌堆

本文汇总[规则向 FAQ](../../assets/docs/规则向FAQ文件.md) 中开发技能与卡牌时高频引用的公共口径，集中作为 `docs/rules/` 的统一查阅依据，避免各逐将文档重复定义或各自猜测。

## 1. 单目标牌清单

依据[FAQ：单目标牌](../../assets/docs/规则向FAQ文件.md#单目标牌)：

- **定义**：仅包含牌面目标条件为“对一名……角色使用”或“对你使用”的基本牌与普通锦囊牌。
- **基本牌（3 种）**：【杀】（含所有属性杀）、【桃】、【酒】。
- **锦囊牌（12 种）**：【过河拆桥】、【顺手牵羊】、【借刀杀人】、【决斗】、【火攻】、【知己知彼】、【远交近攻】、【逐近弃远】、【水淹七军】、【出其不意】、【洞烛先机】、【挟天子以令诸侯】。
- **明确排除**：【铁索连环】、【调虎离山】即使使用时只选择了 1 名目标，也属于**多目标牌**，不是单目标牌。

## 2. 伤害牌清单

依据[FAQ：伤害牌](../../assets/docs/规则向FAQ文件.md#伤害牌)：

- **定义**：仅包含角色能以此牌本身为渠道造成伤害的**基本牌**和**普通锦囊牌**。
- **具体清单（8 种）**：【杀】（含普通/火/雷/冰杀）、【决斗】、【火攻】、【万箭齐发】、【南蛮入侵】、【火烧连营】、【水淹七军】、【出其不意】。
- **明确排除**：延时锦囊（如【闪电】）及装备牌（如【三尖两刃刀】、【朱雀羽扇】等）均不属于伤害牌。

> 注：原始 FAQ 文本中【火烧连营】重复出现两次，去重后共计 8 种。

## 3. 视为使用与泛转化列表

依据[FAQ：视为使用](../../assets/docs/规则向FAQ文件.md#视为使用)与[泛转化列表](../../assets/docs/规则向FAQ文件.md#泛转化列表)：

- **视为使用限制**：延时锦囊牌与装备牌默认**无法被视为使用**（除非技能有明确例外）。
- **泛转化可选范围**：如【奇策】、【蛊惑】等泛转化效果，如无特别说明，**默认只能转化本局初始牌堆中存在的牌名**。
  - **不包含**：【无中生有】（汉晋正式牌堆替换为【洞烛先机】）、七张游戏外势力锦囊（不在初始牌堆内）。
  - **包含**：各种属性【杀】（火杀、雷杀、冰杀）以及国【无懈可击】。
- 汉晋正式牌堆完整牌位见[基础牌表](card-deck.md)。

## 4. 游戏外的牌

依据[FAQ：游戏外的牌](../../assets/docs/规则向FAQ文件.md#游戏外的牌)与[势力禁选](faction-ban.md#5-ban-004君主装备与势力锦囊)：

- 游戏开始时处于“游戏外”的实体牌主要包括两类：
  1. 因本局禁选势力而未加入牌堆的君主装备牌或普通替换装备牌；
  2. 七张势力锦囊（见[基础牌表第 5 节](card-deck.md#5-势力锦囊仅通过特殊手段加入)）。
- **弃牌改移出**：上述游戏外的牌通过特殊手段进入游戏后，**当其置入弃牌堆时，改为移出游戏**（重新回到游戏外区域，不留在弃牌堆中供打捞或重洗）。

## 5. 【杀】的无视次数合并规则

依据[FAQ：【杀】不计入次数限制/无次数限制/无视次数](../../assets/docs/规则向FAQ文件.md#杀不计入次数限制无次数限制无视次数)与[通用约定](general-principles.md)：

- **合并口径**：除持续状态类效果（如【咆哮】、【诸葛连弩】等赋予无限出杀次数的状态）之外，技能描述中写明【杀】“不计入次数限制”或“无次数限制”的，**均合并视为“无视次数”**（既不受当前已用次数限制，也不计入通常出杀次数）。
- **非空闲点默认无视**：在出牌阶段**非空闲时间点**（例如执行其他技能或卡牌效果时插入）使用的【杀】，默认无视通常出杀次数限制且不计入次数。

## 6. 合纵

依据[FAQ：合纵](../../assets/docs/规则向FAQ文件.md#合纵)：

- 采用**只能合纵手牌**的版本（除非具体装备牌如【神授思召】有明文允许从装备区合纵，见[基础牌表](card-deck.md)）。
- **结算流程**：出牌阶段限一次，你可以将至多 3 张带有「合纵」标记的手牌展示并交给一名**与你势力不同或未确定势力**的角色；若该角色**已确定势力**，你摸等量的牌。
- 势力关系判定遵循[通用约定](general-principles.md)（未确定势力者不视作已确定势力，可接收合纵牌但不触发摸牌）。

## 7. 变更武将、主副将技与武将牌堆

### 变更武将

依据[FAQ：变更武将](../../assets/docs/规则向FAQ文件.md#变更武将)及[位置与牌类别](general-principles.md#武将位置武将牌与士兵牌)：

- 变更对象可为主将位，也可为副将位；位置操作“变更主将/副将/武将”允许操作士兵牌，而“将武将牌变更为……”须实际存在武将牌，君主武将牌不可变更。
- **手杀结算流程**：
  1. 从当前武将牌堆检索 **3 张与你势力相同的武将**（若是天然野心家，改为检索其**原本脱离势力**的武将；若是专属野心家，改为从武将牌堆随机抽取 **3 张武将**）；
  2. 从中选择 1 张作为新武将，以**明置状态**加入游戏，替换原位置；
  3. 变更**不触发**「移除武将牌后」与「明置武将牌后」时机；
  4. 暗置状态的武将牌被变更时，**无须亮出验明**；
  5. 如无特别说明，每个包含变更效果的技能**每局默认只能发起一次变更**。

### 主将技 / 副将技

依据[FAQ：主将技/副将技](../../assets/docs/规则向FAQ文件.md#主将技副将技)：

- 主将技/副将技算作**身处主将/副将位置时才拥有的技能**；位于另一位置时不计为拥有该技能。
- **示例**：副将邓艾因主将步骘/步阐等效果选择失去一个技能时，不能选择失去主将技【急袭】；计算副将邓艾的技能数时不计入【急袭】。

### 技能调用的武将牌堆

依据[FAQ：武将牌堆](../../assets/docs/规则向FAQ文件.md#武将牌堆)：

- 技能效果（如变更武将、亮出/检索武将牌堆等）调用的武将牌堆，默认**不包含**：
  1. 本局没有可选势力的武将（已被禁选排除）；
  2. 隐士武将（`YS` 系列）；
  3. 野心家专属武将（`AM` 系列）。

## 8. 待主创确认项（审阅清单）

1. **变更武将的“每技能限一次”与多来源关系**：若角色通过不同武将牌或不同来源分别获得同一变更技能，或通过交换武将取得未用过变更的武将牌，该“每技能限一次”是否按具体武将牌/技能来源分别记录（同[交换武将](general-exchange.md#哪些状态随牌移动)口径）？
2. **专属野心家“变更武将”的对象**：专属野心家本身不可被变更，但若其变更**副将**时，按第 7 节“专属野心家改为随机三个武将”执行；若其副将已有明确普通势力，变更副将时是按“专属野心家（随机 3 将）”还是按“副将原势力”检索？
3. **泛转化列表与禁选势力 / 特殊单目标牌**：若某局因禁选移除了某些君主装备或普通牌，泛转化列表仍只按**基础牌名集合**判断（不受个案牌被摸光影响）；另，【洞烛先机】与【逐近弃远】等汉晋正式牌堆中的牌均在默认泛转化列表内，而【无中生有】不在——此口径是否确认用于后续所有泛转化技能？
4. **【铁索连环】、【调虎离山】与【火烧连营】在伤害牌/单目标牌的边界**：按 FAQ 已明确【铁索连环】和【调虎离山】不为单目标牌，【火烧连营】属伤害牌。对于后续七张**势力锦囊**（如【克复中原】【号令天下】等），是否均按“游戏外牌”规则不进入泛转化，但若已实际使用，是否分别按其牌面是否造成伤害/是否单目标参与技能判定？
