# 国战平行时空：基础牌表

规则裁定：用户已确认实体牌位、替换关系、合纵标记、君主装备所属势力及全部 16 组应变效果。牌表和版本登记本身不表示已实装。

## 1. 读取约定（MUST）

- 仅适用于独立模式 `qiao_heg_mode`；正式卡牌 MUST 独立创建，不得直接导入上游牌堆或用测试内容补齐。
- 第 2 节四张矩阵中，每个非空的花色单元格对应一个基础牌位，唯一键为 `分区/花色/点数`。同名、同花色、同点数但分区不同的牌仍是不同实体牌。
- A/J/Q/K 对应 1/11/12/13；♠/♥/♣/♦ 对应黑桃/红桃/梅花/方块。
- 标准版一、标准版二、势备篇各 52 个牌位，EX 为 6 个牌位，合计 **162 个基础牌位**。EX MUST 纳入基础牌表，不是房主可选扩充包。
- 162 是本表在势力筛选前的牌位数。赤霄剑、虚妄之冕的牌位可因所属势力不在允许集而空缺；有替换牌的牌位仍各占一张。
- 第 5 节的七张势力锦囊均在 162 个基础牌位之外，默认牌堆不加入。
- `特殊装备（替换牌）` 表示依势力规则择一占据同一牌位，MUST NOT 同时加入两张；保留该牌位花色、点数。`（无）` 表示移除时不补牌。
- `·合` 为合纵标记，不是应变条件，也不是额外牌名。`太平要术（惊帆·合）` 中只有替换后的惊帆具有合纵标记。
- `无懈可击·国` 表示国战版本，MUST 与未标 `·国` 的无懈可击区分，不解释为应变或合纵标记。
- `·富甲/残躯/助战/空巢/孤军` 为应变条件；全部对应效果及 UI 文本见第 4 节，不得从上游覆盖或推定不同效果。
- 应变效果按“牌名＋应变条件”复用；同一组合的不同实体牌效果一致。仅在此分组规则中，普通杀、火杀、雷杀、冰杀 MUST 视为不同牌名，不能按引擎 `trueName == slash` 合并。
- 未标应变条件的同名实体牌不自动继承其他实体牌的应变条目；应变 API 及条件时点遵循 [应变规范](adaptation.md)。

### 结算说明（MUST）

- 应变条件满足后，非增减目标的效果强制触发并执行，不再询问是否发动。`目标+1`、`目标-1` 为例外，使用者可以选择是否增减一个合法目标；取消或未实际改变目标不计为触发应变。
- 第 1 组【水淹七军】：先执行弃置装备牌的效果，再执行造成雷电伤害的效果，不能由目标改为二选一或颠倒顺序。
- 第 6 组【逐近弃远】：先拆（弃置目标一张牌），后顺（获得目标一张牌），强制依次执行两项，不再依据距离二选一。例：距离 1、目标只有一张牌，助战成功后 MUST 先弃置该牌；目标因此无牌，后续无法获得牌，不得改为先获得或跳过弃置。
- 第 12 组【闪】：获得的是这张闪所响应的牌，不是闪自身。应变在使用牌时触发；单纯“打出闪”不触发。作为响应而实际“使用闪”时仍按使用牌处理。
- 第 13 组【雷杀】：完整含义为“此牌无视次数，不计入使用次数”，UI 仅显示 `无视次数`。
- 第 15 组【借刀杀人】：所有角色均不能以【无懈可击】响应此牌；目标角色不能使用【杀】响应其效果。MUST 同时覆盖这两个响应层次，不能只禁止其中一个。
- 其他组的 UI 文本也 MUST 保持表内原文；完整语义与程序效果标识不得代替 UI 文本。`摸一张牌` 表示使用者摸一张牌，`伤害+1` 表示此牌造成的伤害增加 1。

禁止把条件名当作效果。正式应变牌 MUST 同时登记条件与效果。此清单中的无懈可击均未标 `·国`，不能与其他四张国战无懈可击混淆。

### 君主装备的结算

#### 飞龙夺凤

♠2，武器，攻击范围 2。使用【杀】每指定一个目标后，装备者可以令该目标弃置一张自己的牌，由目标从合法的手牌和装备中选择。本次【杀】造成的伤害令其实际目标进入濒死时，装备者可以在求桃前获得该目标的一张手牌。两次发动分别选择。濒死段须同时核对本次用牌的伤害来源、渠道和实际目标。连环或转移波及的非目标不会因此触发。君刘备的实体牌移动交互见[天钺](generals/em-shu001-liubei.md#天钺)。基础时机见[指定目标后](../../rulebook/events/use-card.md#连续若干个指定目标后)与[濒死事件](../../rulebook/events/dying.md)。

#### 六龙骖驾

♥K，一张同时占用进攻与防御坐骑栏的装备。锁定技，其他角色到装备者的距离 +X，装备者到其他角色的距离 −X。X 为当前场上与装备者势力相同的角色装备区里的坐骑牌总张数，每张牌计一次，双副类别坐骑也只计一张。按[同势力通用裁定](general-principles.md#汉晋项目通用约定)，装备者始终计入。其全暗且势力尚未确定时，只计自己的六龙骖驾，X = 1。装备者与其同势力角色的坐骑进出、势力变化、死亡或移出游戏后按现状计算。两栏的直接置入要求见[总御](generals/em-wei001-caocao.md#总御)与[装备移动、置入规则](equipment-movement.md)。

#### 定澜夜明珠

♦6，宝物。出牌阶段内的空闲时间点限一次，装备者可弃置 1 至当前体力上限张自己的合法手牌或装备，然后按实际弃置张数摸牌。提供本技能的夜明珠本身不能用于该次弃置。装备技能与武将的制衡各自计次，弃置张数上限仍为体力上限，弃光手牌仍摸等量。聚宝对宝物的移动保护和结束阶段效果见[聚宝](generals/em-wu001-sunquan.md#聚宝)。基础条文见[至多](../../rulebook/terms/value-terms/atMost.md)、[弃置](../../rulebook/terms/card-op-terms/discard.md)及[装备牌](../../rulebook/terms/card-terms/Equip.md)。

#### 太平要术

♥3，防具。防止装备者受到的属性伤害。手牌上限按当前同势力角色数增加，包含装备者自己，适用同势力通则及已确认的群势力天兵人数修正。装备者失去装备区内的此牌后先摸两张，再以摸牌结算后的状态检查体力值是否大于 1，满足则失去 1 点体力。君张角可用【太平要术】自身作为问道的红色弃牌，从弃牌堆获得这张牌。若从装备区支付，还会进入失去防具的结算。参见[问道](generals/em-qun010-zhangjiao.md#问道)、[天兵人数修正](generals/em-qun010-zhangjiao.md#弘法)和[手牌上限](../../rulebook/terms/value-terms/handMax.md)。

#### 赤霄剑

♥9，武器，攻击范围 3。使用【杀】每指定一个目标后，按当时的[大势力](../../rulebook/terms/description-terms/dashili.md)与[小势力](../../rulebook/terms/description-terms/xiaoshili.md)类别判断。一个为大、另一个为小时，该目标须交给用牌者一张红色手牌。未能交出时，该目标不能抵消此次【杀】对自己的结算。其他目标各自结算，已存在的令牌无效等机制仍依各自规则。卡面用语为“其不能抵消此【杀】”。它限定该目标的抵消行为。相关实体牌移动见[天授](generals/em-han001-liuxie.md#天授)。

#### 临筱玉舆

♠5，双副类别坐骑。装备者到其他角色距离 −1，其他角色到装备者距离 +1。此牌进入装备区，或由装备区进入非装备区后，由当前回合角色受益。直接从甲装备区移到乙装备区只满足进入。若同次进出有坐骑因装备栏占用被实际替换，效果改为回复 1 点体力。满体力时仍走回复分支。无关联的坐骑移动不计为替换。由普通坐骑替换临筱玉舆时，临筱玉舆自身就是被替换的坐骑。参见[双副类别坐骑](equipment-movement.md#双副类别坐骑)与[採幸](generals/em-jin001-simayan.md#採幸)。

#### 四海流钱

♠4，宝物。出牌阶段内的空闲时间点，选择从自己到其距离终值大于 1 的一名角色，预先选择该角色恰好两张可以获得的牌，范围是手牌和装备区。将自己装备区的四海流钱交到该角色的手牌区，并获得先前选定的两张牌。两个转移同属一次交换，按[“并”](../../rulebook/terms/description-terms/and.md)处理。目标只有一张可获得的牌时无法发动。卡面没有另定限次，发动本身会使装备者失去提供该技能的宝物。参见[距离终值](../../rulebook/terms/value-terms/distance.md)与[某人的牌](../../rulebook/terms/description-terms/limit_card.md)。

#### 州郡领兵印

♠2，宝物。进入装备区后，按当前势力大小类别逐个询问符合同一类别且能交牌的角色，每人可交一张自己的手牌或装备给装备者。装备者不能将自己的牌交给自己。全场没有大势力时，也没有小势力，无法判定类别相同，此效果不可发动。

准备阶段可令本回合的额定摸牌数、使用【杀】次数上限、手牌上限三项中的一项增加 1 或 2，并将等量扣减分配到另外两项。每项须按选择时的数值足额扣减。例如【杀】次数上限为 1 时，该项最多承担 1 点扣减。三个修正从同一次选择建立，有效期为本回合。用【杀】的上限修正适用于本回合每个出牌阶段内的空闲用牌次数。参见[额定摸牌数](../../rulebook/terms/value-terms/drawCount.md)、[用牌次数](../../rulebook/topics/card-usable-conditions.md)及[手牌上限](../../rulebook/terms/value-terms/handMax.md)。

#### 锦绣征袍

♠2，防具。成为其他角色使用伤害牌的目标后，来牌在本次使用中须具有四种标准花色之一，且装备者的手牌中没有该花色。无花色的来牌即使有实体材料，也不满足花色条件。例如，两张红桃转化出的红色【杀】仍无花色，不能触发锦绣征袍。展示手牌是技能的第一个动作，装备者没有手牌时不能发动。选择发动后，展示手牌并获得本次来牌对应、仍可获得的实体牌。取得材料后再检查装备者的当前手牌是否有四种标准花色，齐备时仅令该牌对装备者无效。无实体材料的来牌无法执行获得。取得实体材料本身只切断对应关系，用牌流程仍继续。伤害牌采用汉晋 FAQ 的[伤害牌范围](../../assets/docs/规则向FAQ文件.md#伤害牌)，【闪电】和伤害装备排除。参见[展示](../../rulebook/terms/card-op-terms/showCards.md)与[用牌实体牌的移动](../../rulebook/events/move-card.md#移至目标区域前2)。

#### 飞云盖海

♦K，双副类别坐骑。装备者未横置时，装备者到其他角色的距离 −2。装备者横置时，改为其他角色到装备者的距离 +2。横置、重置即时改变适用的方向和数值。正常使用和技能直接置入适用[双副类别坐骑规则](equipment-movement.md#双副类别坐骑)。若君孙策破浪将它直接置入其他角色装备区，接收者的两栏均须空置且可用。

#### 神授思召

♠5，武器，攻击范围 2，实体牌有合纵标记。按此牌当前这次进入装备区的回合判断。该回合中仍装备此牌时，装备者使用牌无距离限制，到其应进入弃牌阶段时跳过该阶段。之后的回合可从装备区合纵这张牌，作为[一般合纵只选手牌](../../assets/docs/规则向FAQ文件.md#合纵)的明文例外。仍走一般合纵入口，沿用其出牌阶段限一次、合计至多三张、展示交给合规接收者及按接收者是否已确定势力摸牌的规则。同一回合重新置入时按最新一次置入判断。失去装备后，尚未执行的装备状态效果随之解除。

#### 驺虞幡

♣A，防具。回合外每回合限一次，在真实的需要使用或打出【杀】或【闪】的流程里，可按请求类型视为使用或打出所需牌。该动作实际发生后，为发动者建立本回合下一次受到伤害后的延时效果。被防止的伤害不消耗它。触发后先失去 1 点体力，再弃置自己装备区里的原实体驺虞幡。依据[延时类效果](../../rulebook/topics/skill-effect-classification.md)，先失去防具也仍会执行失去体力。仅当原牌仍在本人装备区且可弃置时才执行最后的弃牌。若此前无下一次伤害，回合结束后该延时效果到期。

#### 虚妄之冕

♣4，宝物。装备者在自己的摸牌阶段多摸两张牌，手牌上限 −1。前者修正的是摸牌阶段的额定摸牌数，后者随装备状态即时生效，最终上限按通则最低为 0。魏或晋至少一个获准加入本局时保留该牌。参见[额定摸牌数](../../rulebook/terms/value-terms/drawCount.md)及[手牌上限](../../rulebook/terms/value-terms/handMax.md)。

#### 血海魔王樽

♣2，宝物。装备者有合法用【酒】需求时可发动，按通用座次依次向同势力角色发出打出黑桃牌的选择，装备者也在候选中。协助者实际打出一张自己的黑桃牌，随后由装备者视为使用【酒】，沿用原需求的使用及合法性检查。第一次协助成功令装备者使用【酒】后，本次需求已满足，立即停止询问。各方均未协助时，保留原用酒流程中本来可用的其他选项。协助使用的是[打出流程](../../rulebook/events/drop-card.md)。

装备者脱离濒死时，将装备区里的此牌交给导致本次濒死的[伤害来源](../../rulebook/terms/description-terms/source.md)。无伤害来源、来源已死亡、来源为自己或原宝物已经离开装备区时，交牌无法执行。装备未发动过前段也可触发后段。
