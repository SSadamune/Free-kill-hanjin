# 装备移动与置入的默认含义

规则裁定：用户已确认的汉晋专属用词约定。它补充当前规则集底稿；尚未直接改写 `rulebook/` 的基础条文。

## 默认目标区域与空栏要求

- “移动装备区里的牌”“将装备牌置于（某角色的）装备区”，默认是将该装备牌移动到目标角色**空置的对应装备栏**。
- 易读描述中，主动“将装备牌置入装备区”默认允许替换冲突的原装备。对应栏位仍须存在且可用。
- “当一张牌置入装备区后”等表述限定移动事件的目标区域和触发时点。此类表述本身不规定该移动能否替换装备。[汉晋 FAQ](../../assets/docs/规则向FAQ文件.md#置入置于装备区)
- “将其装备区的一张牌移动给你”适用同一默认含义：从该角色的装备区移入你的对应空装备栏，不是获得到手牌区。
- “移动”或“置于”遇到对应栏已占用时，不能借该操作替换或弃置原装备。栏位不存在、已废除或另有禁止移动的效果时，按其实际限制处理。
- 效果有明确的特殊说明时依其说明。本约定不把“使用一张装备牌”改写成移动装备，也不改变正常使用装备牌时的替换流程。

移动按正常牌移动流程处理原持有者失去装备、目标装备生效及相关触发；并非使用该装备牌。通用移动流程见[移动事件](../../rulebook/events/move-card.md)。具体技能见[JIN001 司马炎](generals/jin001-simayan.md)。

## 双副类别坐骑

依据汉晋 FAQ 的[双副类别装备牌](../../assets/docs/规则向FAQ文件.md#双副类别装备牌)，六龙骖驾、临筱玉舆和飞云盖海各以一张实体牌同时占用进攻和防御坐骑栏。使用或主动置入双栏坐骑时，两栏原先各有一张则两张均被替换。允许替换的单栏坐骑也可替换占据该栏的双栏坐骑，原双栏坐骑只移动一次，另一栏随之腾空。置于或普通移动双栏坐骑须两个对应空栏都可用。普通装备的使用时机及栏位条件见[装备牌](../../rulebook/terms/card-terms/Equip.md)。
