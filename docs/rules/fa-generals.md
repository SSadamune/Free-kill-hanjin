# 发包 · 十三张武将牌开发稿

共 13 张：六势力各一张普通武将、一张常规君主，另有一张魏／晋司马懿均可升变的野君。两版司马衷分别登记；两种普通司马懿通往同一张野君。31 项武将技能逐项抄录本地表的原文；七面大旗另对专栏逐条补全，七件专装链接到项目既有裁定。每页都有结算顺序和将来实装时可使用的验收场景。

## 版本与公用规则

- 武将技能以[石激桑武将列表](../../assets/docs/石激桑武将列表.json)发包记录为底本。以[紫乔发包总专栏与简略 FAQ](https://www.bilibili.com/opus/1181833308925853766)补齐大旗和技能卡。旧篇仅补充新版仍适用的例子；如董贵人的摸牌对象、君司马衷大旗保留所取牌的代价，均采用新版。
- 七件专装均已有[项目牌表与装备裁定](card-deck.md)。升变、继位、禁选分别沿用[第二君主](second-lord.md)、[势力禁选](faction-ban.md)；野君【嘉平】另规定的转野去向和君司马衷【历劫】明许的交换仅在相应条款适用。
- 发包未新增统领或翼从。牌的区域、实际同势力、技能消耗参见[通用约定](general-principles.md)；多人拼点按[拼点事件](../../rulebook/events/pindian.md)，交换明置位置按[交换武将](general-exchange.md)，双栏坐骑参见[装备移动](equipment-movement.md)。
