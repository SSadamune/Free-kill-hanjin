## 采用版本与来源差异

[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv)“君·司马炎”有两处实质差异：採幸只取得场上或弃牌堆的临筱玉舆，不能取场上其他坐骑；鼎沸没有“限定技”，顺序为失去太康→获得兴图→摸两张，而 JSON 是限定技且先摸两张。用户确认本将以石激桑 JSON 为基准，采用“採幸”的写法、场上坐骑的检索范围及限定技鼎沸的结算顺序。

## 太康与诸王敕封册

**技能原文**：太康：君主技，你拥有“诸王敕封册”。

**关联旗原文**：当一名角色的武将牌首次均明置后，或被晋势力角色杀死后，你可以将一张符合其副将牌面势力的剩余武将牌置为〖赐〗。

（〖赐〗是一种国战标记：出牌阶段限一次，你可以消耗一枚〖赐〗，然后变更一张与此牌单独阴阳鱼数相同的武将牌（限一次），或根据此牌单独阴阳鱼数执行效果：≤3：本回合手牌上限+3。≥4：摸牌至四张。）

两类事件分别处理：“首次均明置”不等于每次双亮，须区分首次状态与变更／升变入口；死亡分支要求杀死该角色的来源当时为晋势力，不能把所有死亡都当作晋杀死。后者读取死者副将的实际牌面资料，不用死者角色当前势力替代；其副将是士兵时不能凭空按某张普通将牌查资料。

剩余牌必须来自实际可用武将牌堆，不能占用在场或已发给别人的将牌，也不能取禁用势力或君主牌。牌面势力条件不能简单等同于角色当前势力。将牌转为“赐”后须从剩余池占用，不能仍让其被普通变更抽到。

2026-11-20 项目裁定：持旗者确认发动后，由系统从当前符合副将牌面势力与入池条件的武将牌中随机抽取一张置为“赐”。首次双亮与晋角色击杀均适用；无合格牌时不获得“赐”。

“赐”的效果比较牌面单独阴阳鱼数，不比较受益者当前体力，也不是消耗普通阴阳鱼标记。手牌上限加3仅本回合；摸牌至四张是补至四张，不是摸四张，已有四张以上不弃牌。

### “赐”的持有与次数裁定

用户确认：

- 形成的“赐”由**诸王敕封册的拥有者**持有，一般即君司马炎，不交给触发首次双亮或死亡事件的角色。持有关系按旗的实际拥有者判断，不硬编码为某个角色 ID。
- 变更分支的“限一次”为**每名角色整局限一次**，执行该分支同时消耗一枚“赐”。取得新“赐”或换回合不刷新已经用掉的整局变更次数。
- 此整局限制只约束变更分支，不把另一项手牌上限／补牌效果改成整局限一次；两类消费仍受原文“出牌阶段限一次”约束，并各自实际消耗“赐”。

候选仍须按原文“符合其副将牌面势力”及[客将](../guest-factions.md)／[牌类别](../general-principles.md#武将位置武将牌与士兵牌)核对；本次持有与次数裁定不取消候选条件，也不自动把“赐”对应的牌直接安装为新武将。

持有者在「赐」面板中单选一张将牌，选牌不打开技能详情。符合消费时机并选中将牌后可点击「消耗一枚赐」，随后在两个普通效果按钮中选择。变更分支不满足条件时按钮置灰。[#25 补充说明](https://github.com/SSadamune/Free-kill-hanjin/issues/25#issuecomment-7033006459)

## 採幸

**技能原文**：採幸：你可以跳过出牌阶段，然后将场上一张坐骑牌或弃牌堆的【临筱玉舆】置入装备区。

于出牌阶段开始前处理跳过；已经因其他效果跳过该阶段，不能再作为本次支付。后续检索场上可移到自己装备区的坐骑牌及弃牌堆中的临筱玉舆。主动置入允许替换原坐骑，双栏坐骑仍要求两类栏位均可用。没有合适牌时，已支付的阶段跳过仍生效。见[装备置入](../equipment-movement.md)。

## 鼎沸

**技能原文**：鼎沸：限定技，结束阶段，若晋势力角色已损失体力值之和大于其体力值之和，你可以摸两张牌，然后失去“太康”并获得“兴图”。

时机是自己的结束阶段。使用当时晋势力角色的实际体力与已损失体力求和，严格“大于”才满足，不能替换为不小于或比较君司马炎个人数值；移出游戏角色不参加通常的场上对比。按顺序摸两张、失去太康、获得项目同文兴图；不是把手牌补至两张。限定状态与失技状态使用公共来源机制；角色获得兴图不自动附将。

## 临筱玉舆与实现状态

**来源装备原文**：锁定技，此牌置入装备区后，或从装备区置入非装备区后，当前回合角色摸一张牌，若有坐骑被替换，则改为回复1点体力。

装备进出后由当前回合角色受益，不是固定由持有者摸牌／回复。实际替换坐骑时改为回复，不额外再摸一张。需要把同一次进出与对应替换事件关联，避免把无关移动当作替换；非使用置入仍遵守空栏要求。
