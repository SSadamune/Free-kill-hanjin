# HAN&WEI032 卫兹

不臣篇（上） · 普通 · 称号“先赞弘谋”。

势力为汉、魏。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 兴武：限定技，其他角色的准备阶段，你可以交给其所有手牌，然后其于本回合每次造成伤害后，若你的手牌数小于势力数，你摸两张牌。

> 烈节：当你受到伤害后，你可以弃置至多两张牌，摸等量的牌并令来源选择一项：1.你摸X张牌；2.弃置X张牌（X为你弃置的红色牌数）。

## 结算

发动〖兴武〗将所有手牌交给一名其他角色后，持续跟踪该受牌角色在本回合内造成的每一次伤害；每次造成伤害后，都实时比较卫兹当时的手牌数与场上势力数，如果手牌数小于势力数，卫兹便摸两张牌。发动〖烈节〗时，卫兹先弃置至多两张牌并摸等量的牌，再统计此次实际弃置的红色牌张数 X，令伤害来源选择一项：让卫兹再摸 X 张牌，或者由伤害来源自己弃置 X 张牌。

## 验收场景

场上共有三个势力。卫兹将手牌全部交出变为空手后，受牌角色在本回合内连续三次造成伤害，且期间卫兹没有发生其他手牌变动：前两次造成伤害后卫兹的手牌数分别从 0 变为 2、从 2 变为 4，因此各摸了两张牌；到第三次造成伤害时卫兹已有 4 张手牌（不再小于势力数 3），因此不再摸牌。
