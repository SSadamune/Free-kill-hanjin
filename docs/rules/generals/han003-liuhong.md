## 鬻爵

**技能原文（JSON）**：鬻爵：每名角色的出牌阶段开始时，你可以弃置一张牌并对其发起“军令”：若其执行，其本回合下次造成伤害后摸两张牌；若其不执行，你暗置其一张武将牌且其本回合不能明置之（若其已有暗置的武将牌，则改为令其叠置）。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“**其他角色**的出牌阶段开始时，你可以弃置一张牌，对其发起‘军令’：若其执行，其本回合**首次**造成伤害后摸两张牌；若其不执行，你暗置其一张武将牌且其本回合不能明置之（若其有暗置的武将牌，则改为令其叠置）。”

**结算分析**：
- 触发时机为目标角色的出牌阶段开始时；“弃置一张牌”为发动消耗，须实际弃置一张手牌或装备牌，无牌不能发动。
- 发起军令按[军令](../../../rulebook/terms/description-terms/junling.md)结算：刘宏从随机两项军令中选一项，目标选择是否执行；目标选择执行即算执行，不以军令内所有子动作均成功执行为前提。
- 执行分支：建立本回合的持续效果（在目标本回合下一次造成伤害后令其摸两张牌）；目标本回合出牌阶段之前已造成过伤害不影响“下次”计数（若采用 CSV“首次”则受影响）。
- 不执行分支：检查目标当前是否已有暗置的武将牌。若已有（至少一张暗置），改为令其定向叠置（见[通用约定](../general-principles.md#配将体力贡献与武将状态)）；若两张均明置，则由刘宏选择暗置其一张**可被暗置的武将牌**，且该武将牌本回合不能明置。
- 不可暗置边界：君主武将牌、专属野心家武将牌不可被选择暗置，士兵/翼从/偏将不属于武将牌；若目标没有暗置武将牌且场上两位置均无法暗置（如君主 + 士兵），则暗置部分无法执行，但仍属正常进入不执行分支。

**待主创确认**：
1. 触发范围与触发条件以 JSON（“每名角色”即含自己、“下次造成伤害”）还是 CSV（“其他角色”、“首次造成伤害”）为准？按本项目既有惯例拟以 JSON 为准，请确认。
2. 目标选择执行军令后，若该军令本身（如军令 1）造成伤害，该伤害是否立即触发“本回合下次造成伤害后摸两张牌”？（从时序看，军令 1 结算时“若其执行”的后续效果尚未建立，应从军令结算完毕之后开始监视“下次造成伤害”，请确认。）
