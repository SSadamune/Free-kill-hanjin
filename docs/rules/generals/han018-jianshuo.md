# HAN018 蹇硕结算约定

## 集兵

每次发动时分别确定本次多摸的牌数 X。回合结束时，对本回合每一次发动分别比较本回合造成的伤害数与该次的 X。伤害数低于该次的 X 时，执行一次失去 1 点体力。

例如，同一回合两次发动分别多摸四张和三张。如果两次判定时本回合造成的伤害数相同，结果如下。

| 本回合造成的伤害数 | 回合末结算 |
| --- | --- |
| 0 至 2 | 两次均不足，分别失去 1 点体力 |
| 3 | 仅 X 为 4 的那次不足，失去 1 点体力 |
| 4 或更多 | 两次均达到各自的 X |
