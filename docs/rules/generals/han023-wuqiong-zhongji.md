## 除奸

**技能原文（JSON）**：除奸：其他角色的出牌阶段开始时，若其体力值或手牌数最大，你可以令其此阶段对你使用【杀】无距离和次数限制，然后此阶段结束时，你对其造成1点伤害。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 将延时伤害时机写作“若如此做，**当前回合结束时**，你对其造成1点伤害”（JSON 为“此阶段结束时”，即出牌阶段结束时）。

**结算分析（按 JSON 口径）**：
- 触发时机：其他角色的出牌阶段开始时。
- 触发条件：该角色当前体力值为在场角色中最大（允许并列最大），**或**手牌数为在场角色中最大（允许并列最大）。在场角色按 `getPresentPlayers()` 计算（排除被移出游戏角色）。
- 效果一（阶段内持续效果）：本出牌阶段内，该角色对伍琼&种辑使用【杀】无距离限制且无次数限制（按[无视次数合并规则](../card-categories-and-operations.md#5-杀的无视次数合并规则)处理：对其出杀不受通常出杀次数限制且不计入次数；对其他角色出杀不受此豁免）。
- 效果二（延时伤害）：按 JSON 在**此出牌阶段结束时**，由伍琼&种辑对该角色造成 1 点普通伤害（须检查目标与来源在结算时仍存活在场；若该角色在此阶段内被跳过剩余流程或阵亡，则不造成伤害）。该后续效果一旦建立属于已建立的延时效果，不因出牌阶段中伍琼&种辑暗置或失去【除奸】而撤销（若伍琼&种辑已死亡则按角色离场规则终止）。

**待主创确认**：
1. 延时伤害时机采用 JSON（“此阶段结束时”，即出牌阶段结束时）还是 CSV（“当前回合结束时”）？按既有惯例拟采用 JSON，请确认。
2. 当目标角色在此阶段内对伍琼&种辑使用【杀】并同时指定了其他角色为目标（如【方天画戟】/【青龙偃月刀】/额外目标）时，“对你使用【杀】无距离和次数限制”是仅在单一目标为伍琼&种辑时适用，还是只要目标包含伍琼&种辑即放宽（对其他目标仍须满足距离条件）？

## 心疾

**技能原文（JSON / CSV 一致）**：心疾：锁定技，你处于鏖战状态。当你于濒死状态失救时，你减1点体力上限并回复体力至1点。

**结算分析**：
- 锁定技，包含两段独立效果：
  1. **自身处于鏖战状态**：伍琼&种辑明置并拥有【心疾】时，**仅伍琼&种辑本人**处于[鏖战状态](../battle-royal.md)（【桃】只能当【杀】或【闪】使用或打出；不影响场上其他未进入鏖战的角色）。当伍琼&种辑暗置或失去【心疾】且全局尚未进入鏖战时，退出鏖战状态。
  2. **濒死失救自救**：当伍琼&种辑处于濒死状态且全部求桃流程结束仍未能回复至 1 点或以上体力（即即将死亡的“失救时”窗口），改为：减 1 点体力上限，然后将体力回复至 1 点（因此脱离濒死，不进入死亡结算）。
     - **体力上限归零边界**：若触发时伍琼&种辑的当前体力上限仅为 1，执行“减 1 点体力上限”后体力上限变为 0，按基础规则角色体力上限降为 0 时直接死亡，无法再“回复体力至 1 点”。
     - 触发次数：原文无“限定技 / 每回合限一次”限制，只要减完体力上限仍 `>= 1` 即可再次触发。

**待主创确认**：
1. 体力上限为 1 且濒死失救时，减 1 点体力上限至 0 直接死亡（无法回复至 1 点），是否确认？
2. 减 1 点体力上限后“回复体力至 1 点”是否属于正式的**回复体力事件**（可被【无当飞军】防回血、可触发回复体力相关技能）？从“回复体力至 1 点”原文看应走正常回复事件，请确认。
