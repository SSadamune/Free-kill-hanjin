## 竭缘

**技能原文（JSON）**：竭缘：当你对其他角色造成伤害时，或受到其他角色造成的伤害时，若其体力值大于等于你，你可以弃置一张红色牌，然后令此伤害+1或-1。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“弃置一张**红色手牌**”（JSON 为“红色牌”，包含装备区的红色装备牌）。

**结算分析（按 JSON 口径）**：
- 触发时机：灵雎对其他角色造成伤害时（伤害加减时机），或灵雎受到其他角色造成的伤害时。无来源伤害或自残不触发。
- 触发条件：对手（另一方其他角色）当前体力值 `>=` 灵雎当前体力值。
- 发动消耗：弃置一张红色牌（按 JSON 含手牌区与装备区红色牌；须实际弃置，不能零弃牌）。
- 效果结算：由灵雎选择令此次伤害 `+1` 或 `-1`（注意：无论是灵雎造成伤害还是受到伤害，均可以任选 `+1` 或 `-1`；若原伤害为 1 且选择 `-1`，伤害降为 0 则防止此次伤害）。

## 焚心

**技能原文（JSON / CSV 一致）**：焚心：当你杀死角色后，你可以变更副将，此次变更额外获得三张其副将牌面势力的备选武将牌。

**结算分析**：
- 触发时机：灵雎杀死一名角色后（死亡结算第 6 步“死亡后”技能时机，见[死亡结算流程](../turn-death-and-reveal-timing.md#4-死亡结算完整时序)；死亡角色此时已亮出全部暗置武将牌）。
- 发动次数：依据[变更武将通则](../card-categories-and-operations.md#变更武将)，“如无特别说明，每个技能只能发起一次变更”，故【焚心】默认每局最多发起一次变更（除非主创确认允许重复变更）。
- 备选武将池组成：
  1. 常规变更的 3 张同势力备选武将（按灵雎当前势力的变更规则检索）；
  2. **额外 3 张**：按死者**副将牌面势力**从当前[技能可用武将牌堆](../card-categories-and-operations.md#技能调用的武将牌堆)中额外检索 3 张备选武将（两组合并去重，通常最多 6 选 1，牌堆不足则取实际可得数量）。
- **特殊副将边界**：
  - 若死者副将位置为**普通士兵、翼从或偏将**（非武将牌，无牌面势力），则无额外备选，仅按常规 3 张进行变更；
  - 若死者副将为**多势力武将**，或牌面势力在本局已被禁选（但该副将靠客将势力入池），需明确额外 3 张的检索口径（是否按牌面势力与本局允许集的交集，或按该副将的牌面势力直接检索；注意武将牌堆本身已排除本局无可选势力的武将）；
  - 若灵雎选择了一张来自死者副将势力的异势力武将作为新副将，变更完成后灵雎**不改变当前势力**（仍维持灵雎原势力）。

2. 当死者副将为**多势力武将**（如魏/蜀双势力）或通过**客将势力**入池（原牌面势力已被本局禁选）时，“额外获得三张其副将牌面势力的备选武将牌”应如何检索？（建议：从本局剩余合法武将牌堆中，筛选满足该副将任一牌面势力的武将至多 3 张；若牌面势力全部被禁则额外为 0 张，或改按本局生效势力检索？请确认。）
