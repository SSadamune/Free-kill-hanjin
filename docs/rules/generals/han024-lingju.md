# HAN024 灵雎：变包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“变”包记录，并对照紫乔 B 站大合集专栏（`1178159943679737864`）及 2026-11-21 已确认裁定整理；本页为规则定稿依据，不表示已实装。

## 将牌资料

- 称号：情随梦逝。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：无。
- 公共依据：[通用约定](../general-principles.md)、[变更武将与武将牌堆](../card-categories-and-operations.md#7-变更武将主副将技与武将牌堆)、[武将弃牌堆](../../development/implementation/guest-factions.md#自愿重抽与弃牌堆)及[变包索引](../bian-generals.md)。

## 竭缘

**技能原文**：竭缘：当你对其他角色造成伤害时，或受到其他角色造成的伤害时，若其体力值大于等于你，你可以弃置一张红色牌，然后令此伤害+1或-1。

**结算分析**：
- 触发时机：灵雎对其他角色造成伤害时（伤害加减时机），或灵雎受到其他角色造成的伤害时。无来源伤害或自伤不触发。
- 触发条件：对手（另一方其他角色）当前体力值 `>=` 灵雎当前体力值。
- 发动消耗：选定手牌区或装备区的一张可弃红色牌并执行弃置，按[发动消耗](../../../rulebook/definitions/skill-elements.md#有消耗)支付。
- 效果结算：由灵雎选择令此次伤害 `+1` 或 `-1`（无论造成伤害还是受到伤害均可任选 `+1` 或 `-1`；原伤害为 1 且选 `-1` 时伤害降为 0 则防止此次伤害）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 与紫乔专栏口径，弃牌范围为“红色牌”（含装备区）。

## 焚心

**技能原文**：焚心：当你杀死角色后，你可以变更副将，此次变更额外获得三张其副将牌面势力的备选武将牌。

**结算分析**：
- 触发时机：灵雎杀死一名角色后（死亡结算第 6 步“死亡后”技能时机，见[死亡结算流程](../turn-death-and-reveal-timing.md#4-死亡结算完整时序)；死亡角色此时已亮出全部暗置武将牌）。
- 发动次数：依紫乔专栏注释，变更武将默认为手杀规则（翻三选一），且**每局每个技能限一次**（因此【焚心】为伪限定技，整个技能来源每局仅能成功发起一次变更）。
- 备选武将池组成：
  1. 常规三张按[公共变更规则](../card-categories-and-operations.md#7-变更武将主副将技与武将牌堆)从灵雎本局势力取将，例如经【拉拢】加入新势力后按新势力取将。天然野心家按其原本脱离的势力取将，专属野心家随机取三张；
  2. **额外 3 张**：按死者**副将牌面势力**从当前[技能可用武将牌堆](../card-categories-and-operations.md#技能调用的武将牌堆)中额外检索 3 张备选武将（两组合并去重，通常最多 6 选 1，牌堆不足则取实际可得数量；若死者副将为士兵/翼从/偏将则无额外备选；若为多势力副将则匹配其任一牌面势力）。
- 势力与旧将去向：
  - 依紫乔专栏注释，额外翻出的异势力备选武将**无视势力限制**进行变更，且**不影响灵雎操作者的当前势力归属**；
  - 换下的旧副将按汉晋[武将弃牌堆](../../development/implementation/guest-factions.md#自愿重抽与弃牌堆)流程处理（加入 `qiao_general_discard_v1` 与 `disabled_generals`，从 `general_pile` 移除，本局不再回池）。

**已确认裁定**：
1. 依紫乔专栏说明，【焚心】遵循每技能每局限一次变更规则（伪限定技），额外翻出的异势力武将无视势力限制且不改变灵雎的势力归属。
