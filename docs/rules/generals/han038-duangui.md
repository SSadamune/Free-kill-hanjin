# HAN038 段珪

不臣篇（中） · 普通 · 称号“逐尽交困”。

势力为汉。配将体力贡献 1.5 点。

珠联璧合登记为张让（HAN004）。

## 卡面原文

> 劫君：当一名角色成为锦囊牌的目标时，若其体力值或手牌数最小，你可以明置此武将牌并令其本回合移出游戏，然后你摸两张牌。若如此做，其下个准备阶段，若其于此期间未再成为过锦囊牌的目标，你暗置一张武将牌。

## 结算

〖劫君〗检查锦囊目标的体力值或手牌数是否最小，并列可满足。须能明置段珪这张武将牌。跟踪该被移出角色直到其下个准备阶段，检查期间是否再次成为过锦囊目标。

## 验收场景

甲被救出后在下一回合又成为锦囊目标，即便该锦囊没有造成效果，甲下个准备阶段也不执行“未再成为过目标”的暗置。
