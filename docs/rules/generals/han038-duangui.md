# HAN038 段珪

不臣篇（中） · 普通 · 称号“逐尽交困”。

势力为汉。配将体力贡献 1.5 点。

珠联璧合登记为张让（HAN004）。

## 卡面原文

> 劫君：当一名角色成为锦囊牌的目标时，若其体力值或手牌数最小，你可以明置此武将牌并令其本回合移出游戏，然后你摸两张牌。若如此做，其下个准备阶段，若其于此期间未再成为过锦囊牌的目标，你暗置一张武将牌。

## 结算

发动〖劫君〗时，先检查成为锦囊牌目标的角色其体力值或手牌数是否为全场最小（并列最小也满足条件），同时段珪必须能够明置这张武将牌。发动后令该目标本回合移出游戏并摸两张牌，同时持续跟踪该角色直到其下个准备阶段，检查其在此期间是否再次成为过锦囊牌的目标；如果未再成为过，则段珪暗置自己的一张武将牌。

## 验收场景

角色甲因〖劫君〗移出游戏并移回后，在下一回合又成为了一张锦囊牌的目标。即使这张锦囊牌最终没有产生效果，到了甲的下个准备阶段时，也不会触发“未再成为过锦囊牌目标”的暗置惩罚。
