## 拔驾

**技能原文**：拔驾：锁定技，此武将牌明置后，你将场上一张装备牌置入装备区，称为“舆”；与你势力相同的其他角色视为装备着“舆”；若为君主装备，对应势力角色不能响应你的牌；当你失去“舆”后，你于此阶段结束时失去1点体力并暗置此武将牌。

**结算分析**：
- 锁定技，分为四段联动效果：
  1. **明置置入“舆”**：此武将牌明置后（遵循明置后统一窗口），选择**其他角色装备区**里的一张装备牌置入杨奉&韩暹的装备区（**不能**选择已在杨奉&韩暹自己装备区里的装备牌原地标为「舆」；按[装备移动与置入](../equipment-movement.md)，“置入”默认允许替换杨奉&韩暹原栏位冲突的旧装备，双副类别坐骑按双栏替换规则处理；若其他角色装备区没有任何装备牌则跳过），并标记该实体装备牌为「舆」。
  2. **同势力共享“舆”**：当杨奉&韩暹明置、【拔驾】有效且仍有自己的「舆」时，所有与杨奉&韩暹势力相同的其他角色**视为装备着「舆」**（享受该装备牌的装备技能与距离/攻击范围修正，不占用真实装备栏、不计入实体装备数、不可被拆顺移动；即使该队友装备区**已有同副类别实体装备**，仍**同时享有**实体装备与虚拟「舆」的双重效果）。
  3. **君主装备强命**：【拔驾】明置且有效时，若你的一张「舆」属于君主装备牌（依紫乔专栏注释，即君主技能里提到的装备牌，**即便对应君主不在场也算**），则**对应势力的角色**不能使用牌响应杨奉&韩暹使用的牌（如不能出【闪】或【无懈可击】）。
     - **实装防坑提醒（【虚妄之冕】）**：汉晋没有双势力君主装备！【虚妄之冕】是野君司马懿的**野心家（`wild`）君主装备**，故拔起【虚妄之冕】时强命对象为**野心家**。`pkg/qiao_mode/rules/cards.lua` 中为【虚妄之冕】登记的 `kingdoms = { "wei", "jin" }` 仅用于**开局禁选保留条件**（魏或晋至少一个未禁时保留该牌），实装【拔驾】时**严禁直接复用该禁选字段**判断“对应势力”，须独立维护君主装备的归属势力映射（魏/蜀/吴/群/汉/晋/野心家）。
  4. **失去自己的「舆」**。装备离开你的装备区时失去「舆」状态。若你明置且【拔驾】有效，失去自己的「舆」触发第四段。若杨奉&韩暹暗置，你可以在这个时机发动第四段亮出该将，再在本次明置后的正常窗口立即结算第一段。放弃亮将则跳过这次效果。阶段内发动第四段时，在该阶段结束时失去 1 点体力并暗置此武将牌；若在回合结束时等阶段外时机发动，仍按本次明置后的窗口取装备，没有阶段末代价。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（同势力共享「舆」+ 阶段结束惩罚 + 直接暗置）。
2. 明置时**不能**选择自己装备区已有的装备牌直接标记为「舆」。
3. 没有双势力君主装备，【虚妄之冕】为**野心家**君主装备，对应强命对象为**野心家**；且君主装备牌不论对应君主是否在场皆算。
4. 同势力其他角色已有同副类别实体装备时，**同时享有**实体装备与虚拟「舆」效果。
5. 在**阶段外**失去「舆」时，**不**触发“于此阶段结束时”的失血与暗置惩罚。
6. 「舆」是实体装备牌在持有者装备区内的状态。暗置杨奉&韩暹、【拔驾】无效或真正失去技能时，原装备仍保留「舆」。装备离开原持有者的装备区即清除状态，移到他人的装备区或日后返回时也须重新通过【拔驾】取得身份。
7. 四段里的「舆」均指你自己的「舆」。再次明置可以增加另一张「舆」，同栏替换会令被替换的旧「舆」离开。暗置或技能无效时暂停共享及君主装备的响应限制；重新明置或恢复有效后，按仍在装备区的全部「舆」结算。
