## 拔驾

**技能原文（JSON）**：拔驾：锁定技，此武将牌明置后，你将场上一张装备牌置入装备区，称为“舆”；与你势力相同的其他角色视为装备着“舆”；若为君主装备，对应势力角色不能响应你的牌；当你失去“舆”后，你于此阶段结束时失去1点体力并暗置此武将牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 在三处有显著差异：① 共享范围写“与你处于**同一队列**的其他角色”（JSON 为“与你势力相同的其他角色”）；② 惩罚时机写“于**当前回合结束时**”（JSON 为“于此阶段结束时”）；③ 暗置条件多写“**若你武将牌均明置**，你暗置此武将牌”（JSON 直接写“暗置此武将牌”）。

**结算分析（按 JSON 口径）**：
- 锁定技，分为四段联动效果：
  1. **明置置入“舆”**：此武将牌明置后（遵循明置后时机），选择场上（含自己或其他角色装备区；若自己已装备着，一般指场上的装备牌，优先排除已在自己装备区里的牌避免无意义原地移动）的一张装备牌置入杨奉&韩暹的装备区（按[装备移动与置入](../equipment-movement.md)，“置入”可主动替换已有同栏装备，须核对双副类别坐骑兼容性；若场上无合法可置入的装备牌则跳过），并标记该实体装备牌为「舆」。
  2. **同势力共享“舆”**：当杨奉&韩暹明置并仍装备着「舆」时，所有与杨奉&韩暹势力相同的其他角色**视为装备着「舆」**（享受该装备牌的装备技能与距离/攻击范围修正，但不占用其真实装备栏、不计入装备区实体牌数，也不可被拆顺移动；特别注意：若「舆」是【木牛流马】、【六龙骖驾】等特殊装备，须界定共享范围）。
  3. **君主装备强命**：若「舆」属于[君主装备](../card-deck.md#3-君主装备与势力)（如魏【六龙骖驾】/【神授思召】、蜀【飞龙夺凤】、吴【定澜夜明珠】、群【太平要术】、汉【赤霄剑】、晋【临筱玉舆】、魏/晋【虚妄之冕】），则**对应势力的角色**不能使用牌响应杨奉&韩暹使用的牌（如不能出【闪】或【无懈可击】）。
  4. **失去“舆”的惩罚**：当杨奉&韩暹从装备区失去「舆」后（无论被拆顺、替换、弃置还是主动交出），清除「舆」标记，并建立延时效果：**于此阶段结束时**，杨奉&韩暹失去 1 点体力并暗置杨奉&韩暹这张武将牌（若此时另一张武将牌已暗置，暗置后进入全暗状态；若处于回合外阶段内失去「舆」，同样在该阶段结束时结算）。
