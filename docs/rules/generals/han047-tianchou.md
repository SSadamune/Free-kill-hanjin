## 锋引

**技能原文（JSON）**：锋引：锁定技，你相邻角色成为与你势力相同的角色使用普通【杀】的目标后，你令其不能响应。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“锁定技，你相邻的角色视为处于所有与你势力相同的角色攻击范围内，且不能响应与你势力相同的角色使用的**红色【杀】**。”（JSON 无攻击范围修正，且为**普通【杀】**而非红色【杀】。）

**结算分析（按 JSON 口径）**：
- 锁定技，无须询问。
- 相邻判定：按当前在场座次计算田畴的上家和下家（排除被移出游戏的角色，见[移出游戏 FAQ](../../../assets/docs/规则向FAQ文件.md#将角色移出游戏)）。
- 触发条件：田畴的相邻角色成为与田畴势力相同的角色（含田畴本人）使用的**普通【杀】**（无属性【杀】，不含火/雷/冰【杀】）的目标后，令该目标不能使用牌响应此【杀】（如不能使用【闪】）。

## 径出

**技能原文（JSON）**：径出：当你于回合内使用牌后，你可以令一名角色本回合移出游戏，然后若场上仅剩你和一名其他角色，你摸两张牌且交给其一张牌，若你与其势力相同，其可以用一个武将交换此武将。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“你于回合内使用牌后，你可令一名**其他角色**本回合移出游戏，然后若场上仅剩你与另一名**你势力的角色**，其可与你各选择一个武将交换之。”（JSON 无摸两张交一张的 CSV 缺失部分，且 JSON 未限定“其他角色”，但依移出游戏通则，当前回合角色不可移出游戏，故回合内实际仍不能移出田畴本人。）

**结算分析（按 JSON 口径）**：
- 触发时机：田畴于自己回合内使用任意一张牌结算完成后（无每回合限一次限制，只要连续用牌即可连续移出其他角色）。
- 移出对象：一名合资格的在场角色；依据[FAQ：将角色移出游戏](../../../assets/docs/规则向FAQ文件.md#将角色移出游戏)，**当前回合角色（田畴本人）与濒死角色即将移出游戏时防止之**，故实际仅可移出非濒死的其他在场角色。
- 后续判定（“然后”）：实际将该角色移出游戏后，检查当前在场角色（排除所有已被移出游戏的角色）是否**仅剩田畴和另外 1 名其他角色**（共 2 人在场）：
  1. 若成立，田畴摸 2 张牌，然后交给那名剩余的在场其他角色 1 张牌（手牌或装备区牌）；
  2. 若田畴与该角色势力相同，该角色可以选择用自己的一个合法明置武将/位置，交换田畴的**此武将牌**（即田畴这张武将牌，见[交换武将](../general-exchange.md)；若该角色全暗或只剩君主等不可交换将牌则无法交换）。
