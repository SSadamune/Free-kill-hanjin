## 唆令

**技能原文（JSON / CSV 一致）**：唆令：出牌阶段限一次，你可以将一张黑色手牌交给一名其他角色并指定另一名角色，令其选择一项：1.将两张黑色手牌当【杀】对后者使用；2.后者可以对其使用任意张【杀】。

**结算分析**：
- 主动技，出牌阶段限一次。
- 发动消耗/动作：选择 1 张黑色手牌、1 名其他角色 A（收牌者）以及另 1 名角色 B（后者，B 不得为 A；是否允许 B 为袁隗本人须确认），将黑色手牌交给 A。
- A 的二选一：
  1. **选项 1**：A 将两张黑色手牌当一张普通【杀】（转化牌，两张黑牌合成为黑色无花色普通【杀】）对 B 使用（按[效果指定的用牌目标条件](../card-use-targets.md)，须核对是否无视距离限制、且不受通常出杀次数限制；若 A 黑色手牌不足 2 张或无法合法对 B 使用【杀】，则选项 1 不可选）；
  2. **选项 2**：B 可以依次对 A 使用任意张手牌中的【杀】（可 0 张，即 B 可以不用或连用多张；按效果插入用牌，不计入且无视通常出杀次数；须明确是否无视距离限制）。

**待主创确认**：
1. “指定另一名角色”（后者 B）是否允许选择**袁隗本人**（即与 A 不同的任意在场角色），还是仅限除袁隗和 A 外的第三人？
2. 选项 1（A 将两张黑手牌当【杀】对 B 使用）和选项 2（B 对 A 使用任意张【杀】），是否均**无视距离限制**（因目标已由技能明确锁定），还是仍需在攻击范围内？
3. 选项 2 中 B 使用的【杀】，是否允许通过转化技/装备技（如丈八蛇矛、龙胆、武圣）在当前窗口内对 A 连续使用【杀】？

## 趋奉

**技能原文（JSON）**：趋奉：每回合限一次，你交给或得到其他角色牌后，若你手牌数大于其，你可以与其各摸一张牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为完全不同的旧版锁定技：“锁定技，其他角色对你使用【远交近攻】结算后，或对你发动合纵后，你与其各摸一张牌。”

**结算分析（按 JSON 口径）**：
- 触发时机：每回合限一次，当袁隗将牌**交给**一名其他角色后（如【唆令】交牌、【仁德】、【合纵】等），或袁隗**得到**一名其他角色的牌后（含对方交牌、袁隗【顺手牵羊】/技能获得等，按“得到”指牌进入手牌区）。
- 触发条件：移动完成后，袁隗当前手牌数严格大于该其他角色当前手牌数。
- 效果结算：袁隗可以选择发动，令袁隗与该其他角色各摸 1 张牌（按座次或袁隗先摸、对方后摸）。

**待主创确认**：
1. 【趋奉】采用 JSON 新版（交牌/得牌且手牌数大于对方时各摸一张）还是 CSV 旧版（远交近攻/合纵各摸一张）？按既有惯例拟采用 JSON 新版，请确认。
