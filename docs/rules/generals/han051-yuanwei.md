# HAN051 袁隗：矢包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“矢”包记录，并对照紫乔 B 站大合集专栏（`1180345691175649301`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 称号：优游图免。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：无。
- 公共依据：[通用约定](../general-principles.md)、[效果指定的用牌目标条件](../card-use-targets.md)及[矢包索引](../shi-generals.md)。

## 唆令

**技能原文**：唆令：出牌阶段限一次，你可以将一张黑色手牌交给一名其他角色并指定另一名角色，令其选择一项：1.将两张黑色手牌当【杀】对后者使用；2.后者可以对其使用任意张【杀】。

**结算分析**：
- 主动技，出牌阶段限一次。
- 发动消耗/动作：选择 1 张黑色手牌、1 名其他角色 A（收牌者，依交牌通则不能为袁隗本人）以及相对于 A 的**另一名角色** B（后者：非 A 的任意在场角色，**允许选择袁隗自己**），将黑色手牌交给 A。
- A 的二选一：
  1. **选项 1**：A 将两张黑色手牌当一张普通【杀】（黑色无花色转化【杀】）对 B 使用（**无视距离限制**且不受通常出杀次数限制；依紫乔专栏注释，若 A 本身没有两张黑色手牌或无法合法对 B 使用【杀】，则选项 1 不可选）；
  2. **选项 2**：B 可以依次对 A 使用任意张【杀】（可 0 张；按效果插入用牌，**无视距离限制**且不计入/无视通常出杀次数，**允许**通过转化技或武器转化如【丈八蛇矛】、【龙胆】等使用【杀】）。

**已确认裁定**：
1. “指定另一名角色（后者）”指非 A 的任意角色，**允许选择袁隗自己**。
2. 选项 1 与选项 2 使用的【杀】均**无视距离限制**；选项 2 **允许**通过转化技/装备转化连续使用【杀】。
3. 依紫乔专栏注释，目标 A 黑色手牌不足 2 张时无法选择选项 1。

## 趋奉

**技能原文**：趋奉：每回合限一次，你交给或得到其他角色牌后，若你手牌数大于其，你可以与其各摸一张牌。

**结算分析**：
- 触发时机：每回合限一次，当袁隗将牌**交给**一名其他角色后（如【唆令】交牌、【仁德】、【合纵】等），或袁隗**得到**一名其他角色的牌后（含对方交牌、袁隗【顺手牵羊】/技能获得等，牌进入手牌区）。
- 触发条件：移动完成后，袁隗当前手牌数严格大于该其他角色当前手牌数。
- 效果结算：袁隗可以选择发动，令袁隗与该其他角色各摸 1 张牌。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（交牌/得牌且手牌数大于对方时各摸一张）。
