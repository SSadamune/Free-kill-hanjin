# HAN055 陶谦：弩包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“弩”包记录，并对照紫乔 B 站大合集专栏（`1181099586803990535`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 客籍：群、蜀。依[紫乔弩包专栏](https://www.bilibili.com/opus/1181099586803990535)中的客将牌图登记。

- 称号：寄州桃园、精兵鸷首。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：无。
- 客将备注：紫乔专栏明确追加陶谦的**蜀**势力客将设定。
- 统领：`{统领：丹阳青巾 |【杀】}`（普通翼从，非偏将；与吴势力贺齐 WU048 共用同一翼从定义）。
- 公共依据：[通用约定](../general-principles.md)、[统领与翼从](../commander-retinue.md)及[弩包索引](../nu-generals.md)。

## 厉治

**技能原文**：厉治：锁定技，与你势力相同的角色结束阶段，若其本回合摸牌数不足三张，则你令其失去1点体力并摸两张牌，否则你摸一张牌且交给其一张牌。

**结算分析**：
- 锁定技，触发时机为任意与陶谦势力相同的在场角色（含陶谦本人）的结束阶段。
- 条件判定：统计该当前回合角色**本回合累计摸牌张数**（含摸牌阶段摸牌及一切技能/卡牌效果的“摸牌”，不含非“摸牌”获得）：
  - **若摸牌数 `< 3`**：该角色失去 1 点体力，然后摸 2 张牌（若失去体力导致其死亡则不摸牌，被救回则摸 2 张牌）；
  - **否则（摸牌数 `>= 3`）**：陶谦摸 1 张牌，然后陶谦交给该角色 1 张牌（手牌或装备区牌均可；依交牌通则，若该角色就是陶谦本人则跳过“交给自己”）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（否则分支“你摸一张牌且交给其一张牌”）。

## 州忧

**技能原文**：州忧：锁定技，当你进入濒死时，你将三张牌交给其他角色（不足则全给），若你本回合首次以此法给出了三张牌，你回复1点体力。

**结算分析**：
- 锁定技，触发时机为陶谦进入濒死状态时（求桃开始前）。
- 交牌流程：陶谦从自己的牌（手牌区与装备区牌均可）中选择 3 张牌（总牌数不足 3 张则全选，为 0 则跳过），**任意分配**交给一名或多名其他在场角色。
- 回复条件：检查本次实际给出的牌数是否恰好为 3 张，且这是**本回合陶谦首次**通过【州忧】实际给出 3 张牌；若均成立，则陶谦回复 1 点体力（若体力值回至 `>= 1` 则直接脱离濒死）。

**已确认裁定**：
1. 【州忧】给出的三张牌可以**任意分配**给一名或多名其他角色（不限全给同一人）。

## 关联翼从：丹阳青巾

- 统领来源：汉·陶谦（HAN055，统领牌【杀】）与吴·贺齐（WU048，统领牌【逐近弃远】）均提供普通翼从【丹阳青巾】，共用同一翼从定义。
- **翼从技能原文**：锁定技，每回合每名角色限一次，当你使用牌指定一名拥有丹阳青巾的角色为目标后，你摸一张牌。
- **结算分析**：
  - 锁定技，每回合每名被指定的拥有【丹阳青巾】的目标角色限一次；
  - 触发条件：持有【丹阳青巾】的角色使用任意一张牌（包括自己对自己使用装备牌、【桃】、【酒】、【洞烛先机】等，与紫乔专栏所述“一般还是靠自己上甲摸牌”一致），指定一名拥有【丹阳青巾】的角色（含自己或其他拥有【丹阳青巾】的角色）为目标后，使用者摸 1 张牌。
  - 若同一角色通过多份【丹阳青巾】独立实例拥有该技能，依据[翼从独立实例](../commander-retinue.md#拥有数量与独立实例)，每份实例各自独立计次并触发。
