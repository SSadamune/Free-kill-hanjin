# HAN086 马日磾

不臣篇（下） · 普通 · 称号“孚尹契璺”“南冠楚囚”。

势力为汉，客籍为群。配将体力贡献 1.5 点。

珠联璧合登记为蔡邕（HAN012）。

客籍在原有主势力全部不可用时按本局允许集启用。[客将](../guest-factions.md)

## 卡面原文

> 秉节：结束阶段，你可以对自己发起“军令”。若你执行，直到你下回合开始，当你每回合首次成为其他角色使用伤害牌的目标时，你对其发起相同的“军令”，若其不执行，取消之。

> 续传：每名角色的弃牌阶段结束时，你可以选择其此阶段弃置的一张牌，然后其可以使用之。

## 结算

发动〖秉节〗时，马日磾先对自己发起“军令”并执行之，同时记住本次选中的军令；直到马日磾的下回合开始前，每回合当他首次成为其他角色使用伤害牌的目标时，对该用牌者发起同一项军令，如果对方不执行，则取消此牌对马日磾的目标。〖续传〗在每名角色的弃牌阶段结束时可以发动，由马日磾从该角色此阶段实际弃置的牌中选择一张，然后由该弃牌角色自己决定是否使用这张牌。

## 验收场景

角色甲在本回合使用的第一张伤害牌指定了马日磾为目标，甲拒绝执行〖秉节〗发起的军令，于是此牌取消对马日磾的目标；随后甲在本回合使用第二张伤害牌再次指定马日磾时，因已超出每回合首次限制，马日磾不能再次发起军令。
