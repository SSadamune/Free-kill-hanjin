# HAN086 马日磾

不臣篇（下） · 普通 · 称号“孚尹契璺”“南冠楚囚”。

势力为汉，客籍为群。配将体力贡献 1.5 点。

珠联璧合登记为蔡邕（HAN012）。

客籍在原有主势力全部不可用时按本局允许集启用。[客将](../guest-factions.md)

## 卡面原文

> 秉节：结束阶段，你可以对自己发起“军令”。若你执行，直到你下回合开始，当你每回合首次成为其他角色使用伤害牌的目标时，你对其发起相同的“军令”，若其不执行，取消之。

> 续传：每名角色的弃牌阶段结束时，你可以选择其此阶段弃置的一张牌，然后其可以使用之。

## 结算

〖秉节〗先对自己发军令并执行，记住选中的军令，后续每回合首次成为他人伤害牌目标时对使用者重发同一军令。〖续传〗每个弃牌阶段结束时从该阶段实际弃置的牌中选一张，是否使用由弃牌者决定。

## 验收场景

甲本回合第一张伤害牌指向马日磾，拒执行军令后取消相应目标；第二张再指马日磾时不能重复发令。
