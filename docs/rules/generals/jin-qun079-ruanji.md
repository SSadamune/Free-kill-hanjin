# JIN&QUN079 阮籍

不臣篇（中） · 普通 · 称号“谧野空堂”“孤鸿夜徘”。

势力为晋、群，客籍为魏。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

客籍在原有主势力全部不可用时按本局允许集启用。[客将](../guest-factions.md)

## 卡面原文

> 行慎：与你势力相同的角色受到伤害后，你可以摸一张牌，然后弃置至少X张牌（X为本回合此技能发动次数）。

> 离伤：当伤害牌指定目标时，若本回合置入过弃牌堆的梅花牌数大于1，你可以取消任意个目标，然后当前回合角色可以令你本回合移出游戏。

## 结算

发动〖行慎〗时，计算最低弃牌数 X 要将本次发动计入在内，且发动次数按回合重新计数。〖离伤〗在伤害牌指定目标时触发，需检查本回合置入过弃牌堆的梅花牌数量是否大于 1；如果满足条件，阮籍可以取消任意个目标，随后由当前回合角色决定是否令阮籍本回合移出游戏。

## 验收场景

同一回合内两名同势力队友各受到一次伤害，阮籍两次都发动了〖行慎〗：两次均先摸一张牌，随后第一次至少弃置一张牌，第二次至少弃置两张牌。
