# JIN&QUN080 刘伶

不臣篇（下） · 普通 · 称号“幕天席地”。

势力为晋、群。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 悠悠：锁定技，你的回合外，当你于一回合内第二次成为锦囊牌的目标后，你令此牌对你无效，然后摸一张牌，本回合移出游戏。

> 忽忽：限定技，当你进入濒死时，你可以令本回合你的所有牌移出游戏，且处于濒死的角色可以将其中一张牌当【酒】使用。

## 结算

〖悠悠〗在刘伶的回合外、当他于同一回合内第二次成为锦囊牌的目标后触发：先令这张锦囊牌对刘伶无效，再令刘伶摸一张牌，最后将刘伶本回合移出游戏。〖忽忽〗将刘伶自己的所有牌在本回合移出游戏，本回合内任意处于濒死状态的角色都可以将其中一张牌当【酒】使用。到了回合结束时，按角色先移回、牌后移回的顺序，将仍因〖忽忽〗移出游戏的牌全部返还至刘伶的手牌中（包括原先位于装备区的牌）。

## 验收场景

角色甲与乙在同一回合内先后进入濒死状态，各取用了一张被〖忽忽〗移出的牌当【酒】使用；到回合结束时，这两张牌已被使用消耗。如果剩余的被移出牌中包含刘伶原先装备的武器牌，该武器牌会直接返回刘伶的手牌中，即使刘伶此时已经装备了另一把武器，也照样返还至手牌。
