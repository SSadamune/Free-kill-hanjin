# JIN&QUN080 刘伶

不臣篇（下） · 普通 · 称号“幕天席地”。

势力为晋、群。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 悠悠：锁定技，你的回合外，当你于一回合内第二次成为锦囊牌的目标后，你令此牌对你无效，然后摸一张牌，本回合移出游戏。

> 忽忽：限定技，当你进入濒死时，你可以令本回合你的所有牌移出游戏，且处于濒死的角色可以将其中一张牌当【酒】使用。

## 结算

〖悠悠〗在回合外第二次成为锦囊目标时，先令牌对刘伶无效，再摸牌并移出角色。〖忽忽〗移出刘伶自己的牌，本回合任一濒死角色均可将其中一张当【酒】使用。回合末按角色先移回、牌后移回的顺序，将仍因〖忽忽〗移出的牌全部返还刘伶手牌，包括原先在装备区的牌。

## 验收场景

甲、乙在同一回合先后濒死，各取一张当【酒】使用。回合结束时，这两张牌已经用掉。剩余牌中有刘伶原先装备的武器，该武器回到刘伶手里，即使他现在已经装备了另一把武器，也照样返手。
