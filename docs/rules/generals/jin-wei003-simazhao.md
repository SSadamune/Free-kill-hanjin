# JIN&WEI003 司马昭（效忠版）

不臣篇（下） · 效忠版 · 称号“狼子野心”。

势力为晋、魏。配将体力贡献 1.5 点。

珠联璧合登记为司马师（JIN002）。

对应专属野心家版见[司马昭（AM(JIN&WEI003)）](am-jin-wei003-simazhao.md)。选将及准备阶段升变见[野心家效忠](../wild-allegiance.md)。

## 卡面原文

> 昭然：出牌阶段开始时，你可以令此阶段内你的手牌对所有角色可见，且你首次失去每种花色最后的手牌后，摸一张牌或弃置其他角色一张牌。

> 挟征：限定技，出牌阶段，你可以令一名角色需将一张基本牌当【杀】对你指定的角色使用，否则你获得其所有手牌，交给其等同其体力值的牌。

## 结算

〖昭然〗开启后，司马昭的手牌在该出牌阶段内会持续对所有角色可见，且每种花色只在该阶段首次失去最后一张手牌时触发结算。〖挟征〗要求被选择的角色将一张基本牌当【杀】对司马昭指定的角色使用；只有对方未按要求使用时，司马昭才获得其所有手牌，并再交给其等同于其体力值数量的牌。这两个技能的结算与标准晋司马昭相同。

[标准晋司马昭的同文裁定](jin003-simazhao.md)适用于此处两技。配将、入池和效忠关系仍按本编号执行。

## 验收场景

若被选中的角色按要求使用了【杀】，即使该【杀】被目标使用【闪】抵消，也已经满足“使用”的条件，司马昭不能获得其手牌。司马昭在出牌阶段中途新摸到的手牌，同样处于〖昭然〗的可见范围内。
