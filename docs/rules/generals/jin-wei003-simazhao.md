# JIN&WEI003 司马昭（效忠版）

不臣篇（下） · 效忠版 · 称号“狼子野心”。

势力为晋、魏。配将体力贡献 1.5 点。

珠联璧合登记为司马师（JIN002）。

对应专属野心家版见[司马昭（AM(JIN&WEI003)）](am-jin-wei003-simazhao.md)。选将及准备阶段升变见[野心家效忠](../wild-allegiance.md)。

## 卡面原文

> 昭然：出牌阶段开始时，你可以令此阶段内你的手牌对所有角色可见，且你首次失去每种花色最后的手牌后，摸一张牌或弃置其他角色一张牌。

> 挟征：限定技，出牌阶段，你可以令一名角色需将一张基本牌当【杀】对你指定的角色使用，否则你获得其所有手牌，交给其等同其体力值的牌。

## 结算

〖昭然〗手牌在出牌阶段持续可见，每个花色只在该阶段首次失去最后一张时结算。〖挟征〗令被选人以基本牌对指定角色使用【杀】，不使用才获得其全部手牌、再交回其体力值张牌。两技与标准晋司马昭同文。

[标准晋司马昭的同文裁定](jin003-simazhao.md)适用于此处两技。配将、入池和效忠关系仍按本编号。

## 验收场景

对方照办用【杀】，但被目标出【闪】抵消，已满足“使用”，司马昭不能取得其手牌。中途又摸进一张手牌也在〖昭然〗的可见范围内。
