# JIN002 司马师：标准包审阅

2026-11-15 按[标准武将表](../standard-generals.md)、外部来源及用户本轮说明审阅。本文记录结算依据，不表示代码已完成；泰然后续时机尚未定案，暂按回合结束时处理。

## 泰然

- 时机为出牌阶段开始时；失去体力与弃牌均含可选表述，不能强制两项都执行。弃牌上限读取执行时已损失体力值，不能只取此次失去体力数。涉及濒死先完整插入濒死流程，见[结算原则](../../../rulebook/definitions/settlement-principles.md)。
- **后续时机待定，暂按回合结束时**执行，对应[回合事件的“回合结束前”](../../../rulebook/events/turn.md#回合结束前)；这不是已最终选定该时机。暂行处理中，回复此次以此法失去的体力数，摸牌按实际以此法弃置的张数，不能直接回满或补满手牌；跳过结束阶段不因此取消回合结束时的后续。
- 已建立的后续效果与当前仍有技能分别处理，见[技能效果分类](../../../rulebook/topics/skill-effect-classification.md)。
- **用户暂定处理**：同回合多个出牌阶段多次发动，在回合结束时分别结算每次发动的记录，不合并回复与摸牌，不以单个标记覆盖早先记录。用户已明确更正此前笔误，暂按“回合结束时分别结算每次记录”理解。
- **来源差异**：JSON 原文写“结束阶段”，CSV 写“回合结束时”；用户明确两者目前尚未定案，项目暂按后者理解，标准表同步标明暂行性质，保留两份外部原始资料。此前将任一时机写成最终采用版本的结论撤回。

## 夷灭

限定技；在造成伤害时比较双方当时体力值，满足大于等于才可发动；翻倍当前伤害值，不是固定加一，也不是翻倍整张牌此后的全部伤害。按[伤害事件](../../../rulebook/events/damage.md)与[限定技](../../../rulebook/terms/description-terms/limit.md)处理，取消不消耗限定机会。

## 统领关联

腹心死士；统领能力提供红桃【出其不意】〈助战→目标+1〉，花色和应变条目都须附在本次使用上。翼从专属技能与两名统领来源的关系见[统领与翼从](../commander-retinue.md)，不能将翼从取得与本次借用牌绑定。

### 腹心死士专属技能

同势力角色回合结束时，两项条件分别检查：“有未发动的限定技”可摸一张再交给其一张自己的牌；“本回合发动过限定技”可视为对其攻击范围内一名角色使用【杀】。可能同时存在未发动的限定技和本回合已发动的另一个限定技，不能写成互斥二选一。

限定技按真实技能标签及发动历史判断，不把统领能力的全局限一记录视为发动限定技；本回合历史也不应因技能后来失去而抹除。第二项范围取当前回合角色的攻击范围，非翼从持有者的攻击范围，按[效果指定目标](../card-use-targets.md)接入；仍须遵循禁止使用／指定。两名统领只共用一个翼从技能 ID，不按取得来源复制技能或叠加触发。
