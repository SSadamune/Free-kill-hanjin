# JIN003 司马昭：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)及其 JSON 来源；不含其他编号的司马昭。

## 昭然

- 出牌阶段开始时选择发动，公开与后续机会持续本阶段。手牌公开是持续[可见](../../../rulebook/terms/description-terms/kejian.md)，不是仅展示发动时的手牌；之后新获得的手牌也须可见。
- 每种花色首次失去最后的手牌后提供一次选择，不是首次发动后才消耗机会；同批失去多种花色须分别识别，重新获得同花色手牌不重开该花色机会。失去包括使用、弃置、交给等，不能只监听弃牌。
- 摸一张或弃其他角色一张牌，按[选择](../../../rulebook/terms/description-terms/choose.md)排除无法执行的选项；无牌可弃时仍可摸牌。阶段事实、可见与已建立效果的持续按[效果分类](../../../rulebook/topics/skill-effect-classification.md)处理。

## 挟征

限定技，出牌阶段发动。先确定被要求用牌的角色及技能指定的用牌目标；“需”表示其有响应选择权，见[需](../../../rulebook/terms/description-terms/need.md)。响应必须是一张基本牌转化为【杀】，不能退化为只找现成杀；素材为该角色自己的手牌或装备区牌，不能任取场上牌。明确指定目标按[目标条件](../card-use-targets.md)处理，独立禁止仍生效。

未实际使用才进入获得全部手牌、交还等同其体力值张牌的分支；不能以杀被闪避或未造成伤害认定未响应。交还范围是发动者自己的牌，不限定刚获得的那些手牌；按实际结算时参数与合法牌区处理，不凭“否则”另加目标必须有手牌的前置条件。
