# JIN004 贾充：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)、[应变规范](../adaptation.md)审阅。

## 通法

同势力角色实际使用应变牌时，由使用者选择交给贾充一张自己的牌；使用者就是贾充时改为弃置。不能只检查成功应变事件，也不能把“交给”统一实现为弃牌。牌的范围见[自己的牌](../../../rulebook/terms/description-terms/limit_card.md)，发动与消耗者不必是技能拥有者，见[技能要素](../../../rulebook/definitions/skill-elements.md)。

支付者为发动者。贾充自己使用并支付时可以依正常技能发动流程明置；同势力其他角色支付时，通法须已经生效。每次有效支付提供本次使用的一个无视条件令牌，不令该牌的全部条目成立；自然满足不消耗令牌。按公共应变流程准备、逐项检测与处理助战。势力按实际国战关系判断。

## 悖弑

在成为其他角色使用的【杀】或锦囊牌唯一目标时检查，锦囊未排除延时锦囊；不能将“唯一目标”替换为单目标牌型标签。弃置一张同类别的自己的牌为发动所需操作，类别为基本／锦囊／装备，不是同牌名。

取消该目标，获得该牌的可获得实体材料，再可使用一张无距离限制的牌。取消目标不是设置不可响应或全局禁止使用；获得不到实体材料不能虚构牌。后续用牌仅豁免距离，其他条件仍按[目标规则](../card-use-targets.md)。

是否对原使用者造成伤害应归属于本次后续用牌的真实伤害记录，不能拿回合总伤害替代；未使用、取消后续用牌或未对其造成伤害时，仍须检查失去1点体力的后续效果。插入技能导致牌提前移动时遵循[此牌](../../../rulebook/terms/description-terms/this_card.md)，不凭旧 ID 从任意区域强取。
