# JIN005 羊祜：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)审阅。公共势力、归属及配将修正见[通用约定](../general-principles.md)。

## 柔克

每名同势力角色每回合首张实际使用的【杀】可改为冰【杀】，不是本回合首次发动时任选一张杀。首次用牌事实须包含技能尚未取得或尚未明置时的历史；不能因晚明置重开首张资格。改牌应保留本次使用、实体材料与已有明确条目，不重新使用第二张杀；改成冰杀不自动继承牌堆中某张冰杀的应变。

无伤害检查在该次用牌结束后进行，不能在首个目标结算完就判断。手牌上限增加的是当前横置角色数，不是此次横置人数，且与是否已触发冰杀分支分别处理。

用牌者是发动者并决定是否改牌。首张【杀】原本就是冰【杀】时仍可询问并执行改牌。羊祜须有已经生效的柔克来源，不能通过柔克明置武将牌。成功改牌且该牌未造成伤害后，羊祜在一次可取消的请求中直接选择至多两名角色。根据[武将状态通用约定](../general-principles.md#配将体力贡献与武将状态)，每名所选角色按结算时状态自动切换，已横置则重置，未横置则横置。

**用户于 2026-11-15 明确**：须实际将首张杀改为冰杀，才可能执行“然后”之后的后续；不选择改牌，即使该杀未造成伤害也没有横置／重置机会。此为易读描述的公共依赖关系，见[通用约定](../general-principles.md#易读描述的时机与然后)，不另作柔克专属语法。

## 顺流

仅在羊祜位于副将时有效，配将体力贡献减一个单独阴阳鱼；不是发放／扣除可消耗标记。已有 `deputyHpAdjust = -1`，须保留。依据[主副将技](../../../rulebook/terms/description-terms/head_deputy.md)及通用约定。

造成一次属性伤害后，选择发动并依次弃置受伤角色及所有横置角色各一张自己的牌；“自己的牌”对受弃牌者指手牌及装备，不包括判定区。由羊祜选牌，不是令这些角色各自弃牌；无牌者不虚构弃牌。横置角色不限定同势力，也不排除自己。

**用户于 2026-11-15 明确**：依[扣减体力事件](../../../rulebook/events/reduce-hp.md#在伤害事件中产生的扣减体力事件)，横置角色受到属性伤害时，在扣减体力流程中先重置；[造成伤害后](../../../rulebook/events/damage.md#造成伤害后)晚于此操作。因此受伤者通常已不横置，只按受伤角色弃一次，不能使用伤害前的横置快照将其再次纳入。

若其他效果使受伤者在顺流的造成属性伤害后时机仍处于横置状态，则其也属于“所有横置角色”，先按受伤角色弃一张，再在横置角色部分弃一张；不能对两部分作全局角色去重。每次实际弃牌仍须检查该角色当时有可弃的牌。
