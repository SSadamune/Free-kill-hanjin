# JIN007 王元姬：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)及其 JSON 来源审阅。

## 识人

准备阶段一次选定至多三名其他势力角色，再按座位分别选择他们各一张手牌。固定所选牌后，由这些角色按[结算顺序](../../../rulebook/definitions/settlement-principles.md)依次声明牌名；不提前公开全部所选牌，不将选牌界面变成偷看所有手牌。按实际势力关系过滤，不按武将印刷势力。

发动者选其中一张展示并获得；只将这张牌的实际牌名与其拥有者的声明比较，不比较另外两人的声明。不同才获得其余被选择的牌，不是获得所有目标的全部手牌。插入结算中所选牌已移动时，按[此牌](../../../rulebook/terms/description-terms/this_card.md)复核。

## 恤下

每回合限一次，其他角色受到一次伤害后，比较实际明置武将牌数；不比较技能数、体力或是否同势力。满足少于王元姬才可交给其两张自己的牌，然后摸两张。须真实交足两张，不将零张或一张作为发动消耗；按[交给](../../../rulebook/terms/card-op-terms/give.md)及[通用消耗约定](../general-principles.md)处理。

标准表／JSON 原文为“交给其两张牌，然后摸两张牌”；运行时资料写成“交给其两张牌并摸两张牌”，改变操作连接词。应回到来源顺序，不将原文改写为同时执行。暗将发动所需明置及条件复核须走公共来源流程，不能仅加一个技能 ID 后模拟全部国战判断。
