# JIN010 张春华：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)审阅。

## 伤逝

任一角色结束阶段提供选项，包含自己；不是回合结束时。第一项要求该角色手牌数大于自己，以任意张自己的手牌合成一张冰【杀】对其使用，不是逐张使用多张冰杀；是否能执行仍须检查合法材料及用牌限制。目标由效果明确规定，接入[显式目标条件](../card-use-targets.md)，而非默认叠加攻击距离。

第一项的首个动作操作自己的手牌，按[通用约定](../general-principles.md)须至少一张合法手牌。公开卡面仍使用原文「任意张」。

第二项只摸至当前已损失体力值，按[补至](../../../rulebook/terms/card-op-terms/drawTo.md)计算差额，手牌已有足够张数时不摸；不能固定摸已损失体力张数。两项均不可执行时不提供无效发动。

## 扼绝

造成伤害时且没有手牌，可以失去自己的一个其他技能，再令本次伤害+1。不得失去扼绝本身；不能只在临时 UI 隐藏技能，也不能将失去单个技能误实现为断肠式失去整张武将牌的全部技能。范围依[通用归属](../general-principles.md)与实际拥有的武将技能确定，排除装备技能、内部辅助骨架及未取得的技能。

技能失去须维护真实来源，避免暗置／再明置重新授回；已建立的持续效果按[效果分类](../../../rulebook/topics/skill-effect-classification.md)保留，不因失去原技能一并撤销。明暗置及主副将专属资格按公共流程处理，不能把另一张未生效将牌上的全部技能直接列为可付代价。

用户于 2026-11-15 明确：若失去的是某张武将牌上的技能，该牌被交换后仍保留此失技状态；新持有者不得重新获得其已经失去的技能。失去记录须按“武将牌及该技能”保存，不能只按原角色保存，也不能把该牌其他未失去技能一并禁用。

若失去的是不在武将牌上的技能，则依其实际授予来源处理，不随交换的武将牌转移。执行失去操作时必须区分这两类来源，尤其不能只对角色调用同名技能删除而不保存归属。公共依据见[失技状态归属](../general-principles.md#失去技能的状态归属)及[交换武将](../general-exchange.md#哪些状态随牌移动)。
