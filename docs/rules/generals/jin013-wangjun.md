# JIN013 王濬：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)、[应变规范](../adaptation.md)及外部 FAQ 的[伤害牌定义](../../../assets/docs/规则向FAQ文件.md#伤害牌)审阅。

## 乘流

伤害牌为可作为伤害渠道的基本牌／普通锦囊，不把闪电或伤害装备也纳入。为使用赋予〈富甲→改为雷电伤害〉条目，富甲允许手牌数并列最多，按应变正式逐项时点检查，不按发动前手牌数预存成功状态。此条目与牌上其他应变条目共存，不能覆盖其他条目，也不能直接把所有牌永久变成雷电伤害。

结算后可横置任意名实际受到此牌伤害的角色。原文以“且”连接，不额外添加“必须先触发富甲”条件；未造成伤害的目标不在候选内，有伤害者也不必是原始目标。须使用本次用牌的伤害关联而非回合总伤害或当前手牌实体 ID。

## 克清

出牌阶段限一次，选一名已横置的其他角色。建立效果持续至王濬再次发动该技能或死亡；目标后来重置不清除关系，只暂停满足横置条件的惩罚，之后再横置可继续生效。

目标每次使用或打出牌时，若其横置，由其弃置自己一张牌；不是王濬选牌，不仅限手牌，也不限制每回合一次。用牌与纯打出事件分别监听，一次实际使用不能双计。失去原技能不自动撤销已建立效果，依[效果分类](../../../rulebook/topics/skill-effect-classification.md)；来源死亡明确终止，不将目标印刷势力作为维持条件。
