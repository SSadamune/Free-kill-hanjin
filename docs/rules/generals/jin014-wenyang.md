# JIN014 文鸯：标准包审阅

2026-11-15 依据[标准武将表](../standard-generals.md)审阅；客将魏、吴依公共客将规则，不把文鸯直接登记为晋魏吴三主势力。

## 膂力

每回合限一次，造成一次伤害后选择一项，不按伤害点数重复发动。第一项摸至当前体力值，按[补至](../../../rulebook/terms/card-op-terms/drawTo.md)取差额。第二项实际弃置全部手牌，然后将体力回复至实际弃置张数，不是回复等量体力，不超过体力上限，也不将高于 X 的体力降为 X，见[回复至](../../../rulebook/terms/description-terms/recover_to.md)。

空手不能执行弃置所有手牌，见[所有牌操作](../../../rulebook/terms/card-op-terms/operateAllCards.md)。选项须核对可执行性与弃牌限制，不把不能全弃时的部分弃置当作已经支付全部要求。

## 夺气

限定技，每个回合结束时检查当前回合角色没有手牌，可获得一个额外回合，包括当前回合就是自己的情况。不是结束阶段触发，也不是该角色失去最后手牌时立即发动。以当前时点检查，不用此前空手快照；额外回合加入正式调度，不递归手工调用阶段流程。

## 文虎

文虎为限一翼从；文鸯统领能力提供冰【杀】，其限一用牌机会与文虎唯一取得分别记录，依[公共规范](../commander-retinue.md)。

翼从专属技能：出牌阶段限一次，弃置自己任意个区域的所有牌后视为使用一张【决斗】，仅改变目标上限为实际完成弃置的区域数 X。区域只指手牌、装备、判定三区，见[角色的区域](../../../rulebook/terms/zone-terms/juesequyu.md)。不能以空区域充数、把装备栏分别算区域或只弃部分牌；须至少执行一次实际弃牌作为消耗。仅改数量不改写原牌其他目标条件，见[目标条件](../card-use-targets.md)。
