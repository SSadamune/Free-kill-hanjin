# JIN015 石苞：前驱审阅

2026-11-15 依据[标准武将表](../standard-generals.md)及[应变规范](../adaptation.md)审阅。

同势力角色准备阶段（包括自己），石苞可使用一张无距离限制的【杀】；不是视为凭空生成杀，须走真实用牌与合法转化入口。只豁免距离，按[通用约定](../general-principles.md)这是技能结算中的用杀，不占用空闲时间点出杀次数。

本次杀附加〈助战→弃置目标角色装备区里的一张牌〉，不能将助战当成技能发动消耗，也不能仅给实体材料永久打标。助战仍排除使用者与当前目标，由其他角色弃同类别手牌；杀上已有条目保留，共同按公共逐项流程执行。

用牌完整结束后检查此杀真实造成过伤害；满足则当前回合角色获得此杀并摸一张，受益者不是固定石苞或受伤目标。只取得仍合法可获得的实体材料，不能将纯虚拟牌造为实体。获得不到材料与后续摸牌的执行分别依原连接词及[结算原则](../../../rulebook/definitions/settlement-principles.md)处理，不能无条件提前摸牌或整段跳过。
