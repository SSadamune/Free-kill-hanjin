# JIN020 荀勖：变包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“变”包记录，并对照紫乔 B 站大合集专栏（`1178159943679737864`）及 2026-11-21 已确认裁定整理；本页为规则定稿依据，不表示已实装。

## 将牌资料

- 称号：翊翊勉事。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：`JIN004`（贾充）。
- 公共依据：[通用约定](../general-principles.md)、[应变](../adaptation.md)、[变更武将](../card-categories-and-operations.md#变更武将)、[武将弃牌堆](../../development/implementation/guest-factions.md#自愿重抽与弃牌堆)及[变包索引](../bian-generals.md)。

## 应政

**技能原文**：应政：与你势力相同的角色回合内限一次，当其使用应变牌后，其可以令你获得此牌，然后若此牌触发应变，你可以令其变更副将（限一次）。

**结算分析**：
- 触发时机：一名与荀勖势力相同的角色（含荀勖本人）在其自己的**回合内**（每回合限一次，按该角色自己回合内计），**使用一张应变牌后**（判断 `isAdaptationCard`，即牌堆里的应变牌或技能赋予应变条目的牌，见[应变规范](../adaptation.md)）。
- 触发顺序（注意主语切换）：
  1. 先由该**同势力角色**选择是否令荀勖获得此牌（从处理区/弃牌堆中取得该实体牌；若是无实体牌的虚拟应变牌或该牌已不在可获取区域则无法获得，不进入后续）；
  2. “然后”：在荀勖实际获得该牌后，若该牌在本次使用中**实际触发了应变效果**（按[应变规范](../adaptation.md)的 `Triggered` 事实判断），则由**荀勖**选择是否令该角色**变更副将**（遵循手杀 3 选 1 流程，依变更武将通则整个【应政】技能来源每局仅能发起一次变更；换下的旧副将按[武将弃牌堆](../../development/implementation/guest-factions.md#自愿重抽与弃牌堆)处理，本局不再回池）。
- 若使用应变牌的是**荀勖本人**：令自己“获得此牌”即收回自己刚使用完毕仍在处理区的实体牌；若触发了应变，再可选变更自己的副将。

**已确认裁定**：
1. 正式版本采用石激桑 JSON（“回合内限一次”）。
2. “变更副将（限一次）”依变更武将通则按【应政】技能来源每局限一次计。

## 拨律

**技能原文**：拨律：出牌阶段限一次，你可以选择一名角色并重铸一张手牌，根据花色修改其使用下张应变牌的应变条件：黑桃~富甲；红桃~残躯；梅花~助战；方片~空巢。

**结算分析**：
- 主动技，出牌阶段限一次。
- 发动消耗/动作：选择一名在场角色（含荀勖自己），并**重铸一张手牌**（将该手牌置入弃牌堆并摸一张牌；无手牌不可发动）。
- 花色映射：根据重铸手牌的花色，为目标角色建立持续状态（跨回合保留直至其使用下一张应变牌消耗，或目标死亡）：
  - `♠` 黑桃 → `<富甲>`（手牌数为全场最多）
  - `♥` 红桃 → `<残躯>`（体力值 `<= 1`）
  - `♣` 梅花 → `<助战>`
  - `♦` 方片 → `<空巢>`（使用后没有手牌）
- 覆盖规则：依紫乔专栏展示的单张可旋转“拨律标记牌”设计，目标未消耗前再次对其发动【拨律】时，新花色条件**覆盖**旧条件。
- 生效方式：当目标角色之后使用下一张**应变牌**时，将其上的**全部应变条件**统一替换为上述指定条件，然后照常走[汉晋应变](../adaptation.md)检测与触发流程（替换后消耗本次【拨律】标记）。

**已确认裁定**：
1. 若目标使用的下张应变牌带有**多项**应变条件，【拨律】将其**全部统一修改**为对应花色的应变条件。
2. 未消耗前重复施加【拨律】时，新条件覆盖旧条件；该标记跨回合保留至目标使用下一张应变牌。
