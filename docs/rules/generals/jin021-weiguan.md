## 乘隙

**技能原文（JSON / CSV 一致）**：乘隙：准备阶段，你可以令一名角色视为使用【以逸待劳】，然后使用者对以此法弃置了非基本牌的目标角色各造成1点伤害。

**结算分析**：
- 触发时机：卫瓘自己的准备阶段。
- 选择一名在场角色作为【以逸待劳】的**使用者**（可以是卫瓘自己，也可以是其他角色；注意：若该角色尚未确定势力，按[同势力判定](../general-principles.md)，只有其自己与自己同势力，故该【以逸待劳】仅指定其自己为目标）。
- 该使用者视为使用一张无实体牌的【以逸待劳】（所有与该使用者势力相同的在场角色成为目标，按座次依次摸两张牌并弃置两张牌）。
- 后续伤害结算（“然后”）：等该【以逸待劳】结算完毕后，记录本次因该【以逸待劳】效果**实际弃置了至少一张非基本牌**（锦囊牌或装备牌）的目标角色，由**该【以逸待劳】的使用者**（注意：伤害来源是使用者，不是卫瓘）按座次依次对这些角色各造成 1 点普通伤害（若使用者自己也弃置了非基本牌，使用者对自己造成 1 点伤害）。
- 若某目标的【以逸待劳】效果被【无懈可击】抵消，则其未以此法弃牌，不会受到后续伤害。

**待主创确认**：
1. 使用者本人若在【以逸待劳】结算中弃置了非基本牌，使用者是否也属于“目标角色”从而**对自己造成 1 点伤害**？（【以逸待劳】目标包含使用者自己，字面无“其他”限定，应包含自己，请确认。）

## 追诛

**技能原文（JSON）**：追诛：轮次技，当一名角色受到致命伤害时，你可以对其发起“军令”。若其执行，你可以防止此伤害；若其不执行，此伤害翻倍。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“若其执行，**防止此伤害**”（必然防止，而非 JSON 的“你可以防止此伤害”可选）。

**结算分析（按 JSON 口径）**：
- 轮次技（每轮限一次，每轮开始时重置）。
- 触发时机：任意在场角色受到**致命伤害时**（即伤害结算中、扣减体力前，且当前伤害值 `>=` 该角色当前体力值；若该伤害在更早时机已被减至低于当前体力值，则不再为致命伤害）。
- 发动流程：卫瓘对**即将受到该致命伤害的角色**发起一次[军令](../../../rulebook/terms/description-terms/junling.md)。
  - **执行分支**：按 JSON，卫瓘**可以选择**是否防止此次致命伤害（若采用 CSV，则必然防止此伤害）。
    - 注意边角交互：若该角色为了执行军令（例如军令 3 失去 1 点体力）而在军令结算中直接进入濒死甚至阵亡，则原伤害后续依常规流程处理（角色已死则中止伤害）；若执行军令后仍存活且卫瓘选择防止伤害，则本次致命伤害被防止。
  - **不执行分支**：此次伤害值翻倍（当前伤害值 `× 2`，如 1 变 2、2 变 4）。

**待主创确认**：
1. 执行分支以 JSON（“你可以防止此伤害”，卫瓘可选救或不救）还是 CSV（“防止此伤害”，执行军令必然免伤）为准？拟以 JSON 为准，请确认。
2. 卫瓘能否在**自己**受到致命伤害时发动【追诛】对自己发起军令？（按“当一名角色受到致命伤害时”未排除自己，若军令本身不允许对自己发起则排除自己，请与吴国太【补益】一并确认军令能否以自己为目标。）
