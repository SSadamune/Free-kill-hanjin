## 烈戎

**技能原文**：烈戎：出牌阶段限一次，你可以失去1点体力，令你本回合攻击范围至多+X（X为你已损失的体力值），视为使用火【杀】<助战→伤害+1>。

**结算分析**：于出牌阶段发动后先失去 1 点体力并完成相关结算，再读取当时已损失的体力值 X。若 X 大于 0，依[「至多」的定义](../../../rulebook/terms/value-terms/atMost.md)从 1 至 X 选择本回合的攻击范围增量，只有一个数值时直接取该值。若 X 为 0，跳过增加攻击范围的动作，继续结算后续视为使用带「助战→伤害+1」的火【杀】。范围增量只作用于攻击范围。应变身份和实际触发依[汉晋应变规则](../adaptation.md)。

## 勤边

**技能原文**：勤边：结束阶段，你可以将一张手牌当【逐近弃远】<助战→执行两项>对你攻击范围内距离最远的一名其他角色使用。

**结算分析**：结束阶段可用自己一张手牌转为逐近弃远，目标从自己攻击范围内的其他角色中选距离最远者，并列可选其一；不是先找全场最远再检查范围。赋助战→执行两项，必须保留其应变牌身份、协助竞速和真实两项效果。
