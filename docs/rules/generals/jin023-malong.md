# JIN023 马隆：阵包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“阵”包记录，来源编号 `1174504737529135105`。卡面描述、规则分析及当前实装状态分别记录。

## 将牌资料

- 称号：灭虏夷险。
- 单将体力贡献：2；主副将技的独立修正另按技能处理。
- 珠联璧合：无；未提供的客将资料不推测。
- 公共依据：[通用约定](../general-principles.md)、[将牌与位置](../general-principles.md#武将位置武将牌与士兵牌)、[效果分类](../../../rulebook/topics/skill-effect-classification.md)及[阵势包索引](../zhen-shi-generals.md)。

统领：八阵兵｜闪。统领能力与翼从效果分别依[公共规则](../commander-retinue.md)。

关联翼从描述：轮次技，一名角色的出牌阶段开始时，你可以视为使用【调虎离山】，此牌结算中其可以将【杀】当【无懈可击】使用。

## 锋械

**技能原文**：锋械：出牌阶段限一次，你可以交换两名角色场上各一张装备牌，若其中一名角色为你，你视为对其中另一名角色或其队列使用一张【杀】。

**结算分析**：出牌阶段限一次，交换两名角色场上各一张装备。依[交换的各一张确定牌](../../../rulebook/terms/card-op-terms/swap.md)，两张先同时移至处理区，再同时移入对方手牌区；不是互相安装装备，也不能套用“交换双方全部装备区牌”的另一段流程。若一名为自己，随后由自己对另一名或其队列视为使用一张杀，文本给出单名角色或其队列两个目标组，不是任意选择其中若干。

## 锥形

**技能原文**：锥形：阵法技，若你为围攻角色，被你围攻的角色对你使用【杀】伤害-1；若你为被围攻角色，你对围攻你的角色使用【杀】伤害+1。

**结算分析**：阵法状态技，自己为围攻者时，被自己围攻者对自己使用杀伤害-1；自己为被围攻者时，对围攻自己的角色使用杀伤害+1。两个方向各查真实围攻关系，不能简单按敌友、相邻或攻击范围判断；不修改无关角色或自己非杀伤害。
