# JIN024 贾南风：权包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“权”包记录，并对照紫乔 B 站大合集专栏（`1178873011318554633`）及 2026-11-21 已确认裁定整理；本页为规则定稿依据，不表示已实装。

## 将牌资料

- 称号：司晨的丹鴸。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：无。
- 公共依据：[通用约定](../general-principles.md)、[武将位置、武将牌与士兵牌](../general-principles.md#武将位置武将牌与士兵牌)、[失去技能的状态归属](../general-principles.md#失去技能的状态归属)及[权包索引](../quan-generals.md)。

## 伤败

**技能原文**：伤败：当你对其他角色造成伤害后，你可以令其弃置每个区域各一张牌。

**结算分析**：
- 触发时机：贾南风对其他角色造成伤害后（每次伤害事件触发一次；目标须仍存活在场，且至少有一个区域有牌可弃置）。
- 效果结算：令受伤角色自己依次从其**手牌区、装备区、判定区**各选择并弃置 1 张牌（无牌的区域跳过；判定区的延时锦囊牌允许被正常弃置，与【无当飞军】一致）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（弃置每个区域各一张牌）。

## 废戮

**技能原文**：废戮：每名角色限一次，当一名角色进入濒死时，你可以令其选择一项：1.你移除其一个武将，其回复1点体力；2.你失去此技能，其死亡。

**结算分析**：
- 触发时机：任意角色（含贾南风本人）进入濒死状态时，**每名角色限一次**（整局对同一名目标角色最多发动一次【废戮】）。
- 选项 1（移除武将救回）：“你移除其一个武将，其回复 1 点体力”：
  - 由贾南风选择目标的一个**可移除的普通武将牌**（排除君主武将牌、明置专属野心家武将牌以及普通士兵/翼从/偏将，依据[位置与牌类别](../general-principles.md#武将位置武将牌与士兵牌)），将其移除（该位置变为士兵并按统领规则转换，被移除武将牌按[移除武将牌](../../../rulebook/terms/general-op-terms/remove.md)进入[武将弃牌堆](../../../rulebook/terms/zone-terms/wujiangpaidui.md#武将弃牌堆)，本局不能再被检索或抽取），然后目标回复 1 点体力。
  - 若目标体力值仍 `<= 0`，则继续处于濒死状态求桃；若恢复至 `>= 1`，则脱离濒死。
  - 若目标当前**没有任何可移除的普通武将牌**（例如仅剩君主/士兵），则选项 1 **不可选**，目标只能选择选项 2。
- 选项 2（废技即死）：“你失去此技能，其死亡”：
  - 贾南风失去【废戮】（按[失去技能的状态归属](../general-principles.md#失去技能的状态归属)，记在该武将牌上）；
  - 目标角色**直接死亡**（立即进入[死亡结算流程](../turn-death-and-reveal-timing.md#4-死亡结算完整时序)，跳过常规求桃流程），本次死亡按**无伤害来源**结算（不触发击杀奖惩）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（移除一个武将回 1 血 / 失去废戮其死亡）。
2. 贾南风**自己**进入濒死时允许发动【废戮】。
3. 目标无可移除的普通武将牌时，选项 1 **不可选**，只能选选项 2。
4. 选项 2 令目标死亡按**无来源死亡**结算。
