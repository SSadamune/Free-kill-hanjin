## 养刀

**技能原文**：养刀：锁定技，若你的装备区里没有武器牌，你视为装备着场上攻击范围最大的所有武器牌。

**结算分析**：
- 锁定技，生效前提是成济&成倅自己的**装备区里没有实体武器牌**。
- 筛选对象：扫描当前**场上**所有存活在场角色（含装备着真实武器的角色，不含移出游戏角色，亦不含其他仅靠“视为装备”获得武器的角色以避免循环）装备区里的全部武器牌，找出其中的**最大攻击范围值 `M`**，成济&成倅视为同时装备着场上所有攻击范围等于 `M` 的武器牌（获得这些武器的攻击范围 `M` 及其武器技能，不占用武器栏）。
- 若场上没有任何实体武器牌，则【养刀】无武器可视为装备，攻击范围保持基础值 1。
- **虚拟装备边界**：与袁术【伪帝】一致，“视为装备着武器牌”仅赋予攻击范围与武器技能，**不**在装备区产生实体武器牌（不能被弃置/获得/移动，也不能对不存在的实体武器执行装备区合纵或重铸；常规【借刀杀人】因无实体武器牌不能指定其为目标）。

## 畜鸣

**技能原文**：畜鸣：其他角色出牌阶段限一次，其可以将一张【杀】当【酒】对你使用，然后将此【杀】交给你并视为对你使用一张无视武器限制的【借刀杀人】或【过河拆桥】。

**结算分析**：
- 供其他角色发动的公共主动入口，每名其他角色在自己的出牌阶段限一次，仅当成济&成倅明置在场时开放。
- 执行流程：
  1. 该其他角色选择一张手牌【杀】（含属性杀）转化当【酒】**对成济&成倅使用**：**不占用发起者自己本回合的饮酒次数**，也不受发起者已饮酒限制，令成济&成倅在当前他人回合内进入“下一张【杀】伤害 +1”的饮酒状态（配合随后【借刀杀人】出杀暴击，本回合结束时按常规清除）；
  2. 然后将该张实体【杀】从处理区**交给成济&成倅**（进入成济&成倅手牌区）；
  3. 紧接着该其他角色二选一，视为对成济&成倅使用一张：
     - **无视武器限制的【借刀杀人】**以成济&成倅为主目标，即使其装备区没有武器也可选择此项。有合法次目标时，发动者须在成济&成倅当前攻击范围内（含【养刀】提供的范围）指定一人，成济&成倅可以对其使用【杀】。没有合法次目标时，跳过指定次目标及出【杀】，直接处理交武器。凡未使用【杀】，若成济&成倅装备区有实体武器，就交给【借刀杀人】的使用者一张。若没有实体武器，则无事发生。见[汉晋牌表中的借刀杀人](../card-deck.md#普通锦囊与装备的审阅结论)。
     - **【过河拆桥】**：对成济&成倅使用一张无实体牌的【过河拆桥】（刚收到一张【杀】，通常必有牌可拆）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（将【杀】当【酒】对成济&成倅使用 + 交【杀】 + 视为用无视武器限制的【借刀杀人】或【过河拆桥】）。
2. 将【杀】当【酒】对成济&成倅使用**不占发起者自己的饮酒次数**，且令成济&成倅在当前他人回合内进入饮酒增伤状态。
3. 依紫乔专栏注释，无视武器限制的【借刀杀人】中若成济&成倅不出【杀】且无武器牌，则直接无事发生。
