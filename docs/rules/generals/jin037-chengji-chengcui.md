## 养刀

**技能原文（JSON）**：养刀：锁定技，若你的装备区里没有武器牌，你视为装备着场上攻击范围最大的所有武器牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 末尾多写一句“，且仍能成为【借刀杀人】的目标”（JSON 将无视武器限制移入【畜鸣】中，故【养刀】删去该句）。

**结算分析（按 JSON 口径）**：
- 锁定技，生效前提是成济&成倅自己的**装备区里没有实体武器牌**。
- 筛选对象：扫描当前**场上**所有存活在场角色（含装备着真实武器的角色，不含移出游戏角色，亦不含其他仅靠“视为装备”获得武器的角色以免循环）装备区里的全部武器牌，找出其中的**最大攻击范围值 `M`**，成济&成倅视为同时装备着场上所有攻击范围等于 `M` 的武器牌（获得这些武器的攻击范围 `M` 及其全部武器技能，且不占用自己的武器栏）。
- 若场上没有任何实体武器牌，则【养刀】无武器可视为装备，攻击范围保持基础值 1。
- **虚拟装备边界**：与袁术【伪帝】一致，“视为装备着武器牌”仅赋予攻击范围与武器技能，**不**在装备区产生实体武器牌（因此不能被【过河拆桥】/【顺手牵羊】弃置或获得；除非另有特例，常规【借刀杀人】因成济&成倅装备区无真实武器牌而无法指定其为目标）。
- **循环防重**：若场上同时有两名拥有【养刀】的角色且均无实体武器，彼此的“视为装备”不互相引用计数。

## 畜鸣

**技能原文（JSON）**：畜鸣：其他角色出牌阶段限一次，其可以将一张【杀】当【酒】对你使用，然后将此【杀】交给你并视为对你使用一张无视武器限制的【借刀杀人】或【过河拆桥】。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“其他角色的出牌阶段限一次，其可以交给你一张【杀】并令你下次造成或受到的伤害+1，视为对你使用【借刀杀人】或【过河拆桥】。”两版核心差异在前半段是“将杀当酒对你使用”还是“交杀并建立下次伤害/受伤 +1”。

**结算分析（按 JSON 口径）**：
- 供其他角色发动的公共主动入口（类似【激将】/【聚宝】外的旗/公共主动技），每名其他角色在自己的出牌阶段限一次，仅当成济&成倅明置在场时开放。
- 执行流程（JSON）：
  1. 该其他角色选择一张手牌【杀】（含属性杀）转化当【酒】**对成济&成倅使用**（注意：通常【酒】目标为自己，此处技能特例允许对成济&成倅使用，使成济&成倅获得饮酒状态——成济&成倅本回合下一张【杀】伤害 +1；该【酒】是否占用该其他角色的饮酒次数，须主创确认）；
  2. 然后将该张实体【杀】从处理区**交给成济&成倅**（进入成济&成倅手牌区）；
  3. 紧接着该其他角色二选一，视为对成济&成倅使用一张：
     - **无视武器限制的【借刀杀人】**（即使成济&成倅装备区没有实体武器牌，也能被指定为【借刀杀人】主目标；发动者须为其指定合法的被杀目标，该被杀目标须处于成济&成倅当前攻击范围内，含【养刀】提供的攻击范围；若成济&成倅不出【杀】，因装备区无实体武器牌则无武器可交，若有实体武器则照常交出）；
     - **【过河拆桥】**（须成济&成倅区域内有牌——注意刚交给他一张【杀】，此时他至少有 1 张手牌，故【过河拆桥】通常必合法）。

**待主创确认**：
1. 【养刀】【畜鸣】以 JSON 新版还是 CSV 旧版为准？按既有惯例拟采用 JSON 新版，请确认。
2. JSON 版【畜鸣】中“将一张【杀】当【酒】对你使用”：
   - 对成济&成倅使用的这张【酒】，使成济&成倅处于“饮酒”状态——因是在**其他角色的回合内**，该饮酒状态自然在当前回合有效（配合紧接着的【借刀杀人】让成济&成倅出的【杀】伤害 +1，当前回合结束时按常规清除），并且**不占用**发起者自己本回合的饮酒次数，也不受发起者已饮酒的限制，是否确认？
   - 若成济&成倅本回合已经因他人或自己饮过酒，是否仍可再次被发动【畜鸣】（或酒效果不叠加）？
3. JSON 版【养刀】中，若场上攻击范围最大的武器包含带特殊交互的武器（如【方天画戟】、【丈八蛇矛】、【神授思召】），成济&成倅获得这些武器技能；但因为是“视为装备”无实体牌，涉及“重铸/合纵此装备牌”或“失去此装备牌”的效果（如【白银狮子】虽为防具不算，但【神授思召】装备区合纵）无法移动不存在的实体牌，是否确认？
