# JIN038 杨骏

不臣篇（中） · 普通 · 称号“阶缘荷栋”。

势力为晋。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 截诏：你可以将一张牌置于牌堆顶以进行<助战>；你可以通过<助战>自己触发锦囊牌应变效果。当你<助战>锦囊牌后，你可以取消此牌，然后令使用者视为使用另一种由你指定的单目标普通锦囊牌（须指定由你指定的一个原目标）。

## 结算

〖截诏〗以置顶代替通常的助战支付，可为自己的锦囊助战。成功助战锦囊才可取消它，另由原使用者使用另一种单目标普通锦囊，杨骏指定的目标取自原目标且须合法。

## 验收场景

杨骏指定原目标甲，若甲与使用者同势力，不能指定改用【远交近攻】指甲；原牌曾经合法选中甲不能免去新牌的自身条件。
