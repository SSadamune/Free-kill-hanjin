# JIN038 杨骏

不臣篇（中） · 普通 · 称号“阶缘荷栋”。

势力为晋。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 截诏：你可以将一张牌置于牌堆顶以进行<助战>；你可以通过<助战>自己触发锦囊牌应变效果。当你<助战>锦囊牌后，你可以取消此牌，然后令使用者视为使用另一种由你指定的单目标普通锦囊牌（须指定由你指定的一个原目标）。

## 结算

〖截诏〗允许杨骏将一张牌置于牌堆顶来替代通常的<助战>消耗，并且可以通过<助战>自己来触发锦囊牌的应变效果。当杨骏成功<助战>锦囊牌后，可以取消该锦囊牌，然后令原使用者视为使用另一种由杨骏指定的单目标普通锦囊牌；杨骏须从原目标中指定一名角色作为新锦囊牌的目标，且该目标必须满足新锦囊牌自身的合法性条件。

## 验收场景

若杨骏从原目标中指定了角色甲，且甲与原使用者势力相同，则杨骏不能指定改用【远交近攻】指向甲；原锦囊牌曾经合法选中甲，并不能免除新锦囊牌自身的目标条件限制。
