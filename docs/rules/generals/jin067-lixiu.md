## 替军

**技能原文（JSON / CSV 一致）**：替军：判定阶段开始前，你可以将场上一张延时锦囊牌移至你判定区，或将一张装备牌置入任意角色装备区。若如此做，此阶段改为出牌阶段。

**结算分析**：
- 触发时机：李秀自己的**判定阶段开始前**（尚未进入判定阶段，因此即使判定区原本无牌也会经历判定阶段开始前窗口；若已被跳过判定阶段则不触发）。
- 二选一前置动作（“若如此做”须实际完成其中一项）：
  1. **移动场上一张延时锦囊牌至自己判定区**：从场上任意其他角色的判定区选 1 张延时锦囊牌（须符合判定区同名不重复等合法目标规则，不能把已在自己判定区的牌原地移动）移入李秀自己的判定区；
  2. **将一张装备牌置入任意角色装备区**：从李秀的**手牌区或装备区**（按[通用约定](../general-principles.md)未特别说明归属时指自己的牌）选择 1 张装备牌，置入场上任意角色（含李秀自己，若选装备区里的牌则不能置入自己原栏位）的装备区（按[装备移动与置入](../equipment-movement.md)，“置入”可替换目标原栏位旧装备，或按空栏口径须主创确认）。
- 阶段改写：完成上述操作后，原本的**判定阶段改为出牌阶段**（跳过判定阶段，立即执行一个额外的出牌阶段；之后照常进入摸牌阶段、原本的出牌阶段、弃牌阶段和结束阶段）。

## 誓众

**技能原文（JSON）**：誓众：每阶段限一次，你使用【杀】时可以多指定至多X个目标（X为你场上的牌数），若目标角色场上牌数各不相同，你摸等同目标数的牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 次数写作“**出牌阶段**限一次”（JSON 为“**每阶段**限一次”，可配合回合外或双出牌阶段分别触发）。

**结算分析（按 JSON 口径）**：
- 触发时机：**每阶段限一次**（结合【替军】一回合两个出牌阶段时，每个出牌阶段各可发动一次），当李秀使用【杀】选择目标时（`AfterCardTargetDeclared` / 额外目标窗口）。
- 额外目标数：计算 `X = 李秀当前场上牌数`（即李秀**装备区牌数 + 判定区牌数**；不含手牌，与【替军】拉延时锦囊进自己判定区、或给自己置入装备高度联动！）。若 `X >= 1`，李秀可按[指定额外目标](../extra-targets.md)为该【杀】多指定 `1 ~ X` 名合法目标（须在攻击范围内且符合【杀】的目标合法性）。
- 摸牌奖励：若发动了【誓众】增加目标，检查此次【杀】**所有最终目标角色**（含原目标与新增目标，计总目标数为 `Y`）各自的**场上牌数**（装备区 + 判定区牌数）是否**两两互不相同**（例如 3 名目标的场上牌数分别为 0、1、3 则满足；若出现两名目标均为 0 则不满足）；若满足，李秀摸 `Y` 张牌。

**待主创确认**：
1. 【誓众】次数以 JSON（“每阶段限一次”）还是 CSV（“出牌阶段限一次”）为准？拟以 JSON 为准，请确认。
2. 【替军】选项 2“将一张装备牌置入任意角色装备区”：
   - 该装备牌明确指**李秀自己的装备牌**（手牌区或装备区），不包含其他角色装备区的牌（选项 1 写明了“场上一张延时锦囊牌”，选项 2 未写“场上”）；
   - 按[装备移动与置入](../equipment-movement.md)，主动“置入”默认要求空栏还是允许顶替目标旧装备？（注意项目[equipment-movement.md](../equipment-movement.md)已裁定汉晋“置入装备区”默认移入**空置**对应装备栏，除非明文允许替换；请确认【替军】是否同样遵守空栏规则。）
3. 【誓众】“若目标角色场上牌数各不相同”是否仅在**实际发动【誓众】多指定了至少 1 名目标**后才判断摸牌（不能在 `X = 0` 或不加目标时白嫖单目标摸 1 牌）？按“可以多指定至多 X 个目标，若……”句式应以实际发动加目标为前提，请确认。
