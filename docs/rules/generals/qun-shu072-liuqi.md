# QUN&SHU072 刘琦

不臣篇（上） · 普通 · 称号“棲江望巢”。

势力为群、蜀。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 问计：出牌阶段开始时，你可以令一名其他角色展示并交给你一张牌，本回合你使用此牌不能被响应，若其与你势力不同，你交给其另一张牌。

> 屯江：结束阶段，若你于本回合使用过牌且未指定其他势力角色，你可以摸等同势力数的牌。

## 结算

〖问计〗标记被展示并交来的那一张，本回合刘琦使用它不能被响应。返还异势力角色的须是另一张牌。〖屯江〗回看本回合实际用牌及指定的角色。

## 验收场景

刘琦整回合没有用牌，结束阶段不能发动〖屯江〗。若只对自己用过【桃】，且没有指定过其他势力角色，可以发动。
