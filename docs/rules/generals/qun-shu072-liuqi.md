# QUN&SHU072 刘琦

不臣篇（上） · 普通 · 称号“棲江望巢”。

势力为群、蜀。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 问计：出牌阶段开始时，你可以令一名其他角色展示并交给你一张牌，本回合你使用此牌不能被响应，若其与你势力不同，你交给其另一张牌。

> 屯江：结束阶段，若你于本回合使用过牌且未指定其他势力角色，你可以摸等同势力数的牌。

## 结算

〖问计〗会标记其他角色展示并交给刘琦的那一张牌，本回合刘琦使用该牌时不能被其他角色响应；若对方与刘琦势力不同，刘琦交还给对方的必须是另一张牌。〖屯江〗在结束阶段回看本回合内刘琦实际使用过的所有牌及其指定过的目标角色。

## 验收场景

如果刘琦整个回合内没有使用过任何牌，则在结束阶段不能发动〖屯江〗；如果刘琦本回合只对自己使用过【桃】，且未指定过其他势力角色为目标，则满足条件，可以发动〖屯江〗。
