# QUN&WEI&WU035 公孙渊（效忠版）

不臣篇（下） · 效忠版 · 称号“狡徒悬海”。

势力为群、魏、吴。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

对应专属野心家版见[公孙渊（AM(QUN&WEI&WU035)）](am-qun-wei-wu035-gongsunyuan.md)。选将及准备阶段升变见[野心家效忠](../wild-allegiance.md)。

## 卡面原文

> 怀异：出牌阶段限一次，你可以展示手牌，若包含两种颜色，你弃置其中一种颜色的牌，获得至多等量名其他角色各一张牌，然后若你因此获得了至少两张牌，你失去1点体力。

## 结算

〖怀异〗展示手牌后，必须同时包含两种颜色，才可以弃置其中一种颜色的牌。根据弃牌数限制获得牌的角色数量，每名其他角色只能获得一张牌，然后再按实际获得牌的数量判断是否失去体力。

## 验收场景

公孙渊弃置三张黑色牌后，若只从甲处获得一张牌，则不失去体力；若从甲、乙处各获得一张牌，则共获得两张牌，须失去 1 点体力。
