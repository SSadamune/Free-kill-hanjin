# QUN&WEI048 张鲁

不臣篇（上） · 普通 · 称号“米道师君”。

势力为群、魏。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 米教：出牌阶段限一次，你可以令一名与你手牌数之差至多为2的其他角色将手牌调整至与你相同。若其因此摸牌，你可以对其造成1点雷电伤害；若其因此弃牌，你可以令其回复1点体力。

> 归安：当作为大势力的势力变化后，你可以令一至两名势力大小与你相同的角色各摸一张牌。

## 结算

〖米教〗选手牌差不超过二的其他角色，按调至相等时实际摸牌或弃牌分别开放雷伤或回复。〖归安〗比较变动前后的大势力集合，再按势力大小筛选摸牌者。

## 验收场景

甲、乙并列大势力，随后只剩甲为大势力。集合已变，可发动〖归安〗。若成员人数有变但大势力仍只有甲，仅此不足以发动。
