# QUN002 吕布：无双与虓猛

卡面来源见[标准武将表](../standard-generals.md)。本页记录原文与既有公共规则的应用，不新增技能效果。

- 无双为“多一张”，在当前所需响应张数上增加一张，不能固定为两张覆盖其他增量。使用【杀】时修改相应目标的【闪】数；指定或成为【决斗】目标时修改对方每次打出【杀】的数量。
- 虓猛适用于使用的【决斗】，不增加“非转化”条件；每回合限一次，由当前回合角色选择额外目标，不由吕布代选。
- 虓猛明确指定候选为“与你势力不同”的角色，依[额外目标规则](../extra-targets.md)处理这一显式条件；“你”指技能拥有者吕布，不改为代选的当前回合角色。
- 其余条件满足时，即使没有合法额外目标，也向当前回合角色显示选人询问。没有目标可选时只能取消，取消不消耗本回合发动次数。
- 已写入某次用牌的响应数量和目标不因随后暗置、失技而撤销，参见[技能效果分类](../../../rulebook/topics/skill-effect-classification.md)。

实现须区分无双与虓猛，不能将上游无双自带的额外决斗目标直接并入汉晋无双。方向见[群包审阅](../../development/implementation/generals/qun-standard.md)。
