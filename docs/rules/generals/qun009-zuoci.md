## 化形

**技能原文**：化形：当你受到1点伤害后、其他角色脱离濒死时或出牌阶段限一次，你可以将一张（首次发动时改为三张）剩余武将牌扣置于武将牌上，称为“魂”，然后选择一项：1.移去一张“魂”；2.将副将武将牌额外变更为一张“魂”。

**结算分析**：
- **三个触发入口**（相互独立，均触发同一套置“魂”+二选一流程）：
  1. 当左慈每受到 1 点伤害后（按伤害点数逐次触发，如受 2 点伤害可触发 2 次）；
  2. 当其他角色脱离濒死时；
  3. 出牌阶段限一次（主动技入口）。
- **前置动作（扣置“魂”）**：
  - 从本局剩余的[技能可用武将牌堆](../card-categories-and-operations.md#技能调用的武将牌堆)中**不限势力**随机抽取 **1 张**（按左慈武将牌整局**首次发动【化形】时改为 3 张**），扣置于左慈武将牌上，称为「魂」（仅左慈本人可见、对其他角色暗置；牌堆剩余不足时取全部，牌堆完全为空时不能执行扣置）。
  - 随牌归属：「魂」属于左慈武将牌上的牌堆，交换武将时随左慈武将牌转移（见[交换武将](../general-exchange.md#哪些状态随牌移动)），不因左慈暗置而移去。
- **然后二选一**：
  1. **选项 1：移去一张“魂”**：从当前「魂」中选 1 张移去（按汉晋[武将弃牌堆](../../development/implementation/guest-factions.md#自愿重抽与弃牌堆)加入 `qiao_general_discard_v1` 与 `disabled_generals`，从本局将池移除）。
  2. **选项 2：将副将武将牌额外变更为一张“魂”**：
     - 依紫乔专栏注释，“将副将武将牌额外变更为魂”无视一般变更“限一次”的次数限制、翻三选一的设定与势力限制，直接将**不为士兵（且非君主）的副将武将牌**变更为任意一张「魂」（若「魂」为野心家则须为洗白形态）；若副将位置无合资格武将牌则不能选选项 2。
     - 被选中的「魂」以**明置状态**成为左慈的新副将（左慈本人势力保持不变，新副将主/副将技按副将位生效）。
     - 被换下来的**旧副将牌**按项目已有的普通变更 / [武将弃牌堆](../../development/implementation/guest-factions.md#自愿重抽与弃牌堆)规则处理：加入 `qiao_general_discard_v1` 与 `disabled_generals` 并从 `general_pile` 移除（由 `general_discard.lua` 拦截，本局后续取将及回池都不会重新放入，不扣回「魂」区）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 与紫乔专栏的单技能【化形】版。
2. 「魂」从剩余武将牌堆中**不限势力**随机抽取，扣置且**仅左慈本人可见**。
3. 选项 2 变更后，被换下的**旧副将牌按普通变更进入汉晋武将弃牌堆**（`qiao_general_discard_v1` / `disabled_generals`，不再回池，不扣回「魂」区）。
