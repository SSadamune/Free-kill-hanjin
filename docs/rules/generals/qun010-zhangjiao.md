# QUN010 张角：鬼道的替换

卡面来源见[标准武将表](../standard-generals.md)。用户于 2026-11-15 确认：“替换”指获得原判定牌，“代替”指不获得原判定牌，公共区别见[通用约定](../general-principles.md)。

- 鬼道在判定牌生效前打出一张自己的黑色牌替换之，包含手牌、装备牌；须完成真实打出，并获得原判定牌。
- 鹰视的“代替”不获得原判定牌，不能因共用改判接口而混同两者。
- 判定使用最终生效的判定牌，参见[判定事件](../../../rulebook/events/judge.md)。同一角色对同一判定的响应次数依[结算原则](../../../rulebook/definitions/settlement-principles.md)，不通过重复改判绕过。
