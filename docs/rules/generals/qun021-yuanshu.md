## 庸肆

**技能原文**：庸肆：出牌阶段限一次，你可以对本回合摸过牌的一名其他角色发起“军令”。若其不执行，你获得其所有手牌，然后交给其等量的牌。

**结算分析**：
- 主动技，出牌阶段限一次。
- 目标条件：本回合内**执行过“摸牌”动作**（包含摸牌阶段摸牌及技能/卡牌效果令其摸牌，不含非摸牌途径从牌堆获得）的一名其他在场角色。
- 发起军令：按[军令](../../../rulebook/terms/description-terms/junling.md)结算。
- 不执行分支：
  1. 袁术获得目标当前**所有手牌**（记录实际获得的张数 `N`；若目标此时手牌数为 0，则 `N = 0`，不执行后续交牌）；
  2. 然后袁术交给目标**等量（`N` 张）的牌**（手牌或装备区牌均可，包含刚才从目标手上拿到的牌；因刚获得 `N` 张手牌，袁术此时牌数必 `>= N`）。
  - 注意：若目标是法正且 `N >= 2`，袁术交还 `N` 张牌时会触发法正【恩怨】第一段。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 与紫乔专栏口径，条件为“本回合摸过牌”。

## 伪帝

**技能原文**：伪帝：锁定技，若场上没有【玉玺】，你视为装备着【玉玺】；当你成为【知己知彼】的目标后，你展示所有手牌。

**结算分析**：
- 锁定技，包含两段独立效果：
  1. **视为装备【玉玺】**：检查当前**场上**（公开装备区，不含手牌、弃牌堆、移出游戏角色装备区）是否存在【玉玺】。若场上没有【玉玺】，则袁术视为装备着【玉玺】（复用汉晋正式【玉玺】装备技能：视为唯一大势力、摸牌阶段摸牌数 +1、出牌阶段开始时视为使用【知己知彼】）。
     - 按常规“视为装备”口径，仅享有【玉玺】装备技能效力，**不在装备区产生实体牌、不占用宝物栏、不计入装备区牌数，且不可被弃置、获得或交换**；一旦场上有角色实际装备【玉玺】，此视为效果自动暂停，待场上再次没有【玉玺】时恢复。
  2. **【知己知彼】负面**：当袁术成为【知己知彼】的目标后（即使该【知己知彼】随后被【无懈可击】抵消，因时机为“成为目标后”），袁术展示其所有手牌（无手牌则不展示）。
