## 庸肆

**技能原文（JSON）**：庸肆：出牌阶段限一次，你可以对本回合摸过牌的一名其他角色发起“军令”。若其不执行，你获得其所有手牌，然后交给其等量的牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 将目标条件写作“本回合**从牌堆获得过牌**的一名其他角色”（范围比“摸过牌”更宽，包含【观星】外如【落英】/亮出从牌堆获得等非“摸牌”途径）。

**结算分析（按 JSON 口径）**：
- 主动技，出牌阶段限一次。
- 目标条件（JSON）：本回合内**执行过“摸牌”动作**（包含摸牌阶段摸牌及技能/卡牌效果令其摸牌）的一名其他在场角色。
- 发起军令：按[军令](../../../rulebook/terms/description-terms/junling.md)结算。
- 不执行分支：
  1. 袁术获得目标当前**所有手牌**（记录实际获得的张数 `N`；若目标此时已无手牌，`N = 0`）；
  2. 然后袁术交给目标**等量（`N` 张）的牌**（手牌或装备区牌均可，包含刚才从目标手上拿到的牌；因刚获得 `N` 张手牌，袁术此时牌数必 `>= N`）。
  - 注意：若目标是法正且 `N >= 2`，袁术交还 `N` 张牌时会触发法正【恩怨】第一段。

**待主创确认**：
1. 目标条件采用 JSON（“本回合摸过牌”）还是 CSV（“本回合从牌堆获得过牌”）？拟采用 JSON，请确认。
2. 当目标执行军令或本身在回合内失去全部手牌导致不执行时手牌数为 0，仍可发动【庸肆】发起军令，不执行时“获得 0 张、交还 0 张”，是否确认？

## 伪帝

**技能原文（JSON / CSV 一致）**：伪帝：锁定技，若场上没有【玉玺】，你视为装备着【玉玺】；当你成为【知己知彼】的目标后，你展示所有手牌。

**结算分析**：
- 锁定技，包含两段独立效果：
  1. **视为装备【玉玺】**：检查当前**场上**（公开装备区，不含手牌、弃牌堆、移出游戏角色装备区）是否存在【玉玺】。若场上没有【玉玺】，则袁术视为装备着【玉玺】（复用汉晋正式【玉玺】装备技能：视为唯一大势力、摸牌阶段摸牌数 +1、出牌阶段开始时视为使用【知己知彼】）。
     - 注意：袁术的宝物栏并不被真实实体【玉玺】占用，仍可正常装备其他宝物牌（如【木牛流马】、【定澜夜明珠】）；一旦场上有其他角色（或袁术自己）实际装备了【玉玺】，此“视为装备”自动失效，待场上再次没有【玉玺】时恢复。
     - 同样受“场上没有”的公开性原则约束，不检查他人手牌中是否藏着【玉玺】。
  2. **【知己知彼】负面**：当袁术成为【知己知彼】的目标后（即使该【知己知彼】随后被【无懈可击】抵消，因时机为“成为目标后”），袁术展示其所有手牌（无手牌则不展示）。

**待主创确认**：
1. 袁术“视为装备着【玉玺】”期间，是否计入“你装备区里有宝物牌 / 你装备区里有牌”的牌数统计？（按三国杀与新月杀常规，“视为装备着某装备”仅获得该装备技能效力，**不**在装备区产生实体牌、**不**增加装备区牌数，也不能被【过河拆桥】/【顺手牵羊】/【甘露】弃置、获得或交换；请确认。）
2. 若场上有多名角色同时拥有【伪帝】（例如其他角色复制/获得【伪帝】）且场上没有【玉玺】，多名角色同时视为装备【玉玺】时，“视为唯一大势力”的冲突如何处理（均视为大势力或均按【玉玺】自身规则处理）？
