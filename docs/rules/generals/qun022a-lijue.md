## 凶算

**技能原文（JSON）**：凶算：限定技，出牌阶段，你可以弃置一张手牌并对一名与你势力相同的角色造成1点伤害，然后摸三张牌，回合结束时复原其一个限定技。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 目标写作“对一名角色”（未限“与你势力相同”），且复原限定技写作“令其一个已发动的限定技视为未发动过”。

**结算分析（按 JSON 口径）**：
- 限定技，主动技，出牌阶段空闲时间点发动。
- 发动消耗：弃置 1 张手牌（须实际弃置手牌，不能弃装备区牌）。
- 合法目标：与李傕势力相同的在场角色（按[同势力判定](../general-principles.md)，**包含李傕本人**）。
- 结算流程：
  1. 对所选同势力角色造成 1 点普通伤害；
  2. 然后（伤害事件结算完，即使该伤害被防止或目标濒死被救回，仍依通常结算；若目标因此死亡则后续复原限定技自然无从执行）李傕摸 3 张牌；
  3. 建立延时效果：在当前**回合结束时**（回合级时机），若该目标仍存活且拥有至少一个**已发动过的明置限定技**，选择其中 1 个令其复原（视为未发动过）。
  - 注意：若目标是李傕自己，在回合结束时可以选择复原刚才用掉的【凶算】本身（从而实现自伤循环），除非明文排除！此点须请主创确认。

**待主创确认**：

2. 当李傕对**自己**发动【凶算】时，回合结束时是否允许选择复原**【凶算】自身**（按字面“复原其一个限定技”在回合结束时【凶算】已是已发动限定技，原版国战李傕正是经典自刷凶算逻辑；请确认汉晋是否保留该机制）？
3. “回合结束时复原其一个限定技”的限定技选择权归**李傕**还是**目标角色**？（按“复原其一个限定技”主语为李傕，应由李傕选择；请确认。）

## 挠袭

**技能原文（JSON）**：挠袭：每回合限一次，当你使用普通锦囊牌后，你可以减1点体力上限并视为再使用一张同牌名的牌（不能包含相同的目标）。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 次数写作“**出牌阶段**限一次”（JSON 为“每回合限一次”）。

**结算分析（按 JSON 口径）**：
- 触发时机：每回合限一次，当李傕**使用一张普通锦囊牌后**（即该普通锦囊牌完全结算结束后；延时锦囊与基本/装备牌不触发；【无懈可击】虽属普通锦囊，但目标为牌且需对应响应时机，实际“使用后”已无待抵消窗口，不能再合法视为使用）。
- 发动消耗：减 1 点体力上限（若当前体力上限为 1，减至 0 会直接死亡，无法继续视为使用）。
- 效果结算：视为再使用一张与原牌**同牌名**的普通锦囊牌（无实体牌、无花色点数；不继承原牌的实体应变标记，除非原牌名本身自带）。
- 目标排除限制（“不能包含相同的目标”）：
  - 新牌指定的目标角色集合，与原牌曾指定过的目标角色集合**交集必须为空**；
  - 因此若原牌是【以逸待劳】、【五谷丰登】、【桃园结义】、【挟天子以令诸侯】等固定包含自己或全体角色的锦囊，或者场上除原目标外已无其他合法目标（如【南蛮入侵】、【万箭齐发】已指定所有其他角色，除非有角色刚从移出游戏归来或原牌被取消目标？注意排除的是曾指定目标），则无法为新牌选出合法目标，不能发动（或先校验存在合法不重叠目标再允许减上限发动，避免空扣上限）。
  - 对于【借刀杀人】，主目标不得与原主目标相同，副目标（被杀角色）是否也不得重叠须注意：通常“目标”指该牌的目标角色（即被借刀者）。

**待主创确认**：
1. 次数限制以 JSON（“每回合限一次”）还是 CSV（“出牌阶段限一次”）为准？拟以 JSON 为准，请确认。
2. 若场上不存在满足“不能包含相同目标”的合法新目标，是否**禁止发动【挠袭】**（防止白扣 1 点体力上限）？另，对群体锦囊（如【南蛮入侵】）若原牌结算后场上所有存活角色都曾是原目标，则无法发动；若恰有角色此前不在目标内（如被调虎离山移出游戏后若非回合末仍不在），仅针对合法且未重复的目标使用，请确认。

## 关联翼从：飞熊军

- 统领来源：李傕（QUN022A）提供 `{统领：飞熊军 |【火攻】}`，普通翼从（非偏将）。
- **翼从技能原文（JSON）**：限定技，出牌阶段，你可以选择一名体力值与你相同的其他角色，依次视为对其使用一张【顺手牵羊】和一张【杀】。
- **结算分析**：
  - 限定技，主动技，出牌阶段空闲时间点发动（每个【飞熊军】独立实例各自拥有一次限定技机会，见[翼从独立实例](../commander-retinue.md#拥有数量与独立实例)）。
  - 合法目标：一名与持有者**当前体力值相同**的其他在场角色。
  - 结算流程：先视为对该目标使用一张【顺手牵羊】，结算完毕后（若双方仍存活在场且合法），再视为对该目标使用一张普通【杀】（不计入且无视通常出杀次数）。
  - **距离与区域边界**：
    - 目标是由技能指定的“一名体力值与你相同的其他角色”，未要求距离为 1 或在攻击范围内——因此这两张视为使用的【顺手牵羊】和【杀】是否**无视距离限制**，以及当目标区域无牌（无法成为【顺手牵羊】合法目标）时，是否跳过【顺手牵羊】直接视为使用【杀】，均须主创确认。
