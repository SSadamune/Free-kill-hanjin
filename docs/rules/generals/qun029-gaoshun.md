## 迅击

**技能原文（JSON）**：迅击：每回合结束时，你可以依次视为对任意名本回合使用过【酒】的角色或明置过武将牌的非当前回合角色各使用一张【杀】。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为完全不同的旧版本：“其他角色于其回合外明置武将牌后，你可以视为对其使用一张【杀】。”（JSON 改为每回合结束时集中结算，且囊括“本回合使用过【酒】的角色”与“本回合明置过武将牌的非当前回合角色”两类目标。）

**结算分析（按 JSON 口径）**：
- 触发时机：每名角色的**回合结束时**（回合级时机）。
- 候选角色集合（满足其一的存活在场角色，排除高顺自己——无法对自己用【杀】）：
  1. 本回合内**使用过【酒】**的角色（不限是否为当前回合角色，含主动喝酒与濒死喝酒自救）；
  2. 本回合内**明置过武将牌**的**非当前回合角色**（例如回合外因响应阵法召唤、受伤发动技能等亮将的角色；当前回合角色自己回合开始亮将不满足此项）。
- 效果结算：高顺从候选集合中选择任意名角色，按指定顺序或座次**依次**视为对每名所选角色使用一张普通【杀】（无实体牌；因为是技能指定目标视为用【杀】，须确认是否**无视距离限制**；每次视为用【杀】独立结算）。

## 擐甲

**技能原文（JSON）**：擐甲：当你指定/成为【杀】的目标后，你可以将一个目标/使用者装备区的一张牌置入你装备区，结算后将你装备区同副类别的牌移动给其。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 有三处限制：① 每回合限一次；② 仅限唯一目标的【杀】；③ 仅限武器或防具牌，且结算后置回“以此法置入的牌”（JSON 删去了每回合限一次、唯一目标和武器/防具限制，并将归还改为“将你装备区**同副类别的牌**移动给其”）。

**结算分析（按 JSON 口径）**：
- 触发时机：当高顺使用【杀】指定目标后（对方为“一个目标”），或高顺成为【杀】的目标后（对方为“使用者”）。
- 借装置入：选择对方装备区的 1 张装备牌，置入高顺的装备区（按[装备移动与置入](../equipment-movement.md)，“置入”可替换高顺原有同栏装备；记录该牌的装备副类别，若为双副类别坐骑则记进攻+防御坐骑两栏）。
- 结算后归还：待此【杀】结算完毕后，若双方均存活在场，将高顺装备区当前所有**同副类别**的装备牌（注意：如果中途高顺换装或失去了原牌，只要高顺该副类别栏位有牌，即移动当前该栏位的牌给对方；若高顺该栏位已空则不移动；若对方该栏位在结算期间又装了新装备导致非空栏，按[空栏规则](../equipment-movement.md)“移动给其”需明确非空栏如何处理）。

## 关联翼从：陷阵营

- 统领来源：群·高顺（QUN029）提供 `{统领：陷阵营 |【逐近弃远】}`，普通翼从（非偏将）。
- **翼从技能原文（JSON）**：当你使用【杀】造成伤害时，你可以弃置一张【桃】、【酒】或装备牌，然后此伤害+1。
- **结算分析**：
  - 触发时机：拥有【陷阵营】的角色使用【杀】造成伤害时（伤害加减窗口）。
  - 发动消耗：弃置 1 张实体牌名为【桃】、实体牌名为【酒】或类别为装备牌的牌（装备牌包含手牌区和装备区；注意鏖战状态下实体【桃】的牌名仍是【桃】，可作为【陷阵营】弃牌消耗）。
  - 效果结算：此【杀】造成的伤害 `+1`。
