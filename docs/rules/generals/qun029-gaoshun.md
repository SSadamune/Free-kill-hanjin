## 迅击

**技能原文**：迅击：每回合结束时，你可以依次视为对任意名本回合使用过【酒】的角色或明置过武将牌的非当前回合角色各使用一张【杀】。

**结算分析**：
- 触发时机：每名角色的**回合结束时**（回合级时机）。
- 候选角色集合（满足其一的存活在场角色，排除高顺自己）：
  1. 本回合内**使用过【酒】**的角色（不限是否为当前回合角色，含主动喝酒与濒死喝酒自救）；
  2. 本回合内**明置过武将牌**的**非当前回合角色**（例如回合外因响应阵法召唤、受伤发动技能等亮将的角色；当前回合角色自己回合内亮将不满足此项）。
- 效果结算：高顺从候选集合中选择任意名角色，按指定顺序或座次**依次**视为对每名所选角色使用一张普通【杀】（无实体牌，**无视距离限制**，每次视为用【杀】独立结算）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（每回合结束时集中结算）。
2. 【迅击】依次视为对所选角色使用的【杀】均**无视距离限制**。

## 擐甲

**技能原文**：擐甲：当你指定/成为【杀】的目标后，你可以将一个目标/使用者装备区的一张牌置入你装备区，结算后将你装备区同副类别的牌移动给其。

**结算分析**：
- 触发时机：当高顺使用【杀】指定目标后（对方为“一个目标”），或高顺成为【杀】的目标后（对方为“使用者”）。
- 借装置入：选择对方装备区的 1 张装备牌，**置入**高顺的装备区（按[装备移动与置入](../equipment-movement.md)，“置入”允许替换高顺原有同栏装备；记录该牌的装备副类别，若为双副类别坐骑则记进攻坐骑与防御坐骑两项副类别）。
- 结算后归还：待此【杀】结算完毕后，将高顺装备区当前所有**同副类别**的装备牌**移动给对方**：
  - 依紫乔专栏注释，若对方已死亡，或高顺装备区已没有该副类别的牌（例如高顺通过【陷阵营】等弃掉了刚抢来的装备牌），则无需执行后续归还；
  - 归还用词为“移动给其”（非“置入”），严格遵循[装备移动与置入](../equipment-movement.md)的**空栏规则**：若对方对应装备栏**已不空则不移动**（留在高顺处）；
  - 若抢来的是**双副类别坐骑**（如【六龙骖驾】/【临筱玉舆】），结算后高顺装备区若同时装着进攻坐骑与防御坐骑（两匹均属同副类别），只要对方对应空栏合法则**两匹都还**。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（无次数/唯一目标/防具武器限制，结算后归还同副类别牌）。
2. 结算后归还时，若对方对应装备栏**已不空则不移动**（留在高顺处）；若抢双副类别坐骑且高顺装备区同时有进攻马与防御马，结算后**都还**（对方栏位为空的前提下）。
3. 依紫乔专栏注释，对方已死亡或高顺装备区已无该副类别装备（含弃掉刚抢来的装备）时无需归还。

## 关联翼从：陷阵营

- 统领来源：群·高顺（QUN029）提供 `{统领：陷阵营 |【逐近弃远】}`，普通翼从（非偏将）。
- **翼从技能原文**：当你使用【杀】造成伤害时，你可以弃置一张【桃】、【酒】或装备牌，然后此伤害+1。
- **结算分析**：
  - 触发时机：拥有【陷阵营】的角色使用【杀】造成伤害时（伤害加减窗口）。
  - 发动消耗：弃置 1 张实体牌名为【桃】、实体牌名为【酒】或类别为装备牌的牌（装备牌包含手牌区和装备区；鏖战状态下实体【桃】的牌名仍是【桃】，可作为弃牌消耗）。
  - 效果结算：此【杀】造成的伤害 `+1`。
