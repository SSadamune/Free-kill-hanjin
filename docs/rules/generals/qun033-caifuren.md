## 窃听

**技能原文（JSON）**：窃听：其他角色的结束阶段，若其本回合未对与其势力不同的角色使用过手牌，你可以摸一张牌，或将其装备区的一张牌移动给你。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 条件写作“若其本回合未对**除其外的角色**使用过**牌**”（JSON 条件改为“未对**与其势力不同的角色**使用过**手牌**”，大幅放宽了对方对队友用牌、或用装备区转化牌时的触发）。

**结算分析（按 JSON 口径）**：
- 触发时机：其他角色的结束阶段。
- 条件判定（JSON）：检查该当前回合角色本回合内是否使用过包含手牌的牌（实体手牌或手牌转化牌，须区分仅用装备区牌/纯虚拟牌是否计入“使用过手牌”）并指定了**与其势力不同的角色**为目标。
  - **势力口径**：依据[通用约定](../general-principles.md)，“与其势力不同的角色”要求双方均已确定势力且势力不同（不包括未确定势力的角色）；若该当前回合角色自己本回合尚未确定势力，则不存在“与其势力不同的角色”。
- 效果二选一：
  1. 蔡夫人摸 1 张牌；
  2. 将该当前回合角色装备区的 1 张牌移动至蔡夫人的对应**空置装备栏**（遵循[空栏规则](../equipment-movement.md)与[双副类别坐骑](../equipment-movement.md#双副类别坐骑)；若对方装备区无任何可合法移入蔡夫人空栏的牌，则选项 2 不可选）。

## 献州

**技能原文（JSON）**：献州：限定技，出牌阶段，你可以将装备区的所有牌交给一名其他角色，回复等量体力，其对攻击范围内至多等量名角色各造成1点伤害。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 将回血与打伤害顺序颠倒为“其对攻击范围内至多等量的角色各造成1点伤害，**然后你回复等量体力**”（JSON 先回复等量体力，再由对方造成伤害）。

**结算分析（按 JSON 口径）**：
- 限定技，主动技，出牌阶段空闲时间点发动；须蔡夫人装备区至少有 1 张牌（不能 0 牌空发）。
- 结算顺序（JSON）：
  1. 蔡夫人将自己装备区里的所有牌（记数量为 `X`，双副类别坐骑仍计 1 张）全部交给一名其他在场角色 A（进入 A 的手牌区）；
  2. 蔡夫人回复 `X` 点体力（上限封顶；即使蔡夫人满血仍可发动，此时实际回复 0 点）；
  3. 然后 A 从其**攻击范围内**选择至多 `X` 名角色（可放弃选 0 名？按“至多”不含 0 还是可选不伤害？若 A 攻击范围内无角色则跳过；且注意此步骤在 A 收到牌之后，通常不改变 A 的装备区武器），A 对这些角色按座次各造成 1 点普通伤害（伤害来源为 A；若 A 放弃伤害或无目标，按 JSON 蔡夫人已先回血，不会回滚；若采用 CSV 则需注意蔡夫人因 A 伤害自己导致死活先后顺序）。

   - 若该角色本回合对**未确定势力角色**使用手牌，按[通用约定](../general-principles.md)“与你势力不同”要求双方均已确定势力，故对暗将用牌**不破坏**【窃听】条件；是否确认按此通用口径，还是意图按“其他势力角色”包含未确定势力？
