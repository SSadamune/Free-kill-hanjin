# QUN033 蔡夫人：矢包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“矢”包记录，并对照紫乔 B 站大合集专栏（`1180345691175649301`）及 2026-11-21 已确认裁定整理；本页为规则定稿依据，不表示已实装。

- 称号：梅谢未霜、襄江的蒲苇。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：`QUN&HAN030`（刘表，属不臣篇双势力武将，尚未正式登记）。
- 公共依据：[通用约定](../general-principles.md)、[装备移动与置入](../equipment-movement.md)及[矢包索引](../shi-generals.md)。

## 窃听

**技能原文**：窃听：其他角色的结束阶段，若其本回合未对与其势力不同的角色使用过手牌，你可以摸一张牌，或将其装备区的一张牌移动给你。

**结算分析**：
- 触发时机：其他角色的结束阶段。
- 条件判定：逐次检查当前回合角色用过的牌。对于实体手牌或含手牌材料的转化牌，在“成为目标时”按规则确定其对谁使用过此牌，并按该时点的势力判断。只要其中一次对与其势力不同的角色使用过手牌，本回合便不满足【窃听】。纯装备区材料和无实体牌的虚拟牌不计。[牌的使用事件与【镇卫】案例](../../../rulebook/events/use-card.md#连续若干个成为目标时)
  - 目标在该窗口被取消时不计入；目标转移时按转移后的目标判断。例如，本回合唯一从手牌使用的【杀】原指定异势力角色，其唯一目标被【镇卫】取消，蔡夫人可以发动。若目标保留，只是用【闪】抵消了【杀】，仍算对该角色使用过手牌。
  - **势力口径**：依据[通用约定](../general-principles.md)，“与其势力不同的角色”要求双方均已确定势力且势力不同，**对未确定势力（暗将）角色使用手牌不算“与其势力不同”**（不破坏【窃听】触发条件）；若当前回合角色自身尚未确定势力，则不存在与其势力不同的角色。
- 效果二选一：
  1. 蔡夫人摸 1 张牌；
  2. 将该当前回合角色装备区的 1 张牌移动至蔡夫人的对应**空置装备栏**（遵循[空栏规则](../equipment-movement.md)与[双副类别坐骑](../equipment-movement.md#双副类别坐骑)；若对方装备区无任何可合法移入蔡夫人空栏的牌，则选项 2 不可选）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（未对与其势力不同的角色使用过手牌）。
2. 对**未确定势力（暗将）**角色使用手牌**不算**“与其势力不同”，不破坏【窃听】条件。

## 献州

**技能原文**：献州：限定技，出牌阶段，你可以将装备区的所有牌交给一名其他角色，回复等量体力，其对攻击范围内至多等量名角色各造成1点伤害。

**结算分析**：
- 限定技，主动技，出牌阶段空闲时间点发动；须蔡夫人装备区至少有 1 张牌（不能 0 牌空发）。
- 结算顺序：
  1. 蔡夫人将自己装备区里的所有牌（记数量为 `X`，双副类别坐骑仍计 1 张）全部交给一名其他在场角色 A（进入 A 的手牌区）；
  2. 蔡夫人先回复 `X` 点体力（上限封顶；即使蔡夫人满血仍可发动，此时实际回复 0 点）；
  3. 然后 A 从其**攻击范围内**选择 `1 ~ X` 名角色，按座次各造成 1 点普通伤害（伤害来源为 A）。遵循项目“至多”不含 0 的通用规则，只要 A 攻击范围内存在至少 1 名角色，**不能选 0 名角色放弃伤害**；若 A 攻击范围内完全没有任何角色，则自然跳过伤害步骤（蔡夫人已完成的回复不回滚）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（先回复等量体力，再由收牌角色造成伤害）。
2. “对攻击范围内至多等量名角色各造成 1 点伤害”遵循“至多”不含 0 原则，**不能选 0 人**放弃伤害（仅攻击范围内无任何角色时跳过）。
