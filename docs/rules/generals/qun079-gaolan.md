# QUN079 高览：矢包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“矢”包记录，并对照紫乔 B 站大合集专栏（`1180345691175649301`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 客籍：魏。按[紫乔矢包专栏](https://www.bilibili.com/opus/1180345691175649301)客将牌图标注与边框颜色登记。

- 称号：攘诟之柱、名门的峦柱。
- 单将体力贡献：2（原码 `6969`，对应 4 单独阴阳鱼）。
- 珠联璧合：客将珠联 `zhulian_ke` 为 `WEI009`（张郃），与紫乔专栏标注一致。
- 公共依据：[通用约定](../general-principles.md)、[交换武将](../general-exchange.md)及[矢包索引](../shi-generals.md)。

## 袭阵

**技能原文**：袭阵：出牌阶段开始时，你可以弃置一张牌并令所有其他势力角色各选择一项：1.本回合不能使用或打出牌；2.你弃置其一张牌。

**结算分析**：
- 触发时机：高览自己的出牌阶段开始时；须实际弃置 1 张牌（手牌或装备区牌）作为发动消耗，且场上存在其他势力角色（按[通用约定](../general-principles.md)，“其他势力角色”为同势力角色的补集，**包含未确定势力角色**）。
- 依次选择：从当前回合角色（高览）起按逆时针座次，令所有其他势力角色各二选一：
  1. **选项 1**：该角色本回合剩余时间内不能使用且不能打出任何牌（包含【闪】、【桃】、【无懈可击】等响应牌）；
  2. **选项 2**：由**高览**选择并弃置该角色的一张牌（手牌暗选、装备区明选；若该角色没有牌，则选项 2 不可选，强制选选项 1）。

## 芟敌

**技能原文**：芟敌：结束阶段，你可以选择一个势力之中两名本回合受到过伤害的角色，交换其各一个武将。

**结算分析**：
- 独立技能，触发时机为高览自己的结束阶段（不依赖本回合是否发动过【袭阵】）。
- 目标条件：选择一个势力（不限于异势力，未排除高览自己所属势力），该势力中须至少存在 **2 名本回合受到过伤害**的存活在场角色，且这两名角色均拥有至少 1 张可合法交换的明置武将/位置（遵守[交换武将](../general-exchange.md)：君主与明置专属野心家不可交换，暗置不可交换）。
- 效果结算：高览选定这两名同势力受伤角色，并由**高览指定**双方各哪一个合法明置武将/位置执行交换。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（拆分为独立【袭阵】+【芟敌】，【袭阵】仅对其他势力且由高览弃牌）。
2. 【芟敌】交换两名角色各一个武将时，双方具体参与交换的武将位置由**高览指定**。
