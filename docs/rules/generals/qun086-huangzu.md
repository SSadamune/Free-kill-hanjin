# QUN086 黄祖

不臣篇（下） · 普通 · 称号“遮山扼江”。

势力为群。配将体力贡献 2 点。

## 卡面原文

> 袭射：其他角色的准备阶段，你可以弃置装备区的一张牌并视为对其使用一张【杀】（若其体力值小于你，此【杀】不能被响应），你可以重复此流程，当你因此杀死角色后，你可以变更副将（备选武将对其他角色不可见，变更后的武将处于暗置状态）。

## 结算

〖袭射〗每次都须弃黄祖装备区的一张牌并另用一张【杀】，每次比较当前体力决定能否响应。由此杀人后可选变更副将，候选对别人保密且新副将暗置。

刘表的记录列有黄祖，核对该配对时须考虑反向登记。

## 验收场景

黄祖装备区有两张牌，首发杀被闪避也可再弃第二张续射；若再无装备，不能用手中装备充当下一次消耗。
