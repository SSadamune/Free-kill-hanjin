# QUN086 黄祖

不臣篇（下） · 普通 · 称号“遮山扼江”。

势力为群。配将体力贡献 2 点。

## 卡面原文

> 袭射：其他角色的准备阶段，你可以弃置装备区的一张牌并视为对其使用一张【杀】（若其体力值小于你，此【杀】不能被响应），你可以重复此流程，当你因此杀死角色后，你可以变更副将（备选武将对其他角色不可见，变更后的武将处于暗置状态）。

## 结算

〖袭射〗每次发动都必须弃置黄祖装备区里的一张牌，并视为对当前回合角色使用一张新的【杀】；每次都会按双方的当前体力值比较结果来决定该【杀】能否被响应。若黄祖因此流程杀死角色，可以选择变更副将，且备选武将对其他角色不可见，变更后的新副将处于暗置状态。

刘表的珠联璧合记录中列有黄祖，核对该配对关系时须一并考虑这一反向登记。

## 验收场景

黄祖装备区里有两张牌时，即使第一张【杀】被目标使用【闪】抵消，也可以再弃置第二张装备牌继续视为使用【杀】；若装备区里已没有牌，则不能使用手牌中的装备牌来充当下一次发动的消耗。
