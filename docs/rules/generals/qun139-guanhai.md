## 版本重大差异（JSON vs CSV）

两份外部资料的管亥属于**完全不同的两套技能设计**：

- **石激桑 JSON 版（双技能【卸尾】+【诱阙】）**：
  > 卸尾：每轮各限一次，你可以一张手牌置于武将牌上（称为“饵”），并视为使用【杀】/【闪】。
  > 诱阙：出牌阶段，你可以用点数最小的“饵”与一名角色拼点：没赢者展示手牌，弃置其中点数大于拼点牌的牌，视为对赢者使用雷【杀】，此牌造成伤害后，你摸一张牌。
- **药枫 CSV 版（单技能【索粮】）**：
  > 索粮：每回合限一次，当你对其他角色造成伤害后，你可以展示其至多X张手牌（X为你与其手牌数之差，至多为5），获得其中的梅花和红桃牌，若你未以此法获得牌，你弃置展示的牌。

## 卸尾（按 JSON 版本结算分析）

- **每轮各限一次**：每轮内，视为使用【杀】限 1 次、视为使用【闪】限 1 次（两分支各自独立计次，每轮开始时重置；仅限“使用”，不含纯“打出”）。
- 发动代价：将 1 张手牌明置/置于管亥武将牌上，称为「饵」（注意卡面原文写作“你可以一张手牌置于武将牌上”，缺“将”字属原资料笔误，语义为“将一张手牌置于武将牌上”；依[FAQ：牌类标记](../../../assets/docs/规则向FAQ文件.md#牌类标记)，「饵」不因暗置置入弃牌堆，交换武将时随管亥武将牌移动）。
- 效果结算：在合法需要使用【杀】或【闪】的窗口，视为使用一张无实体牌的普通【杀】或【闪】（受通常出杀次数约束，非空闲点效果用杀不占次数）。

## 诱阙（按 JSON 版本结算分析）

- 主动技，出牌阶段空闲时间点发动（无明文每阶段限一次，只要仍有「饵」且存在可拼点的角色即可再次发动）。
- 前置要求：管亥武将牌上至少有 1 张「饵」，且目标角色有手牌可参与拼点（若允许选自己则不合拼点定义，拼点目标须为有手牌的其他在场角色）。
- 拼点规则：管亥**不消耗手牌**，而是直接取「饵」中**点数最小的一张**作为管亥的拼点牌（若有多张并列最小点数，由管亥选择其中一张）与目标角色拼点；拼点后两张拼点牌按常规置入弃牌堆。
- 拼点结果结算：
  - **若分出胜负**（存在赢者与没赢者）：
    1. 没赢者展示其所有手牌；
    2. 没赢者弃置展示的手牌中**所有点数大于其自身拼点牌**（还是大于双方拼点牌/管亥拼点牌？须主创明确！）的牌；
    3. 没赢者视为对赢者使用一张无实体牌的**雷【杀】**（是否无视距离限制须明确）；
    4. 若该雷【杀】造成伤害后，管亥摸 1 张牌（无论赢者是管亥还是对手，只要该雷【杀】造成伤害，均由管亥摸 1 牌）。
  - **若平局（点数相等）**：双方均未赢（没有赢者），跳过后续。

- 统领来源：群·管亥（QUN139）提供普通翼从【青州精锐】（JSON 统领牌为【铁索连环】，CSV 统领牌为雷【杀】）。
- **翼从技能原文（JSON）**：出牌阶段限一次，你可以令一名手牌数最小的角色选择一项：1.弃置一张手牌；2.你对其造成1点伤害。
- **结算分析**：
  - 主动技，出牌阶段限一次（每份【青州精锐】独立实例各限一次）。
  - 合法目标：场上所有存活在场角色（含持有者自己）中，手牌数**最小**的角色（允许并列最小；注意手牌数为 0 的角色也是手牌数最小的角色，其无法选择选项 1“弃置一张手牌”，只能选择选项 2 承受 1 点伤害）。
