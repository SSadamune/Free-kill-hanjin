# SHU&WU081 郝普

不臣篇（中） · 普通 · 称号“惭恨入地”。

势力为蜀、吴。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 维谷：锁定技，当你指定或成为【杀】的目标后，你选择一项：1.摸一张牌并展示之；2.弃置一张牌。选择完成后，本回合你和对方均不能再使用此牌花色的牌。

## 结算

〖维谷〗由郝普选择摸一张牌并展示，或者弃置一张牌；随后根据所摸或所弃置之牌的花色，同时限制郝普与该【杀】对应的另一方（使用者或目标）在本回合内不能再使用该花色的牌。此限制持续至本回合结束，仅检查角色所使用牌的花色。

## 验收场景

角色甲使用一张黑桃【杀】指定郝普为目标，郝普发动〖维谷〗并选择弃置一张红桃牌；此后，甲与郝普双方在本回合内均不能再使用红桃牌，而黑桃牌仍可按正常规则使用。
