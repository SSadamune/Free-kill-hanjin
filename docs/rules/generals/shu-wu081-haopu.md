# SHU&WU081 郝普

不臣篇（中） · 普通 · 称号“惭恨入地”。

势力为蜀、吴。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 维谷：锁定技，当你指定或成为【杀】的目标后，你选择一项：1.摸一张牌并展示之；2.弃置一张牌。选择完成后，本回合你和对方均不能再使用此牌花色的牌。

## 结算

〖维谷〗由郝普选择摸一并展示或弃一，随后按所摸或所弃之牌的花色同时限制郝普和相对的用牌者／目标。限制持续到本回合结束，检查使用牌的花色。

## 验收场景

甲用黑桃【杀】指定郝普，郝普选择弃一张红桃牌。此后双方本回合均不能使用红桃牌，黑桃牌仍按原规则使用。
