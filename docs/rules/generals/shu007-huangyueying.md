# SHU007 黄月英：集智的牌范围

卡面来源见[标准武将表](../standard-generals.md)。用户于 2026-11-14 确认，集智“当你使用非转化且非虚拟的锦囊牌时”的含义为：当你使用有对应实体牌且未经转化的锦囊牌时，你可以摸一张牌。

- 包含普通锦囊和延时锦囊，不添加“普通锦囊”限制。
- 排除转化使用的锦囊牌，以及无对应实体牌的视为使用。
- 玩家文本中的“虚拟牌”指无对应实体牌的牌；与规则集[实体／虚拟牌](../../../rulebook/terms/card-terms/virtualCard.md)的信息对象定义不同。两者的描述层次依[通用约定](../general-principles.md)区分，不能据规范术语将集智的触发范围解释为空集。

本次确认关闭蜀包审阅中提出的集智术语问题，保留卡面及外部来源原文。此项仅确认规则语义，不表示技能已实现或通过验证；实现状态见[开发状态](../../development/status.md)。
