## 散谣

**技能原文（JSON）**：散谣：出牌阶段限一次，你可以弃置一张牌，对一名体力值或手牌数最大的角色造成1点伤害。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 仅写作“对一名**体力值最大**的角色造成1点伤害”（不含“或手牌数最大”）。

**结算分析（按 JSON 口径）**：
- 主动技，出牌阶段限一次。
- 发动消耗：弃置 1 张牌（手牌或装备区牌均可，须实际弃置）。
- 合法目标：所有在场角色（含马谡自己，依 `getPresentPlayers()` 计算）中，**体力值为全场最大**（允许并列）**或手牌数为全场最大**（允许并列）的角色。
  - **关键时序**：若马谡弃置的是一张手牌，是在**选择目标时（弃牌前）**判断手牌数最大，还是弃牌后？按主动技界面交互规范，选牌与选目标在同一次主动技提交中完成，客户端与服务端均在**发动条件检查（弃牌前）**判定合法目标集合。
- 效果结算：对所选目标造成 1 点普通伤害。

## 制蛮

**技能原文（JSON）**：制蛮：当你对其他角色造成伤害时，你可以防止此伤害，然后获得其区域里的一张牌，若其与你势力相同，其可以变更副将（限一次）。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“获得其**场上**的一张牌”（仅限装备区或判定区，不含手牌区；JSON 写“区域里的一张牌”，包含手牌区、装备区、判定区）。

**结算分析（按 JSON 口径）**：
- 触发时机：马谡对其他角色造成伤害时（伤害防止窗口）。
- 效果结算：
  1. 防止此次伤害；
  2. 然后（须实际防止伤害）马谡从该目标角色的**区域**（按 JSON 含手牌区、装备区、判定区；若采用 CSV 则仅限装备区、判定区）中选择并获得 1 张牌（目标区域全空时跳过获得，仍可按原文继续判断后续同势力变更，或需确认是否跳过）；
  3. 若该目标角色与马谡势力相同，该目标角色可以选择**变更其副将**（限一次：按[变更武将通则](../card-categories-and-operations.md#变更武将)，整个【制蛮】技能来源每局仅能发起一次变更；若该同势力角色选择不变更，则不消耗这次变更机会）。

**待主创确认**：

2. 当目标角色区域无牌时，马谡是否仍可发动【制蛮】防止伤害，并在目标与自己同势力时令其变更副将？（按上游与“然后”口径，只要实际防止了伤害，目标无牌跳过取牌后仍可令同势力目标选择变更副将；请确认。）
