# SHU037 黄皓

不臣篇（中） · 普通 · 称号“神降之诳”“便辟侫慧”。

势力为蜀，客籍为晋。配将体力贡献 1.5 点。

珠联璧合登记为刘禅（EM(SHU013)）、刘禅（SHU013）。

客籍在原有主势力全部不可用时按本局允许集启用。[客将](../guest-factions.md)

## 卡面原文

> 寝情：与你势力相同的角色弃置任意角色的牌后，你可以令一名与你势力相同的角色重铸一张牌，然后重铸牌的角色可以变更副将（限一次）。

> 贿生：每回合限一次，当你受到伤害时，你可以对来源展示X张手牌（X为本回合其对你使用过的牌数），然后其获得其中一张并防止此伤害。

## 结算

〖寝情〗以与黄皓势力相同的角色弃置任意角色的牌为触发条件，先令一名同势力角色重铸一张牌，只有实际执行了重铸牌的角色才可以随后选择变更副将；该“限一次”的变更额度依照含变更效果的技能规则记录。〖贿生〗根据伤害来源在本回合内对黄皓使用过的牌数，决定黄皓需要展示的手牌数量。

## 验收场景

若角色甲本回合内没有对黄皓使用过任何牌，而是通过技能直接对黄皓造成伤害，此时 X 为 0，不能发动〖贿生〗；如果甲此前对黄皓使用过两张牌且黄皓拥有至少两张手牌，则黄皓可以展示两张手牌供甲获得其中一张并防止此伤害。
