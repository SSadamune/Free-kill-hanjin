# SHU037 黄皓

不臣篇（中） · 普通 · 称号“神降之诳”“便辟侫慧”。

势力为蜀，客籍为晋。配将体力贡献 1.5 点。

珠联璧合登记为刘禅（EM(SHU013)）、刘禅（SHU013）。

客籍在原有主势力全部不可用时按本局允许集启用。[客将](../guest-factions.md)

## 卡面原文

> 寝情：与你势力相同的角色弃置任意角色的牌后，你可以令一名与你势力相同的角色重铸一张牌，然后重铸牌的角色可以变更副将（限一次）。

> 贿生：每回合限一次，当你受到伤害时，你可以对来源展示X张手牌（X为本回合其对你使用过的牌数），然后其获得其中一张并防止此伤害。

## 结算

〖寝情〗以同势力角色弃置任意角色的牌为触发，先令同势力角色重铸，实际重铸者才可变更副将。变更额度依含变更效果的技能记录。〖贿生〗按本回合伤害来源对黄皓用过的牌数定展示数。

## 验收场景

甲本回合没对黄皓用过牌，却以技能伤害黄皓，X为零，不能发动〖贿生〗；若甲此前对其用过两张且黄皓有足够手牌，则展示两张供甲取一。
