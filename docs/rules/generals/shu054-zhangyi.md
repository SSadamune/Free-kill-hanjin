## 殿军

**技能原文（JSON）**：殿军：回合结束时，你可以执行额外的出牌阶段。每回合限一次，当你需要使用【杀】时，你可以失去1点体力，将一张手牌当【杀】使用。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为完全不同的旧版锁定技：“锁定技，回合结束时，你受到1点无来源的伤害，然后执行一个额外的出牌阶段。”（JSON 改为可选执行额外出牌阶段且不掉血，并新增了每回合限一次失血将手牌当【杀】用的第二段！）

**结算分析（按 JSON 口径）**：
- 包含两段独立效果：
  1. **回合结束时额外出牌阶段**：张翼自己的**回合结束时**（回合级时机，不是结束阶段），张翼可以选择发动，立即插入执行一个额外的出牌阶段（该额外出牌阶段结束后，继续完成原回合剩余的回合结束时流程；注意：该额外出牌阶段内若再次使用【杀】或触发其他效果，依然归属于当前回合内，受本回合已用次数的回合级限制，但出牌阶段限一次的技能会随新出牌阶段刷新）。
  2. **失血转杀**：每回合限一次（任意角色的回合内均可），当张翼需要使用【杀】时（包含主动出牌阶段空闲时间点与被动需要使用【杀】的响应窗口，不含纯“打出【杀】”窗口），张翼可以失去 1 点体力（若因此进入濒死并被救回仍继续完成用杀，若死亡则中止），将 1 张手牌当普通【杀】使用（转化为实体牌转化杀，受通常出杀次数约束，非空闲点效果用杀不占次数）。

## 抗锐

**技能原文（JSON）**：抗锐：有角色于其回合内首次扣减体力后，你可以选择一项：1.其回复1点体力；2.其本回合下次造成伤害时，此伤害+1且其本回合手牌上限为0。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 技能名写作“亢锐”，触发条件为“于其回合内首次**受到伤害**后”（JSON 为“首次**扣减体力**后”，涵盖受到伤害和失去体力——完美联动张翼自己【殿军】第二段的“失去 1 点体力”！）。

**结算分析（按 JSON 口径）**：
- 触发时机：任意在场角色（含张翼本人）于**该角色自己的回合内**，**首次扣减体力后**（包括因受到伤害扣减体力、因失去体力扣减体力；不因减体力上限被动压低体力算不算“扣减体力”，须按规则集口径确认；仅计该角色自己回合内首次，错过或放弃则本回合不再触发）。
- 二选一：
  1. **选项 1**：令该角色回复 1 点体力（若已满血则选项 1 无效或不可选）；
  2. **选项 2**：为该角色建立两项本回合持续效果：① 其本回合下一次造成伤害时，此伤害 `+1`；② 其本回合手牌上限改为 `0`（注意：若其手牌上限为 0，在随后弃牌阶段须弃光所有手牌；若是在张翼【殿军】的回合结束时额外出牌阶段才触发，则已过弃牌阶段，巧妙规避了手牌上限 0 的负面！）。
