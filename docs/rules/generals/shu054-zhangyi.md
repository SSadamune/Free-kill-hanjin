# SHU054 张翼：弩包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“弩”包记录，并对照紫乔 B 站大合集专栏（`1181099586803990535`）及 2026-11-21 已确认裁定整理；本页为规则定稿依据，不表示已实装。

## 将牌资料

- 称号：逆命承志、秉心维旅。
- 单将体力贡献：2（原码 `6969`，对应 4 单独阴阳鱼）。
- 珠联璧合：`SHU027`（廖化）。
- 公共依据：[通用约定](../general-principles.md)、[回合结束时](../general-principles.md#易读描述的时机与然后)及[弩包索引](../nu-generals.md)。

## 殿军

**技能原文**：殿军：回合结束时，你可以执行额外的出牌阶段。每回合限一次，当你需要使用【杀】时，你可以失去1点体力，将一张手牌当【杀】使用。

**结算分析**：
- 包含两段独立效果：
  1. **回合结束时额外出牌阶段**：张翼自己的**回合结束时**（回合级时机，非结束阶段），张翼可以选择发动，立即插入执行一个额外的出牌阶段；该额外出牌阶段结束后，**直接接续剩余的回合结束时流程**（不再进入弃牌阶段，也不再触发一次【殿军】；阶段限一次技能随新出牌阶段刷新）。
  2. **失血转杀**：每回合限一次（任意角色的回合内均可），当张翼需要使用【杀】时（含主动出牌阶段空闲时间点与被动需要使用【杀】的响应窗口，不含纯“打出【杀】”窗口），张翼可以失去 1 点体力（若此时恰为张翼自己回合内首次扣减体力，在失血后先触发【抗锐】，随后继续结算该转化【杀】；若死亡则中止），将 1 张手牌当普通【杀】使用（受通常出杀次数约束，非空闲点效果用杀不占次数）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（可选额外出牌阶段 + 每回合限一次失血转【杀】）。
2. 回合结束时插入的额外出牌阶段结束后，**直接接续剩余回合结束流程**（不再进入弃牌阶段，也不再触发【殿军】）。

## 抗锐

**技能原文**：抗锐：有角色于其回合内首次扣减体力后，你可以选择一项：1.其回复1点体力；2.其本回合下次造成伤害时，此伤害+1且其本回合手牌上限为0。

**结算分析**：
- 触发时机：任意在场角色（含张翼本人）于**该角色自己的回合内**，**首次扣减体力后**（包含受到伤害扣减体力、失去体力扣减体力，**不包含**仅因减体力上限被动压低体力值；仅计该角色自己回合内首次，放弃或错过则本回合不再触发）。
- 二选一：
  1. **选项 1**：令该角色回复 1 点体力（已满血则无效/不可选）；
  2. **选项 2**在该角色本回合下次造成伤害时生效。此时令该次伤害 +1，同时将该角色的手牌上限初值设为 0，持续至本回合结束。若选定此项后该角色本回合没有再造成伤害，其手牌上限照常计算。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（首次“扣减体力后”触发）。
2. “扣减体力”**不包含**纯减体力上限导致的被动体力下降（仅限受到伤害与失去体力）。
3. 选项 2 在上述伤害时机修改[手牌上限](../../../rulebook/terms/value-terms/handMax.md)的**初值**，与卞夫人【约俭】的初值口径相同。阴阳鱼等加减值仍照常计算，例如本回合已有 +2 修正且无其他修正时，初值设为 0 后的手牌上限为 2。
