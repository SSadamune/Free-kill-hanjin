## 简亮

> 简亮：摸牌阶段开始时，若你的手牌最少，你可以令与你势力相同的所有角色各摸一张牌。

在邓芝的摸牌阶段开始时比较手牌数，并列最少也满足。发动后，邓芝和当时与他同势力的其他角色各摸一张；该次摸牌独立于本摸牌阶段的常规摸牌。[最大与最小](../../../rulebook/terms/value-terms/maxMin.md) · [同势力](../general-principles.md)

## 危盟

> 危盟：出牌阶段限一次，你可以获得一名其他角色至多X张手牌（X为你的体力值），交给其等量的牌。纵横：将“体力值”改为“体力上限”。

邓芝从一名其他角色手中获得一至 X 张牌，另受该角色可获得手牌数限制。原版 X 取邓芝的当前体力值。取得后，邓芝选择等同实际取得数量的自己的牌交给原角色，可用手牌或装备区的牌。纵横版 X 改取发动者的体力上限。普通牌图与 JSON 的连接处为“交给其等量的牌”，专栏正文和纵横技能卡写“然后交给其等量的牌”；各版均按先获得、后等量交还处理。[至多](../../../rulebook/terms/value-terms/atMost.md) · [交给](../../../rulebook/terms/card-op-terms/give.md)

**危盟·纵横**　取牌上限改用发动者的体力上限，按实际取得张数交还。期限和已有同版技能的处理见[纵横通则](../multi-faction-and-ambition.md#3-纵横机制)。[纵横技能卡图](https://i0.hdslb.com/bfs/new_dyn/e492cdaab5ba2662ec6815bdffdad75c13446044.jpg)

> 出牌阶段限一次，你可以获得一名其他角色至多X张手牌（X为你的体力上限），然后交给其等量的牌。

## 验收场景

1. 邓芝与甲各有一张手牌，其余角色更多，仍可发动〖简亮〗。异势力甲即使与他并列最少也不因此摸牌。
2. 发动者 1/3 体力，乙有四张手牌。原版最多取一张，纵横版最多取三张；若只取两张就交还两张。
