## 度断

**技能原文（JSON）**：度断：当你需要使用或打出【杀】或【闪】时，你可以令你本回合不能使用和打出此牌名的牌，然后摸两张牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 仅写作“当你需要**使用**【杀】或【闪】时，你可以令你本回合不能**使用**此牌名的牌，然后摸两张牌。”（JSON 同时覆盖**使用和打出**。）

**结算分析（按 JSON 口径）**：
- 触发时机：当杨仪需要使用【杀】、需要打出【杀】、需要使用【闪】、或需要打出【闪】的任意响应/主动窗口（需注意：若杨仪本回合已因【度断】或其他效果处于“不能使用和打出【杀】（或【闪】）”状态，则不能再次对同一牌名发动【度断】；每回合对【杀】和【闪】可各自最多发动一次）。
- 效果结算：
  1. 为杨仪建立本回合禁止效果：本回合剩余时间内不能使用且不能打出该对应牌名（【杀】含全部属性杀，或【闪】）；
  2. 然后杨仪摸 2 张牌；
  3. 本次响应窗口并未因此提供【杀】或【闪】，杨仪自然无法再对该窗口打出/使用此牌名（直接放弃响应或受牌效果结算，如受到【杀】伤害或【决斗】受伤）。
- 客户端交互注意：主动出牌阶段空闲点是否算“当你需要使用【杀】时”？按三国杀常规，“当你需要使用或打出【杀】或【闪】时”既涵盖被动响应（如被杀出闪、决斗出杀、南蛮万箭、借刀等），若在出牌阶段可主动出杀时亦作为主动入口（类似【激将】/【护驾】），须主创确认是否含主动出牌阶段。

## 孤忿

**技能原文（JSON）**：孤忿：锁定技，当你不因【桃】而回复体力后，你用一个武将交换与你势力相同的其他角色一个武将；你的方片锦囊牌只能当【酒】使用。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“锁定技，当你不因【桃】而回复体力后，你**变更此武将**，或用**此武将**交换另一名与你势力相同的角色的一个武将。**若你处于鏖战状态**，你的**红色锦囊牌**只能当【酒】使用。”（两版在是否可变更、是否限定交换此武将、以及“只能当【酒】”的触发条件与牌色范围三处均不同。）

**结算分析（按 JSON 口径）**：
- 锁定技，包含两段效果：
  1. **非桃回血强制交换**：当杨仪不因【桃】（包括实体【桃】、转化【桃】、珠联当【桃】）而回复体力后（例如【桃园结义】、技能回血、升变回血、【酒】濒死回血等），若场上存在与杨仪势力相同的其他角色且双方均有可交换的明置武将/位置，杨仪**必须**选择自己的一个合法明置武将与一名同势力其他角色的一个合法明置武将执行[交换武将](../general-exchange.md)（若无合法同势力交换对象则自然跳过）。
  2. **方片锦囊只能当【酒】**：复用[“X 只能当 Y 使用／打出”](../only-as.md)公共机制——杨仪的实体方片锦囊牌（包括方片普通锦囊和方片延时锦囊）不能按原牌名直接使用，但可以当【酒】使用（包含主动出牌阶段增伤与濒死自救；实体牌名本身不变，不影响其他转化技能；因为【酒】濒死自救属于“不因【桃】而回复体力”，自救回血后会自然联动第一段交换武将！）。
