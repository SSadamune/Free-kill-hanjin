# SHU091 杨仪：矢包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“矢”包记录，并对照紫乔 B 站大合集专栏（`1180345691175649301`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 客籍：魏。按[紫乔矢包专栏](https://www.bilibili.com/opus/1180345691175649301)客将牌图标注与边框颜色登记。

- 称号：才盈杯杓、高傲的孤鹬。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：无。
- 公共依据：[通用约定](../general-principles.md)、[“X 只能当 Y 使用／打出”](../only-as.md)、[交换武将](../general-exchange.md)及[矢包索引](../shi-generals.md)。

## 度断

**技能原文**：度断：当你需要使用或打出【杀】或【闪】时，你可以令你本回合不能使用和打出此牌名的牌，然后摸两张牌。

**结算分析**：
- 触发时机：当杨仪需要使用【杀】、需要打出【杀】、需要使用【闪】、或需要打出【闪】的窗口——**包含出牌阶段空闲时间点主动发动**（封【杀】摸 2 牌，与紫乔专栏“度断不出杀摸二为杨仪提供了不错的回合内过牌”一致）以及被动响应窗口。
- 触发限制：依紫乔专栏注释，“令你本回合不能使用此牌名：也就不会再生成‘当你需要使用时’”，故本回合一旦禁止【杀】（或【闪】），该牌名本回合不再弹出【度断】询问（每回合对【杀】与【闪】至多各发动一次）。
- 效果结算：
  1. 建立本回合禁止效果：本回合剩余时间内不能使用且不能打出对应牌名（【杀】含全部属性杀，或【闪】）；
  2. 然后杨仪摸 2 张牌；
  3. 本次响应窗口并未提供【杀】或【闪】，杨仪自然无法再对该窗口使用或打出此牌名。

**已确认裁定**：
1. 正式版本采用石激桑 JSON（覆盖“使用或打出”），且依紫乔专栏确认**允许在出牌阶段空闲时间点主动发动**。

## 孤忿

**技能原文**：孤忿：锁定技，当你不因【桃】而回复体力后，你用一个武将交换与你势力相同的其他角色一个武将；你的方片锦囊牌只能当【酒】使用。

**结算分析**：
- 锁定技，包含两段效果：
  1. **非桃回血强制交换**：当杨仪不因【桃】（包括实体【桃】、转化【桃】、珠联当【桃】）而回复体力后（如【桃园结义】、技能回血、升变回血、【酒】濒死回血等），若场上存在与杨仪势力相同的其他角色且双方均有可交换的明置武将/位置，杨仪**必须**选择自己的**任意一个合法明置武将/位置**（不限于杨仪此武将），与一名同势力其他角色的一个合法明置武将/位置执行[交换武将](../general-exchange.md)（若无合法同势力交换对象则跳过）。
  2. **方片锦囊只能当【酒】**：复用[“X 只能当 Y 使用／打出”](../only-as.md)公共机制——杨仪手牌中的实体方片锦囊牌（含普通锦囊与延时锦囊）不能按原牌名直接使用，只能当【酒】使用（含出牌阶段增伤与濒死自救；仅限“使用”，不含“打出”；【酒】濒死自救属于非桃回血，会自然联动第一段交换武将）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 口径，按“**一个武将**”处理（B 站专栏正文所写“此武将”为旧版文案，不采用）。
