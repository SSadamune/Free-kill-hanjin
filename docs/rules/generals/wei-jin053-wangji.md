# WEI&JIN053 王基

不臣篇（上） · 普通 · 称号“经行合一”。

势力为魏、晋。配将体力贡献 1.5 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 奇制：每回合限一次，当你使用基本牌或锦囊牌指定目标后，你可以弃置一名不为此牌目标的角色一张牌，然后其摸一张牌。

> 进趋：准备阶段，你可以摸两张牌，然后弃置手牌至至多为体力上限，令本回合“奇制”可发动次数和你的手牌上限+X（X为以此法弃牌数）。

## 结算

〖奇制〗在本牌第一次指定目标后由王基选一名不在整张牌目标中的角色，弃置其一张牌，再由该角色摸一张。〖进趋〗先摸二，再按实际弃牌数同时提高本回合发动次数和手牌上限。

若〖进趋〗摸完手牌数已不大于体力上限，作者明确可只摸不弃，X为0。

## 验收场景

体力上限四，准备阶段摸后有六张手牌并弃两张。本回合〖奇制〗共可发动三次，手牌上限增加二；此时用一张多目标锦囊，〖奇制〗仍只询问一次。
