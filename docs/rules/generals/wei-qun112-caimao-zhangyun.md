# WEI&QUN112 蔡瑁&张允

不臣篇（中） · 普通 · 称号“蛟海腾云”。

势力为魏、群。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 逐流：锁定技，你的回合内，当你连续使用：两张伤害牌时，你回复1点体力；三张非伤害且非回复牌时，你失去1点体力。然后重置此计次。

> 叠浪：锁定技，当你使用【杀】对其他角色造成伤害时，若其体力值与你相同，此伤害+1。

## 结算

〖逐流〗只统计蔡瑁&张允在自己回合内的连续用牌序列：当连续使用两张伤害牌或连续使用三张非伤害且非回复牌达到相应门槛并执行效果后，重置计次。〖叠浪〗在造成伤害时比较受伤角色与蔡瑁&张允的当前体力值，适用范围包括属性【杀】引发的连环传导伤害。

## 验收场景

若蔡瑁&张允在自己回合内依次使用四张伤害牌且每次都处于可回复状态，则第二张与第四张会分别触发〖逐流〗回复体力。当一张属性【杀】通过连环传导伤害至另一名与蔡瑁&张允当前体力值相同的角色时，同样会重新检查并触发〖叠浪〗加伤。
