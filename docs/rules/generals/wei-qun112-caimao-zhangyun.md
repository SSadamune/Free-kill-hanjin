# WEI&QUN112 蔡瑁&张允

不臣篇（中） · 普通 · 称号“蛟海腾云”。

势力为魏、群。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

## 卡面原文

> 逐流：锁定技，你的回合内，当你连续使用：两张伤害牌时，你回复1点体力；三张非伤害且非回复牌时，你失去1点体力。然后重置此计次。

> 叠浪：锁定技，当你使用【杀】对其他角色造成伤害时，若其体力值与你相同，此伤害+1。

## 结算

〖逐流〗只看自己回合内的连续用牌序列。连续两张伤害牌或三张既不伤害也不回复的牌达到相应门槛后重计。〖叠浪〗在造成伤害时比较受伤者与蔡瑁&张允的当前体力，含属性杀的传导伤害。

## 验收场景

依次用四张伤害牌且每次均可回复，第二、第四张分别触发〖逐流〗。一张属性杀传导至另一名等体力角色时，重新检查〖叠浪〗。
