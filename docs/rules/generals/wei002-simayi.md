# WEI002 司马懿：应期结算约定

本文记录 2026-11-13 确认的应期结算与 2026-11-20 补充的客籍判定。卡面来源见[标准武将表](../standard-generals.md)，汉晋原创规则参考见外部[规则向 FAQ](../../../assets/docs/规则向FAQ文件.md)。

> 应期：锁定技，若你配将为多势力或客将，☯️+2。

1. “配将”指与司马懿组成双将的另一张武将牌，不限司马懿位于主将还是副将。
2. “☯️+2”是配将体力贡献修正，不是取得两枚可消耗的阴阳鱼标记。按[配将体力贡献通则](../general-principles.md#配将体力贡献与武将状态)接入组合计算。
3. 条件在开局配将时确定，不能等到明置司马懿才结算，也不因明暗置反复生效。
4. 牌面有多个势力字的武将是多势力武将牌，其牌面身份不受禁选影响。所有主势力被禁用且拥有多于一个副势力的客将也视为多势力武将牌。应期的客将条件使用本局生效的客籍。曹操的魏势力未禁、仍以魏配将时，是正常单势力配将，应期不增加上限。[FAQ 判断基准](../../../assets/docs/规则向FAQ文件.md#双势力多势力武将牌的判断基准) · [#25 补充说明](https://github.com/SSadamune/Free-kill-hanjin/issues/25#issuecomment-7033006459)
5. 通常交换、移除或替换另一张武将不重新计算已确定的体力上限；升变依公共流程重算。不能因配将后来不满足条件便撤销原收益，也不能因普通换将后来满足条件便新增收益。
