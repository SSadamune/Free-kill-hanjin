# WEI021B 毛玠：权包技能审阅

- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：`WEI021A`（崔琰）。

## 征辟

**技能原文**：征辟：出牌阶段限一次，你可以将一张牌交给一名角色，其展示并交给你一张非基本牌或两张基本牌，若其有暗置武将牌，本回合此技能限两次。

**结算分析**：
- 主动技，基础次数为出牌阶段限一次；交牌可以是手牌或装备区牌。
- 交牌后，目标角色须展示并交还给毛玠“一张非基本牌”或“两张基本牌”；目标刚收到毛玠给的牌同样可作为交还候选。
- 若目标角色同时满足两种组合，由目标自行选择其一；若两种组合均无法凑齐（如专栏所述“若对方仅有一张基本牌，则两项均不可选”），则跳过交还。
- 次数扩容：“若其有暗置武将牌，本回合此技能限两次”属于动态上限提升——本回合只要发动【征辟】指定过带有暗置武将牌的角色，本回合该技能的出牌阶段使用上限提升至 2 次（不叠加至 3 次）。须接入汉晋主动技公共动态次数声明，避免自定义 `can_use` 绕过限次。

**已确认裁定**：
1. 依据汉晋交牌通则，牌不能交给自己，故【征辟】目标仅限**其他角色**。
2. 目标交还“一张非基本牌”时，**允许**选择其**装备区**的装备牌（与手牌中的非基本牌同等合法）。
3. 依紫乔专栏说明，若目标仅有一张基本牌（两种交还组合均无法凑齐），两项均不可选、直接跳过交还。

## 奉迎

**技能原文**：奉迎：限定技，你可以将所有手牌当【挟天子以令诸侯】使用（无视大势力限制），使用时所有与你势力相同的角色摸牌至其体力上限。

**结算分析**：
- 限定技，主动技（出牌阶段空闲时间点发动，因【挟天子以令诸侯】仅限出牌阶段使用）。
- 发动要求至少有 1 张手牌（转化为【挟天子以令诸侯】须有实体牌作为材料，0 手牌不可发动）。
- 豁免大势力限制：即使毛玠当前不是大势力，仍可使用此转化【挟天子以令诸侯】。
- 摸牌时机：在此【挟天子以令诸侯】**使用时**（在【无懈可击】响应与牌效果结算之前），所有与毛玠势力相同的角色（含毛玠本人，按座次依次）将手牌摸至其当前体力上限（手牌数已大于等于体力上限者不摸牌）。摸到【无懈可击】可立即用于后续响应；即使该【挟天子以令诸侯】随后被抵消，摸牌效果已发生。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 与紫乔专栏口径，摸牌时机为“使用时”。
