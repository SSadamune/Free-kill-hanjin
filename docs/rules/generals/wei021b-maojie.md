## 征辟

**技能原文（JSON）**：征辟：出牌阶段限一次，你可以将一张牌交给一名角色，其展示并交给你一张非基本牌或两张基本牌，若其有暗置武将牌，本回合此技能限两次。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 与 JSON 正文一致（仅有换行空格差异）。

**结算分析**：
- 主动技，基础次数为出牌阶段限一次；“将一张牌交给一名角色”应排除自己（交给其他角色，按一般交牌交互确认）。交牌可以是手牌或装备区牌。
- 交牌后，目标角色须展示并交还给毛玠“一张非基本牌”或“两张基本牌”（可从手牌或装备区选择，非基本牌含锦囊牌和装备牌）；目标刚收到毛玠给的牌，同样可作为交还候选。
- 若目标角色同时满足两种组合，自行选择其一；若两种组合均无法凑齐（例如仅有 1 张基本牌），则无需交还（或不能凑齐即不执行交还）。
- 次数扩容：“若其有暗置武将牌，本回合此技能限两次”属于动态上限提升——本回合只要发动【征辟】指定过带有暗置武将牌的角色，本回合该技能的出牌阶段使用上限提升至 2 次（不叠加至 3 次）。须接入汉晋主动技公共动态次数声明，避免自定义 `can_use` 绕过限次。

**待主创确认**：
1. “交给一名角色”是否明确限定为**其他角色**（不能自己交给自己刷暗将两次）？按常理应为其他角色，请确认。
2. 目标角色“展示并交给你一张非基本牌或两张基本牌”时，若目标既有非基本牌（含装备区）又有基本牌，装备区的装备牌是否允许被选为“非基本牌”交还？另，若目标无法凑齐任一合法组合，是否直接跳过交还（不展示全部手牌验明，还是需展示全部手牌以证无牌）？

## 奉迎

**技能原文（JSON）**：奉迎：限定技，你可以将所有手牌当【挟天子以令诸侯】使用（无视大势力限制），使用时所有与你势力相同的角色摸牌至其体力上限。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 将后半句写作“**然后**令所有与你势力相同的角色摸牌至其体力上限”。

**结算分析（按 JSON 口径）**：
- 限定技，主动技（出牌阶段空闲时间点发动，因【挟天子以令诸侯】仅限出牌阶段使用）。
- 发动要求至少有 1 张手牌（“将所有手牌当……使用”须有实体材料组成转化牌，且【挟天子以令诸侯】使用后将结束出牌阶段并在弃牌阶段后获得额外回合，目标为自己）。
- 豁免大势力限制：即使毛玠当前不是大势力（甚至尚未成为最大势力），仍可使用此转化【挟天子以令诸侯】。
- 摸牌时机（JSON“使用时”）：在此【挟天子以令诸侯】**使用时**（在【无懈可击】响应与牌效果结算之前），所有与毛玠势力相同的角色（含毛玠本人，按座次依次）将手牌摸至其当前体力上限（手牌数已大于等于体力上限者不摸牌）。因为是在“使用时”摸牌，即使该【挟天子以令诸侯】随后被【无懈可击】抵消，摸牌效果已发生。

**待主创确认**：
1. 摸牌时机以 JSON（“使用时”，先摸牌再走无懈与挟天子结算）还是 CSV（“然后”，等挟天子使用/结算后再摸牌）为准？拟以 JSON 为准，请确认。
2. 毛玠仅有 0 张手牌时，是否明确不能发动【奉迎】（转化牌须有至少一张实体牌作为材料，见[通用约定](../general-principles.md)）？
