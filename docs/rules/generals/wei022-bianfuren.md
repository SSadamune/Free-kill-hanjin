# WEI022 卞夫人：变包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“变”包记录，并对照紫乔 B 站大合集专栏（`1178159943679737864`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 称号：奕世之雍容。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：`EM(WEI001)`（君曹操）、`WEI001`（曹操）。
- 公共依据：[通用约定](../general-principles.md)、[回合与时机](../turn-death-and-reveal-timing.md)及[变包索引](../bian-generals.md)。

## 挽危

**技能原文**：挽危：每回合限一次，当确定与你势力相同的角色因其他势力角色的获得或弃置而移动的牌时，你可以将此次移动的牌改为你的一张牌。

**结算分析**：
- 触发时机：每回合限一次，当**即将确定**与卞夫人势力相同的角色（含卞夫人本人）的牌，因**其他势力角色**（按[其他势力口径](../general-principles.md)，含未确定势力角色）执行“获得”或“弃置”操作而移动时（选牌后、实际移出区域前的替代拦截窗口）。
- 效果结算：卞夫人选择自己的一张牌（手牌或装备区牌均可，须可被合法获得或弃置），将**此次移动的全部原定牌**整体替换为卞夫人的这一张牌，继续由该其他势力角色按原移动原因获得或弃置。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（团队护牌【挽危】）。
2. 当其他势力角色一次获得或弃置同势力角色的**多张牌**时，【挽危】**全部挡下**，统一改为移动卞夫人选择的 **1 张牌**。

## 约俭

**技能原文**：约俭：轮次技，与你势力相同的角色准备阶段，你可令其本回合手牌上限为X（X为其体力上限），弃牌阶段结束时若其未弃置牌，其摸一张牌。

**结算分析**：
- 轮次技（每轮限一次，每轮开始时重置）。
- 触发时机：一名与卞夫人势力相同的角色（含卞夫人本人）的准备阶段。
- 效果一（修改手牌上限初值）：令该角色本回合的**基础手牌上限（初值）**等于其当前体力上限（而非锁死不可加减；若该角色本回合消耗阴阳鱼手牌上限 `+2` 或受其他手牌上限增减效果影响，仍在此基础上正常叠加）。
- 效果二（弃牌阶段未弃牌摸牌）：该角色本回合弃牌阶段结束时，若其在此弃牌阶段内**未弃置过牌**，则其摸 1 张牌；若跳过了弃牌阶段则不触发。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（轮次技【约俭】）。
2. 依紫乔专栏说明，【约俭】是将目标的**手牌上限初值**设为体力上限，不阻止后续其他加减手牌上限效果继续叠加。
