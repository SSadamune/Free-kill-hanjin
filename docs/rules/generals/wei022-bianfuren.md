## 挽危

**技能原文（JSON）**：挽危：每回合限一次，当确定与你势力相同的角色因其他势力角色的获得或弃置而移动的牌时，你可以将此次移动的牌改为你的一张牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为完全不同的旧版本：“当确定你被其他角色弃置或获得的牌时，你可以改为自己选择失去的牌，然后摸一张牌。”

**结算分析（按 JSON 口径）**：
- 触发时机：每回合限一次，当**即将确定**与卞夫人势力相同的角色（含卞夫人本人）的牌，因**其他势力角色**（按[其他势力口径](../general-principles.md)，含未确定势力角色）执行“获得”或“弃置”操作而移动时（即选牌之后、实际移出区域之前的替代拦截窗口）。
- 效果结算：卞夫人选择自己的一张牌（手牌或装备区牌均可，须可被合法获得或弃置），将此次移动的原定牌**替换为卞夫人的这张牌**（继续由该其他势力角色按原移动原因获得或弃置）。
- **多张牌边界**：当其他势力角色一次获得或弃置同势力角色的**多张牌**（例如一次弃置两张手牌、或【庸肆】获得全部手牌）时，卞夫人将“此次移动的牌”全部替换为自己的 **1 张牌**，还是仅替换其中 1 张、抑或需替等量张牌？此点须主创明确。

2. JSON 新版【挽危】面对其他势力角色**一次获得或弃置多张牌**时，是否允许用卞夫人自己的 **1 张牌** 整体顶替该次移动的全部牌（从而把对方弃/拿 N 张压缩为弃/拿卞夫人 1 张），还是仅限原本移动 1 张牌时触发，或只能替换其中 1 张？

## 约俭

**技能原文（JSON）**：约俭：轮次技，与你势力相同的角色准备阶段，你可令其本回合手牌上限为X（X为其体力上限），弃牌阶段结束时若其未弃置牌，其摸一张牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为旧版锁定技：“锁定技，与你势力相同的角色的弃牌阶段开始时，若其本回合未使用牌指定过其他势力的角色，本回合其手牌上限至少为其体力上限。”

**结算分析（按 JSON 口径）**：
- 轮次技（每轮限一次，每轮开始时重置）。
- 触发时机：一名与卞夫人势力相同的角色（含卞夫人本人）的准备阶段。
- 效果一（固定手牌上限）：令该角色**本回合手牌上限为 X（X 为其当前体力上限）**。
  - 注意：用词为“手牌上限为 X”而非“至少为 X”，若该角色在回合内另有其他修改手牌上限的加减效果（如消耗阴阳鱼手牌上限 +2），需确认是覆盖固定为 X，还是将基础手牌上限（通常等于当前体力值）改为等于体力上限并叠加其他加减修正。
- 效果二（弃牌阶段未弃牌摸牌）：该角色本回合弃牌阶段结束时，若其在此弃牌阶段内**未弃置过牌**（手牌数未超过上限、主动技能未弃牌等），则其摸 1 张牌。若跳过了弃牌阶段，则没有弃牌阶段结束时，不摸牌。

**待主创确认**：
1. JSON 新版【约俭】“令其本回合手牌上限为 X（X 为其体力上限）”与其他手牌上限加减效果（如消耗阴阳鱼 +2、【克己】等）的叠加口径：是**将基础手牌上限设为体力上限**（允许消耗阴阳鱼继续 +2），还是强行锁定为等于体力上限？
