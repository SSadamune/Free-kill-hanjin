## 司镇

**技能原文（JSON）**：司镇：你响应过牌的阶段结束时，你可以视为使用一张【杀】（若与你势力相同的角色此阶段均未受到过伤害，此【杀】无距离限制）。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 多加了一个前置条件“**若此阶段你未受到过伤害**，你可以视为使用一张【杀】，且若此阶段与你势力相同的角色均未受到过伤害，此【杀】无距离限制。”（JSON 删去了“若此阶段你未受到过伤害”的前置门槛，即使曹真本阶段受伤仍可发动，只是不享无距离限制。）

**结算分析（按 JSON 口径）**：
- 触发时机：任意角色的任意**阶段结束时**，前提是曹真在**此阶段内响应过牌**（例如使用【闪】响应【杀】/【万箭齐发】、打出【杀】响应【南蛮入侵】/【决斗】、使用【无懈可击】响应锦囊牌、弃牌响应【火攻】/【贯石斧】等；须明确“响应过牌”在引擎中对应的精确范围）。
- 效果结算：曹真可以视为使用一张无实体牌的普通【杀】（不计入且无视通常出杀次数；合法目标须在曹真攻击范围内，除非满足括号内的无距离条件）。
- 括号加成：若所有与曹真势力相同的角色（含曹真本人）在**此阶段内均未受到过伤害**，则此张视为使用的【杀】无距离限制（可指定场上任意合法其他角色）。

## 关联翼从：虎豹骑

- 统领来源：魏·曹真（WEI034，统领牌【闪】）与魏·曹纯（WEI061，统领牌【杀】）均提供普通翼从【虎豹骑】，共用同一翼从定义。
- **翼从技能原文（JSON）**：每回合首张由拥有虎豹骑的角色使用且目标唯一的【杀】结算后，你可以对相同目标使用一张【杀】并摸一张牌。
- **结算分析**：
  - 触发条件：任意回合内，当**本回合第一张**满足以下全部条件的【杀】结算完毕后：
    1. 使用者是**拥有【虎豹骑】的角色**（含持有者自己或其他拥有【虎豹骑】的队友/对手）；
    2. 该【杀】的目标**唯一**（最终目标仅为 1 名角色，不含双目标/多目标【杀】）。
  - 触发对象：场上所有拥有【虎豹骑】的角色（按座次依次询问，包含该首张【杀】的使用者本人，也可以是另一名拥有【虎豹骑】的队友！）。
  - 效果结算：对**同一名目标角色**（若目标仍存活在场）使用一张手牌/可用转化【杀】（不是“视为使用”，须实际使用一张合法【杀】；不计入且无视通常出杀次数；是否无视距离须确认），然后摸 1 张牌（“并摸一张牌”仅在确实使用了这张追击【杀】后触发）。

**待主创确认**：
1. 【司镇】采用 JSON 版（不要求曹真本阶段未受伤）还是 CSV 版（要求曹真本阶段未受伤）？按既有惯例拟采用 JSON 版，请确认。
2. 【司镇】“你响应过牌”的精确判定范围：是否指本阶段内曹真**因其他牌/同牌的响应询问而使用或打出过牌**（如对【杀】/【决斗】/【南蛮】/【万箭】使用或打出【杀】/【闪】，或使用【无懈可击】响应锦囊），不包含响应【火攻】展示/弃牌、也不包含响应【铁索连环】等非响应牌操作？
3. 【虎豹骑】的两处关键细节：
   - 追击“对相同目标使用一张【杀】”是否**无视距离限制**（因为目标已经强制锁定为原【杀】的唯一目标）？
   - 若某拥有【虎豹骑】的角色使用了一张目标唯一的【杀】，之后该【杀】通过【方天画戟】/【铁脊】等增加了额外目标变成 2 目标，则该【杀】不属于“目标唯一”，不消耗“首张”机会；若确实目标唯一但发动者选择放弃追击，是否仍已消耗本回合“首张”机会？
