# WEI035 陈群：矢包技能审阅

- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。

## 品第

**技能原文**：品第：出牌阶段，或当你受到伤害后，你可以弃置一张本回合未以此法选择过的类别的牌，然后令一名本回合未以此法选择过的其他角色摸或弃置X张牌（X为你本回合发动此技能的次数）。若其已受伤，你横置。

**结算分析**：
- **双触发入口**：
  1. 陈群的出牌阶段空闲时间点（主动技）；
  2. 陈群受到伤害后（任意回合均可，触发技）。
- **两项本回合不重复约束**（两个入口共用本回合记录）：
  1. 弃置的牌类别（基本牌、锦囊牌、装备牌）须为本回合尚未因【品第】弃置过的类别（每回合最多发动 3 次）；
  2. 指定的其他角色须为本回合尚未因【品第】选择过的其他在场角色。
- 发动消耗：实际弃置 1 张符合未选类别的牌（手牌或装备区牌均可）。
- 效果结算：
  - `X` 为陈群本回合发动【品第】的累计次数（含本次，即 1/2/3）；
  - 由陈群决定令该其他角色摸 `X` 张牌或弃置 `X` 张牌（不足全弃；目标无牌可弃时只能选择摸牌）；
  - 若该其他角色**已受伤**（体力值 `<` 体力上限），陈群定向横置（若陈群已处于横置状态则不再变化，也不重复触发【法恩】；若由未横置变为横置则触发陈群自己的【法恩】）。

## 法恩

**技能原文**：法恩：有角色横置或叠置后，你可以令其摸一张牌。

**结算分析**：
- 触发时机：任意在场角色（含陈群本人）**横置后**（由未横置变为横置；重置不触发），或**叠置后**（由平置变为叠置；**平置不触发**，依紫乔专栏注释“在大合集修改叠置写法之后，明确无法因角色平置而摸牌”）。
- 效果结算：陈群可以选择发动，令该角色摸 1 张牌（无回合次数限制）。

**已确认裁定**：
1. 依紫乔专栏注释，【法恩】明确仅在横置或叠置后触发，**不能**因角色平置摸牌。
