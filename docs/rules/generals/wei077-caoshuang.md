# WEI077 曹爽（效忠版）

不臣篇（下） · 效忠版 · 称号“缧絷何辞”。

势力为魏。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

对应专属野心家版见[曹爽（AM(WEI077)）](am-wei077-caoshuang.md)。选将及准备阶段升变见[野心家效忠](../wild-allegiance.md)。

## 卡面原文

> 黩进：与你势力相同的角色弃牌阶段开始时，若其本回合未造成过伤害，你可以令其摸两张牌并视为对其攻击范围内由你指定的另一名角色使用一张【杀】，然后此阶段结束时，其每弃置过一张【杀】便失去1点体力。

## 结算

〖黩进〗在同势力角色弃牌阶段开始检查其本回合是否已造成过伤害。目标须在该角色攻击范围内，由曹爽指定；阶段结束逐张统计该阶段弃置过的【杀】。

## 验收场景

甲受〖黩进〗摸二并视为出杀命中，随后在弃牌阶段弃两张【杀】；阶段结束失去两点体力，不因刚造成了伤害撤回已建立的后续。
