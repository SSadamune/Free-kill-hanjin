# WEI077 曹爽（效忠版）

不臣篇（下） · 效忠版 · 称号“缧絷何辞”。

势力为魏。配将体力贡献 2 点。

资料表未从本牌列出珠联对象。

对应专属野心家版见[曹爽（AM(WEI077)）](am-wei077-caoshuang.md)。选将及准备阶段升变见[野心家效忠](../wild-allegiance.md)。

## 卡面原文

> 黩进：与你势力相同的角色弃牌阶段开始时，若其本回合未造成过伤害，你可以令其摸两张牌并视为对其攻击范围内由你指定的另一名角色使用一张【杀】，然后此阶段结束时，其每弃置过一张【杀】便失去1点体力。

## 结算

〖黩进〗在与曹爽势力相同的角色的弃牌阶段开始时，先检查该角色本回合是否未造成过伤害；满足条件并发动后，由曹爽指定该角色攻击范围内的另一名角色作为视为使用【杀】的目标；到该弃牌阶段结束时，再逐张统计该角色在此弃牌阶段中弃置过的【杀】的数量并令其失去等量体力。

## 验收场景

角色甲受〖黩进〗影响摸两张牌并视为使用【杀】命中造成伤害，随后在弃牌阶段弃置了两张【杀】；到弃牌阶段结束时，甲仍须失去 2 点体力，不会因为刚刚那张【杀】造成了伤害而撤回已经建立的后续结算。
