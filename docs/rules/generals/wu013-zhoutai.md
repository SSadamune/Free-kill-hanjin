# WU013 周泰：不屈描述修正

卡面来源见[标准武将表](../standard-generals.md)。用户于 2026-11-14 确认原文存在语病，删去“若你未移去牌，”，修正为：

> 锁定技，当你进入濒死时，你摸X张牌（X为你本回合濒死的次数），将一张牌置于武将牌上，称为“创”，然后移去至每种花色各一张，无须移去则改为回复体力至1点。

摸牌数为 X，置为“创”的牌为一张，不沿用旧程序数据中“将X张牌置于武将牌上”的文本。触发时机按[濒死事件](../../../rulebook/events/dying.md)的“进入濒死状态时”理解，不与后续“处于濒死状态时”混用。

“创”随周泰的武将牌移动。暗置周泰时保留全部“创”。[汉晋 FAQ](../../../assets/docs/规则向FAQ文件.md)

交换武将牌时，原有的“创”随周泰到新位置，保留原牌及次序。移除周泰或真正失去这份【不屈】时，将该实例剩余的“创”置入游戏牌弃牌堆。暗置期间确实失去【不屈】也按此处理。[交换武将](../general-exchange.md) · [武将牌上与牌旁的牌](../../../rulebook/terms/zone-terms/sideArea.md)

外部来源文件保留原文；程序实现与验证状态见[开发状态](../../development/status.md)。
