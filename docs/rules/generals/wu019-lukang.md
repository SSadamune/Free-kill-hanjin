# WU019 陆抗：权包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“权”包记录，并对照紫乔 B 站大合集专栏（`1178873011318554633`）及 2026-11-21 已确认裁定整理；本页为规则定稿依据，不表示已实装。

## 将牌资料

- 称号：孤柱扶廈。
- 单将体力贡献：2（原码 `6969`，对应 4 单独阴阳鱼）；主将技【决堰】含 `☯️-1` 体力贡献修正，作主将时体力贡献为 1.5。
- 珠联璧合：无。
- 公共依据：[通用约定](../general-principles.md)、[应变](../adaptation.md)、[国战标记](../player-count-and-marks.md)及[权包索引](../quan-generals.md)。

## 决堰

**技能原文**：决堰：主将技（☯️-1），准备阶段，你可以选择区域内一张牌，令一名其他角色将此牌当冰【杀】对你使用，然后你令本回合摸牌阶段摸牌数、使用【杀】次数、攻击范围共计+3。

**结算分析**：
- 主将技（仅作主将时拥有并生效，见[主副将技](../card-categories-and-operations.md#主将技--副将技)），带有 `☯️-1` 配将体力贡献修正（见[通用约定](../general-principles.md#配将体力贡献与武将状态)）。
- 触发时机：陆抗自己的准备阶段。
- 前置动作：陆抗选择**自己区域内**的一张牌（手牌区、装备区或判定区均可，依据“某人的区域”术语），令一名其他角色将该实体牌转化当冰【杀】对陆抗使用（**无视距离限制**且无视通常出杀次数）。
  - 若选中的是判定区的延时锦囊牌（如【乐不思蜀】），该牌作为实体材料被转化为冰【杀】进入处理区并结算，陆抗可借此移出判定区延时锦囊。
  - 若该其他角色因禁止目标等原因无法合法对陆抗使用此冰【杀】，则不可选择该角色发动。
- 后续分配（“然后”）：在该冰【杀】**使用结算完毕后**（若陆抗仍存活），陆抗将共计 3 点增益自由分配到“本回合摸牌阶段摸牌数”“本回合使用【杀】次数上限”“本回合攻击范围”三项中（任意非负整数分配，总和为 3）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（区域一张牌当冰【杀】 + 分配三项共计 +3）。
2. 该转化冰【杀】**无视距离限制**。
3. 三项共计 +3 在该冰【杀】**结算完毕后**再分配。

## 恪守

**技能原文**：恪守：你可以将两张牌当【闪】或【无懈可击】使用且具有<孤军→获得或消耗一枚阴阳鱼标记>。

**结算分析**：
- 转化技，在合法需要使用【闪】或【无懈可击】的窗口发动（仅限“使用”，不可用于纯“打出【闪】”窗口）。
- 转化材料：2 张牌（手牌或装备区牌均可，未限定颜色或类别）；转化为 1 张普通【闪】或【无懈可击】，且按[汉晋应变](../adaptation.md)登记应变条目 `<孤军 → 获得或消耗一枚阴阳鱼标记>`。
- 应变判定与标记操作：使用此转化牌时若陆抗满足`<孤军>`（已确定势力且本势力存活在场角色数为 1），则触发应变效果（属于正式应变牌，可与铜雀、贾充等应变关联技能联动）：
  - 若选择**获得**：获得 1 枚阴阳鱼标记（受[阴阳鱼标记上限 5](../player-count-and-marks.md#阴阳鱼标记上限)约束）；
  - 若选择**消耗**（须陆抗当前已有至少 1 枚阴阳鱼标记）：消耗自己 1 枚阴阳鱼标记并直接触发其标记效果（摸 1 张牌或令本回合手牌上限 +2）。

**已确认裁定**：
1. 正式版本采用石激桑 JSON（`<孤军→获得或消耗一枚阴阳鱼标记>`）。
2. 依紫乔专栏注释，“消耗标记”指触发该国战标记原本的效果（以阴阳鱼为例，即摸 1 张牌或令本回合手牌上限 +2），使陆抗能提前兑现已有标记收益。
