## 决堰

**技能原文（JSON）**：决堰：主将技（☯️-1），准备阶段，你可以选择区域内一张牌，令一名其他角色将此牌当冰【杀】对你使用，然后你令本回合摸牌阶段摸牌数、使用【杀】次数、攻击范围共计+3。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为完全不同的旧版本：“主将技，你计算体力上限减少1个单独的阴阳鱼。准备阶段，你可以选择一个有牌的区域并于本回合获得对应效果，结束阶段弃置此区域所有牌：判定区，获得‘集智’并跳过判定阶段；装备区，摸三张牌且手牌上限+3；手牌区，使用【杀】次数+3。”

**结算分析（按 JSON 口径）**：
- 主将技（仅作主将时拥有并生效，见[主副将技](../card-categories-and-operations.md#主将技--副将技)），带有 `☯️-1` 配将体力贡献修正（见[通用约定](../general-principles.md#配将体力贡献与武将状态)）。
- 触发时机：陆抗自己的准备阶段。
- 前置动作（“可以 A，然后 B”依赖关系见[通用约定](../general-principles.md#易读描述的时机与然后)）：陆抗选择**自己区域内**的一张牌（手牌区、装备区或判定区均可，依据“某人的区域”术语），并令一名其他角色将该实体牌转化当冰【杀】对陆抗使用。
  - 注意：该转化冰【杀】由该其他角色使用，若该其他角色无法合法对陆抗使用此冰【杀】（如陆抗处于不可被杀指定状态、或该角色被限制不能出杀），须明确无合法使用时不可执行后续分配。
  - 若该冰【杀】成功使用（触发冰【杀】结算，包含可能的防具/【闪】/冰杀弃两牌防伤等），则执行后续“然后”：陆抗将共计 3 点增益自由分配到“本回合摸牌阶段摸牌数”“本回合使用【杀】次数上限”“本回合攻击范围”三项中（例如 3/0/0、2/1/0、1/1/1 等非负整数分配）。
- 若选中的是判定区的延时锦囊牌（如【乐不思蜀】），该牌作为实体材料被转化为冰【杀】进入处理区并结算，陆抗等于借机移除了判定区延时锦囊。

**待主创确认**：
1. 【决堰】采用 JSON 新版（选区域一张牌令他人当冰杀对自己用 + 分配三项共计 +3）还是 CSV 旧版（选有牌区域获得对应效果、结束阶段弃置该区域）？按既有惯例拟采用 JSON 新版，请确认。
2. JSON 新版中“令一名其他角色将此牌当冰【杀】对你使用”：
   - 是否**无视距离限制**（因为目标已强制指定为陆抗）？
   - 后续三项“共计 +3”是在冰【杀】**使用结算完成后**分配，还是在冰【杀】**宣告使用时**即分配？（按“然后”语义通常在用杀动作执行/结算完毕后分配；且若陆抗因该冰杀阵亡则不再分配。）

## 恪守

**技能原文（JSON）**：恪守：你可以将两张牌当【闪】或【无懈可击】使用且具有<孤军→获得或消耗一枚阴阳鱼标记>。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 将应变效果写作 `<孤军→补充阴阳鱼标记>`（“补充”仅 0→1，不能超过 1 枚，且不能消耗；JSON 写“获得或消耗一枚阴阳鱼标记”，允许叠加获得至上限 5 或顺便消耗已有标记）。

**结算分析（按 JSON 口径）**：
- 转化技，在合法需要使用【闪】或【无懈可击】的窗口发动（仅限“使用”，不可用于纯“打出【闪】”窗口）。
- 转化材料：2 张牌（手牌或装备区牌均可，未限定颜色或类别）；转化为 1 张普通【闪】或【无懈可击】，且按[汉晋应变](../adaptation.md)登记应变条目 `<孤军 → 获得或消耗一枚阴阳鱼标记>`。
- 应变判定：使用此转化牌时若陆抗满足`<孤军>`（已确定势力且本势力存活在场角色数为 1），则触发应变效果（属于正式应变牌，可与铜雀、贾充等应变关联技能联动）；受[阴阳鱼标记上限 5](../player-count-and-marks.md#阴阳鱼标记上限)约束。

**待主创确认**：
1. 【恪守】的孤军应变效果采用 JSON（“获得或消耗一枚阴阳鱼标记”）还是 CSV（“补充阴阳鱼标记”）？拟采用 JSON，请确认。
2. 若采用 JSON“获得或消耗一枚阴阳鱼标记”：
   - 触发孤军应变时，若陆抗当前有 0 枚阴阳鱼，是否只能执行“获得 1 枚阴阳鱼”；若已有 `1~4` 枚阴阳鱼，则二选一（获得 1 枚，或直接触发消耗 1 枚阴阳鱼的效果——如摸 1 牌或手牌上限 +2）？
   - 若“消耗一枚阴阳鱼标记”指的是**直接触发阴阳鱼标记效果（摸 1 牌 / 手牌上限 +2）**，请确认该消耗是否同时消耗自己已有的一枚阴阳鱼，还是凭空触发一次消耗效果？（按“获得或消耗一枚阴阳鱼标记”字面，通常理解为：自己已有阴阳鱼时可选择弃置/触发消耗自己 1 枚阴阳鱼，以配合某些消耗标记触发技；若无则只能获得。）
