## 铁脊

**技能原文（JSON）**：铁脊：你可以将两张牌当目标+1的火【杀】使用，然后选择一名与你势力相同的其他角色，若此火【杀】伤害数大于1，则你与其补充阴阳鱼标记，否则其选择是否用一个武将交换此武将。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 为完全不同的旧版本且无【醇义】：“你可以将两张牌当火【杀】使用或打出，然后若此牌造成伤害，你可以将这些牌交给一名其他角色，若其与你势力相同，你可以令其选择是否用一个武将交换此武将。”

**结算分析（按 JSON 口径）**：
- 转化技（仅限“使用”，不含“打出”；无每回合限一次限制，受通常出杀次数约束，非空闲点效果用杀不占次数）。
- 转化材料：2 张牌（手牌或装备区牌均可，不限颜色/类别），当一张**额外可选 1 个目标（目标上限 +1）的火【杀】**使用（可只选 1 名目标，也可在合法攻击范围内选 2 名目标）。
- 结算完毕后的“然后”分支：
  - 该火【杀】结算结束后，程普选择一名与自己势力相同的其他角色（若场上没有其他同势力角色，则无法选择，跳过后续）；
  - 统计此张火【杀】在本次结算中**实际造成的总伤害点数**（包含对单个目标造成的 2 点以上伤害，或对多个目标/铁索传导造成的合计伤害？需明确是否包含属性传导伤害）：
    - 若伤害总数 `> 1`（即 `>= 2`）：程普与该角色各**补充** 1 枚阴阳鱼标记（依据[FAQ：消耗/补充国战标记](../../../assets/docs/规则向FAQ文件.md#消耗补充国战标记)，“补充”仅在当前为 0 枚时获得至 1 枚，已有阴阳鱼则不增加）；
    - 否则（伤害总数 `<= 1`，含被闪避 0 伤或仅造成 1 点伤害）：该同势力角色选择是否用自己的一个合法明置武将/位置，与程普的**此武将牌**（程普）执行[交换武将](../general-exchange.md)。

## 醇义

**技能原文（JSON，CSV 未录）**：醇义：与你势力相同的角色可以将国战标记当【酒】使用。

**结算分析**：
- 群体增益技（无“锁定技”标签，由与程普势力相同的角色在需要使用【酒】的窗口主动发动，含程普本人；仅当程普明置在场时生效）。
- 适用标记：任意国战标记（阴阳鱼、先驱、珠联璧合），参照[FAQ：将国战标记当牌使用](../../../assets/docs/规则向FAQ文件.md#将国战标记当牌使用)——消耗该国战标记当一张无色无实体牌的【酒】使用（包含出牌阶段增伤与濒死自救；使用后该标记消耗并移回标记堆，同时计为一次“消耗国战标记”）。
- 受通常【酒】的使用次数限制（每回合限一次，濒死自救不受该限制）。

**待主创确认**：
1. 程普采用 JSON 新版（新版【铁脊】+【醇义】）还是 CSV 旧版（仅旧版【铁脊】）？按既有惯例拟采用 JSON 新版，请确认。
2. JSON 版【铁脊】中“若此火【杀】伤害数大于 1”：若此火【杀】命中铁索连环目标并经属性传导造成多点伤害，传导伤害是否计入“此火【杀】伤害数”？（在引擎中传导伤害的 `card` 仍为此火【杀】，一般计入；请确认。）
3. 【醇义】中的“国战标记”是否包含全部三种常规国战标记（阴阳鱼、珠联璧合、先驱），但不包含君主专属特殊标记（如诏书、赐）？
