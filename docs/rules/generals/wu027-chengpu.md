# WU027 程普：矢包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“矢”包记录，并对照紫乔 B 站大合集专栏（`1180345691175649301`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 称号：三朝虎首。
- 单将体力贡献：2（原码 `6969`，对应 4 单独阴阳鱼）。
- 珠联璧合：`EM(WU010)`（君孙策）、`WU010`（孙策）、`WU005`（周瑜）。
- 公共依据：[通用约定](../general-principles.md)、[交换武将](../general-exchange.md)、[国战标记当牌使用](../../../assets/docs/规则向FAQ文件.md#将国战标记当牌使用)及[矢包索引](../shi-generals.md)。

## 铁脊

**技能原文**：铁脊：你可以将两张牌当目标+1的火【杀】使用，然后选择一名与你势力相同的其他角色，若此火【杀】伤害数大于1，则你与其补充阴阳鱼标记，否则其选择是否用一个武将交换此武将。

**结算分析**：
- 转化技（仅限“使用”，不含“打出”；无每回合限一次限制，受通常出杀次数约束，非空闲点效果用杀不占次数）。
- 转化材料：2 张牌（手牌或装备区牌均可，不限颜色/类别），当一张**额外可选 1 个目标（目标上限 +1）的火【杀】**使用（可只选 1 名目标，也可在合法攻击范围内选 2 名目标）。
- 结算完毕后的“然后”分支：
  - 该火【杀】结算结束后，程普选择一名与自己势力相同的其他角色（若场上没有其他同势力角色则跳过后续）；
  - 统计此张火【杀】在本次结算中**实际造成的总伤害点数**（包含直接命中多个目标的伤害，也**计入**经【铁索连环】属性传导造成的伤害）：
    - 若伤害总数 `> 1`（即 `>= 2`）：程普与该角色各**补充** 1 枚阴阳鱼标记（依紫乔专栏注释，“补充标记”指国战标记从 0 到 1，已有阴阳鱼则不增加）；
    - 否则（伤害总数 `<= 1`，含被闪避 0 伤或仅造成 1 点伤害）：该同势力角色选择是否用自己的一个合法明置武将/位置，与程普的**此武将牌**（程普）执行[交换武将](../general-exchange.md)。

**已确认裁定**：
1. 正式版本采用石激桑 JSON 新版（新版【铁脊】+【醇义】）。
2. 此火【杀】经【铁索连环】**传导**造成的伤害**计入**“此火【杀】伤害数大于 1”。

## 醇义

**技能原文**：醇义：与你势力相同的角色可以将国战标记当【酒】使用。

**结算分析**：
- 群体增益技（由与程普势力相同的角色在需要使用【酒】的窗口主动发动，含程普本人；仅当程普明置在场时生效）。
- 适用标记：**所有国战标记**——包含阴阳鱼、珠联璧合、先驱以及君司马炎的 **〖赐〗**（依紫乔弩包专栏分类，〖赐〗与阴阳鱼/珠联璧合同属国战标记；诏书属于独立指示物，不属于国战标记）。
- 消耗规则：参照紫乔专栏注释及[FAQ：将国战标记当牌使用](../../../assets/docs/规则向FAQ文件.md#将国战标记当牌使用)——消耗该国战标记当一张**无色无实体牌**的【酒】使用（包含出牌阶段增伤与濒死自救；使用后该标记移出游戏返回标记堆，同时计为一次“消耗国战标记”）。
- 受通常【酒】的使用次数限制（每回合限一次，濒死自救不受该限制）。

**已确认裁定**：
1. 【醇义】可用的国战标记**包含**常规国战标记（阴阳鱼、珠联璧合、先驱）与君司马炎的 **〖赐〗**（诏书非国战标记，不包含）。
