## 密重

**技能原文（JSON / CSV 一致）**：密重：锁定技，当你受到伤害时，若你的手牌数等于体力值，此伤害-1。

**结算分析**：
- 锁定技，触发时机为顾雍受到伤害时（扣减体力前）。
- 判断顾雍当前手牌数是否严格等于当前体力值；若成立，此伤害 `-1`（降为 0 则防止此次伤害）。

## 秉壹

**技能原文（JSON）**：秉壹：每阶段限一次，当你因弃置而失去牌后，你可以展示手牌，若颜色均相同，你令至多等同你手牌数的角色各摸一张牌。

**来源差异（CSV）**：[药枫 CSV](../../../assets/docs/药枫桑大合集337.csv) 写作“令至多**等量名**角色各摸一张牌”，语义与 JSON 一致（JSON 明确指出了“等同你手牌数”而非“等同弃置张数”）。

**结算分析**：
- 触发时机：**每阶段限一次**（不限于弃牌阶段，出牌阶段主动弃牌或他回合被【过河拆桥】/技能弃牌均可触发，同一阶段内只可发动一次），当顾雍因“弃置”原因失去牌（手牌或装备区牌均可）后。
- 前置要求：顾雍此时至少有 1 张手牌（若弃光手牌为 0 张，无法展示手牌，且至多 0 名角色无意义）。
- 效果结算：
  1. 顾雍展示当前所有手牌；
  2. 若所有展示的手牌颜色均相同（全红或全黑），设顾雍此时手牌数为 `X`，顾雍选择 `1 ~ X` 名在场角色（含顾雍自己），按座次依次令这些角色各摸 1 张牌（“至多”不含 0，见[阵势包公共依据](../zhen-shi-generals.md#公共结算依据)）。
