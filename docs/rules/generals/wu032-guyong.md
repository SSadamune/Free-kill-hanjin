# WU032 顾雍：矢包技能审阅

依据[石激桑武将列表](../../../assets/docs/石激桑武将列表.json)的“矢”包记录，并对照紫乔 B 站大合集专栏（`1180345691175649301`）及 2026-11-21 已确认裁定整理。

## 将牌资料

- 客籍：汉。按[紫乔矢包专栏](https://www.bilibili.com/opus/1180345691175649301)客将牌图标注与边框颜色登记。

- 称号：持恒以渐、庙堂的玉磬。
- 单将体力贡献：1.5（原码 `696`，对应 3 单独阴阳鱼）。
- 珠联璧合：客将珠联 `zhulian_ke` 为 `HAN012`（蔡邕），与紫乔专栏标注一致（常规珠联不含张昭；正式客将登记以客将表为准）。
- 公共依据：[通用约定](../general-principles.md)及[矢包索引](../shi-generals.md)。

## 密重

**技能原文**：密重：锁定技，当你受到伤害时，若你的手牌数等于体力值，此伤害-1。

**结算分析**：
- 锁定技，触发时机为顾雍受到伤害时（扣减体力前）。
- 判断顾雍当前手牌数是否严格等于当前体力值；若成立，此伤害 `-1`（降为 0 则防止此次伤害）。

## 秉壹

**技能原文**：秉壹：每阶段限一次，当你因弃置而失去牌后，你可以展示手牌，若颜色均相同，你令至多等同你手牌数的角色各摸一张牌。

**结算分析**：
- 触发时机：**每阶段限一次**（不限于弃牌阶段，出牌阶段主动弃牌或他回合被【过河拆桥】/技能弃牌均可触发，同一阶段内只可发动一次），当顾雍因“弃置”原因失去牌（手牌或装备区牌均可）后。
- 前置要求：顾雍此时至少有 1 张手牌（若弃光手牌为 0 张则无法展示手牌）。
- 效果结算：
  1. 顾雍展示当前所有手牌；
  2. 若所有展示的手牌颜色均相同（全红或全黑），设顾雍此时手牌数为 `X`，顾雍选择 `1 ~ X` 名在场角色（含顾雍自己，“至多”不含 0），按座次依次令这些角色各摸 1 张牌。
