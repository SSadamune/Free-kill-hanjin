# WU038 岑昏

不臣篇（中） · 普通 · 称号“伐梁倾瓴”。

势力为吴。配将体力贡献 1.5 点。

珠联璧合登记为孙皓（WU045）。

## 卡面原文

> 兴筑：每回合每种副类别限一次，你可以将一张装备牌当【勠力同心】使用或重铸。

> 众矢：锁定技，当你受到非传导属性伤害时，若你横置，与你势力相同的其他角色依次重置，然后此伤害+1。

## 结算

〖兴筑〗同一回合按装备副类别记机会，同副类别转化使用与重铸共享。〖众矢〗限横置时受非传导属性伤害，同势力其他角色依次重置，须有人实际重置才加伤。

## 验收场景

岑昏横置，受一点直接火焰伤害。若队友均未横置，则无人重置，伤害仍是一点；有一名队友实际重置时，改为两点。
