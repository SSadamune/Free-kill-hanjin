# WU086 吴景

不臣篇（上） · 普通 · 称号“坚攻勉策”“汗马鎏金”。

势力为吴，客籍为群。配将体力贡献 2 点。

珠联璧合登记为孙坚（WU009）。

客籍在原有主势力全部不可用时按本局允许集启用。[客将](../guest-factions.md)

## 卡面原文

> 合击：当一名角色使用【决斗】或红色【杀】后，若此牌仅指定唯一目标且非转化，你可以对相同目标使用一张【决斗】或【杀】并摸一张牌。

> 风扬：阵法技，其他势力角色每回合首次弃置或获得你队列的角色装备区里的牌时，防止之。

## 结算

〖合击〗核对原牌是否为非转化的【决斗】或红色【杀】且仅指定了唯一目标；满足条件时，由吴景对同一目标追击使用一张【决斗】或【杀】并摸一张牌。〖风扬〗按每名其他势力角色分别记录其本回合第一次弃置或获得吴景所在队列角色装备区牌的行为，并予以防止。

## 验收场景

一名角色使用一张非转化的红色【杀】仅指定甲为目标后，吴景可以再对甲使用一张合法的【杀】或【决斗】并摸一张牌；如果原牌是其他角色将红色装备牌转化而来的【杀】，则不满足“非转化”条件，不能触发〖合击〗。
