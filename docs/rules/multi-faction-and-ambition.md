# 多势力声明、暴露野心、拉拢人心与纵横（规范草案）

本文整理汉晋国战中尚未全面接入代码、但已有明确外部 FAQ 依据的四项核心原创规则草案（对应 [Issue #2](https://github.com/SSadamune/Free-kill-hanjin/issues/2)、终局胜负窗口、不臣篇及纵横捭阖包），供主创人工审阅与后续实现使用。**标明“待确认”的细则未经主创拍板前不视为定案。**

> 外部依据：[规则向 FAQ](../../assets/docs/规则向FAQ文件.md)；未发布的叛首、叛谍、宗族指示物、臣属本页仅在操作限制处注明边界，不展开实装规范。

## 1. 多势力武将与首次明置声明势力

### 身份判断基准（已确认）

依据[通用约定](general-principles.md#配将体力贡献与武将状态)与[FAQ：双势力/多势力武将牌的判断基准](../../assets/docs/规则向FAQ文件.md#双势力多势力武将牌的判断基准)：

- 制图左上角印有多个势力字的武将即为多势力武将牌，**不受本局禁选势力影响**（不能因为禁选后只剩 1 个可用势力，就认为原牌不再是多势力武将）。
- 所有主势力均被禁选、且拥有多于 1 个副势力（客将势力）的客将，在本局也视为多势力武将牌。
- 多势力武将的所有主势力在配将与禁选时同等有效，放在主将或副将位置均可（见[势力禁选](faction-ban.md#1-内容边界与术语)）。

### 首次明置声明势力（对应 Issue #2）

依据[FAQ：多势力武将规则](../../assets/docs/规则向FAQ文件.md#多势力武将规则)：

1. **选将阶段不提前锁死唯一势力**：当两名所选武将（含多势力武将、客将启用多副势力、或主将为专属野心家）在本局允许势力内存在**多于一种合法搭配势力**时，选将阶段仅校验存在合法搭配，不强制在暗置状态下锁死最终势力。
2. **首次明置时声明**：一名角色首次明置一张武将牌时，若该武将牌的所属势力存在多种可能（如多势力武将、管宁等），须正确声明该武将牌所属势力：
   - **适配势力定义**：指该武将牌本局有效主势力中，能够与其配将形成合法双将组合的势力集合。
   - **唯一适配势力**：若适配势力只有 1 种（例如：配将已明置或为单势力武将且双方仅有 1 个共同允许势力），必须声明该唯一适配势力。
   - **多适配势力（自选声明）**：若其主将为**未明置的野心家专属武将**，或两张武将牌在本局允许集内共有**多于一种相同势力**，则由该角色从所有合法适配势力中**自选声明**其中一种。
3. **连锁约束**：一旦先明置的武将牌声明并确定了势力，另一张暗置武将牌在后续明置、野心家效忠判断或响应阵法召唤时，均须受已声明势力的合法搭配约束（参考 FAQ 极例：公孙渊-孟达组合，若孟达已因响应蜀势力【将略】或【天覆】明置并声明为蜀，则公孙渊不可再效忠魏；若孟达未明置，则可按魏孟达组合效忠）。

## 2. 暴露野心与拉拢人心

本节针对**野心家专属武将**（`kingdom = "wild"`）；普通武将因人数超员变为野心家时不触发暴露野心与建国询问（见[野心家效忠](wild-allegiance.md)）。

### 触发时机：暴露野心

- 在[死亡结算流程](turn-death-and-reveal-timing.md#4-死亡结算完整时序)第 2 步及其他触发胜负判定的节点，**游戏即将结束时**（场上仅余唯一势力，准备宣告胜利之前），所有仍处于暗置状态的野心家专属武将**依次明置**（按当前回合角色起逆时针座次），然后依次发起**「拉拢人心」**。
- 被移出游戏且主将暗置的专属野心家，可以触发「暴露野心」明置主将，但**不能发起「拉拢人心」**。
- 若因暴露野心或拉拢人心导致场上不再只剩唯一势力，则本次胜利条件不再成立，游戏继续进行。

### 执行流程：拉拢人心

1. 发起者声明一个新的国号作为自己的势力（可选国号**排除「汉」「晋」**，未被占用的「韩」仍可选，见[野心家效忠](wild-allegiance.md)）。
2. 令所有符合条件的角色依次选择是否将自己的势力改为发起者的势力。
3. **响应人数上限**：默认**只有 1 名角色**可以响应加入（首位选择响应者改变势力后停止询问）；部分专属野心家技能可增加「拉拢人心」可响应的角色数。
4. **后续限制**：通过「拉拢人心」成功改变势力的角色，之后**不可再改变势力**。

### 特殊武将牌操作限制

依据[FAQ：特殊武将牌操作限制](../../assets/docs/规则向FAQ文件.md#特殊武将牌操作限制)及已确认项目口径（[通用约定](general-principles.md#武将位置武将牌与士兵牌)）：

| 牌类 / 角色身份 | 不可移除 / 变更 / 交换 | 不可暗置 | 不可改变势力 |
| --- | --- | --- | --- |
| 君主武将牌 | 是（项目裁定按实际牌身份，不因暗置解除） | 是 | 是 |
| 专属野心家武将牌 | 明置时不可（特殊明文除外） | 是 | 是 |
| 拉拢成功势力角色 | 按普通武将牌处理 | 按普通武将牌处理 | 是 |
| 臣属 / 叛谍 / 叛首（未发布） | FAQ 列明受限，本阶段暂不实装 | 臣属不可 | 均不可 |

## 3. 纵横机制

依据[FAQ：纵横](../../assets/docs/规则向FAQ文件.md#纵横)，供未来「纵横捭阖」分包（12 将）复用：

- **定位**：「纵横」是一个技能中可能包含的动作，不是独立时机。
- **发动效果**：当带「纵横」动作的技能指定其他角色后，若该目标角色**当前不拥有该技能的“纵横版本”（简称“纵横技能”）**，发动者可以令该目标**视为拥有该纵横技能，直到目标角色的下一个回合结束**。
- **纵横技能生成规则**：
  1. 按原技能描述中专门注明的“纵横：……”修改要求调整文本与效果（如有）；
  2. 默认**删除原技能中与“纵横”动作及纵横触发相关的字段**，防止被授予者继续二次连锁纵横（除非技能另有明文说明）。

## 4. 待主创确认项（审阅清单）

1. **「拉拢人心」的“符合条件的角色”范围**：发起拉拢人心时，除被移出游戏者及规则明文禁止改势力者（君主、专属野心家、已拉拢成功角色）外，是否**所有其他存活角色（含已明置的普通势力角色、暗置角色、超员天然野心家）**均可选响应，还是仅限未确定势力 / 非大势力 / 孤军角色？
2. **「暴露野心」的明置顺序与副将处理**：终局触发暴露野心时，若存在多名未明置的专属野心家，按当前回合角色起逆时针依次“全部先明置，再依次发起拉拢人心”，还是“第一人明置并拉拢完，再轮到第二人明置并拉拢”？此外，暴露野心仅明置专属野心家主将，还是同时明置其副将？
3. **多势力武将响应强制/自愿明置（如阵法召唤、技能预亮）**：当一名角色持有暗置多势力武将，因响应某势力阵法召唤（如蜀势力）或某势力专属效果而明置时，其声明势力是否必须限制为该触发势力（即只能声明为蜀）？若先明置的副将是多势力武将、而主将是暗置专属野心家，主将之后明置暴露为野心家时，副将之前自选声明的势力是否直接覆盖为野心家？
4. **「纵横」授予的到期点与重名冲突**：
   - “直到其下一个回合的结束”：若目标在自己当前回合内被授予纵横技能，是在**当前回合结束**到期，还是在**再下一个回合结束**到期？额外回合是否计入“下一个回合”？
   - 若目标角色本身已拥有原版（带纵横的）同名技能，但尚不拥有“纵横技能”版本，是否仍可对其授予纵横版本（并作为独立来源共存）？
5. **专属野心家暗置状态下的移除/交换保护**：项目已裁定**君主武将牌**按实际牌身份受保护（即使暗置也不可被移除/变更/交换）；**专属野心家武将牌**在暗置状态是否与君主一致按实际牌身份保护，还是按 FAQ 原文仅保护“明置的专属野心家”？
