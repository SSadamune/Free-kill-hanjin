## 主创速审：待裁定问题汇总

### 一、版本基准总确认（JSON vs CSV 差异）

按项目既有惯例，**拟统一以 [石激桑武将列表.json](../../assets/docs/石激桑武将列表.json) 为正式卡面与版本基准**。以下 9 将存在实质差异，请主创确认是否全部采用 JSON 版：

1. **管亥（QUN139）**：两份资料完全不同——JSON 为双技能【卸尾】（置「饵」每轮各限一次转杀/闪）+【诱阙】（最小饵拼点雷杀），统领牌为【铁索连环】；CSV 为单技能【索粮】，统领牌为雷【杀】。
2. **高顺（QUN029）**：【迅击】JSON 为每回合结束时集中视为杀喝酒或回合外亮将者（CSV 为回合外亮将后立刻杀）；【擐甲】JSON 无每回合限一次/唯一目标/仅武器防具限制，且结算后还同副类别牌（CSV 限制较多）。
3. **张翼（SHU054）**：【殿军】JSON 为可选额外出牌阶段 + 失血转杀（CSV 为锁定自伤执行额外出牌阶段）；【抗锐】JSON 为“首次扣减体力后”（CSV 为“首次受到伤害后”）。
4. **杨奉&韩暹（HAN043）**：【拔驾】JSON 为同势力共享「舆」+ 阶段结束惩罚 + 直接暗置（CSV 为同队列共享 + 回合结束惩罚 + 双明才暗置）。
5. **陶谦（HAN055）**：【厉治】否则分支 JSON 为“你摸一张牌且交给其一张牌”（CSV 为“令你或其摸一张牌”）。
6. **曹真（WEI034）**：【司镇】JSON 删去“若此阶段你未受到过伤害”前置门槛（CSV 保留该门槛）。
7. **韩当（WU028）**：【弓骑】JSON 攻击范围 `+4`（CSV 为无限）；【解烦卫】统领牌 JSON 为【杀】（CSV 为【知己知彼】）。
8. **李秀（JIN067）**：【誓众】JSON 为“每阶段限一次”（CSV 为“出牌阶段限一次”）。
9. **孟观（JIN076）**：【积弩】JSON 为“使用或打出”均判定（CSV 仅“使用”）。

### 二、关键结算边界确认

1. **杨奉&韩暹【拔驾】**：
   - 明置时若场上只有自己装备区有装备，能否直接标记为「舆」？
   - 「舆」为魏/晋双势力【虚妄之冕】时是否同时对魏、晋强命？
   - 阶段外失去「舆」时，“于此阶段结束时”惩罚如何落点？
   - 同势力其他角色已有同副类别实体装备时，是否仍同时享有虚拟「舆」效果？
   - JSON `zhulian_ke` 登记 `WEI010`（徐晃），确认其客将势力含魏。
2. **管亥【诱阙】（若采 JSON 版）**：
   - 「饵」是否为明置公开？原文漏字“你可以一张手牌”按“你可以将一张手牌”处理？
   - “弃置其中点数大于拼点牌的牌”中的“拼点牌”指**没赢者自己的拼点牌**还是**赢者的拼点牌**？视为使用雷【杀】是否无视距离？
3. **高顺【迅击】与【擐甲】**：
   - 【迅击】依次视为使用【杀】是否无视距离？
   - 【擐甲】借双副类别坐骑后归还同副类别牌的边界，以及对方原栏位非空时的处理（顶替还是留在高顺处）？
4. **张嶷【越险】与张翼【殿军】/【抗锐】**：
   - 【越险】“只能使用因此摸的牌响应此【杀】”是否明确封锁【八卦阵】/【八阵】与统领【闪】？同时满足 `<2` 手牌且未受伤时可在 `0/1/2` 三选一？
   - 【殿军】回合结束时额外出牌阶段结束后是否直接接续剩余回合结束流程（不再弃牌/再触发殿军）？【抗锐】“扣减体力”是否排除纯减上限压低体力？选项 2“手牌上限为 0”是绝对覆盖还是可被阴阳鱼 +2 加回？
5. **陶谦【州忧】、曹真【司镇】、曹纯【督锐】、李秀【替军】/【誓众】、孟观【积弩】**：
   - 【州忧】3 张牌是可任意分配给多名其他角色，还是必须全给同一名其他角色？
   - 【司镇】“响应过牌”是否仅指响应询问使用或打出牌？【督锐】同势力伤害统计按结算时同势力追溯？
   - 【替军】置入装备牌仅限李秀自己的装备牌，且是否遵循[空栏规则](equipment-movement.md)？【誓众】摸牌须以实际多指定目标为前提？
6. **翼从公共边界**：
   - **虎豹骑**：追击【杀】是否无视距离？首张唯一目标【杀】放弃追击是否仍消耗本回合“首张”？
   - **宿卫中军**：判定后视为用【杀】是否无视距离？
   - **解烦卫**：能否对满血角色发动以纯复原技能？对他人复原限定技由谁选择？
   - **丹阳青巾**：自己对自己用【桃】/【酒】/装备牌是否触发？贺齐【华甲】对同一角色多份丹阳青巾按人去重计装备数？
