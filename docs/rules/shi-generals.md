## 主创速审：待裁定问题汇总

### 一、版本基准总确认（JSON vs CSV 差异）

按项目既有惯例，**拟统一以 [石激桑武将列表.json](../../assets/docs/石激桑武将列表.json) 为正式卡面与版本基准**。以下 8 将存在实质差异，请主创确认是否全部采用 JSON 版：

1. **程普（WU027）**：JSON 为新版【铁脊】（目标+1火杀、伤>1补阴阳鱼否则换将）+【醇义】（同势力国战标记当酒）；CSV 为旧版【铁脊】且无【醇义】。
2. **袁隗（HAN051）**：【趋奉】JSON 为每回合限一次交/得牌且手牌数大于对方各摸一；CSV 为远交近攻/合纵锁定技。
3. **杨仪（SHU091）**：【度断】JSON 含使用和打出（CSV 仅使用）；【孤忿】JSON 为必换将+常驻方片锦囊只能当酒（CSV 为变更或换此将+仅鏖战红色锦囊当酒）。
4. **高览（QUN079）**：JSON 拆为独立【袭阵】（仅其他势力、高览拆牌）+【芟敌】（不限异势力）；CSV 为单技能合并版。
5. **田畴（HAN047）**：【锋引】JSON 为普通【杀】强命无攻距加成（CSV 为红杀+攻距）；【径出】JSON 多出“摸两张交一张”且换此武将。
6. **成济&成倅（JIN037）**：【畜鸣】JSON 为“将杀当酒对你使用 + 交杀 + 视为用无视武器限制借刀/过拆”；CSV 为交杀令下次伤害/受伤+1。
7. **蔡夫人（QUN033）**：【窃听】JSON 为“未对与其势力不同角色使用过手牌”（CSV 为未对除其外角色用过牌）；【献州】JSON 先回血后打伤（CSV 先打伤后回血）。
8. **胡奋（JIN066）**：【威惠】【练战】JSON 为“你可以”可选触发（CSV 为必然触发）。
