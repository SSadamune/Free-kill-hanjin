## 公共结算依据

- 矢包 12 名普通武将均不依赖未发布的原创大系统，且无新增统领翼从；高频复用机制包括[交换武将](general-exchange.md)（田畴、杨仪、程昱、程普、高览、胡奋共 6 将）、[移出游戏](../../assets/docs/规则向FAQ文件.md#将角色移出游戏)（田畴）、[“只能当”](only-as.md)（杨仪）、[额外目标](extra-targets.md)（董允）、[装备移动与置入](equipment-movement.md)（蔡夫人）及[国战标记当牌使用](../../assets/docs/规则向FAQ文件.md#将国战标记当牌使用)（程普）。
- **编号纠错**：成济&成倅正式编号以石激桑 JSON 及紫乔专栏的 `JIN037` 为准（旧版药枫 CSV 误标为 `JIN035`）。

## 已确认裁定与实装约束

- **版本基准**：矢包全部 12 名普通武将均以[石激桑武将列表](../../assets/docs/石激桑武将列表.json)为正式版本（杨仪【孤忿】明确以 JSON“**一个武将**”为准，不采专栏旧文案“此武将”）；旧版药枫 CSV 差异不再作为候选。
- **指代通则**：“其他角色”为非“你”的角色；相对于目标 A 的“另一名角色”为非 A 的任意角色（**包含“你”自己**）。
- **田畴**：【锋引】为普通【杀】强命无攻距加成；【径出】摸两张交一张且换此武将，移出游戏防止当前回合与濒死角色被移出；确认客魏及与夏侯惇的客将珠联。
- **袁隗**：【唆令】“另一名角色（后者）”允许选**袁隗自己**，目标无两张黑手牌不可选选项 1；选项 1 与选项 2 的【杀】均**无视距离**，选项 2 **允许**通过转化技/装备转化出【杀】；【趋奉】采用交/得牌手牌更多各摸一新版。
- **陈群**：【法恩】明确**平置不摸牌**；紫乔专栏评论区确认陈群**客蜀**。
- **程昱**：【胆戾】复用君曹操【建安】已实装技能 ID。摸牌追平允许摸 0 张；来源已死亡时，仍可移除副将并回复 1 点体力，跳过来源弃牌。【脱先】交换武将时由被指定的**另一名同势力角色**选定双方各一个合法明置武将。
- **董允**：【秉正】为董允自己回合结束时、摸/弃由董允决定；【舍宴】严格遵循额外目标合法性（专栏附图确认远交近攻新版统一摸 3 一次、洞烛先机/无中生有可加目标）。
- **杨仪**：【度断】覆盖使用与打出，**允许在出牌阶段空闲时间点主动发动**，禁止某牌名后本回合不再生成“当你需要使用时”；【孤忿】按 JSON“**一个武将**”交换，方片锦囊（含延时锦囊）只能当【酒】使用。
- **程普**：【铁脊】火【杀】经【铁索连环】**传导**造成的伤害**计入**“此火【杀】伤害数大于 1”，补充标记指从 0 到 1；【醇义】国战标记**包含**常规三标记与君司马炎的 **〖赐〗**（诏书非国战标记，不包含），标记当牌使用为无色且用后返还标记堆。
- **顾雍与高览**：顾雍珠联以 JSON 为准（客将珠联蔡邕，不含张昭）；高览【芟敌】具体交换的两个武将位置由**高览指定**，客将珠联张郃。
- **蔡夫人**：【窃听】按“成为目标时”确定实际用牌对象，取消的目标不计，转移后按新目标判断。对**未确定势力（暗将）**角色使用手牌**不算**“与其势力不同”，不破坏条件；【献州】先回血再打伤，“至多等量名角色”遵循“至多”不含 0 原则，**不能选 0 人**放弃伤害（仅攻击范围内无任何角色时跳过）。
- **成济&成倅**：【养刀】视为装备无实体牌，不能移动/合纵不存在的实体武器；【畜鸣】将【杀】当【酒】对成济&成倅使用**不占发起者饮酒次数**，且令成济&成倅在当前他人回合内进入饮酒状态；无视武器限制的【借刀杀人】若不出【杀】且无武器则无事发生。
- **胡奋**：【威惠】【练战】均为可选触发，交换后按新位置与新持有者触发对应主/副将技；明置后/交换后均在**当前结算结束后**执行。
