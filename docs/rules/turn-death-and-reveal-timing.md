# 回合轮次、死亡流程、移出游戏与明置后结算时序

本文整理汉晋国战中四项跨技能的公共结算时序规范，依据[规则向 FAQ](../../assets/docs/规则向FAQ文件.md) 与已确认项目规范编写，供开发对齐引擎事件及后续规则集编纂参考。标明“待确认”的边界须经主创裁定。

## 1. 将角色移出游戏

以【调虎离山】（手杀版：“出牌阶段，对一至两名其他角色使用。目标角色本回合移出游戏。”）及同类技能效果为主要来源，另见[卡牌版本](card-deck.md#普通锦囊与装备的审阅结论)。

### 生效范围与例外

角色处于「移出游戏」状态时，**除以下三项外，该角色视为不存在**：

1. **结算游戏胜负条件**；
2. **执行部分死亡流程相关结算**；
3. **判断天然野心家出现条件**。

被视为不存在的范围包括但不限于：

- 距离与座次计算、相邻/围攻/队列关系；
- 存活角色数与在场角色列表计算、大小势力判定；
- 指定或成为牌的目标、普通技能选人；
- 执行技能的延时效果、发动普通技能、体力值变化、与场上角色对比手牌数/体力值等参数；
- 响应`<助战>`、发起或响应「拉拢人心」、参与「君主接替」。

### 特殊边界

- **暴露野心例外**：被移出游戏且主将暗置的专属野心家，在终局判定时仍可发动「暴露野心」（因涉及胜负结算），但**不能发起「拉拢人心」**。
- **鏖战不受影响**：鏖战是在新的回合开始时判定，此时前一回合的移出游戏状态已经结束，故移出游戏不影响鏖战判定。
- **防止移出**：**当前回合角色**或**处于濒死状态的角色**即将被移出游戏时，防止之。
- **归来时机**：移出游戏默认持续至**当前回合结束时的最后面**。其后仅允许极少数特定效果触发：①“本回合将牌移出游戏”的返还效果（如【破军】牌）；②“角色移入游戏后”效果。

## 2. 武将牌明置后与交换后统一结算窗口

依据[FAQ：武将牌明置后/交换后](../../assets/docs/规则向FAQ文件.md#武将牌明置后交换后)：

- 所有国战标记的天然获取（珠联璧合、阴阳鱼、先驱）以及糜夫人【闺秀】、廖化【当先】等“明置武将牌后”效果，**不在执行明置动作的当下立刻插入结算**。
- 这些效果统一挂起，直到**当前结算事件结束时，进入下一个空闲时间点或回合流程里的下一个时机之前**，从当前回合角色开始按**逆时针座次**依次处理本期间明置过武将牌的角色。
- 同一名角色在此窗口同时触发“明置武将牌后”技能与天然国战标记获取时，**技能结算先于游戏规则（天然标记获取）**。

### 典型案例

1. 全暗的黄月英-诸葛亮使用【敕令】，黄月英因【集智】明置，诸葛亮因【敕令】效果明置；双方在【敕令】完全结算后的下一个空闲时间点之前，才结算天然珠联璧合标记。
2. 全暗的黄月英-廖化使用【敕令】，黄月英因【集智】明置，廖化因【敕令】效果明置；在【敕令】结算后、进入下个空闲点前，① 先触发【当先】获得先驱标记，② 再由游戏规则获得天然阴阳鱼标记。

### 与升变、双亮记录的衔接

- 普通双亮、普通君主升变、死亡继位及野心家效忠对珠联璧合与阴阳鱼的重判，均须与本窗口协调，避免重复领取已领过的标记，详见[第二君主：升变后的珠联璧合与阴阳鱼](second-lord.md#升变后的珠联璧合与阴阳鱼)。

## 3. 回合开始与回合结束的完整轮次时序

依据[FAQ：更详尽的回合开始和结束时轮次结算](../../assets/docs/规则向FAQ文件.md#更详尽的回合开始和结束时轮次结算)：

- **轮次归属**：每轮开始时视为本轮第一个行动角色的回合内；每轮结束时视为本轮最后一个行动角色的回合内。因此均受“回合内 / 回合外”“每回合限一次”等状态与次数约束。
- **时机区分**：区分“结束阶段”（阶段级）与“回合结束时”（回合级，对应 `rulebook/events/turn.md#回合结束前`），详见[通用约定](general-principles.md#易读描述的时机与然后)。

### 回合开始时顺序

1. 若当前角色为本轮第一个行动的角色，为当前轮数赋值（轮数 +1）；
2. 判断此时是否进入**鏖战状态**（场上没有两名势力相同的角色，且 `N >= 7` 时存活 `<= 4`，或 `N <= 6` 时存活 `<= 3`）；
3. 若此时是本局游戏第一个回合，执行**“游戏开始时”**效果；
4. 若当前角色为本轮第一个行动的角色，执行**“每轮开始时”**效果；
5. 若当前角色处于**叠置**状态：将其变为平置（若其同时为本轮最后一个行动的角色，在此结算**“每轮结束时”**效果），并立即终止本回合（跳过本回合所有剩余时机及“回合结束时”），进入下个回合的“回合开始时”；
6. 若当前角色有暗置的武将牌，其可以明置任意张武将牌（明置后的天然标记与技能结算按第 2 节窗口处理）；
7. 执行**“回合开始时”**效果与技能（如【当先】等）。

### 回合结束时顺序

1. 执行**“回合结束时”**效果与技能（若其中产生“获得额外回合”，则在此时确定即将执行额外回合，从而影响“谁是本轮最后一个行动的角色”的判断，但实际额外回合要等到本回合完全结束后才开始）；
2. 结算【敕令】的“此牌置入弃牌堆的回合结束时”效果；
3. 曾被施加“本回合移出游戏”或“移出游戏直到某时机”效果的**角色**移入游戏（并触发“角色移入游戏后”效果）；
4. 曾被施加“本回合移出游戏”或“移出游戏直到某时机”效果的**牌**（如【破军】扣置牌）移入游戏；
5. 若当前角色为本轮最后一个行动的角色，执行**“每轮结束时”**效果。

## 4. 死亡结算完整时序

依据[FAQ：更详尽的死亡结算流程](../../assets/docs/规则向FAQ文件.md#更详尽的死亡结算流程) 与[第二君主](second-lord.md#升变与继位)：

1. **因死亡调整武将牌状态**（亮出暗置武将牌）→ 若死者为君主，在此窗口依次询问场上其他存活同势力合格主将进行**君主死亡升变接替**（*注：原 FAQ 所列“臣诸葛亮”属未发布臣属内容，仅保留挂钩位置*）；
2. **判定胜利条件** → 若触发终局（场上仅余唯一势力），在正式结束游戏前插入未明置专属野心家的**「暴露野心」与「拉拢人心」**窗口（见[暴露野心与拉拢人心](multi-faction-and-ambition.md#2-暴露野心与拉拢人心)），若拉拢改变势力使胜负不再成立，则游戏继续；
3. **死亡准备**：调整体力值等其他死亡准备工作；
4. **“死亡时”技能**（如【断肠】等）；
5. **死亡后续三步**：
   - `5.1` 死人离场、死亡弃牌；
   - `5.2` 击杀奖惩结算；
   - `5.3` 若死者为君主且未在第 1 步发生继位，执行**君死转野**（同势力其余存活角色变为野心家；*注：原 FAQ 所列“辅臣诏 3”属未实装/后续挂钩点*）；
6. **“死亡后”技能**；
7. **死亡后时机效果**。

## 5. 待主创确认项（审阅清单）

1. **额外回合与“每轮结束时”的精确边界**：若本轮原本最后行动的角色 A 在自己回合末获得额外回合（或令其他角色 B 在本回合后插队执行额外回合），“每轮结束时”是否统一延后到该额外回合结束时再结算，且归属于实际执行完该额外回合的角色回合内？
2. **叠置跳过回合时的“回合结束时”遗留效果**：按第 3 节步骤 5，叠置跳过回合“没有本回合剩余时机和回合结束时”。若在叠置平置前已经存在某些以“该角色回合结束时”为节点的极罕见效果，是否直接随该回合终止而跳过，不进入第 3 节回合结束序列？
3. **“明置武将牌后”窗口的触发边界**：当某名角色通过一个技能同时亮出主、副将，或在同一张牌结算中先后明置两张武将牌时，在当前事件结束后的统一窗口里，是按该角色合并结算一次“双亮天然标记”，还是分别按两次明置记录？另，若在明置后至当前事件结束前该角色死亡或再次暗置，原挂起的【闺秀】与天然标记是否不再触发？
4. **交换武将后的“交换后”窗口**：FAQ 标题为“武将牌明置后/交换后”，正文仅详述“明置武将牌后”。当前已实装技能若涉及“交换后”触发，是否同样遵循“当前结算事件结束后、下个空闲点前按逆时针依次结算”？
