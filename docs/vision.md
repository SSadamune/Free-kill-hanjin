# 项目方向与文档职责

本项目希望建立一套可供人和程序共同依循的《汉晋规则集》，据此将汉晋国战移植到新月杀，并为未来的群聊结算问答提供可引用的规则与实现依据。本仓库当前负责规则编纂和游戏实装；问答 bot 是后续使用这些成果的独立应用，不在本轮建设范围内。

规则编纂以现有《三国杀规则集》为起点，明确汉晋继承、修改和新增的内容，逐步形成自己的术语、流程、机制及武将／卡牌规范描述。规范描述表达精确的游戏语义；玩家卡面描述服务于阅读和操作，程序代码承担引擎实现，三者需要相互对应。

开发采用双向核对：从规则生成实现和自动化测试，用实际结算发现规则遗漏、歧义或实现偏差，再据来源及用户裁定修订。目标是规则与程序一致；代码或测试已存在、已通过，不会自动使某个行为成为规则。

## 三类规则资料与当前基准

- `docs/rules/`：外部参考《三国杀规则集》，保留为外部来源副本；日常具体条文引用转向 `rulebook/` 中的工作底稿。
- `rules/`：项目设计、机制裁定、内容登记及约束规范，记录汉晋差异和未决问题，服务于开发及未来编纂；它与正式规则集是两类文档，不是正式规则集的当前版本。
- `rulebook/`：未来《汉晋规则集》的独立编纂位置。以外部规则集为基础，按汉晋国战的规则修订和补充，采用接近原规则集的组织、格式与文风，形成高度精炼、成体系的规则资料。已复制外部规则作为工作底稿，汉晋专属修订与规范描述仍待逐项编纂。

《汉晋规则集》是未来最终标准。当前按 `rulebook/` 中继承的基础条文与已确认的汉晋项目裁定开发；未来经确认的正式条目逐步成为其覆盖范围内的标准，不能把未完成的目录当作完整替代。项目规范若与正式条目出现冲突，应显式核对并修订，不由代码现状静默决定。

以上是文档角色及编纂阶段的说明，不改变游戏内技能、牌面与通则之间的结算优先关系。

## 为后续问答保留的依据

规则应具有稳定的条款标识或路径、来源与差异说明、明确的确认状态；对应实现和测试可链接追溯。后续问答应区分规则结论、尚待裁定的问题和程序当前行为，发现二者不一致时指出偏差，不能把实现缺陷当成裁定。当前不建设独立知识库或复制一份规则供 bot 使用。
