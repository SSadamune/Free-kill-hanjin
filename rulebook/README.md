## 改编与维护

正式《汉晋规则集》将在此底稿基础上，按汉晋国战规则修订补充，保持接近外部规则集的组织、格式与精炼文风。现有 `rules/` 是[项目设计与裁定规范](../rules/README.md)，提供汉晋改编依据，不是本规则集的另一版本，不能直接搬入作为正式条文。

当前具体规则引用统一指向本目录中的相同文件。尚未改编的基础条文与原参考资料一致，已确认的汉晋差异继续以对应项目规范明确标注；不能把尚未适配的底稿内容当作对汉晋差异的否定。逐项编纂时注明继承、修订或新增依据，并区分草案与已确认内容。代码存在、测试通过不自动构成规则确认。

卡面描述资料、规范描述和引擎实现的职责见[编写指南](../docs/development/normalized-descriptions.md)。程序接口、测试结果、开发进度及故障历史另存于[开发资料](../docs/development/README.md)，不混入正式规则正文。

复制基线沿用原资料的部分 API 链接，其中存在当前仓库没有收录的目标；这些链接不证明新月杀接口存在。引擎 API 仍需核对锁定版本源码。原资料的上游版本与来源信息尚待核实，不补写未经确认的版本或授权结论。

项目整体目标见[愿景说明](../docs/vision.md)，当前编纂及实装完成度见[开发状态](../docs/development/status.md)。
