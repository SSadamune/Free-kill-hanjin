# 起始手牌与手气卡

角色取得起始手牌后，可以使用手气卡重抽起始手牌。每次重抽消耗一次手气卡。

大合集按下列规则确定开局手气卡次数。若本局角色数大于或等于 7，则自 7 号位起，每名角色各获得一次手气卡。房间设置的通用手气卡次数按 0 计算。

自由模式按房间设置确定通用手气卡次数。若「后置位补偿」设为「手气卡」，且本局角色数大于或等于 7，则自 7 号位起，每名角色额外获得一次手气卡。该选项默认设为「无」。

座次补偿的手气卡与高岱技能提供的手气卡分别计算。

依据[《规则向 FAQ》游戏人数相关规则](../../assets/docs/规则向FAQ文件.md#游戏人数相关规则)及[汉晋项目裁定](../../docs/rules/general-principles.md)。
