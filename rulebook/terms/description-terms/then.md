# ▷

连接两个效果的符号，只有执行了“▷”左边最近的一个效果，才能执行“▷”右边的第一个效果。

汉晋易读描述中的“[某角色]可以[动作 A]，然后[动作 B]”遵循同一依赖关系：须实际执行 A 才能执行 B；选择不执行 A 时，不能单独执行 B。B 另有条件时仍须满足其条件。此项依用户于 2026-11-15 确认补充，时机与描述口径见[通用约定](../../../docs/rules/general-principles.md#易读描述的时机与然后)。
