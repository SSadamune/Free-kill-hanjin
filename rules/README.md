# 紫乔汉晋国战规则索引

国战规则以手杀国战为基础。“群狼环鼎”作为可选机制，由模式设置中的同名开关统一控制，默认关闭；关闭时保留普通鏖战，禁用新鏖战、历史事件（含赋礼、不进则退等）及奇珍规则。房主主动开启后启用上述机制；候选势力、独立牌表和汉晋其他既定规则仍按各自规范执行。

本目录是 agent 与开发者共同遵循的规则规范来源。规则变更必须先同步对应文档，提交前核对实现、测试和状态说明一致。

全扩展通用表述约定：凡涉及对牌、武将或技能的操作，未特别说明归属时，均指操作者自己的牌、自己的武将或自己的技能。

未特别说明时，依次询问从当前回合角色开始，按逆时针座次进行。所有升变共用体力收益：按国战规则重算双将组合，若上限较升变前增加，则给现有体力上限加 1 并回复 1 点体力；持平或减少均不调整。

- [1. 势力禁选](faction-ban.md)：房主候选势力/允许上限、服务端校验、禁选与发将/牌堆联动已实现并通过基础与规则测试；正式标准将池与完整牌表已接入。
- [2. 应变](adaptation.md)：五种条件、多条目独立结算、每来源一次忽略、助战竞速及单张杀“无视次数”已实现；条件时点已确认逐项重检，统一快照仅保留为开发对照分支；手牌标记、选牌提示与具体条件触发文案已实现，客户端排版仍待人工验收；全部正式应变牌已登记牌位与条目；标准武将技能仅展示。

- [3. 统领与翼从](commander-retinue.md)：统领能力、无士兵条件、按来源的兵种存续/迁移、白板士兵逐位转换、客户端可用的手动视为技及服务端同势力复核、交换完成接口已实现并通过自动化测试；标准包已登记 19 条统领来源与 14 种翼从。
- [4. 交换武将](general-exchange.md)：明置武将的交换范围、体力上限、随将保留的技能状态与牌堆已实现并通过专测；统领模块已按 `Exchange.addCompletionListener` 接口接入，标准包武将空壳已接入。

所有武将与卡牌均独立创建。上游国战和其他扩展仅作为流程/API及实装参考，不能直接进入汉晋将池或牌堆。

统一版本登记位于 `pkg/hanjin_mode/rules/general_versions.lua`：`Versions.register` 同时登记君主版和野心家效忠版；`Versions.plan` 供选将池使用，`general_pool.lua` 再按本局势力解析。君主版使用显式登记而不是上游按名字识别的 `lordGenerals`。

- [5. 第二君主](second-lord.md)：普通君主升变、死亡继位顺序与合法性、有君仍可超员、转野、明置/势力/技能同步、体力与标记、模式胜负已实现；`tests/second_lord.lua` 覆盖，正式君主武将仍待设计。
