# 紫乔汉晋国战规则索引

国战规则以手杀国战为基础。“群狼环鼎”作为可选机制，由模式设置中的同名开关统一控制，默认关闭；关闭时不启用历史事件（含赋礼、不进则退等）及奇珍规则，房主主动开启后启用这些附加机制。两种设置下，汉晋鏖战均为【桃】只能当【杀】或【闪】使用或打出；候选势力、独立牌表和汉晋其他既定规则仍按各自规范执行。

本目录是 agent 与开发者共同遵循的规则规范来源。规则变更必须先同步对应文档，提交前核对实现、测试和状态说明一致。

`docs/rules/` 下全部文章是技能描述解读与「规范化描述」的基础参考，涵盖术语定义、结算原则、事件流程与专题。技能描述按规则集的逻辑结构理解，须查阅相关原文，不能以自然语言猜测代替正式定义，也不能将已有明确规则列为设计建议。汉晋项目已确认的差异按用户裁定及本目录规范执行并标明差异。

公共规则保留在本目录顶层；具体武将规则统一存于 `generals/`，按武将编号一将一文件，记录结算细节、裁定、测试设计和当前状态，由本文及标准武将表链接。

开发验证遵循[测试分层与验收范围](testing.md)：核心行为本轮验证，公共机制复用已有覆盖，复杂边界按具体风险补测；结算场景不机械转换为逐项测试任务。

测试用“自由选将”允许候选外武将，并忽略势力禁用和国战配对限制；正常合法组合仍保留客将等既有势力解析。入口为右键或长按候选武将，具体例外见[势力禁选规范](faction-ban.md#测试用自由选将例外)，关闭后执行正常规则。

全扩展通用表述约定：凡涉及对牌、武将或技能的操作，未特别说明归属时，均指操作者自己的牌、自己的武将或自己的技能。

“某人的牌”按[规则集定义](../docs/rules/terms/description-terms/limit_card.md)指其手牌区和装备区里的牌，不含判定区及武将牌上／旁等区域中的牌；“某人的区域”是另一个术语，不能与“某人的牌”混用。

“出牌阶段”作为使用／发动时机，是“出牌阶段内的空闲时间点”的缩写。除非另有说明，只有在这些空闲时间点使用的【杀】才受通常出杀次数限制并计入该次数；执行技能／牌等效果时使用的【杀】不涉及这一限制和计次，即使事件发生在出牌阶段内。不能以当前阶段等于出牌阶段代替对使用时机的判断，也不能将此规则归因于强制使用或虚拟牌身份。参见[阶段事件](../docs/rules/events/phase.md)与[一张牌能被使用的条件](../docs/rules/topics/card-usable-conditions.md)。

技能描述须区分发动消耗与后续效果：未特别允许零张时，“交给”默认至少交一张；任一发动消耗无法执行就不能发动，也不能执行其他消耗。“然后”表示按顺序执行后续能执行的效果，不能仅因后续无法执行而否定已可支付的发动消耗。弃置须区分足额消耗、一般效果和技能明文允许的“不足全弃、无牌不弃”，不能一概要求足额或一概允许少付。基础语法参见[弃置](../docs/rules/terms/card-op-terms/discard.md)与[技能的使用事件](../docs/rules/events/use-skill.md)；刘协两技能的具体裁定见[专项规则](generals/han001-liuxie.md)。

通用转换描述见[“X 只能当 Y 使用／打出”](only-as.md)：这是描述语法，不是独立技能；转换操作归属于原技能或规则。不改变实体牌牌名，不妨碍其他转化，多个此类效果提供的用途可并存。公共来源、内部同步、服务端复核及时效管理已实现并加入默认国战测试；正式武将技能仍须各自接入。

[鏖战状态](battle-royal.md)单独规定桃当杀／闪的效果。汉晋独立接管、群狼开关两态、木牛与傲才受限入口及上游房间隔离已实现并加入默认国战测试；可复用傲才尚未挂正式武将，交互仍待人工视觉验收。

未特别说明时，依次询问从当前回合角色开始，按逆时针座次进行。所有升变共用体力收益：按国战规则重算双将组合，若上限较升变前增加，则给现有体力上限加 1 并回复 1 点体力；持平或减少均不调整。
