# 紫乔汉晋国战规则索引

国战规则以手杀国战为基础。“群狼环鼎”作为可选机制，由模式设置中的同名开关统一控制，默认关闭；关闭时不启用历史事件（含赋礼、不进则退等）及奇珍规则，房主主动开启后启用这些附加机制。两种设置下，汉晋鏖战均为【桃】只能当【杀】或【闪】使用或打出；候选势力、独立牌表和汉晋其他既定规则仍按各自规范执行。

本目录是 agent 与开发者共同遵循的规则规范来源。规则变更必须先同步对应文档，提交前核对实现、测试和状态说明一致。

全扩展通用表述约定：凡涉及对牌、武将或技能的操作，未特别说明归属时，均指操作者自己的牌、自己的武将或自己的技能。

通用转换描述见[“X 只能当 Y 使用／打出”](only-as.md)：这是描述语法，不是独立技能；转换操作归属于原技能或规则。不改变实体牌牌名，不妨碍其他转化，多个此类效果提供的用途可并存。公共来源、内部同步、服务端复核及时效管理已实现并加入默认国战测试；正式武将技能仍须各自接入。

[鏖战状态](battle-royal.md)单独规定桃当杀／闪的效果。汉晋独立接管、群狼开关两态、木牛与傲才受限入口及上游房间隔离已实现并加入默认国战测试；可复用傲才尚未挂正式武将，交互仍待人工视觉验收。

未特别说明时，依次询问从当前回合角色开始，按逆时针座次进行。所有升变共用体力收益：按国战规则重算双将组合，若上限较升变前增加，则给现有体力上限加 1 并回复 1 点体力；持平或减少均不调整。

- [1. 势力禁选](faction-ban.md)：房主候选势力/允许上限、服务端校验、禁选与发将/牌堆联动已实现并通过基础与规则测试；正式标准将池与完整牌表已接入。
- [2. 应变](adaptation.md)：五种条件、多条目独立结算、每来源一次忽略、助战竞速及单张杀“无视次数”已实现；条件时点已确认逐项重检，统一快照仅保留为开发对照分支；手牌标记、选牌提示与具体条件触发文案已实现，客户端排版仍待人工验收；全部正式应变牌已登记牌位与条目；标准武将技能仅展示。

- [3. 统领与翼从](commander-retinue.md)：统领能力、无士兵条件、按来源的兵种存续/迁移、白板士兵逐位转换、客户端可用的手动视为技及服务端同势力复核、交换完成接口已实现并通过自动化测试；标准包已登记 19 条统领来源与 14 种翼从。
- [4. 交换武将](general-exchange.md)：明置武将的交换范围、体力上限、随将保留的技能状态与牌堆已实现并通过专测；统领模块已按 `Exchange.addCompletionListener` 接口接入，标准包武将空壳已接入。

所有武将与卡牌均独立创建。上游国战和其他扩展仅作为流程/API及实装参考，不能直接进入汉晋将池或牌堆。

统一版本登记位于 `pkg/hanjin_mode/rules/general_versions.lua`：`Versions.register` 同时登记君主版和野心家效忠版；`Versions.plan` 供选将池使用，`general_pool.lua` 再按本局势力解析。君主版使用显式登记而不是上游按名字识别的 `lordGenerals`。

- [5. 第二君主](second-lord.md)：普通君主升变、死亡继位顺序与合法性、有君仍可超员、转野、明置/势力/技能同步、体力与标记、模式胜负已实现；`tests/second_lord.lua` 覆盖，正式君主武将仍待设计。
- [6. 野心家效忠](wild-allegiance.md)：开局版本替换、准备阶段升变、三个时机条件、多人/多势力检查、拒绝保持原状及统一版本登记已实现；`tests/wild_allegiance.lua` 与 `tests/guest_allegiance.lua` 覆盖，正式野心家武将仍待设计。
- [7. 客将](guest-factions.md)：原有主势力全禁后的客将势力启用、选将界面内逐张自愿重抽及服务端配将复核已实现；`tests/guest_allegiance.lua` 与 `tests/standard_generals.lua` 覆盖，客户端显示与交互仍待人工验收；标准包 51 张武将已登记客将势力。
- [8. 基础牌表](card-deck.md)：列出 162 个基础牌位（含固定 EX）、合纵与国战标记、君主装备替换关系、16 组应变效果及 UI 文本。另表列出七张仅通过特殊手段加入的势力锦囊。完整牌表已接入牌堆构建；按 `pkg/hanjin_cards/data/reuse.lua`，67 个牌型已按确认版本复用或适配新月杀实装，17 个牌型（10 个君主装备相关牌型及 7 个势力锦囊）仍为空壳；临筱玉舆的双坐骑栏交互与效果尚待实现。
- [9. 六势力标准武将包](standard-generals.md)：90 张独立武将、14 种翼从的编号、称号、体力上限、客将势力、珠联璧合、统领与翼从及逐将技能原文已登记；武将与翼从的专属技能仅展示名称和说明。
- [10. 同一张牌的多次结算](card-resolution.md)：多结算采用 OL 规则，仅重复目标流程结束后的使用结算，不重新使用同名牌；同次用牌已确立的使用方法保持不变，【酒】①／②是其中一个示例。现有复用流程符合，默认国战套件已加入专项回归。
- [11. 指定额外目标](extra-targets.md)：默认遵循牌面目标条件；技能明确约束候选条件时按该条件选取，仅约束数量不构成例外。公共适配、借刀独立副目标、群体上下文及专项回归已纳入版本控制；独立审阅和复杂目标集成验收仍待完成。
- [12. 效果指定的用牌目标条件](card-use-targets.md)：使用、视为使用及转化使用均依效果是否明确约束目标条件处理；“其他角色”属于显式目标条件。目标策略及部分入口接线的初步实现已纳入版本控制；审阅发现的执行顺序和复杂目标问题仍待修正，不能标为完整实装。
