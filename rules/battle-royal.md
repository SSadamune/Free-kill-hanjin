# 鏖战状态

适用于汉晋国战；通用转换描述的定义见[“X 只能当 Y 使用／打出”](only-as.md)。

角色进入鏖战状态即获得效果：“【桃】只能当【杀】或【闪】使用或打出”。实体【桃】的牌名仍为【桃】。

凡通过合法途径直接使用／打出非转化实体【桃】，均受此限制，不限于手牌区。通过“傲才”选择牌堆中的实体【桃】，或使用【木牛流马】牌堆中的实体【桃】，也须遵循此规则。相关入口需要允许其按鏖战提供的用途选择【杀】或【闪】，不能仅关闭直接用桃而遗漏转换入口；鏖战本身不额外授予从任意牌区取牌的权限。

以下结果均属于确认的规则：

| 情形 | 结果 |
| --- | --- |
| 需要使用【桃】，直接选择实体【桃】 | 不允许直接按【桃】使用 |
| 用实体【桃】发动鏖战转换 | 可以当【杀】或【闪】使用或打出 |
| 同时有“红桃牌只能当【过河拆桥】使用” | 红桃【桃】可分别当【杀】、【闪】或【过河拆桥】使用；该额外效果不授予打出【过河拆桥】的权限 |
| 用“急救”将实体【桃】当【桃】使用 | 满足急救条件时允许，属于转化用牌 |
| 用本系列“龙胆”将实体【桃】当【酒】使用或打出 | 满足龙胆条件时允许，实体牌仍为【桃】 |

## 进入与模式开关

进入时机沿用锁定国战现有流程：回合开始满足人数及势力条件、房间启用的首次洗牌条件，以及其他效果调用上游进入函数的路径。汉晋规则优先处理常规入口，遇到上游授予普通／新鏖战技能时撤销这些技能并清理本房间残留状态技，安装汉晋来源；重复进入不会重复叠加来源。本文不另行变更鏖战进入时机。

群狼环鼎默认关闭；开关两种设置下桃均只能按鏖战当杀／闪。开启时仍保留历史事件及奇珍等原有附加机制，关闭时不启用这些机制。状态横幅与房间设置帮助文本已同步。普通上游国战房间保留其原有普通／新鏖战行为，不修改全局上游函数或 `.dev/` 依赖。
