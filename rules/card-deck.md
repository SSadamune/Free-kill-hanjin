# 紫乔汉晋国战：基础牌表

规则裁定：用户已确认实体牌位、替换关系、合纵标记、君主装备所属势力及全部 16 组应变效果。牌表和版本登记本身不表示已实装。

## 1. 读取约定（MUST）

- 仅适用于独立模式 `hanjin_heg_mode`；正式卡牌 MUST 独立创建，不得直接导入上游牌堆或用测试内容补齐。
- 第 2 节四张矩阵中，每个非空的花色单元格对应一个基础牌位，唯一键为 `分区/花色/点数`。同名、同花色、同点数但分区不同的牌仍是不同实体牌。
- A/J/Q/K 对应 1/11/12/13；♠/♥/♣/♦ 对应黑桃/红桃/梅花/方块。
- 标准版一、标准版二、势备篇各 52 个牌位，EX 为 6 个牌位，合计 **162 个基础牌位**。EX MUST 纳入基础牌表，不是房主可选扩充包。
- 162 是本表在势力筛选前的牌位数。赤霄剑、虚妄之冕的牌位可因所属势力不在允许集而空缺；有替换牌的牌位仍各占一张。
- 第 5 节的七张势力锦囊均在 162 个基础牌位之外，默认牌堆不加入。
- `特殊装备（替换牌）` 表示依势力规则择一占据同一牌位，MUST NOT 同时加入两张；保留该牌位花色、点数。`（无）` 表示移除时不补牌。
- `·合` 为合纵标记，不是应变条件，也不是额外牌名。`太平要术（惊帆·合）` 中只有替换后的惊帆具有合纵标记。
- `无懈可击·国` 表示国战版本，MUST 与未标 `·国` 的无懈可击区分，不解释为应变或合纵标记。
- `·富甲/残躯/助战/空巢/孤军` 为应变条件；全部对应效果及 UI 文本见第 4 节，不得从上游覆盖或推定不同效果。
- 应变效果按“牌名＋应变条件”复用；同一组合的不同实体牌效果一致。仅在此分组规则中，普通杀、火杀、雷杀、冰杀 MUST 视为不同牌名，不能按引擎 `trueName == slash` 合并。
- 未标应变条件的同名实体牌不自动继承其他实体牌的应变条目；应变 API 及条件时点遵循 [应变规范](adaptation.md)。

### 结算说明（MUST）

- 应变条件满足后，非增减目标的效果强制触发并执行，不再询问是否发动。`目标+1`、`目标-1` 为例外，使用者可以选择是否增减一个合法目标；取消或未实际改变目标不计为触发应变。
- 第 1 组【水淹七军】：先执行弃置装备牌的效果，再执行造成雷电伤害的效果，不能由目标改为二选一或颠倒顺序。
- 第 6 组【逐近弃远】：先拆（弃置目标一张牌），后顺（获得目标一张牌），强制依次执行两项，不再依据距离二选一。例：距离 1、目标只有一张牌，助战成功后 MUST 先弃置该牌；目标因此无牌，后续无法获得牌，不得改为先获得或跳过弃置。
- 第 12 组【闪】：获得的是这张闪所响应的牌，不是闪自身。应变在使用牌时触发；单纯“打出闪”不触发。作为响应而实际“使用闪”时仍按使用牌处理。
- 第 13 组【雷杀】：完整含义为“此牌无视次数，不计入使用次数”，UI 仅显示 `无视次数`。
- 第 15 组【借刀杀人】：所有角色均不能以【无懈可击】响应此牌；目标角色不能使用【杀】响应其效果。MUST 同时覆盖这两个响应层次，不能只禁止其中一个。
- 其他组的 UI 文本也 MUST 保持表内原文；完整语义与程序效果标识不得代替 UI 文本。`摸一张牌` 表示使用者摸一张牌，`伤害+1` 表示此牌造成的伤害增加 1。

禁止把条件名当作效果。正式应变牌 MUST 同时登记条件与效果。此清单中的无懈可击均未标 `·国`，不能与其他四张国战无懈可击混淆。
