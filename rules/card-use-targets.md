# 紫乔汉晋国战：效果指定的用牌目标条件

状态：用户已确认以下规则。三种公共目标策略、现有公共转换／统领／玉玺入口及复杂目标的选择／宣告阶段复核已实现并加入默认回归。后续新增技能仍须按其效果明确传入策略；客户端视觉与真实网络表现另行人工验收。

## 默认条件与显式条件（MUST）

- 效果未另行规定目标条件时，MUST 遵循原牌面的使用目标条件。仅改变牌的来源或生成方式，不自动无视距离等条件。
- 效果直接声明某项例外，例如“无距离限制”，MUST 按声明放宽相应限制；未被该声明改写的条件仍按正常规则处理。
- 效果明确规定对哪些角色使用牌时，MUST 按该效果的目标条件确定候选，不再将原牌面使用目标条件机械叠加。“其他角色”本身就是目标条件，不能因为条件简单就退回原牌面的距离等条件。
- 使用、视为使用、转化使用遵循同一判断原则；不能仅按是否为虚拟牌或转化牌，决定是否忽略目标条件。
- 仅改变目标数量与明确指定目标范围须区分。例如，“多指定至多 X 名角色为目标”仅改变数量；“视为对 X 名其他角色使用……”同时明确了目标为“其他角色”。指定额外目标的对应规则见[指定额外目标](extra-targets.md)。

## 【顺手牵羊】示例

下列两种效果均允许对距离大于 1 的角色使用【顺手牵羊】：

| 效果原文 | 目标条件的处理 |
| --- | --- |
| “你使用【顺手牵羊】（无距离限制）” | 明确取消距离限制，其他未改写条件仍按正常规则处理 |
| “视为对 X 名其他角色使用【顺手牵羊】” | 按效果指定的“其他角色”确定目标，不叠加原牌面的距离 1 条件 |

目标条件被替代不等于已经重新使用一次牌，也不自动改变牌的效果。目标是否实际能被获得牌等结果，仍在结算中依正常流程处理。与其他禁止用牌／禁止指定目标效果的关系不得简单通过跳过全部合法性检查处理。

## 实现约定

调用入口应明确传入“沿用原条件”“仅放宽指定限制”或“使用效果自定目标条件”，而非从是否为转化牌、牌名或目标人数推断。界面候选与服务端提交复核须使用同一规则，显式目标条件须与目标数量分别传递。

实现位于 `pkg/hanjin_mode/rules/card_use_targets.lua`，房间内筛选代理及宣告复核位于 `skills/card_use_targets.lua`。原牌面条件、仅无距离限制和显式条件三种策略与目标数量分别传递；普通上游国战房间不安装汉晋行为。

## 当前实现核对

### 执行入口与次数

- `askToUseCard` 返回已选择并复核的使用数据，由调用者执行一次。
- `selectVirtualCard` 强制上游选择阶段 `skip = true`，附加服务端令牌并复核后返回，完全不执行卡牌。公共转换等需把使用数据交回引擎的入口使用此接口。
- `askToUseVirtualCard` 是选择并执行入口：内部先调用 `selectVirtualCard`，验证成功后执行一次 `room:useCard`。包括调用者传入 `skip` 的情况，它都遵循此执行契约；只需选择时必须调用 `selectVirtualCard`，不得再次执行已使用的返回数据。
- `useVirtualCard`／`useCard` 对已构造的使用数据先附加策略并复核，再执行一次。目标不合法、取消或验证失败时不产生使用、移牌及伤害副作用。

### 选择与宣告的两阶段复核

选择阶段通过实际牌技的 `targetFilter`、`feasible`、固定目标及数量限制检查原始选择，并保存服务端选择快照。宣告阶段在引擎执行牌技 `onUse` 之后检查：

- 群体牌、AOE和固定目标可合法展开，不将展开后的目标数量机械套用选择阶段的数量限制。
- 借刀主目标与 `subTos` 分开复核，副目标须符合相应主目标自己的合法杀目标条件；不同主目标可以分别指定同一副目标。
- 原选择中仍存在的角色按原选择条件复核；合法移除的目标不被重新加回，也不再强制满足原始最小数量。
- 展开或新增的主目标使用对应的额外目标规则与上下文；新增副目标独立校验。联军盛宴保留所选势力，即使代表角色后来改变势力也不能切换群体。

两阶段均保留同次请求的距离、次数、固定目标等参数，以及独立的禁止用牌／禁止指定检查。策略令牌与使用者、牌名、请求及原始选择绑定，伪造令牌不能借用或删除其他使用的授权；取消、完成或后续清理时释放授权，嵌套候选查询与异常不残留策略栈。

### 验证与接入边界

`tests/card_use_targets.lua` 与 `tests/extra_targets.lua` 已覆盖默认／无距离／显式策略、两类顺手牵羊的远距离及无牌目标、数量与条件的区别、固定／群体／AOE展开、借刀主副目标、令牌请求绑定、取消及失败无副作用、普通上游房间隔离。

真实入口回归还包括原技能归属的转换、统领目标不合法时不支付移将代价，以及玉玺 `EventPhaseStart → cost → on_use → 知己知彼 → 查看确认` 的完整流程，检查实际使用及完成事件各一次。内部助手测试不代替这些整链断言。

本规范不自动为未来技能或任意第三方用牌入口赋予目标策略。新入口须显式接入并补充相应牌的复杂目标回归；人工客户端视觉、联网与重连验收仍待完成。
