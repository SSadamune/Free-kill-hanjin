# 紫乔汉晋国战：效果指定的用牌目标条件

规则裁定：用户已确认以下目标条件规则。

## 默认条件与显式条件（MUST）

- 效果未另行规定目标条件时，MUST 遵循原牌面的使用目标条件。仅改变牌的来源或生成方式，不自动无视距离等条件。
- 效果直接声明某项例外，例如“无距离限制”，MUST 按声明放宽相应限制；未被该声明改写的条件仍按正常规则处理。
- 效果明确规定对哪些角色使用牌时，MUST 按该效果的目标条件确定候选，不再将原牌面使用目标条件机械叠加。“其他角色”本身就是目标条件，不能因为条件简单就退回原牌面的距离等条件。
- 使用、视为使用、转化使用遵循同一判断原则；不能仅按是否为虚拟牌或转化牌，决定是否忽略目标条件。
- 仅改变目标数量与明确指定目标范围须区分。例如，“多指定至多 X 名角色为目标”仅改变数量；“视为对 X 名其他角色使用……”同时明确了目标为“其他角色”。指定额外目标的对应规则见[指定额外目标](extra-targets.md)。

## 【顺手牵羊】示例

下列两种效果均允许对距离大于 1 的角色使用【顺手牵羊】：

| 效果原文 | 目标条件的处理 |
| --- | --- |
| “你使用【顺手牵羊】（无距离限制）” | 明确取消距离限制，其他未改写条件仍按正常规则处理 |
| “视为对 X 名其他角色使用【顺手牵羊】” | 按效果指定的“其他角色”确定目标，不叠加原牌面的距离 1 条件 |

目标条件被替代不等于已经重新使用一次牌，也不自动改变牌的效果。目标是否实际能被获得牌等结果，仍在结算中依正常流程处理。与其他禁止用牌／禁止指定目标效果的关系不得简单通过跳过全部合法性检查处理。
