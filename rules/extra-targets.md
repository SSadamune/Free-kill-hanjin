# 紫乔汉晋国战：指定额外目标

规则裁定：用户已确认以下额外目标规则。

## 1. 默认范围与例外（MUST）

效果让角色使用、视为使用或转化使用牌时，也按效果是否明确规定目标条件处理，通用规则及【顺手牵羊】示例见[效果指定的用牌目标条件](card-use-targets.md)。

- 如无特别说明，额外目标 MUST 符合原牌面的目标条件，包括距离、势力、区域内有牌等条件；不能因为效果允许“多指定目标”，就自动忽略这些条件。
- 候选范围 MUST 按本次使用方法、已选群体等上下文和当前目标列表动态计算。某牌正常情况下因“已指定所有合法目标”而没有额外目标，不等于该牌永久禁止增加目标；若其他效果已移除合法目标，该角色仍满足本次牌面目标条件且未在当前目标列表中，就可以重新作为额外目标。
- 第 2 节逐牌清单用于说明通常场景及组织测试，MUST NOT 在公共实现中按牌名硬编码“可／不可增加目标”清单。应复用牌面目标条件与本次使用上下文；牌自身确有特殊语义时，由对应目标规则表达。
- 延时锦囊牌、装备牌不能指定额外目标。【闪】、【无懈可击】以牌为目标，不能增加角色目标。
- “如无特别说明”指提供额外目标的技能效果未另行约束额外目标的条件。若技能明确规定候选条件，例如“你使用【XX】可以多指定一名距离 1 的角色为目标”，则按该条件决定额外目标范围，不再受该牌原有牌面目标条件约束。不能将原牌条件与新条件机械叠加。
- **数量限制不等于条件限制。** “多指定至多 X 名角色为目标（X 为……）”仅改变数量，候选角色仍须满足原牌面的目标条件。不能将所有增目标效果都解释成自定义候选范围。
- 【桃】、【酒】、【洞烛先机】、【无中生有】沿用简雍时代的特殊结算，允许增加其他角色为目标，不能以原本目标为“你”为由拒绝。
- 增加目标不等于重新使用一张牌；使用结算及多结算规则见 [同一张牌的多次结算](card-resolution.md)。【酒】增加目标后，仍须保持本次已确立的使用方法。

## 2. 逐牌约束（默认无特别说明时）

| 牌 | 额外目标约束 |
| --- | --- |
| 杀 | 可以增加符合目标条件的角色；不能忽略攻击距离限制。 |
| 顺手牵羊 | 可以增加符合目标条件的角色；不能忽略距离限制。 |
| 决斗 | 可以增加目标，各目标依次结算。 |
| 借刀杀人 | 可以增加有武器牌且符合目标条件的角色；每个新增目标 MUST 单独选择其需使用【杀】的目标，不能自动继承原目标对应的杀目标。 |
| 以逸待劳 | 通常无额外目标：已指定所有与你势力相同的合法角色；若其中合法目标被移除，可重新增加。 |
| 远交近攻 | 可以增加符合目标条件的角色，不能增加与使用者势力相同的角色。 |
| 水淹七军 | 可以增加符合目标条件的角色，不能增加装备区没有牌的角色。 |
| 火烧连营 | 通常无额外目标：已指定下家队列的所有合法角色；合法目标被移除后可重新增加。 |
| 勠力同心 | 通常无额外目标：已指定所选的所有大势力或所有小势力角色；被移除且仍符合本次所选类别的角色可重新增加，不能加入另一类角色。 |
| 联军盛宴 | 通常无额外目标：已指定所选范围内的所有合法角色；被移除且仍符合本次所选范围的角色可重新增加，不能改选其他势力。 |
| 挟天子 | 通常无额外目标：“你”已在目标列表中；使用者被移除且仍合法时可重新增加，不能据此增加其他角色。 |
| 闪、无懈可击 | 不可增加角色目标；目标为牌。 |
| 桃、酒、洞烛先机、无中生有 | 允许增加其他角色为目标，按对应效果结算。 |
| 延时锦囊牌、装备牌 | 无法指定额外目标。 |

本表中的默认候选范围与第 1 节的显式条件例外须一起理解；仅约束数量的技能仍适用本表的默认条件。
