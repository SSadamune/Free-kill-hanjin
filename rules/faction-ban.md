# 紫乔汉晋国战：势力禁选规范

状态：禁选框架已实现。正式武将、卡牌及装备效果尚未设计实装；卡牌对应表是牌堆策略登记，不代表已创建这些卡牌。

本文是后续 agent 实现、审查和测试的规则依据。`MUST` 表示必须满足；不得使用其他国战版本的规则替代本文。

## 1. 内容边界与术语

1. 模式代码名为 `hanjin_heg_mode`，显示名为“紫乔汉晋国战”。基础引擎为 FreeKill v0.5.25，上游依赖由 `dependencies.lock.json` 固定。
2. 所有可选武将、可摸实体卡牌 MUST 独立创建于汉晋内容包，使用汉晋独立标识。不得把上游国战或身份局的武将、卡牌直接加入本模式。
3. 上游仅作为规则流程、接口及实现参考。复用其房间、双将明暗、事件、请求和展示框架不表示复用上游游戏内容。
4. `anjiang` 等引擎暗将占位符是显示/流程基础设施，不是加入将池的正式武将。后续士兵、翼从等正式内容仍须独立创建。
5. 常规势力集合为 `wei / shu / wu / qun / han / jin`，对应魏/蜀/吴/群/汉/晋。野心家专属武将的 `kingdom = "wild"`，不占常规势力名额。
6. 当前阶段，多势力武将的每个所属势力都视为“主势力”。引擎字段 `kingdom` 和 `subkingdom` MUST 同等参与禁选判断；“主势力”不是只指 `kingdom` 字段。未来新机制引入后再修订本条。
7. 用户提供的是实体桌游规则；程序可省略无意义的桌面操作。本次“重摸”实现为发牌前排除，不提供发牌后的重摸按钮。

## 2. BAN-001：本局允许势力

### 输入

- `general_pile`：本局已经通过模式白名单、禁将及同名替换规则筛选的武将牌堆。
- `K`：该牌堆所有非野心家武将涉及的常规势力去重集合，同时统计 `kingdom` 和 `subkingdom`。
- 上一局记录：胜利常规势力集合 `W`、被禁势力集合 `P`；首次开局没有此记录。

### 结果与约束

1. 时机 MUST 在分发任何武将牌之前。
2. 当 `|K| <= 4` 时，允许势力为 `K`，禁选集合为空。即使上一局有胜利势力，也不额外禁选。这一点已由用户明确确认。
3. 当 `|K| > 4` 时，选出禁选集合 `B`，使 `|K - B| = 4`。
4. 对当前仍在 `K` 中的上一局胜利势力，MUST 有 `W ∩ K ⊆ B`。
5. 上一局被禁势力，本局 MUST 不被禁，即 `P ∩ B = ∅`。
6. 先满足必禁、必留约束，再使用房间随机数发生器从剩余候选势力中无放回补足 `B`。不得使用全进程共享随机结果代替房间随机数。
7. 上局记录指向本局不存在的势力时，不为该势力保留名额。
8. 如果记录相互矛盾，或必留/必禁约束不足以合法保留四势力，MUST 明确拒绝继续初始化，不得偷偷忽略约束。
9. 禁选结果一经确定，本局保持不变；不得在后续取将时重新随机势力。

## 3. BAN-002：武将筛选和选将

1. 非野心家武将仅在其所有所属常规势力均被禁选时排除。
2. 例如魏/蜀双势力武将：魏被禁、蜀未被禁时 MUST 保留，但只能选择蜀势力。
3. 排除的武将 MUST 同时加入本局 `disabled_generals`，避免同名替换和后续随机取将把它们重新引入。
4. 将牌分发 MUST 无重复；每位玩家保留至少一组合法主副将。野心家专属武将只能作主将，不能作副将。
5. 选将回复 MUST 在服务器端验证：属于该玩家获分发的武将或合法同名替换、未被禁、主副将不重复、存在允许的共同势力。
6. 多势力组合按双方势力交集再与本局允许集合求交；不得因为交集中另一项被禁就清空仍合法的势力。
7. 超时、取消、格式错误、越界武将、重复武将或无效势力回复 MUST 回退到该玩家获发的合法组合；无效势力不能被写入角色初始标记。
8. 未被选择的将牌只放回一次。最终选中的牌（含合法同名替换所消耗的原牌）不得同时留在公共将池。
9. 将池无法支持所有玩家合法双将时，MUST 报告初始化失败，不得借用上游武将补齐。

## 4. BAN-003：野心家专属武将数量

- 房间选项键：`hanjin_wild_count`，默认 `4`；由房主设置非负整数。
- 此选项直接替代实体规则中“若将池不大”的判断，不设置隐含将池大小阈值。
- 设定值 `N` 表示本局随机保留至多 `N` 张野心家专属武将。少于 `N` 张时全部保留；设为 `0` 时全部排除。
- 筛选发生在发将前，使用房间随机数进行无放回抽样；未保留的专属武将亦加入 `disabled_generals`。
- 本条不针对游戏过程中因人数规则变为野心家的普通武将，也不限制野心家玩家人数。

## 5. BAN-004：君主装备与势力锦囊

### 已确认的装备登记

| 势力 | 独立君主装备 | 普通替代装备 | 程序登记名 |
| --- | --- | --- | --- |
| 魏 | 六龙骖驾 | 爪黄飞电 | `hanjin__liulongcanjia` → `hanjin__zhuahuangfeidian` |
| 蜀 | 飞龙夺凤 | 雌雄双股剑 | `hanjin__dragon_phoenix` → `hanjin__double_swords` |
| 吴 | 定澜夜明珠 | 吴六剑 | `hanjin__luminous_pearl` → `hanjin__six_swords` |
| 群 | 太平要术 | 惊帆 | `hanjin__peace_spell` → `hanjin__jingfan` |
| 汉 | 赤霄剑 | 无：直接额外加入 | `hanjin__chixiao_sword` |
| 晋 | 临筱玉舆 | 绝影 | `hanjin__linxiao_yuyu` → `hanjin__jueying` |

魏蜀吴群按用户确认保持原对应关系；晋不采用上游戢鳞潜翼。上表的独立标识不创建任何上游卡牌副本。

临筱玉舆的设计要求是“进攻与防御双副类别坐骑，类似六龙骖驾”。登记保存两个副类别；引擎当前仅有单一 `sub_type` 字段，因此后续正式卡牌实现 MUST 显式处理两个坐骑栏位及相关距离/装备交互，不能只写数组便声称完成了装备效果。具体效果、花色、点数由后续卡牌设计确定。

### 牌堆构建

1. 输入牌堆 MUST 仅来自允许的独立汉晋卡牌包。
2. 本局允许某装备所属势力时，该君主装备使用其对应普通装备的牌堆位置；普通装备仅移出匹配的那一张，不得按牌名批量删除所有同名牌。
3. 匹配位置以登记的替代牌名、相同花色和点数确定。后续成套牌堆定义 MUST 保持配对牌位一致。
4. 该势力被禁时，君主装备移入本局游戏外区；恢复对应普通装备。保留原牌位花色与点数，不改变其他牌。
5. 已存在对应普通实体牌时 MUST 复用，不能重复加入。自定义牌堆缺少对应实体副本但已定义该独立普通牌类型时，可用 `Room:printCard` 创建房间内替代副本；普通牌类型本身未定义时不得用上游同名牌兜底。
6. 赤霄剑没有替代关系：汉允许时直接加入，汉被禁时移出且不生成替代牌。
7. 势力锦囊按显式登记归属筛选：所属势力被禁就移出摸牌堆，不默认补入其他锦囊。
8. 魏/蜀/吴/群的既有参考锦囊登记为独立的号令天下/克复中原/固国安邦/文和乱武；汉、晋新势力锦囊设计完成后通过 `registerTrick` 添加。
9. 当前仅完成禁选/替换策略和登记接口；正式卡牌效果、实体牌清单、花色点数及美术未实现。本规范不授权自行编造效果或把无效果测试牌发布为正式卡牌。

## 6. BAN-005：同房间上一局记录

1. 使用引擎 `Room:getSessionData()` / `Room:setSessionData()` 保存到原生房间对象；禁止按进程全局变量、全服最近一局或用户账号共享记录。
2. 命名空间键为 `hanjin_faction_ban_v1`，结构为：

```lua
{ version = 1, winners = { "wei" }, banned = { "han", "jin" } }
```

3. 不得覆盖 SessionData 内其他扩展的字段。
4. 正常 `fk.GameFinished` 时，从胜利角色的实际常规势力去重得到 `winners`，并保存本局 `banned`。野心家胜利不伪装成某个常规势力；平局的 `winners` 为空。
5. 下一局开始筛选时读取并消费上一局记录；如果这局初始化失败或被异常中断，旧记录不得再次冒充“上一局结果”。
6. 同一房间改玩其他模式时，在 `fk.GamePrepared` 清除汉晋历史字段，避免隔局误用。
7. 原生房间关闭时记录随之销毁；新房间即使复用了数字房间号，也不得继承旧记录。游戏进程重启后不保留。
8. 不使用 `getSessionId()` 推断跨局间隔：核对的 Qt 引擎同版本源码虽公开该接口，但未发现实际递增实现。本规则依赖房间 SessionData 生命周期及事件。

## 8. 自动化验收

执行 `python scripts/test.py`。默认套件包括上游流程回归、纯规则测试及独立汉晋场景。

- 六势力禁二、五势力禁一、四势力及更少不禁；上一局约束正确、矛盾记录不静默降级。
- 双势力任一势力允许就保留；初始势力必须属于合法交集。
- 野心家默认四名、设为零、数量少于上限；从公共将池与已选武将合计检查上限。
- 经真实 `Request` 的取消/超时默认回复与非法回复均能得到合法双将。
- 连续两局中，上局胜利势力被禁、上局被禁势力保留；改模式清除历史，不同房间隔离。
- 君主装备成对替换、赤霄剑只增删、临筱玉舆与绝影互换、势力锦囊禁用。
- 汉晋场景中的每张实体卡与每名可选武将都来自独立汉晋包，原版内容被白名单排除。

测试数据位于 `tests/support/hanjin_content.lua`，仅在测试进程中登记独立无效果对象；不被 `init.lua` 引用、不进入发布同步内容，也不代表首批正式武将或卡牌设计。上游回归测试单独使用参考内容，不作为汉晋游戏内容。

本轮未人工验收界面、联网和断线重连；装备具体效果及双坐骑栏位交互属于后续正式卡牌实现验收。
