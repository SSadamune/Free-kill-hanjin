# HAN001 刘协：天命、密诏结算裁定草案

规则裁定：六项审阅问题已明确；其余明确标为建议或待审阅的内容仍待裁定，不因已有代码或测试而自动确认。本文是结算裁定草案，尚不是全部技能的定稿规范描述。

## 1. 基础约定

- 正式武将资料见[标准武将包](../standard-generals.md)：HAN001 刘协，汉势力，客将势力为群、魏。技能属于刘协所在武将牌，不因为配在主将或副将而改变效果；均不是主将技、副将技、锁定技。
- 下文 A 为发动密诏的角色，B 为收牌者兼拼点发起者，C 为 A 随后选择的拼点对象。“你”指技能当前持有者，不硬编码武将姓名。
- “某人的牌”是规则术语，指其手牌区和装备区里的牌；不是按自然语言推测牌的归属。依据[规则集：限定角色的牌](../../rulebook/terms/description-terms/limit_card.md)，密诏可以交自己的手牌和装备区里的牌，不包括判定区、处理区及私人牌堆中的牌。
- 明暗置、技能无效、技能获得／失去、武将移除／替换遵循国战公共流程；暗将发动时应明置实际提供技能的武将牌，不能明置另一张无关武将牌来取得发动资格。武将交换后不能让原持有者继续凭旧技能来源发动。
- 天命与密诏都没有敌友限制；不能将“不同势力数”误读成密诏只能选择不同势力的角色。
- 本文不引入身份模式刘协的其他效果，尤其天命没有“体力值最多者也可发动”的附加结算，密诏也不是必须交出全部手牌。

## 2. 天命

> 当你成为【杀】的目标后，你可以弃置两张手牌（不足则全弃，无牌则不弃），摸两张牌。

### 2.1 触发与选择

1. 时机为技能持有者成为【杀】的目标后，发生在该目标的【杀】效果结算及要求出【闪】之前。不是受到伤害后，也不是使用者指定目标时。
2. 按【杀】的真实牌名类别识别，包含普通【杀】、火【杀】、雷【杀】及依法转化／视为使用的【杀】；不能仅匹配普通杀内部名称。
3. 无每回合或每阶段次数限制。每次合法的成为目标事件提供一次选择，不因目标列表中有其他角色而额外发动。
4. 可以拒绝发动；拒绝后不弃牌、不摸牌。没有手牌仍可选择发动。
5. 不取消【杀】、不将目标移除，也不自动抵消伤害。天命结算结束后，原【杀】继续按当前状态结算；新摸的手牌可以用于随后正常响应。
6. 成为目标前已被取消目标的，不产生这次发动机会；天命结算后原【杀】被其他效果取消或无效，不回滚已经弃牌、摸牌的结果。
7. 同一张牌仅增加使用结算次数时，不重新产生“成为目标后”事件，不能因此再发动天命，见[多次结算](../card-resolution.md)。若其他效果实际重新使用一张【杀】，按新的目标事件处理。

### 2.2 弃牌与摸牌

用户已依据[牌状态改变事件：因发动暗置武将牌的技能而明置](../../rulebook/events/change-state.md)确认：发动时选择技能目标（若有），同时确定消耗的全部细节，包括本次要弃置的具体牌；随后明置提供天命的刘协武将牌、确定势力，再按已确定的细节执行弃牌，最后摸牌。明置之后不能重新选择消耗；“明置后”时机仍依公共流程延后产生，不能为修复弃牌顺序而提前触发。

1. **已确认：** 在发动时确认消耗细节，根据当时可以弃置的手牌数 K，确定应弃张数 `D = min(2, K)` 并选定具体牌。K≥2 弃两张，K=1 弃尽唯一可弃手牌，K=0 不执行弃牌移动，仍可发动并摸两张。
2. 只从可弃置的手牌中选择，不能选择禁弃手牌，也不能拿装备牌、判定牌或私人牌堆补足。K≥2 时由发动者选择两张，不能主动少弃或多弃。
3. “不足则全弃，无牌则不弃”明确允许不足额或零张弃置；不能因存在禁弃手牌而拒绝发动。例如三张手牌仅一张可弃时弃这一张，其余两张保留；全部手牌禁弃时不弃，仍摸两张。此为本技能明确文本的处理，不能推导成其他技能的弃牌消耗一概可少付。通用弃置语法参见[弃置](../../rulebook/terms/card-op-terms/discard.md)。
4. 先一次弃置所选手牌，正常处理该次弃牌及牌移动触发，再摸两张；不能先摸后弃，不能将整个过程简化成手牌净增减。
5. 摸牌数固定为两张，不随实际弃牌数变化；正常的摸牌替代／禁止及牌堆处理仍适用。
6. 结算中若弃牌引发其他效果，之后应使用当时状态继续处理；若发动者已经死亡，不再对死者执行后续摸牌。此为本草案的中途结算建议，需与公共死亡流程核对。

## 3. 密诏

> 出牌阶段限一次，你可以将至少X张牌交给一名其他角色（X为与你不同的势力数），然后令其与另一名由你选择的其他角色拼点：赢的角色视为对没赢的角色使用一张【杀】。

### 3.1 发动、限次与势力数

1. 只能在自己的出牌阶段内的空闲时间点主动发动；技能文本的“出牌阶段”是该时机的缩写，不能在此阶段中的其他事件结算内任意发动。每个出牌阶段至多一次；不是每回合一次。额外出牌阶段单独计次。取消发动选择不计次；交牌消耗执行完毕即已发动并计次，后续未能拼点／未产生【杀】不返还次数。交牌消耗不能执行时不能发动，不能先记次、执行其他消耗或开始后续效果。
2. 收牌者 B 为一名存活的其他角色，B≠A；不受距离、势力、敌友及是否有装备的限制。
3. **X 的统计口径已确认。** 在发动合法性确定时，按场上存活角色已确定的实际势力统计，与 A 当前势力不同的势力各计一次。同势力有多人只计一次；每名野心家视为独立势力；全暗置且势力未确定者不计，不能把 `unknown` 算成一个势力，也不能读取暗将秘密信息补算。
4. X 不取房主候选势力数、不取本局允许势力数、不取不同势力的角色人数，也不取武将牌上印刷势力和客将势力的并集。刘协以客将身份入局、改变势力或转为野心家时，使用角色当前实际势力。
5. 建议先完成因发动暗将技能引起的明置／势力确定，再确定本次 X。选择期间若势力或牌权变化，应在交牌前复核；进入交牌结算后锁定本次 X，后续势力变化不要求追加或退回牌。
6. **最低交牌数已确认：`max(1, X)`。** “交给”这一动作默认至少交一张，因此 X=0 时仍须交至少一张；这是基础描述语法，不是额外添加的技能限制。A 可交满足下限的任意张数，不强制交出全部手牌；没有足够可交牌时不能发动。

### 3.2 交牌

1. 可交 A 当前手牌区及装备区中可以交出的牌，可混合选择；不包括判定牌及私人牌堆。这是“自己的牌”的既定术语范围。交牌不是弃置，单纯“禁止弃置”的牌不因此禁止交出；若另有效果禁止移动／交出，则遵循该限制。
2. **交牌属于发动消耗，已确认。** 所选牌作为一次交牌移动交入 B 的手牌区。原本为装备的牌也先进入 B 手牌，不自动装备。按实际移动正常触发失牌、得到牌、失去装备等效果。消耗与后续效果须分开，消耗不能执行则不能发动；参见[技能的使用事件](../../rulebook/events/use-skill.md)。
3. 完整处理这次交牌及其连锁效果后，再选择拼点对象 C。不把“交牌＋拼点＋出杀”合并为不能插入结算的原子操作。
4. B 原本无手牌不妨碍收牌；收牌后能否拼点，按此时实际状态判断。不能要求 B 在收牌前就有手牌。
5. **“然后”的处理已确认。** 先完成合法交牌消耗，再依当时状态执行后续拼点；没有合法拼点对象就结束，已交的牌不收回、次数不返还。不要求发动前就保证有合法 C 或为 C 保留拼点牌。后续效果不能执行，不反过来否定已能执行的交牌消耗。
6. 提交前复核交牌消耗确实可以执行，不能以“后续尽可能执行”为由允许少交。交牌已经合法执行后，得到牌／失牌等连锁效果再次移动这些牌，不回滚、不追加交牌，后续按实际状态处理。涉及替代交牌动作、导致消耗本身是否成立的特殊效果，需核对该效果的具体规则，不能统一视为支付成功。

### 3.3 选择第三人及拼点

1. C 为 A 选择的一名存活角色，C≠A 且 C≠B。“另一名……其他角色”据此解释为第三名角色；A 不参与这次拼点。
2. C 的选择不受距离、势力及敌友限制，但必须满足 B 对 C 的合法拼点条件。通常双方均需有手牌，且不存在禁止 B 对 C 拼点的效果；特殊拼点权限依其对应规则处理，不能为密诏一概忽略空手限制。
3. A 选择 C，B 与 C 分别选择自己的拼点牌；A 无权替 B 或 C 选牌。B 可以使用刚得到的手牌拼点，也可以选自己原有手牌。
4. 有合法 C 时，“令其”是后续强制流程，建议不得通过取消选择来只拿交牌收益；无合法 C 时跳过后续，不虚构拼点结果。
5. 拼点发起者为 B，对象为 C，原因记录为密诏。按正常拼点流程处理选牌、展示、点数修改、胜负确认、拼点后效果和牌的去向。
6. B 点数大于 C，B 赢、C 没赢；小于则 C 赢、B 没赢；相等时双方均没赢，没有赢家，密诏不产生【杀】。不能将“B 没赢”直接当作“C 赢”。
7. 使用最终确认的拼点结果，不能只比较实体牌原始点数。拼点牌默认按公共流程处理，技能本身不让赢家获得拼点牌。
8. 后续用牌前再次检查参与者是否仍存活及能否使用／被指定。拼点完成后的牌移动或其他技能造成角色死亡，不得对死者继续使用【杀】。
9. 建议 A 在交牌后死亡时不再要求死者选择 C；如已完成 C 的选择且拼点已经开始，按已经建立的拼点及后续效果继续处理，不因 A 失去技能或离场而随意回滚。具体事件中断点须在实装时与引擎公共流程核对。

### 3.4 赢家视为使用【杀】

1. 有唯一赢家 W 时，W 为【杀】使用者，另一名拼点角色 L 为目标，A 只是技能发动者，不是此【杀】的使用者或默认伤害来源。
2. 视为使用一张普通、无实体子牌的【杀】，不消耗赢家的实体【杀】，不拿拼点牌充当子牌，也不继承拼点牌的花色、点数、属性或应变条目。
3. “视为……使用”不是“可以……使用”，具备合法条件时应直接执行，不询问赢家是否愿意、不要求交出实体牌。不因赢家空手而失败。
4. “对没赢的角色”已经明确指定用牌目标，按[效果指定的用牌目标条件](../card-use-targets.md)处理：不机械叠加普通【杀】的攻击距离条件；禁止使用、禁止指定等独立限制仍需核对，不能跳过全部合法性检查。仅因双方距离超出攻击范围，不应取消此【杀】。
5. **次数按既定规则处理：** 除非另有说明，只有在出牌阶段内的空闲时间点使用的【杀】才受该阶段通常使用次数限制并计入该次数。密诏的【杀】在技能效果结算中使用，即使此时处于某个出牌阶段内，也不是空闲时间点的使用，因而不涉及通常次数限制，也不计入通常次数；不是因为强制使用、虚拟牌身份或指定了目标而获得特殊权限。依据[阶段事件](../../rulebook/events/phase.md)及[一张牌能被使用的条件](../../rulebook/topics/card-usable-conditions.md)。独立的禁止使用／禁止指定效果仍正常适用。
6. 按完整用牌流程处理宣告、目标事件、响应、防具、伤害及使用结束；目标可以正常出【闪】，符合条件的技能可触发。禁止用牌／禁止指定导致不能执行时，跳过此【杀】，不改成直接伤害、不换目标、不返还密诏次数。
7. 密诏的此次效果只令赢家使用一张【杀】，不重复执行。

## 4. 已确认裁定与其余审阅问题

| Q1（已确认） | 不同势力数的统计口径 | 存活、已确定的实际势力去重并排除自身；未知不计，各野心家独立计数。暗将发动与明置的具体接线顺序仍按第 3.1 节建议核对 |
