# JIN001 司马炎：垂统、兴图结算约定

本文依据用户给定卡面描述、已确认的装备移动裁定及现有项目公共规则整理，用于实现；不宣称已完成《汉晋规则集》的正式规范描述。

## 基础资料与来源

司马炎为晋势力，武将编号 JIN001，技能属于司马炎所在的主将或副将牌，均不是主将技、副将技或锁定技。原卡面资料见[标准武将表](../standard-generals.md)。发动暗将技能须明置实际提供技能的武将牌，不能以明置另一张牌代替；技能无效或失去时按公共来源流程处理。

## 垂统

> 当其他角色进入濒死时，你可以将其装备区的一张牌移动给你。

1. 在其他角色进入濒死时提供一次发动机会；排除自己，不以敌友或势力关系筛选。不是每次求桃询问一次，也不是角色死亡后发动。时机依据见[濒死事件](../../rulebook/events/dying.md)。
2. 由发动者选择该濒死角色装备区中的一张合法装备牌，移入发动者空置的对应装备栏，遵循[装备移动通则](../equipment-movement.md)。不能移入手牌，不能替换已有装备；没有合法可移动牌时不发动，取消不移动。
3. 移动前复核牌仍在该角色装备区、目标栏仍合法；按正常移牌处理失去与得到装备的相关结算。此移动本身不回复体力、不结束濒死流程；其他连锁效果及濒死流程照常继续。

## 兴图

> 每回合结束时，若本回合有应变牌被使用过，你可以选择一项：1.将一张装备牌当【桃】对一名角色使用；2.摸一张牌。

1. 每名角色的回合结束时检查，包括自己的回合；不是结束阶段开始时。额外回合按各自回合独立检查。
2. 本回合任意角色实际使用过至少一张应变牌即满足条件；不要求是司马炎使用，不要求成功触发应变。多张只提供本次回合结束的一个发动机会。应变牌身份按[应变定义](../adaptation.md)及汉晋应变 API 判断，包含依法明确赋予条目的虚拟／转化牌或本次使用，不能仅依据实体牌标记或 `Triggered` 成功事件。
3. 回合内尚未明置司马炎或后来才获得技能，不抹去该回合已经发生的用牌事实；回合结束时能否发动仍按当时技能来源与有效性判断。只选择而未实际使用、纯打出牌，不计入本条件；不能把上一回合的记录带到本回合。
4. 第一项使用发动者自己手牌区或装备区中的一张装备牌作转化素材，不包括判定区、其他角色的装备或未获授权的私人牌堆。依据[自己的牌](../../rulebook/terms/description-terms/limit_card.md)。这是当桃使用，不是弃置；材料不能仅因禁止弃置而排除。
5. 桃的目标为技能明确指定的一名角色，可为自己或其他角色，按[效果指定的用牌目标条件](../card-use-targets.md)接入；独立禁止使用、禁止指定等限制仍生效，不能擅自改成只能对自己使用。执行一次完整用牌流程，不简化成直接回复体力，也不重复使用。
6. 第二项摸一张牌，不要求拥有装备牌；没有合法第一项时仍可选摸牌。选项合法性按[选择](../../rulebook/terms/description-terms/choose.md)复核；发动为可选，可以放弃。鏖战等其他公共效果仍按其规则处理。

实现与验证结果由开发资料记录；规则约定与实现完成度分别维护。
