# QUN001 华佗：济世与客将替换

卡面来源见[标准武将表](../standard-generals.md)。以下为 2026-11-15 用户确认，不修改外部 JSON 中的方括号原文。

- 济世可将自己的红色牌当【桃】对濒死角色使用，牌的范围依[通用约定](../general-principles.md)，不限手牌；没有“回合外”限制。仍须遵守禁止使用【桃】等规则。
- 方括号中的交换段受房间“客将替换”设置控制。该设置尚未实装，目前默认开启，因此须采用交换效果；不能因为设置缺失而关闭这段效果。
- 此濒死结算结束后，若提供济世的华佗武将牌为客将，与济世发动者势力不同的角色依次选择是否用一张武将牌交换此华佗。客将指资料身份，不要求本局已经启用客将势力，见[通用约定](../general-principles.md#配将体力贡献与武将状态)。
- 此效果明确优先于[普通交换](../general-exchange.md)的同势力限制；不据此放宽明置位置、君主／专属野心家等其他限制。
- 首次成功交换后结束本次询问，不继续询问后续角色去交换已经转移的华佗。询问顺序依[通用约定](../general-principles.md)。

规则已确认不表示已实装。接口方向及当前差异见[群包审阅](../../docs/development/implementation/generals/qun-standard.md)。
